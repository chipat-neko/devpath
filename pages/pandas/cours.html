pandas : analyser des données avec Python

pandas est la bibliothèque qui a fait de Python un outil d'analyse de données de premier plan. Son objet central, le DataFrame, est un tableau nommé sur lequel on charge, nettoie, filtre, regroupe et croise des données réelles en quelques lignes lisibles. Ce cours te mène de la Series jusqu'à une analyse de bout en bout : charger un CSV, traiter les valeurs manquantes, grouper, joindre, travailler des séries temporelles et exporter un résultat propre.

Bien s'équiper

Les extensions VS Code pour pandas

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent l'exécution, l'auto-complétion (IntelliSense) et l'exploration visuelle des tableaux.

À installer pour pandas

  • Python (Microsoft) — exécution, environnement et débogage.
  • Pylance (Microsoft) — IntelliSense rapide et types.
  • Jupyter (Microsoft) — notebooks interactifs, idéals pour explorer un DataFrame cellule par cellule.
  • Data Wrangler (Microsoft) — visualiser et nettoyer un DataFrame dans une vue tableau.

Pour qui ?

Idéal si tu connais déjà les bases de Python (variables, listes, dictionnaires, fonctions) et que tu veux tirer du sens de données réelles. Aucune statistique avancée n'est supposée. Le code n'est pas exécuté dans le site : chaque exemple montre ses sorties en commentaire.

Ce que tu vas apprendre

Du DataFrame à l'analyse complète

À la fin du cours, tu sauras

  • charger, inspecter et typer un jeu de données (read_csv, info, dtypes, valeurs manquantes) ;
  • sélectionner, filtrer et trier avec loc/iloc, les masques booléens et sort_values ;
  • créer des colonnes, regrouper avec groupby et croiser avec pivot_table ;
  • joindre des tables (merge), traiter des séries temporelles et exporter proprement.

Pour qui, et pourquoi

Ce cours s'adresse aux futurs data analysts, développeurs back-end, scientifiques ou à toute personne qui manipule des fichiers de données. pandas est aujourd'hui l'outil de référence pour explorer, nettoyer et résumer des données tabulaires en Python — la première étape de presque tout projet de données, y compris en apprentissage automatique.

Chaque leçon est autonome et illustrée par du code commenté sur un même fil rouge : les ventes d'une petite librairie en ligne. Le code ne s'exécute pas dans l'éditeur du site : les sorties (y compris les tableaux) sont montrées en commentaire.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • pandas manipule des données tabulaires en Python, au-dessus de NumPy.
  • Deux structures : la Series (une colonne) et le DataFrame (un tableau).
  • Charger avec read_csv ; toujours inspecter (head, info, describe) avant d'analyser.
  • Sélectionner par étiquette loc ou position iloc ; filtrer avec des masques booléens (&, |, ~ avec parenthèses).
  • Résumer par groupe avec groupby (split-apply-combine) ; croiser avec pivot_table.
  • Relier des tables avec merge (les jointures façon SQL).
  • Préférer le calcul vectorisé à une boucle ; exporter avec to_csv(index=False).
Series
Tableau 1D indexé (une colonne) : des valeurs, un index et un type.
DataFrame
Tableau 2D : un ensemble de Series alignées sur le même index, une par colonne nommée.
Index
Étiquettes des lignes d'une Series ou d'un DataFrame ; sert à l'alignement et à la sélection.
dtype
Type d'une colonne (int64, float64, object, datetime64, category).
NaN
Valeur manquante (un flottant spécial) ; se propage dans les calculs et n'est ni 0 ni chaîne vide.
Masque booléen
Series de True/False qui sélectionne les lignes d'un DataFrame.
groupby
Découper par clé, agréger chaque groupe, recombiner (split-apply-combine).
merge
Joindre deux tables sur une clé commune : inner, left, right, outer.
