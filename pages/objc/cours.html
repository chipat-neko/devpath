Objective-C : l'héritage d'iOS

Pendant près de trente ans, Objective-C a été le langage d'Apple : le Mac, puis l'iPhone et l'iPad à leurs débuts. C'est du C augmenté d'une couche objet inspirée de Smalltalk, avec sa syntaxe à messages entre crochets. Swift l'a remplacé pour le neuf, mais des millions de lignes tournent encore : ce cours t'apprend à le lire, le maintenir, et comprendre les fondations des plateformes Apple.

Bien s'équiper

Les extensions VS Code pour Objective-C

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) : ces outils apportent coloration et débogage. Sur macOS, Xcode reste l'environnement de référence pour Objective-C.

À installer pour Objective-C

  • C/C++ (Microsoft) — coloration et IntelliSense (base commune avec le C).
  • CodeLLDB (Vadim Chugunov) — débogueur natif.

Pour qui ?

Idéal si tu connais déjà le C ou un langage orienté objet, et que tu veux travailler dans l'écosystème Apple — pour maintenir du code existant, comprendre les frameworks, ou faire le pont avec Swift. Chaque notion propre à Objective-C est expliquée depuis le début.

Ce que tu vas apprendre

Lire, comprendre et maintenir le code Apple

À la fin du cours, tu sauras

  • lire la syntaxe à messages ([objet methode:arg]) et manier NSString ;
  • créer des classes (.h/.m), des propriétés et des méthodes ;
  • utiliser protocoles, catégories et le patron de délégation ;
  • comprendre la gestion mémoire (ARC, cycles), les blocks et la cohabitation avec Swift.

Pour qui, et pourquoi

Objective-C reste incontournable dans l'écosystème Apple : une grande partie du code en production et des frameworks est écrite avec lui. Le connaître permet de maintenir l'existant, de comprendre en profondeur iOS et macOS, et de préparer idéalement le passage à Swift — dont chaque nouveauté répond à une limite d'Objective-C.

Chaque leçon est autonome et illustrée par du code commenté. Le code ne s'exécute pas dans l'éditeur du site : les exemples montrent la syntaxe et les sorties attendues en commentaire.
