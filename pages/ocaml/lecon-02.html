Module 1 · Les bases d'OCaml — Leçon 02

Types, inférence et fonctions

~50 min Avancé Prérequis : leçon 1

À la fin de cette leçon, tu sauras

  • déclarer des valeurs avec let et comprendre l'inférence de types ;
  • manier les types de base (int, float, bool, string, char) ;
  • définir des fonctions et comprendre la curryfication ;
  • utiliser l'application partielle et l'opérateur |>.
Sommaire de la leçon

La signature d'OCaml, c'est l'inférence de types : tu écris du code presque sans annotations, et le compilateur déduit le type de chaque expression — puis vérifie que tout est cohérent. Couplée aux fonctions et à la curryfication, elle donne un code à la fois concis et d'une sûreté remarquable.

L'inférence en action

Tu n'écris pas les types : OCaml les devine à partir de la façon dont tu utilises les valeurs. Le REPL te les montre.

OCaml a déduit : double prend un int et renvoie un int (à cause de * 2) ; ^ concatène des chaînes.

Les types de base

OCaml part d'un petit noyau de types primitifs. On en a croisé en leçon 1 ; voici les cinq à connaître, chacun avec sa notation propre.

Les booléens se combinent avec && (et), || (ou) et not. Les comparaisons (=, <, >) fonctionnent sur presque tous les types et renvoient un bool : 1 < 2, "a" < "b" et 'x' = 'x' sont tous valides.

Piège fréquent

'A' (guillemets simples) est un char ; "A" (guillemets doubles) est une string d'un seul caractère. Ce sont deux types distincts : String.length "A" vaut 1, mais String.length 'A' ne compile pas. Beaucoup de langages ignorent cette distinction ; OCaml la fait.

Définir une fonction

let nom params = corps. Pas de return : la valeur du corps est le résultat. Le type fléché int -> int se lit « prend un int, renvoie un int ».

Remarque : pas de parenthèses ni de virgules pour appeler : somme 3 4, pas somme(3, 4).

La curryfication

Idée fondamentale : en OCaml, une fonction à « plusieurs arguments » est en réalité une suite de fonctions à un seul argument. Le type de somme est int -> int -> int, c'est-à-dire int -> (int -> int) : donne-lui un entier, elle renvoie une fonction qui attend le second.

L'application partielle

Conséquence directe : on peut n'appliquer qu'une partie des arguments pour obtenir une nouvelle fonction. C'est élégant et très utilisé.

Les fonctions anonymes

Le mot-clé fun crée une fonction sans nom — utile pour les fonctions d'ordre supérieur (leçon 7).

L'opérateur pipe |>

L'opérateur |> passe une valeur comme dernier argument de la fonction à sa droite. Il transforme des appels imbriqués en un pipeline lisible de gauche à droite.

Astuce

Le pipe a un jumeau : @@ applique la fonction de gauche à l'argument de droite. print_endline @@ string_of_int 42 évite les parenthèses de print_endline (string_of_int 42). Moyen mnémotechnique : |> pousse la donnée vers la droite, @@ tire l'argument vers la gauche.

Annoter quand on veut

L'inférence n'empêche pas d'annoter explicitement, pour documenter ou guider le compilateur.

Pièges fréquents

Piège fréquent

Appeler une fonction avec des parenthèses et des virgules : somme(3, 4) ne fait pas ce que tu crois ! OCaml l'interprète comme un appel avec un seul argument, le tuple (3, 4) — et lève une erreur de type. Écris somme 3 4.

Pour aller plus loin

Pour aller plus loin

L'inférence d'OCaml repose sur l'algorithme de Hindley-Milner, qui garantit de trouver le type le plus général sans aucune annotation. C'est pourquoi tes fonctions sont souvent polymorphes automatiquement : let identite x = x a le type 'a -> 'a, valable pour tout type.

Glossaire

Inférence de types
Déduction automatique du type des expressions par le compilateur, sans annotation. Le REPL affiche le type déduit (ex. int -> int).
Type fléché
Notation a -> b décrivant une fonction qui prend un a et renvoie un b. La flèche associe à droite.
Curryfication
Fait qu'une fonction à plusieurs arguments est en réalité une suite de fonctions à un seul argument. C'est le comportement par défaut en OCaml.
Application partielle
Fournir seulement une partie des arguments d'une fonction pour obtenir une nouvelle fonction spécialisée (ex. somme 5).
Fonction anonyme
Fonction sans nom introduite par fun : fun x -> x + 1. Pratique comme argument d'une autre fonction.
Pipe (|>)
Opérateur qui passe la valeur de gauche comme dernier argument de la fonction de droite : x |> f = f x. Rend les traitements lisibles.
Polymorphisme
Capacité d'une fonction à s'appliquer à plusieurs types. OCaml infère souvent des types polymorphes comme 'a -> 'a (variable de type 'a).
char
Type d'un caractère unique, noté entre guillemets simples : 'A'. À distinguer de la string (guillemets doubles), même longue d'un seul caractère.
@@ (application)
Pendant du pipe : f @@ x vaut f x. Il applique la fonction de gauche à l'argument de droite, ce qui évite une paire de parenthèses.

Récap et vérification

  • L'inférence déduit les types ; le REPL les affiche (int -> int).
  • Appel sans parenthèses : somme 3 4 ; pas de return.
  • Curryfication : une fonction à n arguments = suite de fonctions à 1 argument → application partielle.
  • fun pour les anonymes ; |> pour les pipelines.
