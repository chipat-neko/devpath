Module 1 · Les bases de Pascal — Leçon 02

Variables, types et affectation

~44 min Débutant Prérequis : leçon 1

À la fin de cette leçon, tu sauras

  • déclarer des variables dans la section var ;
  • utiliser les types integer, real, char, boolean, string ;
  • affecter avec := ;
  • lire une saisie avec readln.
Sommaire de la leçon

Un programme qui ne fait qu'afficher du texte fixe est vite limité. Pour qu'il calcule, retienne et réagisse, il lui faut des variables : des cases nommées qui contiennent des valeurs. Pascal, fidèle à sa rigueur pédagogique, exige qu'on déclare chaque variable avec son type avant de l'utiliser. Cette discipline, qui peut sembler lourde au début, est précisément ce qui forme de bons réflexes. Cette leçon pose ces fondations.

Déclarer une variable : la section var

En Pascal, les variables se déclarent dans une section var, placée avant le begin du corps. On indique le nom, puis le type après deux-points.

Tout doit être déclaré avant d'être utilisé : c'est une règle d'or de Pascal. Le compilateur refuse une variable inconnue, ce qui élimine d'emblée les fautes de frappe sur les noms.

Les types de base

Pascal propose un petit jeu de types fondamentaux, clairs et bien définis :

  • integer — les nombres entiers (42, -7) ;
  • real — les nombres à virgule (3.14, -0.5) ;
  • char — un seul caractère ('A') ;
  • boolean — vrai ou faux (true/false) ;
  • string — une suite de caractères ('Bonjour').

L'affectation avec :=

Pour donner une valeur à une variable, on utilise l'opérateur d'affectation := (deux-points suivis du égal). On le lit « reçoit » : age := 20 se lit « age reçoit 20 ».

On peut déclarer plusieurs variables d'un même type sur une ligne en les séparant par des virgules (x, y, somme : integer;). Les opérations arithmétiques usuelles sont +, -, *, / (division réelle), ainsi que div (division entière) et mod (reste).

Lire une saisie avec readln

Pour rendre un programme interactif, readln lit ce que l'utilisateur tape au clavier et le range dans une variable.

Le type de la variable guide la lecture : readln(age) attend un entier puisque age est un integer. C'est l'un des intérêts du typage : Pascal sait quoi faire de la saisie.

Les constantes

Pour une valeur fixe qui ne doit jamais changer, on la déclare dans une section const. On lui donne un nom parlant, ce qui rend le code plus lisible.

La notation aire:0:2 contrôle l'affichage d'un réel : ici, deux chiffres après la virgule. Sans elle, Pascal afficherait le nombre en notation scientifique.

Cas réel : afficher un prix dans un logiciel de caisse

Un logiciel de facturation stocke les prix en real et les quantités en integer. Sans mise en forme, un total comme 9.99 s'afficherait 9.9899999E+00 — illisible pour un client ! La notation total:0:2 impose exactement deux décimales (9.99), le bon format pour une monnaie. Choisir le bon type et le bon affichage, c'est déjà penser comme un logiciel professionnel.

Pièges fréquents

Piège fréquent

Confondre / et div. En Pascal, / donne toujours un résultat réel (7 / 2 vaut 3.5), même entre deux entiers ; pour une division entière, il faut div (7 div 2 vaut 3) et mod pour le reste (7 mod 2 vaut 1). Affecter 7 / 2 à une variable integer provoque une erreur de type : le résultat réel ne rentre pas dans un entier.

Pour aller plus loin

Pour aller plus loin

Le typage fort de Pascal n'est pas qu'une contrainte : c'est un filet de sécurité. En obligeant à déclarer le type de chaque donnée, il permet au compilateur d'attraper quantité d'erreurs avant l'exécution — un nombre rangé dans un caractère, une chaîne additionnée à un entier… Cette idée, centrale chez Wirth, irrigue tous les langages typés modernes, de Java à TypeScript.

Glossaire

Variable
Case mémoire nommée qui contient une valeur susceptible de changer ; en Pascal, elle a un type fixé à la déclaration.
Type
Nature d'une donnée (entier, réel, caractère, booléen, chaîne) ; il détermine les valeurs possibles et les opérations autorisées.
Section var
Zone, placée avant le begin, où l'on déclare toutes les variables avec leur type.
Affectation (:=)
Opération qui donne une valeur à une variable ; se lit « reçoit » (age := 20).
div / mod
Division entière et reste : 7 div 2 vaut 3, 7 mod 2 vaut 1 ; à distinguer de / qui donne un réel.
readln
Instruction qui lit une saisie clavier et la range dans une variable, en suivant son type.
Constante (const)
Valeur fixe nommée qui ne change jamais pendant l'exécution ; rend le code plus lisible et sûr.
Typage fort
Discipline de Pascal qui exige un type pour chaque donnée ; le compilateur détecte alors de nombreuses erreurs avant l'exécution.

Récap et vérification

  • On déclare les variables dans la section var, avec leur type, avant le begin.
  • Types de base : integer, real, char, boolean, string.
  • := affecte (« reçoit ») ; readln lit une saisie ; const pour les valeurs fixes.
  • / divise en réel ; div et mod pour la division entière et le reste.
