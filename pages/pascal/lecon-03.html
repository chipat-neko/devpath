Module 1 · Les bases de Pascal — Leçon 03

Conditions et boucles

~45 min Débutant Prérequis : leçon 2

À la fin de cette leçon, tu sauras

  • décider avec if/then/else et case ;
  • répéter avec for, while et repeat ;
  • comprendre le rôle de begin/end dans les blocs ;
  • combiner conditions avec and, or, not.
Sommaire de la leçon

Un programme qui suit toujours le même chemin reste rudimentaire. Pour qu'il décide et répète, il faut des structures de contrôle. Pascal les offre avec sa clarté coutumière : des conditions lisibles et trois sortes de boucles, chacune adaptée à une situation. C'est ici que ton programme devient vraiment vivant. Cette leçon couvre if, case, et les boucles for, while et repeat.

La condition if … then … else

La structure if exécute une instruction selon qu'une condition est vraie ou fausse.

Attention à un détail très pascalien : pas de point-virgule avant else. Le if … then … else forme une seule instruction ; un point-virgule juste avant else la couperait et provoquerait une erreur. Les comparaisons sont =, <> (différent), <, >, <=, >=.

Les blocs begin … end

Si une branche doit contenir plusieurs instructions, on les regroupe entre begin et end. C'est le rôle fondamental de ce couple : délimiter un bloc.

Sans le begin … end, seule la première instruction ferait partie du then : une erreur classique. Le bloc rend la portée explicite.

Combiner des conditions

On relie des conditions avec and, or, not. En Pascal, mieux vaut parenthéser chaque comparaison, car les opérateurs logiques ont une priorité élevée.

Le choix multiple avec case

Quand on teste une même variable contre plusieurs valeurs, case est plus lisible qu'une cascade de if.

On peut grouper des valeurs avec des virgules (6, 7) ou des plages (1..5). La branche else couvre les cas restants.

La boucle for : un nombre de tours connu

Quand on sait combien de fois répéter, for est idéale : une variable de contrôle parcourt une plage.

to compte en montant, downto en descendant. La variable i avance automatiquement : on ne la modifie pas soi-même dans la boucle.

Les boucles while et repeat

Quand le nombre de tours dépend d'une condition, deux formes existent. while teste avant chaque tour (peut ne jamais s'exécuter) ; repeat … until teste après (s'exécute au moins une fois).

Subtilité de syntaxe : while … do ne répète qu'une instruction (d'où le begin … end si besoin), tandis que repeat … until encadre naturellement plusieurs instructions sans bloc supplémentaire.

Cas réel : le menu d'un distributeur

Un distributeur de billets — ou le menu d'un jeu — affiche ses options, lit le choix, agit, puis recommence tant que l'on ne demande pas de quitter. On veut montrer le menu au moins une fois : c'est exactement le rôle de repeat … until. Le corps (afficher, lire, traiter) s'exécute d'abord, et until choix = 0 arrête la boucle quand l'utilisateur tape 0. Avec un while, il faudrait initialiser artificiellement la variable de choix avant le tout premier tour.

Pièges fréquents

Piège fréquent

Mettre un point-virgule juste avant else : if x = 1 then writeln('un'); else … est une erreur en Pascal. Le then et le else appartiennent à la même instruction ; le point-virgule la termine prématurément. Règle simple : jamais de ; juste avant else.

Pour aller plus loin

Pour aller plus loin

Pascal fut un fer de lance de la programmation structurée, mouvement des années 1970 qui prônait l'abandon du goto (les sauts arbitraires) au profit de structures claires : séquence, condition, boucle. L'article célèbre de Dijkstra, « Go To Statement Considered Harmful », incarne cette idée. Programmer en Pascal, c'est hériter directement de cette discipline qui a assaini la façon d'écrire du code.

Glossaire

Structure de contrôle
Construction qui pilote l'ordre d'exécution : condition (décider) ou boucle (répéter).
if … then … else
Exécute une branche si la condition est vraie, l'autre sinon ; pas de ; avant else.
case … of
Choix multiple lisible : teste une même variable contre des valeurs, listes (6, 7) ou plages (1..5).
Boucle for
Répète un nombre de fois connu ; une variable de contrôle parcourt une plage (to ou downto).
Boucle while
Répète tant que une condition est vraie, testée avant chaque tour : peut ne jamais s'exécuter.
Boucle repeat … until
Répète jusqu'à ce qu'une condition soit vraie, testée après : s'exécute au moins une fois.
Opérateur logique
and, or, not relient des conditions ; en Pascal, on parenthèse chaque comparaison.
Bloc begin … end
Regroupe plusieurs instructions en une seule unité, notamment dans une branche ou une boucle.

Récap et vérification

  • if … then … else décide ; pas de ; avant else ; comparaisons =, <>, <, >…
  • begin … end regroupe plusieurs instructions dans une branche.
  • case pour le choix multiple (plages 1..5, listes 6, 7).
  • Boucles : for (tours connus), while (test avant), repeat … until (test après).

Vérifie ta compréhension

  1. Pourquoi ne met-on pas de ; avant else ?
  2. Quelle différence entre while et repeat ?
  3. À quoi sert begin … end dans un if ?
