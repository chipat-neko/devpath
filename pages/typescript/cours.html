TypeScript : du typage au quotidien

Tu écris du JavaScript, mais une faute de type ne se révèle qu'à l'exécution ? TypeScript ajoute un typage statique vérifié avant même de lancer le code : tu attrapes les erreurs dans l'éditeur, tu refactores sans peur et tu profites d'une autocomplétion qui connaît tes données. Ce cours te mène de la première annotation aux génériques et à la pratique en vrai projet.

Bien s'équiper

Les extensions VS Code pour TypeScript

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils complètent le support TypeScript déjà présent dans l'éditeur.

À installer pour TypeScript

  • ESLint (Microsoft) — analyse du code typé.
  • Prettier - Code formatter (Prettier) — formatage automatique.
  • Pretty TypeScript Errors (yoavbls) — rend les erreurs de type lisibles.
  • Error Lens (Alexander) — affiche les erreurs en ligne.
  • Import Cost (Wix) — poids des imports.

Prérequis

Ce cours suppose que tu es à l'aise avec JavaScript moderne (fonctions, objets, modules, async). TypeScript est un sur-ensemble de JavaScript : tout ce que tu sais reste vrai, on ajoute les types par-dessus.

Ce que tu vas apprendre

Du premier type au vrai projet

À la fin du cours, tu sauras

  • installer et compiler du TypeScript (tsc, tsconfig, mode strict) et exploiter l'inférence ;
  • typer données et fonctions : primitifs, tableaux, tuples, interfaces, alias, optionnels et readonly ;
  • maîtriser le système de types : unions & littéraux, narrowing, génériques et types utilitaires ;
  • structurer un projet : classes typées, modules, fichiers .d.ts, @types et migration JS → TS.

Pour qui, et pourquoi

Ce cours est pour les développeurs JavaScript qui veulent fiabiliser leur code et travailler sereinement sur de plus gros projets. TypeScript est aujourd'hui la norme de fait dans l'écosystème front-end (React, Angular, Vue) comme back-end (Node), et la majorité des offres d'emploi le demandent.

Chaque leçon part d'un besoin concret du quotidien JS, montre le type qui le résout, et illustre l'erreur que le compilateur attrape. Le code se compile (il ne s'exécute pas dans l'éditeur) : les résultats et les erreurs tsc sont montrés en commentaire.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Ajoute le typage statique à JavaScript ; compile vers du JS.
  • Annoter avec : type (let x: number).
  • Décrire des objets avec interface ou type.
  • Unions (A | B), génériques (<T>).
  • Éviter any ; préférer unknown au besoin.
  • Les types disparaissent à l'exécution → valider les données externes (Zod…).
  • Tout l'écosystème JavaScript reste disponible.
Type

interface
Description de la forme d'un objet.

Type valant l'un OU l'autre (string | number).

Type paramétré (Array<T>).
any
Désactive la vérification de types (à éviter).
unknown
Alternative SÛRE à any (à restreindre avant usage).

Déduction automatique des types par le compilateur.
Transpilation
Compilation de TypeScript vers du JavaScript.
