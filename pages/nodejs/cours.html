Node.js : JavaScript côté serveur

Tu connais JavaScript dans le navigateur ? Node.js te permet de l'exécuter partout ailleurs : outils en ligne de commande, scripts d'automatisation et surtout des serveurs et des API. Ce cours te mène des fondations (modules, npm, asynchrone) jusqu'à une API REST prête pour la production.

Bien s'équiper

Les extensions VS Code pour Node.js

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Node.js

  • ESLint (Microsoft) — qualité du code serveur.
  • Prettier - Code formatter (Prettier) — mise en forme automatique.
  • REST Client (Huachao Mao) — tester des requêtes HTTP depuis un fichier.
  • DotENV (mikestead) — coloration des fichiers .env.
  • npm Intellisense (Christian Kohler) — complète les imports de modules.

Prérequis

Ce cours suppose que tu es à l'aise avec JavaScript moderne (fonctions, async/await, modules). Node, c'est ce même langage, côté serveur.

Ce que tu vas apprendre

Du script au serveur de production

À la fin du cours, tu sauras

  • structurer un projet Node : modules (CommonJS/ESM), npm et scripts ;
  • maîtriser l'asynchrone (boucle d'événements, promesses, EventEmitter, streams) ;
  • interagir avec le système : fichiers (fs), process et variables d'environnement ;
  • construire un serveur HTTP puis une API REST avec Express (middleware, erreurs), la tester et la sécuriser ;
  • brancher une base de données, gérer l'authentification (bcrypt, JWT) et le temps réel (WebSockets).

Pour qui, et pourquoi

Ce cours est pour les développeurs JavaScript qui veulent sortir du navigateur : créer des outils, automatiser des tâches, et surtout bâtir le « back-end » d'une application — l'API que consomment des front-ends comme React.

Chaque leçon est autonome et illustrée par du code que tu peux exécuter dans ton terminal avec node.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Exécute du JavaScript côté serveur (moteur V8).
  • Gestionnaire de paquets npm ; dépendances dans package.json.
  • E/S asynchrones non bloquantes (boucle d'événements).
  • Modules intégrés (node:http, node:fs…).
  • Frameworks web comme Express.
V8
Moteur JavaScript (celui de Chrome) qui exécute le code.
npm
Gestionnaire de paquets de l'écosystème Node.
package.json
Fichier décrivant le projet, ses scripts et dépendances.
Event loop
Boucle gérant les opérations asynchrones sur un seul thread.
Module
Unité de code importée (require / import).
Express
Framework web minimaliste (routes, middlewares).
