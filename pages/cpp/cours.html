C++ : performance et objets

Le C++ ajoute au C la puissance de l'abstraction : objets, généricité et une vaste bibliothèque (la STL), sans renoncer au contrôle ni à la vitesse. C'est le langage des jeux vidéo, du calcul haute performance et des systèmes critiques. Ce cours te mène des classes au C++ moderne : RAII, sémantique de déplacement, templates et pointeurs intelligents.

Bien s'équiper

Les extensions VS Code pour C++

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour C++

  • C/C++ (Microsoft) — IntelliSense et débogage.
  • C/C++ Extension Pack (Microsoft) — outillage complet.
  • CMake Tools (Microsoft) — gestion du build CMake.
  • clangd (LLVM) — analyse puissante, en alternative.
  • Code Runner (Jun Han) — compiler/exécuter en un clic.

Niveau

Cours avancé. Des notions de C (mémoire, pointeurs) aident beaucoup : le C++ s'appuie dessus puis offre des outils pour les dompter (RAII, pointeurs intelligents, conteneurs). À défaut, des bases solides en programmation suffisent pour démarrer.

Ce que tu vas apprendre

Du C aux abstractions modernes

À la fin du cours, tu sauras

  • compiler du C++ (g++), utiliser iostream, les références, auto et les fonctions ;
  • concevoir des classes avec le RAII, l'héritage, le polymorphisme et la surcharge d'opérateurs ;
  • maîtriser la sémantique de copie/déplacement, les templates et la STL (conteneurs, algorithmes, lambdas) ;
  • écrire du C++ moderne et sûr : pointeurs intelligents, exceptions, optional et organisation d'un projet (CMake).

Pour qui, et pourquoi

Ce cours s'adresse à qui vise la performance avec un haut niveau d'abstraction : jeux vidéo, moteurs de rendu, finance, robotique, systèmes embarqués exigeants. Le C++ est puissant et vaste ; ce cours privilégie le C++ moderne (C++11 à C++20), plus sûr et plus expressif que le C++ historique.

Chaque leçon est illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties sont montrées en commentaire.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Inclure des en-têtes (#include <iostream>) ; afficher avec std::cout.
  • Compilé en code natif, proche de la machine (performant).
  • RAII : le destructeur libère automatiquement les ressources en fin de portée.
  • Préférer std::vector et std::string aux tableaux C bruts.
  • Passer les gros objets par référence constante (const T&).
  • Programmation générique avec les templates.
  • POO complète : classes, héritage, polymorphisme.
Pointeur

Alias d'une variable existante (T&).
RAII
Libération automatique des ressources via le destructeur, en fin de portée.
Destructeur
Méthode appelée à la destruction d'un objet.
std
Espace de noms de la bibliothèque standard.
Template
Outil de programmation générique sur le type.
std::vector
Tableau dynamique de la bibliothèque standard.
Surcharge
Plusieurs fonctions de même nom, aux paramètres différents.
Constructeur
Méthode d'initialisation d'un objet.
Smart pointer
Pointeur qui gère la mémoire tout seul (unique_ptr, shared_ptr).
