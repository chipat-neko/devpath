Haskell : la programmation fonctionnelle pure

Haskell apprend à penser autrement : des fonctions pures, une immutabilité totale, un système de types qui attrape les erreurs avant l'exécution, et une évaluation paresseuse qui autorise les listes infinies. On y démystifie les monades sans une once de jargon gratuit. Cette façon de penser irrigue Rust, Scala, TypeScript… et te rend meilleur partout.

Bien s'équiper

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

Pour qui ?

Idéal si tu sais déjà programmer dans un langage impératif (le cours Python ou le cours JavaScript suffisent) et que tu veux élargir ta façon de penser. Chaque concept fonctionnel est expliqué depuis le début — y compris les monades, sans mystification.

Ce que tu vas apprendre

Du connu (les fonctions) à l'inconnu (les monades)

À la fin du cours, tu sauras

  • penser fonctionnel : fonctions pures, curryfication, récursion et foldr/foldl ;
  • exploiter le système de types : types algébriques, pattern matching, type classes, Maybe/Either ;
  • comprendre foncteurs, applicatives et les monades (enfin démystifiées) avec la notation do ;
  • passer à la pratique : IO, évaluation paresseuse, Cabal, QuickCheck et un vrai petit programme.

Pour qui, et pourquoi

Ce cours s'adresse aux curieux qui veulent changer de paradigme et aux développeurs qui visent des domaines où la correction prime (compilateurs, finance, blockchain, outils critiques). Apprendre Haskell, c'est aussi mieux écrire dans tous les autres langages : l'immutabilité, les types et les fonctions pures sont partout.

Chaque leçon est autonome et illustrée par du code commenté. Le code ne s'exécute pas dans l'éditeur du site : les sorties de GHCi sont montrées en commentaire.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Fonctionnel pur : pas d'effets de bord cachés.
  • Valeurs immuables ; évaluation paresseuse (lazy).
  • Typage statique fortement inféré.
  • Définir une fonction : nom args = expression.
  • Les effets (E/S) sont encapsulés dans le type IO.
  • Filtrage par motif et fonctions d'ordre supérieur (map, filter, fold).
  • Composer avec le point : f . g.
Pureté
Une fonction ne dépend que de ses arguments, sans effet de bord.
Immuabilité
Les valeurs ne changent jamais.
Évaluation paresseuse
On ne calcule une valeur qu'au moment où elle est nécessaire.
Inférence de types
Le compilateur déduit les types sans annotation.
Monade
Structure encapsulant un calcul (ex. IO pour les effets).
Ordre supérieur
Fonction qui prend ou renvoie une autre fonction.
Composition
Combiner des fonctions avec le point (.).
Filtrage par motif
Déstructurer une valeur selon sa forme.
