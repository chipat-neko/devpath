Module 3 · Administrer le système — Leçon 10

Modules, objets et .NET

~50 min Avancé Prérequis : leçon 9

À la fin de cette leçon, tu sauras

  • installer et importer des modules (Install-Module, PowerShell Gallery) ;
  • organiser ton code en module réutilisable (.psm1, manifeste) ;
  • appeler directement des classes .NET ([System.Math], [datetime]) ;
  • définir tes propres classes PowerShell.
Sommaire de la leçon

PowerShell ne se limite pas à ses cmdlets : on peut l'étendre avec des modules (des paquets de commandes), et plonger directement dans tout l'écosystème .NET. C'est ce qui le rend aussi puissant : derrière le shell se cache une plateforme de programmation complète.

Installer des modules

La PowerShell Gallery est le dépôt officiel de modules. Find-Module cherche, Install-Module installe, Import-Module charge dans la session, Get-Module liste.

Le -Scope CurrentUser installe sans droits administrateur.

Écrire son propre module

Un module est un fichier .psm1 regroupant des fonctions. On l'importe comme n'importe quel module. Export-ModuleMember choisit ce qui est public.

Le manifeste de module

Pour un vrai module, un manifeste .psd1 décrit version, auteur, dépendances et fonctions exportées. New-ModuleManifest le génère.

Le caractère ` (accent grave) en fin de ligne permet de continuer une commande sur la suivante.

Appeler directement .NET

Toute classe .NET est accessible entre crochets. [Math] pour les maths, [DateTime] pour les dates, [System.IO.Path] pour les chemins… On appelle les méthodes statiques avec ::.

Quand aucune cmdlet ne fait l'affaire, .NET a presque toujours la réponse.

Créer une instance d'objet .NET

Pour les méthodes non statiques, on instancie avec ::new() (ou l'ancien New-Object).

Définir ses propres classes

PowerShell 5+ permet de déclarer des classes, avec propriétés et méthodes — utile pour modéliser proprement un domaine.

Un cas réel — la boîte à outils d'une équipe

Cas réel : mutualiser ses fonctions

Dans une équipe d'administration, les mêmes fonctions reviennent partout : analyser des journaux, formater un rapport, appeler une API interne. Plutôt que copier-coller ces fonctions dans chaque script, on les regroupe dans un module Outils.psm1 accompagné de son manifeste, déposé sur un partage réseau ou une Gallery interne.

Chacun dispose alors des mêmes commandes, testées et versionnées une fois pour toutes.

Pièges fréquents

Piège fréquent

Les méthodes d'objets .NET qui renvoient une valeur (comme $sb.Append(...) ou $liste.Add(...)) polluent le pipeline de sortie. Préfixe-les de [void] ou affecte le résultat pour éviter des objets parasites dans ta sortie.

Pour aller plus loin

Pour aller plus loin

Un module bien rangé suit une structure : dossier MonModule/ contenant MonModule.psm1 et MonModule.psd1. Place-le dans un des chemins de $env:PSModulePath et Import-Module MonModule le trouvera par son nom.

Antisèche — modules et .NET

Glossaire

Module
Paquet de commandes (fonctions, cmdlets) que l'on charge dans une session pour l'étendre.
PowerShell Gallery
Dépôt public officiel de modules, source de Install-Module.
.psm1
Fichier de module regroupant des fonctions réutilisables.
Manifeste (.psd1)
Fichier décrivant un module : version, auteur, dépendances, fonctions exportées.
Membre statique
Méthode ou propriété appartenant au type lui-même, appelée avec [Type]::Membre.
::new()
Syntaxe moderne d'instanciation d'un objet .NET (équivalent de New-Object).
class
Mot-clé (PowerShell 5+) définissant une classe avec propriétés et méthodes.
[void]
Transtypage qui jette la valeur de retour d'une expression pour ne pas polluer la sortie.

Récap et vérification

  • La PowerShell Gallery fournit des modules (Install-Module, Import-Module).
  • Un module .psm1 regroupe des fonctions ; un manifeste .psd1 le décrit.
  • Les classes .NET s'appellent entre crochets ([Math]::Sqrt) et s'instancient avec ::new().
  • PowerShell sait définir ses propres classes avec class.

Vérifie ta compréhension

  1. Quelle cmdlet installe un module depuis la Gallery ?
  2. Comment appeler la méthode statique Sqrt de la classe Math ?
  3. Pourquoi préfixer $sb.Append(...) de [void] ?
