PowerShell : automatiser Windows

PowerShell est le shell et le langage d'automatisation de Windows — et désormais de macOS et Linux. Son idée de génie : le pipeline d'objets, où circulent des données structurées plutôt que du texte à découper. De la première cmdlet aux fonctions avancées, du registre au remoting, ce cours fait de toi un automatiseur efficace.

Bien s'équiper

Les extensions VS Code pour PowerShell

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour PowerShell

  • PowerShell (Microsoft) — IntelliSense, débogage et analyse (PSScriptAnalyzer).

Pour qui ?

Aucun prérequis de programmation strict : si tu sais utiliser un ordinateur Windows et que tu veux automatiser tes tâches, ce cours te prend par la main. Une notion de logique (variables, boucles), par exemple via le cours Python, accélère la lecture.

Ce que tu vas apprendre

De la console à l'automatisation

À la fin du cours, tu sauras

  • manier les cmdlets et le pipeline d'objets (filtrer, trier, projeter, transformer) ;
  • écrire des scripts et des fonctions avancées avec paramètres validés ;
  • gérer les erreurs, manipuler fichiers, CSV/JSON et le registre ;
  • aller plus loin : modules et .NET, remoting, parallélisme, tests Pester et PowerShell 7.

Pour qui, et pourquoi

Ce cours s'adresse aux administrateurs système, techniciens, devops et à tous ceux qui veulent cesser de cliquer pour enfin automatiser. PowerShell est l'outil incontournable de l'administration Windows et un atout majeur côté cloud (Azure) et CI/CD.

Chaque leçon est autonome et illustrée par du code commenté que tu peux reproduire dans ta console. Les sorties sont montrées en commentaire.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Le pipeline transmet des objets (.NET), pas du texte.
  • Commandes en Verbe-Nom (Get-Process, Set-Item…).
  • Variables avec $nom ; objets via [pscustomobject]@{}.
  • Filtrer avec Where-Object, boucler avec ForEach-Object.
  • Aide intégrée : Get-Help.
  • Multiplateforme depuis PowerShell 6+ (Core).
Cmdlet
Commande nommée selon le modèle Verbe-Nom.
Pipeline
Chaîne de commandes se passant des objets.
Objet
Donnée structurée (.NET) circulant dans le pipeline.
Where-Object
Filtre les objets selon une condition.
ForEach-Object
Exécute un bloc sur chaque objet du pipeline.
Hashtable
Table de paires clé-valeur : @{}.
