Module 4 · PowerShell en pratique — Leçon 13

Manipuler le texte : les expressions régulières

~50 min Intermédiaire Prérequis : leçon 12

À la fin de cette leçon, tu sauras

  • tester et extraire du texte avec -match et la variable $Matches ;
  • capturer des fragments avec des groupes, y compris nommés ;
  • réécrire du texte avec -replace et le découper avec -split ;
  • fouiller des fichiers avec Select-String et aiguiller avec switch -regex.
Sommaire de la leçon

Le pipeline de PowerShell transporte des objets, mais le monde réel déborde de texte : journaux, fichiers de configuration, sorties de programmes externes (git, ipconfig, ping…). Pour y trouver une adresse IP, une date ou un code d'erreur, l'outil de précision s'appelle l'expression régulière — un motif qui décrit une forme de texte plutôt qu'un texte exact.

Un motif décrit une forme

Une regex (de l'anglais regular expression) est une petite grammaire : \d signifie « un chiffre », \d+ « un ou plusieurs chiffres », \w « un caractère de mot ». PowerShell s'appuie sur le moteur de regex de .NET, l'un des plus complets qui soit.

Tester avec -match

L'opérateur -match renvoie $true ou $false selon que le texte contient le motif. Bonus : il remplit au passage la variable automatique $Matches avec ce qui a été trouvé.

Par défaut, -match est insensible à la casse. Utilise -cmatch pour distinguer majuscules et minuscules.

Capturer avec des groupes

Des parenthèses autour d'une portion du motif créent un groupe de capture : son contenu est rangé dans $Matches[1], $Matches[2]… Bien plus lisible : on peut nommer un groupe avec (?<nom>…) et le relire par son nom.

Réécrire avec -replace

L'opérateur -replace remplace ce qui correspond au motif. Dans le texte de remplacement, $1, $2… réinjectent les groupes capturés : idéal pour reformater.

Attention : le motif d'abord, le texte ensuite

Dans chaîne -replace motif, remplacement, le premier argument est une regex, le second une chaîne. Pour insérer un $ littéral dans le remplacement, il faut le doubler : '$$'.

Découper avec -split, aiguiller avec switch -regex

-split coupe une chaîne partout où le motif correspond ; switch -regex compare une valeur à plusieurs motifs et exécute le premier bloc qui correspond.

Fouiller des fichiers : Select-String

Select-String est le « grep » de PowerShell — mais fidèle à l'esprit maison, il renvoie des objets (MatchInfo) portant le nom du fichier, le numéro de ligne, la ligne entière et les groupes capturés.

Un cas réel — analyser un journal web

Cas réel : qui a provoqué les erreurs 500 ?

Après un incident, on veut connaître les adresses IP à l'origine des erreurs serveur (code 500) dans un journal d'accès, et les compter. Une regex isole l'IP et le code ; le pipeline fait le reste.

Résultat : le top 5 des IP fautives, prêtes à être bloquées. Aucun découpage de texte à la main : la regex nomme, le pipeline agrège.

Astuce et garde-fous

Astuce : chercher un texte littéral

Si tu veux rechercher un texte fixe contenant des caractères spéciaux (un point, un +…), échappe-le avec [regex]::Escape("192.168.0.1"), ou passe -SimpleMatch à Select-String : le point ne veut alors plus dire « n'importe quel caractère ».

Piège fréquent : le quantificateur glouton

.* capture le plus possible. Sur <a><b>, le motif <.*> prend tout d'un coup. Rends-le paresseux avec .*?, ou sois plus précis : [^>]*. Pense aussi aux ancres ^ et $ pour coller au début ou à la fin.

Pour aller plus loin

Pour aller plus loin

Sous le capot, c'est la classe .NET [regex] : [regex]::Matches($texte, $motif) renvoie toutes les correspondances d'un coup. En PowerShell 7, -replace accepte même un bloc de script comme remplacement : 'a1b2' -replace '\d', { [int]$_.Value * 2 }.

Antisèche — expressions régulières

Glossaire

Expression régulière
Motif décrivant une forme de texte (chiffres, mots, dates…) plutôt qu'un texte exact.
-match
Opérateur qui teste si un texte contient le motif ; remplit $Matches.
$Matches
Table de hachage automatique contenant le fragment trouvé et les groupes capturés.
Groupe de capture
Portion du motif entre parenthèses dont le contenu est mémorisé.
Groupe nommé
Groupe (?<nom>…) relu par son nom plutôt que par son numéro.
-replace
Opérateur qui réécrit ce qui correspond au motif ; $1… réinjectent les groupes.
Quantificateur
+, *, ?, {n,m} : combien de fois l'élément se répète.
Select-String
Cmdlet qui cherche un motif dans des fichiers et renvoie des objets MatchInfo.

Récap et vérification

  • -match teste et remplit $Matches ; -cmatch tient compte de la casse.
  • Les groupes (?<nom>…) capturent des fragments, réutilisés dans $Matches ou via $1 dans -replace.
  • -split découpe, switch -regex aiguille, Select-String fouille des fichiers.
  • Attention aux quantificateurs gloutons (.*) : rends-les paresseux (.*?) ou plus précis.
