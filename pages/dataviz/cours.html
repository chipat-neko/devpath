Data visualisation : donner à voir les données

Un tableau de chiffres se lit ligne par ligne ; un bon graphique se comprend d'un coup d'œil. La data visualisation est l'art — et la discipline — de traduire des données en formes visuelles qui disent vrai. Ce cours t'apprend à choisir la forme selon la question posée, à maîtriser les graphiques essentiels (barres, courbes, distributions, nuages, compositions, cartes), à régler l'échelle, la couleur et la densité, à annoter pour raconter — et à démasquer les graphiques qui trompent.

Bien s'équiper

À installer pour visualiser

  • Python (Microsoft) — exécution, environnement et débogage.
  • Jupyter (Microsoft) — notebooks interactifs : chaque graphique s'affiche sous sa cellule.
  • Pylance (Microsoft) — auto-complétion des API matplotlib et pandas.
  • Data Wrangler (Microsoft) — explorer et profiler un tableau avant de le tracer.

Pour qui ?

Idéal si tu sais déjà manipuler des données — un peu de Python et de pandas aide, mais le cœur du cours est conceptuel et vaut pour n'importe quel outil (Excel, R, Tableau…). Aucune statistique avancée n'est supposée. Le code n'est pas exécuté dans le site : chaque graphique est dessiné pour être vu, et le code matplotlib qui le produit est montré à côté.

Ce que tu vas apprendre

De la question au graphique juste

À la fin du cours, tu sauras

  • choisir la bonne forme selon la question (comparer, évoluer, distribuer, corréler, composer) ;
  • construire et lire les graphiques essentiels : barres, courbes, histogrammes, boîtes à moustaches, nuages de points, cartes ;
  • régler l'échelle et l'axe zéro, la couleur (et le daltonisme), la densité et les petits multiples ;
  • annoter pour porter un message, et repérer les graphiques qui mentent.

Pour qui, et pourquoi

Ce cours s'adresse aux futurs data analysts, développeurs, journalistes de données, chefs de projet — à toute personne qui doit montrer des données et non seulement les calculer. Savoir produire un tableau ne suffit pas : c'est le graphique qui convainc, alerte ou trompe. Ce cours prolonge naturellement pandas : une fois les données prêtes, il faut les donner à voir.

Chaque leçon est autonome et illustrée par des graphiques dessinés — bons et mauvais exemples côte à côte — avec le code matplotlib qui les produit. Le fil rouge : les données ouvertes d'une ville fictive, Belleville, qui offrent toutes les formes de données (fréquentation, climat, trajets, logements, quartiers).

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Un graphique encode des données en canaux visuels : la position et la longueur se lisent le mieux, la couleur et l'aire moins bien.
  • On choisit la forme selon la question : comparer → barres, évoluer → courbe, distribuer → histogramme/boîte, corréler → nuage, composer → barre empilée.
  • Les barres partent de zéro ; un axe tronqué exagère. Réserve l'échelle log aux ordres de grandeur.
  • La couleur encode une variable : palette séquentielle, divergente ou qualitative ; teste le daltonisme et ne code jamais que par la couleur.
  • Gère la densité : transparence, agrégation, petits multiples plutôt qu'un nuage illisible.
  • Une carte choroplèthe montre un taux, pas des effectifs bruts (sinon c'est une carte de population).
  • Un bon graphique a un titre-message, s'épure (rapport data-encre) et s'annote pour raconter.
Encodage visuel
Traduction d'une donnée en attribut graphique (position, longueur, aire, couleur, forme) ; certains canaux se lisent plus précisément que d'autres.
Marque & canal
La marque est l'objet dessiné (barre, point, ligne) ; le canal est la propriété qui porte la donnée (sa position, sa taille, sa couleur).
Axe zéro
Origine d'un axe. Obligatoire pour des barres ; le tronquer exagère visuellement les écarts.
Distribution
Façon dont se répartissent les valeurs d'une variable ; se montre par un histogramme ou une boîte à moustaches.
Nuage de points
Graphique reliant deux variables numériques, un point par observation ; révèle corrélation, tendance et valeurs aberrantes.
Palette séquentielle / divergente / qualitative
Trois familles de couleurs : dégradé ordonné, deux pôles autour d'un centre, teintes distinctes pour des catégories.
Choroplèthe
Carte où chaque zone est colorée selon une valeur ; à exprimer en taux normalisé, jamais en effectif brut.
Rapport data-encre
Principe de Tufte : maximiser la part d'encre qui porte de l'information, retirer le décor inutile.
