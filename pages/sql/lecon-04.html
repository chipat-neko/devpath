Module 02 · Calculer et agréger — Leçon 04

Fonctions et expressions

~33 min Débutant Module 1 recommandé

À la fin de cette leçon, tu sauras

  • savoir écrire des expressions de calcul dans SELECT et nommer le résultat avec AS ;
  • savoir utiliser les fonctions courantes de chaînes, de nombres et de dates ;
  • savoir remplacer les NULL avec COALESCE et écrire des conditions avec CASE ;
  • savoir convertir un type avec CAST et reconnaître les variantes selon le SGBD.
Sommaire de la leçon

Jusqu'ici, tu sais lire des colonnes telles qu'elles sont stockées avec SELECT … FROM. Mais une requête peut faire bien plus que recopier des valeurs : elle peut calculer, transformer et combiner les données au moment de l'affichage. Multiplier un prix par une quantité, mettre un nom en majuscules, arrondir un montant, remplacer une valeur manquante : tout cela se fait directement dans le SELECT.

Dans cette leçon, tu vas découvrir les expressions et les fonctions les plus utiles. On travaille sur une petite table produits, que voici :

idnomprixquantiteremise
1Clavier25.04NULL
2Souris12.5102.0
3Écran149.992NULL
4Câble HDMI7.0201.5

La table produits utilisée dans tous les exemples.

Les expressions et les alias avec AS

Une expression, c'est un petit calcul écrit dans le SELECT. Tu peux utiliser les opérateurs +, -, * et / avec des colonnes et des nombres. Par exemple, calculer la valeur totale en stock (prix multiplié par quantité) :

Le mot-clé AS donne un alias, c'est-à-dire un nom lisible à la colonne calculée. Sans lui, l'en-tête afficherait quelque chose comme prix * quantite, peu pratique.

nomtotal
Clavier100.0
Souris125.0
Écran299.98
Câble HDMI140.0

Une nouvelle colonne total apparaît, calculée ligne par ligne.

Note

Le mot AS est facultatif : prix * quantite total fonctionne aussi. Mais l'écrire rend la requête bien plus claire. Si ton alias contient un espace, mets-le entre guillemets doubles : AS "valeur en stock".

Les fonctions de chaînes

Une fonction prend une valeur entre parenthèses et en renvoie une autre. Pour le texte, les plus courantes sont UPPER (majuscules), LOWER (minuscules), LENGTH (longueur) et TRIM (supprime les espaces au début et à la fin).

nom_majusculelongueur
CLAVIER7
SOURIS6
ÉCRAN5
CÂBLE HDMI10

UPPER transforme le texte ; LENGTH compte les caractères.

Pour extraire une partie d'un texte, SUBSTRING prend la chaîne, la position de départ et le nombre de caractères. La syntaxe standard s'écrit avec les mots FROM et FOR :

nomdebut
ClavierCla
SourisSou
ÉcranÉcr
Câble HDMICâb

SUBSTRING(nom FROM 1 FOR 3) garde les trois premiers caractères. MySQL accepte aussi la forme SUBSTRING(nom, 1, 3).

Enfin, la concaténation colle deux textes. En SQL standard, on utilise l'opérateur || :

etiquette
Clavier : 25.0
Souris : 12.5
Écran : 149.99
Câble HDMI : 7.0

L'opérateur || assemble texte et valeurs en une seule colonne.

Piège fréquent

La concaténation change selon le SGBD. || est le standard (PostgreSQL, SQLite, Oracle). MySQL utilise plutôt la fonction CONCAT(nom, ' : ', prix), et SQL Server l'opérateur +. La fonction CONCAT(…) est le plus portable : elle existe sur PostgreSQL, MySQL et SQL Server (et sur SQLite depuis sa version 3.44).

Les fonctions numériques

Pour les nombres, retiens ROUND (arrondir), ABS (valeur absolue), CEIL / FLOOR (arrondir au-dessus / en-dessous) et MOD (reste d'une division). ROUND accepte un second argument : le nombre de décimales.

nomprix_ttcplancher
Clavier30.025
Souris15.012
Écran179.99149
Câble HDMI8.47

ROUND(…, 2) garde deux décimales ; FLOOR ramène à l'entier inférieur.

Piège fréquent

Attention à la division entière. Si deux nombres entiers sont divisés, certains moteurs renvoient un entier : 7 / 2 donne 3 et non 3.5. Pour forcer un résultat décimal, écris 7.0 / 2 ou convertis avec CAST (voir plus bas).

Les fonctions de date

Pour obtenir la date du jour, le standard propose CURRENT_DATE (et CURRENT_TIMESTAMP pour la date avec l'heure). Pour isoler une partie d'une date — l'année, le mois, le jour — on utilise EXTRACT :

aujourd_huiannee
2026-06-102026

EXTRACT(YEAR FROM …) renvoie seulement l'année sous forme de nombre.

Note

Les dates sont le domaine où les SGBD divergent le plus. MySQL propose NOW() et YEAR(ma_date) ; PostgreSQL suit le standard EXTRACT ; SQLite, qui n'a pas de vrai type date, utilise strftime('%Y', ma_date). Vérifie toujours la documentation de ton moteur.

Gérer les valeurs NULL

Une cellule vide en SQL vaut NULL : c'est une absence de valeur, pas un zéro. Le problème : tout calcul impliquant NULL donne NULL. Dans notre table, la remise est parfois absente. Calculer prix - remise donnerait donc NULL pour le Clavier et l'Écran.

La fonction COALESCE résout cela : elle renvoie la première valeur non NULL de sa liste. On l'utilise pour fournir une valeur par défaut :

nomprix_remise
Clavier25.0
Souris10.5
Écran149.99
Câble HDMI5.5

Sans COALESCE, le Clavier et l'Écran auraient affiché NULL.

À l'inverse, NULLIF(a, b) renvoie NULL si a est égal à b. C'est pratique pour éviter une division par zéro : montant / NULLIF(quantite, 0) renvoie NULL plutôt que de provoquer une erreur quand la quantité vaut 0.

Des valeurs conditionnelles avec CASE

Le CASE est un « si… alors… sinon » qui choisit une valeur selon une condition. Sa forme est : CASE WHEN condition THEN valeur ELSE autre_valeur END. Tu peux enchaîner plusieurs WHEN.

nomprixgamme
Clavier25.0moyen
Souris12.5abordable
Écran149.99cher
Câble HDMI7.0abordable

SQL teste les WHEN dans l'ordre et s'arrête au premier vrai.

Convertir un type avec CAST

Parfois, une valeur n'est pas dans le bon type : un nombre stocké en texte, ou un entier qu'on veut traiter en décimal. CAST(valeur AS type) effectue la conversion. C'est aussi une solution propre au piège de la division entière :

nomprix_entierpart
Clavier251.333…
Souris123.333…
Écran1490.666…
Câble HDMI76.666…

En convertissant quantite en décimal, la division garde ses décimales.

Cas réel

Le back-office d'une boutique affiche, pour chaque article, une ligne prête à lire : UPPER(nom) pour le titre, ROUND(prix * 1.2, 2) pour le prix TTC, un badge de gamme calculé par CASE, et COALESCE(remise, 0) pour ne pas laisser de trou quand aucune remise n'est saisie. Aucune de ces valeurs n'est stockée dans la table : elles sont toutes calculées à la volée par la requête d'affichage.

Pièges fréquents

  • La concaténation diffère selon le moteur. || (standard, PostgreSQL, SQLite), CONCAT(…) (MySQL et autres), + (SQL Server). Ne mélange pas les styles.
  • Tout calcul avec NULL vaut NULL. Une addition, une soustraction ou une concaténation impliquant une valeur absente renvoie NULL. Protège-toi avec COALESCE.
  • Division entière contre décimale. 7 / 2 peut donner 3. Utilise 7.0 / 2 ou CAST(… AS DECIMAL) pour obtenir 3.5.
  • Un alias ne s'utilise pas dans WHERE. Le WHERE est évalué avant que l'alias n'existe. Tu dois répéter l'expression. En revanche, ORDER BY accepte l'alias.

Piège fréquent

Ceci échoue : SELECT prix * quantite AS total FROM produits WHERE total > 100;. L'alias total n'existe pas encore au moment du WHERE. Écris plutôt WHERE prix * quantite > 100. Par contre, ORDER BY total est autorisé.

Antisèche : fonctions et expressions

Les transformations de cette leçon, rangées par famille.

Glossaire

Expression
Calcul écrit dans le SELECT combinant colonnes, opérateurs et fonctions ; évalué ligne par ligne.
Alias (AS)
Nom lisible donné à une colonne calculée ; utilisable dans ORDER BY, mais pas dans WHERE.
Fonction
Opération nommée qui prend des arguments entre parenthèses et renvoie une valeur : ROUND(…), UPPER(…).
Concaténation
Mise bout à bout de textes avec || (standard) ou CONCAT(…) (portable).
NULL
Absence de valeur ; tout calcul l'impliquant renvoie NULL.
COALESCE
Renvoie la première valeur non NULL de sa liste ; sert à donner une valeur par défaut.
CASE
Expression conditionnelle « si… alors… sinon » ; teste les WHEN dans l'ordre, garde le premier vrai.
CAST
Conversion explicite d'une valeur vers un autre type : CAST(quantite AS DECIMAL).

Récap et vérification

  • Une expression calcule dans le SELECT ; AS nomme le résultat.
  • Fonctions de chaînes : UPPER, LOWER, LENGTH, SUBSTRING, TRIM, concaténation avec || ou CONCAT.
  • Fonctions numériques : ROUND, ABS, CEIL, FLOOR, MOD.
  • Fonctions de date : CURRENT_DATE, EXTRACT (variantes NOW(), strftime).
  • COALESCE remplace les NULL ; NULLIF crée un NULL conditionnel.
  • CASE WHEN … THEN … ELSE … END choisit une valeur ; CAST convertit un type.
