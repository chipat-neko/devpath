Conditions et boucles

~30 min Débutant Leçon 2 recommandée

À la fin de cette leçon, tu sauras

  • Écrire des conditions avec if, elseif, else, le ternaire et match (PHP 8) ;
  • Parcourir et répéter avec for, while, do...while et surtout foreach ;
  • Contrôler une boucle avec break et continue, et reconnaître les valeurs truthy/falsy ;
  • Utiliser la syntaxe alternative (if: / endif;, foreach: / endforeach;) pour mélanger PHP et HTML.
Sommaire de la leçon

Jusqu'ici ton code PHP s'exécutait ligne après ligne, toujours dans le même ordre. Mais un vrai programme doit décider (afficher « Bonjour » ou « Bonsoir » selon l'heure) et répéter (afficher 50 produits sans réécrire 50 fois le même HTML). C'est exactement le rôle des conditions et des boucles.

Souviens-toi : tout ce code tourne sur le serveur. PHP exécute tes if et tes foreach, puis envoie au navigateur uniquement le HTML final. Pour lancer les exemples, on utilise le serveur intégré : dans le dossier de ton fichier, démarre-le puis ouvre l'adresse dans ton navigateur.

Démarre le serveur PHP, puis ouvre http://localhost:8000 dans ton navigateur.

1. if / elseif / else et le ternaire

Un if exécute un bloc seulement si une condition est vraie. Tu peux enchaîner des cas avec elseif et prévoir un cas par défaut avec else.

Pour un choix simple entre deux valeurs, le ternaire condition ? siVrai : siFaux est plus court.

2. switch (avec break) et surtout match

Le switch compare une valeur à plusieurs cas. Attention : sans break, PHP « tombe » dans le cas suivant (le fameux fall-through).

En PHP moderne, préfère match (PHP 8). Il renvoie une valeur, compare en strict (===, donc pas de surprise entre 1 et "1"), et n'a pas de fall-through : pas besoin de break.

Note

Plusieurs valeurs peuvent partager le même résultat : sépare-les par une virgule, comme 200, 201 => "OK".

3. Les boucles : for, while, do...while

Une boucle répète un bloc. for est idéale quand tu connais le nombre de tours : tu écris l'initialisation, la condition et l'incrément sur une ligne.

while répète tant que la condition reste vraie (elle est testée avant chaque tour). do...while exécute le bloc au moins une fois, puis teste la condition à la fin.

4. foreach : la boucle reine des tableaux

Pour parcourir un tableau, foreach est la plus simple et la plus sûre. Elle te donne directement chaque élément, sans gérer d'indice à la main.

Avec un tableau associatif, récupère la clé et la valeur en même temps grâce à $cle => $valeur.

5. break et continue

break arrête complètement la boucle. continue saute le tour en cours et passe au suivant.

6. La syntaxe alternative dans du HTML

Quand tu mélanges PHP et HTML dans une page, les accolades { } deviennent vite illisibles. PHP propose une syntaxe alternative avec : et un mot-clé de fermeture (endif;, endforeach;) : parfaite pour les templates.

Astuce

La balise courte <?= ... ?> est un raccourci pour <?php echo ... ?>. Passe toujours le texte par htmlspecialchars() pour échapper la sortie et éviter qu'un contenu malveillant ne s'exécute dans la page.

7. Les valeurs truthy et falsy

Dans un if, PHP convertit la valeur en booléen. Certaines valeurs sont considérées comme fausses (falsy) : false, 0, 0.0, "" (chaîne vide), "0" (le piège !), null et [] (tableau vide). Tout le reste est vrai (truthy).

Pièges fréquents

Piège fréquent

Ne confonds pas = et ==. $x = 5 affecte 5 à $x (toujours vrai), alors que $x == 5 compare. Un if ($x = 5) est presque toujours un bug. Préfère même === qui compare valeur ET type.

Piège fréquent

Oublier break dans un switch fait exécuter les cas suivants. Et la chaîne "0" est falsy : un champ contenant « 0 » sera vu comme vide dans un if ! C'est l'une des raisons de préférer match et les comparaisons strictes.

Piège fréquent

Un match sans cas correspondant et sans default lève une erreur UnhandledMatchError qui casse la page. Ajoute presque toujours une branche default. Et en syntaxe alternative, n'oublie jamais le endif; ou endforeach; de fermeture, sinon la page reste incomplète.

Pour aller plus loin

Pour aller plus loin

L'opérateur Elvis ?: renvoie la valeur de gauche si elle est truthy, sinon celle de droite : $nom ?: "Anonyme". Tu peux aussi imbriquer plusieurs foreach en syntaxe alternative pour des listes dans des listes. Enfin, array_map() applique une fonction à chaque élément d'un tableau sans écrire de boucle : array_map(fn($p) => $p * 2, $prix) avec une arrow function. On l'utilisera plus tard avec les tableaux.

Un cas réel : le « 0 » qui refusait de quitter le panier

Cas réel

Une boutique en ligne laissait ses clients ajuster la quantité d'un article avant paiement. Le code de mise à jour ressemblait à if ($_POST['quantite']) { mettreAJour(); } pour « ne traiter que si une quantité a été saisie ». Problème : taper 0 pour retirer un article ne faisait rien. La valeur "0" reçue du formulaire est falsy en PHP : la condition était fausse, la ligne restait dans le panier et le client se retrouvait facturé pour un produit qu'il croyait avoir enlevé. Le même piège frappe un champ « numéro de rue : 0 », un solde de 0 € ou l'entier 0 comme identifiant valide. La parade : ne jamais tester la simple « vérité » d'une saisie, mais son existence puis son format : if (($_POST['quantite'] ?? '') !== ''), suivi d'une validation numérique. Retiens la liste des valeurs falsy — surtout le traître "0".

Antisèche

Glossaire

Condition
Expression évaluée à vrai ou faux qui décide si un bloc s'exécute ; construite avec if/elseif/else, le ternaire ou match.
Ternaire
Raccourci condition ? siVrai : siFaux qui renvoie l'une de deux valeurs selon la condition ; à réserver aux choix simples pour rester lisible.
match
Expression de PHP 8 qui compare une valeur en strict (===), renvoie un résultat et n'a pas de fall-through ; lève une erreur si aucun cas ne correspond sans default.
Boucle
Structure qui répète un bloc : for (nombre de tours connu), while/do…while (tant qu'une condition tient), foreach (chaque élément d'un tableau).
foreach
Boucle dédiée aux tableaux ; foreach ($t as $cle => $valeur) expose la clé et la valeur sans gérer d'indice à la main.
break / continue
break arrête complètement la boucle ; continue saute le tour courant et passe au suivant.
Truthy / Falsy
Valeurs converties en vrai ou faux dans un contexte booléen ; falsy : false, 0, 0.0, "", "0", null, []. Tout le reste est truthy.
Syntaxe alternative
Écriture if: … endif;, foreach: … endforeach; qui remplace les accolades ; parfaite pour mêler proprement PHP et HTML dans un template.

Récap et vérification

  • if / elseif / else et le ternaire ? : pour décider ; === compare valeur et type.
  • match (PHP 8) renvoie une valeur, compare en strict, sans break ni fall-through — préfère-le au switch.
  • for, while, do...while pour répéter ; foreach pour parcourir un tableau (avec $cle => $valeur).
  • break arrête la boucle, continue saute un tour.
  • Syntaxe alternative (if:/endif;, foreach:/endforeach;) pour mélanger PHP et HTML proprement.
  • Valeurs falsy : false, 0, "", "0", null, [] — attention à "0" !
