Fonctions et tableaux

~34 min Débutant Leçon 3 recommandée

À la fin de cette leçon, tu sauras

  • Savoir écrire une fonction typée en PHP avec paramètres, valeur de retour et valeurs par défaut ;
  • Savoir créer et parcourir des tableaux indexés et associatifs avec foreach ;
  • Savoir utiliser les fonctions de tableau essentielles (count, array_map, array_filter…) ;
  • Comprendre la portée des variables et écrire des arrow functions avec fn().
Sommaire de la leçon

Jusqu'ici tu as écrit des bouts de code qui s'exécutent de haut en bas. Mais dès qu'un programme grandit, tu répètes les mêmes opérations et tu manipules des listes de données : une liste de prénoms, un panier d'articles, une fiche utilisateur. Deux outils règlent ces deux problèmes : les fonctions (pour factoriser et nommer un morceau de logique) et les tableaux (pour stocker plusieurs valeurs ensemble).

Rappelle-toi : tout ce code tourne sur le serveur. PHP exécute tes fonctions, parcourt tes tableaux, puis génère du HTML qui est envoyé au navigateur. Le visiteur ne voit jamais le PHP, seulement le résultat. On affichera donc les sorties en commentaire (// …) ou dans un bloc « Sortie ».

Écrire une fonction

Une fonction est un bloc de code réutilisable qui porte un nom. Tu lui donnes des paramètres (les données d'entrée) et elle te rend une valeur de retour avec return. En PHP moderne, on type les paramètres et le retour : c'est fortement recommandé, ça documente le code et ça attrape les erreurs tôt.

Ici string $nom dit que le paramètre doit être une chaîne, et : string après les parenthèses dit que la fonction renvoie une chaîne. Tu peux aussi donner une valeur par défaut à un paramètre : il devient alors facultatif.

Note

Les paramètres avec valeur par défaut doivent venir après ceux sans défaut. Sinon PHP ne sait pas quel argument va où.

La portée des variables

Une variable créée à l'intérieur d'une fonction n'existe que dans cette fonction. Et inversement : une fonction ne « voit » pas les variables définies à l'extérieur. C'est la portée (scope). C'est volontaire : ça évite que tes fonctions s'emmêlent entre elles.

La bonne pratique est de passer les données dont la fonction a besoin par ses paramètres, plutôt que de compter sur des variables globales. Ton code reste prévisible et testable : avec les mêmes entrées, tu obtiens toujours la même sortie.

Les arrow functions

Pour les petites fonctions d'une seule expression, PHP 8 propose une écriture courte : la fonction fléchée fn() => …. Particularité bien pratique : elle capture automatiquement les variables environnantes (pas besoin de les passer ni d'écrire use).

Une arrow function tient sur une seule expression (pas de bloc { … } ni de return à écrire : le résultat de l'expression est renvoyé). On les utilise surtout combinées avec les fonctions de tableau, qu'on voit plus bas.

Les tableaux : indexés et associatifs

Un tableau (array) stocke plusieurs valeurs dans une seule variable. Il en existe deux usages, mais c'est le même type en PHP. Le tableau indexé range les valeurs par numéro de position, en commençant à 0. Le tableau associatif range les valeurs par clé (un nom que tu choisis).

Les crochets [ … ] sont la syntaxe moderne pour créer un tableau (tu verras parfois l'ancienne forme array( … ), c'est la même chose).

Accéder, ajouter, modifier

On lit et on écrit une case avec les crochets. Pour ajouter une valeur à la fin d'un tableau indexé, on utilise la syntaxe courte $t[] = … : PHP attribue tout seul le prochain index.

Parcourir avec foreach

foreach est la boucle reine pour les tableaux : elle passe sur chaque élément sans que tu aies à gérer un compteur. Sur un tableau associatif, tu récupères en plus la clé.

Astuce

Quand tu génères du HTML à partir d'un tableau (une liste de produits par exemple), foreach est ton outil principal. Pense à échapper chaque valeur affichée avec htmlspecialchars() pour éviter les injections.

Les fonctions de tableau essentielles

PHP fournit une grande boîte à outils pour les tableaux. En voici les plus utiles au quotidien.

Sur un tableau associatif, array_keys() renvoie la liste des clés et array_values() la liste des valeurs. array_values() sert d'ailleurs à « réindexer » proprement le résultat d'un array_filter() si tu veux retrouver des clés 0, 1, 2….

Les tableaux multidimensionnels

Un tableau peut contenir d'autres tableaux. C'est ainsi qu'on représente une liste d'objets : par exemple une liste d'utilisateurs, chacun étant un tableau associatif.

Pièges fréquents

Piège fréquent

Oublier le typage. Sans string, int ou : float, PHP accepte n'importe quoi et tu obtiens des bugs silencieux (une chaîne traitée comme un nombre, par exemple). Type tes paramètres et tes retours dès le départ.

Piège fréquent

Modifier un tableau pendant un foreach par valeur ne change rien : tu travailles sur une copie. Pour modifier les éléments en place, on peut utiliser la référence foreach ($t as &$v), mais à manier avec prudence : pense à faire unset($v); après la boucle pour éviter des effets de bord surprenants.

Piège fréquent

Confondre indexé et associatif. $t[0] n'existe pas si ton tableau a des clés texte, et accéder à une clé absente déclenche un avertissement. Vérifie d'abord avec isset($t["nom"]) en cas de doute.

Pour aller plus loin

Pour aller plus loin

La déstructuration [$a, $b] = [1, 2]; extrait des valeurs d'un coup. Les fonctions variadiques function somme(int ...$n) acceptent un nombre libre d'arguments. Les arguments nommés saluer(nom: "Léa") rendent les appels lisibles. Enfin array_reduce() agrège un tableau en une seule valeur, et les Collections des frameworks (Laravel, Symfony) offrent une API objet plus riche par-dessus les tableaux.

Un cas réel : l'API dont le tableau devenait un objet

Cas réel

Une équipe exposait une API qui renvoyait les produits en promotion. Le code filtrait le catalogue avec array_filter($produits, fn($p) => $p['promo']) puis json_encode(). En développement, tout marchait ; en production, l'application mobile plantait dès qu'un produit du milieu de la liste était en promo. Cause : array_filter conserve les clés d'origine. Si les éléments gardés portent les clés 0, 2, 5, json_encode ne voit plus un tableau « 0, 1, 2… » mais un objet {"0":…,"2":…,"5":…} — et le client, qui attendait un tableau JSON, échouait. La correction tenait en un appel : array_values(array_filter(...)) pour réindexer proprement à partir de 0. Depuis, la règle d'équipe est simple : après un array_filter destiné au JSON, toujours array_values().

Antisèche

Glossaire

Fonction
Bloc de code nommé et réutilisable ; reçoit des paramètres, exécute une logique et renvoie une valeur avec return.
Paramètre / Argument
Le paramètre est la variable déclarée dans la signature ; l'argument est la valeur réelle passée à l'appel. On type les paramètres (int $x) pour attraper les erreurs tôt.
Type de retour
Type de la valeur renvoyée, écrit après les parenthèses (: string, : float) ; documente le contrat et fait échouer un return incohérent.
Portée (scope)
Zone de visibilité d'une variable ; celles créées dans une fonction n'existent pas dehors, et l'inverse : passe les données par paramètres.
Arrow function
Fonction courte d'une seule expression : fn($x) => … ; capture automatiquement les variables environnantes, sans use.
Tableau (array)
Structure qui stocke plusieurs valeurs ; indexé (clés 0, 1, 2…) ou associatif (clés choisies), c'est le même type en PHP.
Tableau associatif
Tableau dont les clés sont des noms que tu choisis (["nom" => "Léa"]) ; on le parcourt avec foreach ($t as $cle => $valeur).
array_map / array_filter
array_map transforme chaque élément (même taille) ; array_filter sélectionne selon un test et garde les clés (pense à array_values()).

Récap et vérification

  • Une fonction factorise du code : paramètres typés, return et type de retour, valeurs par défaut.
  • La portée isole les variables : passe les données par paramètres.
  • Les arrow functions fn($x) => … sont des fonctions courtes qui capturent leur contexte.
  • Les tableaux (indexés ou associatifs) sont le même type array ; on les parcourt avec foreach.
  • Boîte à outils : count, array_map, array_filter, in_array, sort, implode/explode.

  3. Quand utiliser array_map plutôt que array_filter ?
