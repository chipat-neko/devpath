PHP : le web côté serveur

Une énorme partie du web tourne sous PHP : WordPress, Wikipédia, d'innombrables sites et API. C'est le langage qui génère des pages dynamiques sur le serveur, traite les formulaires et dialogue avec les bases de données. Ce cours te mène des bases aux formulaires, à la sécurité, à la POO et à PDO : de quoi construire un vrai back-end.

Bien s'équiper

Les extensions VS Code pour PHP

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour PHP

  • PHP Intelephense (Ben Mewburn) — IntelliSense PHP rapide.
  • PHP Debug (Xdebug) — débogage avec Xdebug.
  • PHP DocBlocker (Neil Brayfield) — génère les blocs de documentation.
  • PHP Namespace Resolver (Mehedi Hassan) — importe et trie les namespaces.

Pour qui ?

Aucun prérequis en programmation. Connaître un peu de HTML aide, car PHP s'imbrique dans les pages pour les rendre dynamiques. On part du tout début.

Ce que tu vas apprendre

Des bases à un back-end complet

À la fin du cours, tu sauras

  • écrire du PHP (types, conditions, boucles, fonctions) et l'imbriquer dans des pages HTML ;
  • manipuler les tableaux et traiter les formulaires ($_GET, $_POST), gérer sessions et cookies ;
  • sécuriser une application : injection SQL, XSS, CSRF et hachage des mots de passe ;
  • structurer en objets (POO, namespaces), interroger une base avec PDO et utiliser Composer.

Pour qui, et pourquoi

Ce cours s'adresse à qui veut créer des sites et des applications web dynamiques côté serveur : futurs développeurs back-end, intégrateurs WordPress, ou curieux qui veulent comprendre ce qui se passe « derrière » une page. PHP est facile à déployer, omniprésent, et reste très demandé.

Chaque leçon est illustrée par du code commenté. Le code s'exécute sur un serveur (il ne tourne pas dans l'éditeur du site) : les sorties sont montrées en commentaire.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Le code PHP s'ouvre avec <?php ; les variables commencent par $.
  • Afficher avec echo.
  • Tableaux associatifs avec => (clé => valeur).
  • Concaténer les chaînes avec le point (.).
  • POO : classes, accès via $this->propriete.
  • Requêtes préparées (PDO) contre l'injection SQL.
