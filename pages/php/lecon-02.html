Variables, types et opérateurs

~33 min Débutant Leçon 1 recommandée

À la fin de cette leçon, tu sauras

  • savoir créer une variable avec le préfixe $ et reconnaître les types string, int, float, bool et null ;
  • savoir construire des chaînes avec l'interpolation en guillemets doubles, la concaténation . et le heredoc ;
  • savoir comparer en toute sécurité avec === plutôt que == et utiliser l'opérateur null-coalescent ?? ;
  • savoir définir des constantes et inspecter une valeur avec var_dump.
Sommaire de la leçon

Dans la leçon précédente, tu as vu que PHP s'exécute sur le serveur et fabrique du HTML qu'il renvoie au navigateur. Pour produire ce HTML, il faut d'abord stocker et manipuler des données : un prénom, un prix, un nombre de messages non lus. C'est le rôle des variables, des types et des opérateurs.

Dans cette leçon, tu vas écrire de petits scripts dans un fichier index.php, les lancer avec le serveur intégré de PHP, et observer la sortie. Tu ne cliques sur aucun bouton : PHP tourne en dehors du navigateur, sur ta machine ou sur un vrai serveur.

Les variables : le préfixe $

En PHP, toute variable commence par un signe dollar $ suivi de son nom. Tu n'as pas besoin de déclarer son type : PHP le devine tout seul d'après la valeur. C'est ce qu'on appelle le typage dynamique.

Le nom de la variable est sensible à la casse : $nom et $Nom sont deux variables différentes.

Piège fréquent

Oublier le $. Si tu écris nom = "Léa";, PHP croit que nom est une constante ou une fonction et lève une erreur. Mets toujours le dollar : $nom.

Les types de base

Chaque valeur a un type. Les types que tu vas rencontrer tout le temps sont :

  • string : du texte, par exemple "Léa" ;
  • int : un entier, par exemple 17 ;
  • float : un nombre à virgule, par exemple 9.99 ;
  • bool : un booléen, true ou false ;
  • null : l'absence de valeur.

Plus tard tu verras aussi array (les tableaux) et object (les objets). Pour l'instant, ces cinq-là suffisent. Une même variable peut changer de type au fil du programme, mais évite de le faire sans raison : ça rend le code confus.

Les chaînes : guillemets doubles, simples, heredoc

C'est une particularité importante de PHP. Avec des guillemets doubles, PHP remplace les noms de variables par leur valeur : c'est l'interpolation. Avec des guillemets simples, le texte est pris au pied de la lettre, sans aucun remplacement.

Pour assembler deux chaînes, on utilise l'opérateur de concaténation, qui est le point . (et non + comme dans d'autres langages).

Quand la variable touche d'autres lettres, encadre-la d'accolades pour lever l'ambiguïté : "{$nom}s". Pour un long bloc de texte sur plusieurs lignes, le heredoc est pratique : il se comporte comme des guillemets doubles (interpolation active).

Astuce

Le marqueur de fin du heredoc (ici TEXTE;) doit être seul sur sa ligne. Choisis un mot que tu n'utilises pas dans le texte. Si tu n'as pas besoin d'interpolation, utilise le nowdoc avec des guillemets simples : <<<'TEXTE'.

Le type juggling : == contre ===

PHP fait des conversions automatiques de type quand il en a besoin : c'est le type juggling. Pratique, mais source de surprises. Le cœur du problème, c'est la comparaison.

L'opérateur == est lâche : il convertit les valeurs avant de comparer. L'opérateur === est strict : il compare la valeur et le type, sans rien convertir. Préfère toujours ===.

Le comportement de == a changé entre les versions de PHP. C'est exactement pour ça qu'on l'évite : === donne le même résultat partout, sans surprise.

Les opérateurs courants

Tu disposes des opérateurs arithmétiques classiques : +, -, *, /, % (modulo) et ** (puissance). Pour ajouter du texte à la fin d'une chaîne existante, l'opérateur .= est très utile.

Côté logique, on combine des conditions avec && (et), || (ou) et ! (non). Les opérateurs de comparaison sont <, >, <=, >=, === et !==.

Deux opérateurs modernes simplifient beaucoup le code. Le ternaire choisit entre deux valeurs selon une condition. L'opérateur null-coalescent ?? renvoie la valeur de gauche si elle existe et n'est pas null, sinon celle de droite : idéal pour une valeur par défaut.

Les constantes

Une constante est une valeur qui ne change jamais après sa définition. Par convention on l'écrit en MAJUSCULES, et elle n'a pas de $. Deux façons de la définir : le mot-clé const (au niveau du fichier ou d'une classe) ou la fonction define().

Inspecter avec var_dump

Quand tu ne sais pas ce que contient une variable, var_dump() te dit son type et sa valeur. C'est ton meilleur outil de débogage. À ne pas confondre avec echo, qui affiche juste la valeur brute.

Pour exécuter le script, lance le serveur intégré de PHP dans le dossier du fichier, puis ouvre http://localhost:8000 dans ton navigateur.

Le serveur sert index.php ; chaque rechargement de la page ré-exécute le script côté serveur.

Pièges fréquents

Piège fréquent

Confondre . et +. En PHP, on colle des chaînes avec .. Si tu écris "Article" + " stylo", PHP tente une addition de nombres : sur deux textes non numériques, il lève une TypeError en PHP 8. Pour concaténer, c'est toujours le point.

Piège fréquent

L'interpolation ne fonctionne qu'en guillemets doubles. 'Bonjour $nom' affiche littéralement Bonjour $nom. Accéder à une variable jamais définie déclenche un avertissement : protège-toi avec ??.

Pour aller plus loin

Pour aller plus loin

PHP moderne permet de fixer les types. declare(strict_types=1); en haut du fichier interdit les conversions silencieuses sur les arguments typés. Tu peux typer une propriété ou un paramètre (function prix(float $ht): float), regrouper des valeurs fixes dans un enum (PHP 8.1) et choisir une valeur avec match, plus sûr que la comparaison lâche car il compare avec === en interne.

Un cas réel : le == qui ouvrait la porte

Cas réel

Une famille de failles célèbres en PHP vient directement de l'égalité lâche ==. Du code d'authentification comparait deux empreintes (hash) avec ==. Or, avant PHP 8.0, deux chaînes de la forme "0esuivie de chiffres" — que certains hash produisent — étaient interprétées comme des nombres en notation scientifique (0 × 10…), donc toutes égales à 0. Résultat : "0e830400..." == "0e462097..." renvoyait true alors que les mots de passe étaient différents : c'est le contournement d'authentification par « magic hashes ». La parade tient en un caractère : comparer avec === (ou la fonction dédiée hash_equals()). PHP 8 a durci ==, mais la règle reste gravée : pour tout ce qui touche à la sécurité, jamais d'égalité lâche. Un simple troisième = ferme la porte.

Glossaire

Variable
Emplacement nommé qui stocke une valeur ; en PHP son nom commence toujours par $ et il est sensible à la casse ($nom ≠ $Nom).
Typage dynamique
PHP déduit le type d'une variable de la valeur affectée, sans déclaration ; une variable peut même changer de type (à éviter sans raison).
Interpolation
Remplacement des variables par leur valeur à l'intérieur d'une chaîne à guillemets doubles (ou d'un heredoc) ; les guillemets simples n'interpolent pas.
Concaténation
Assemblage de deux chaînes avec l'opérateur . (le point) ; .= ajoute à la fin d'une chaîne existante. En PHP, jamais +.
Type juggling
Conversions automatiques de type effectuées par PHP ; pratiques mais sources de surprises, surtout lors des comparaisons avec ==.
Égalité stricte ===
Compare la valeur ET le type sans convertir ; à préférer à l'égalité lâche ==, qui convertit d'abord et peut donner des résultats inattendus.
Opérateur ??
Null-coalescent : renvoie l'opérande de gauche si elle existe et n'est pas null, sinon celle de droite. Idéal pour une valeur par défaut, sans avertissement.
Constante
Valeur fixée une fois pour toutes (const ou define()), écrite par convention en MAJUSCULES et sans $.

Récap et vérification

  • Une variable commence par $ ; PHP devine son type (typage dynamique).
  • Types de base : string, int, float, bool, null.
  • Guillemets doubles = interpolation ; guillemets simples = littéral ; concaténation avec ..
  • Compare avec === (strict), pas == (lâche).
  • ?? donne une valeur par défaut ; les constantes s'écrivent sans $ ; var_dump() inspecte.

Vérifie ta compréhension

  1. Pourquoi 'Bonjour $nom' n'affiche-t-il pas le prénom, contrairement à "Bonjour $nom" ?
  2. Quelle différence entre "1" == 1 et "1" === 1 ? Lequel vaut-il mieux utiliser et pourquoi ?
  3. Que renvoie $couleur ?? "bleu" si $couleur n'a jamais été définie ?
