Markdown : rédiger en texte lisible

Markdown met en forme du texte avec quelques signes discrets, tout en restant lisible tel quel. C'est le format des README, de la documentation, des issues et des notes : un savoir-faire transversal utile à tout développeur. Ce cours court et pratique te le fait maîtriser de bout en bout.

Bien s'équiper

Les extensions VS Code pour Markdown

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils complètent l'aperçu Markdown déjà intégré à l'éditeur.

À installer pour Markdown

  • Markdown All in One (Yu Zhang) — raccourcis, sommaire et aperçu.
  • markdownlint (David Anson) — vérifie le style du Markdown.
  • Markdown Preview Enhanced (Yiyi Wang) — aperçu riche et export.
  • Paste Image (mushan) — coller une image directement dans le document.

Pour qui ?

Pour tout le monde : dès qu'on écrit un README, une issue ou une note, on écrit du Markdown. Aucun prérequis. Le cours complète bien Git (la doc vit dans le dépôt) et HTML (Markdown se convertit en HTML).

Ce que tu vas apprendre

Toute la syntaxe, et son bon usage

À la fin du cours, tu sauras

  • expliquer l'intérêt de Markdown et écrire titres, paragraphes, emphase, listes ;
  • insérer des liens, des images et des citations ;
  • afficher du code avec coloration, et créer des tableaux et listes de tâches (GFM) ;
  • rédiger un bon README et appliquer les bonnes pratiques.

Pour qui, et pourquoi

Markdown est l'outil d'écriture quotidien du développeur : documenter un projet, ouvrir une issue claire, prendre des notes, rédiger un article. Une fois appris, il sert partout, avec la même syntaxe simple. C'est l'un des apprentissages au meilleur rapport effort/utilité.

Ce cours est court et pratique : chaque leçon montre la syntaxe sur des exemples concrets, jusqu'à la rédaction d'un vrai README. Garde un aperçu Markdown ouvert pour voir le rendu en direct : c'est la meilleure façon d'apprendre.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • **gras**, *italique*, `code en ligne`.
  • Titres avec # (le nombre de # donne le niveau).
  • Listes : - (puces), 1. (numérotées).
  • Liens [texte](url) ; images ![alt](url).
  • Blocs de code entre trois accents graves.
