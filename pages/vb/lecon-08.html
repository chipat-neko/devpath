Module 3 · VB en pratique — Leçon 08

VB.NET : formulaires et événements

~50 min Avancé Prérequis : leçon 7

À la fin de cette leçon, tu sauras

  • situer VB.NET et la plateforme .NET ;
  • créer des classes et objets ;
  • construire une interface (Windows Forms) ;
  • réagir aux événements (clic, saisie).
Sommaire de la leçon

VBA automatise Office ; mais pour créer des applications complètes — avec fenêtres, boutons, bases de données — on passe à VB.NET, le Visual Basic moderne intégré à la plateforme .NET de Microsoft. Il reprend la syntaxe lisible que tu connais, en y ajoutant la puissance objet et l'immense bibliothèque .NET. Cette leçon présente VB.NET, les classes, et le modèle qui a fait le succès de Visual Basic : la programmation événementielle.

VB.NET et la plateforme .NET

.NET est l'écosystème de développement de Microsoft : une vaste bibliothèque de classes, un environnement d'exécution, et plusieurs langages qui le partagent (C#, F#, et VB.NET). Écrire en VB.NET, c'est accéder à tout cela : accès aux fichiers, au réseau, aux bases de données, à des interfaces graphiques riches.

Sub Main() est le point d'entrée d'une application VB.NET. Remarque qu'on peut déclarer et initialiser une variable sur une ligne : Dim nom As String = ….

Les classes : créer ses propres objets

VB.NET est pleinement orienté objet. Une classe est un modèle qui regroupe des données (propriétés) et des comportements (méthodes). On crée ensuite des objets à partir de ce modèle.

Une Property est un champ accessible de l'extérieur ; une Sub (ou Function) dans la classe est une méthode. New Personne() crée un objet. C'est le socle de toute application VB.NET structurée.

Les formulaires Windows

L'atout historique de Visual Basic, c'est de créer des interfaces visuellement. Avec Windows Forms, on dessine une fenêtre dans le concepteur de Visual Studio (boutons, zones de texte…), puis on écrit le code qui réagit aux actions de l'utilisateur. Chaque contrôle est un objet avec des propriétés (.Text, .Visible…) et des événements.

La programmation événementielle

Le cœur d'une application à fenêtres : le programme attend que l'utilisateur agisse, puis réagit. À chaque action (clic, saisie) correspond un événement, et on écrit une procédure qui s'exécute quand il se produit.

La clause Handles Button1.Click relie cette procédure à l'événement « clic du bouton ». Quand l'utilisateur clique, VB.NET appelle automatiquement la procédure. C'est ce modèle — « dessiner l'interface, coder les réactions » — qui a rendu Visual Basic si populaire : on crée une application fonctionnelle très vite.

Le caractère de continuation de ligne

Tu as peut-être remarqué le tiret bas _ en fin de ligne dans l'exemple précédent : il permet de couper une instruction longue sur plusieurs lignes pour la lisibilité. En VB.NET récent, il est souvent facultatif, mais on le rencontre fréquemment.

Pièges fréquents

Piège fréquent

Croire que le code VBA fonctionne tel quel en VB.NET. Beaucoup de choses se ressemblent, mais des différences existent : en VBA on écrit Set obj = … pour affecter un objet, ce qui a disparu en VB.NET ; MsgBox existe dans les deux mais MessageBox.Show est la forme .NET ; les bibliothèques diffèrent. Quand tu portes du code de l'un à l'autre, attends-toi à des ajustements, surtout autour des objets et des entrées/sorties.

Pour aller plus loin

Pour aller plus loin

VB.NET et C# partagent exactement la même plateforme .NET : tout ce que l'un fait, l'autre le fait aussi, avec une syntaxe différente. Microsoft a d'ailleurs annoncé concentrer ses nouveautés sur C#, faisant de VB.NET un langage stable mais peu évolué. Si tu apprécies VB.NET, sache que passer à C# est facile : les concepts sont identiques, seule la « grammaire » change. La leçon 9 reviendra sur ce choix.

Glossaire

.NET
Plateforme de développement de Microsoft : bibliothèque de classes, environnement d'exécution (CLR) et langages (VB.NET, C#, F#).
VB.NET
Version moderne de Visual Basic, pleinement orientée objet, bâtie sur .NET.
Classe
Modèle regroupant des données (propriétés) et des comportements (méthodes), à partir duquel on crée des objets.
Objet / instance
Exemplaire concret d'une classe, créé avec New.
Property
Donnée d'une classe accessible de l'extérieur, en lecture et/ou écriture.
Méthode
Procédure (Sub) ou fonction (Function) définie dans une classe.
Événement
Signal émis par un contrôle lors d'une action de l'utilisateur (clic, saisie…).
Handles
Clause reliant une procédure à un événement : la procédure s'exécute quand l'événement survient.

Récap et vérification

  • VB.NET est le Visual Basic moderne sur la plateforme .NET (partagée avec C#).
  • Une classe regroupe propriétés et méthodes ; New crée un objet.
  • Windows Forms : on dessine l'interface, on code les réactions.
  • Programmation événementielle : Handles Controle.Evenement relie code et action.
