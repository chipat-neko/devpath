Module 1 · Les bases de Visual Basic — Leçon 02

Variables, types et opérateurs

~45 min Débutant Prérequis : leçon 1

À la fin de cette leçon, tu sauras

  • déclarer des variables avec Dim ... As ;
  • utiliser les types (Integer, Double, String, Boolean) ;
  • manier les opérateurs et la concaténation (&) ;
  • comprendre Option Explicit.
Sommaire de la leçon

Pour qu'un programme calcule et retienne, il lui faut des variables : des cases nommées contenant des valeurs. Visual Basic les déclare avec le mot-clé Dim, et te laisse — c'est une de ses souplesses — préciser ou non leur type. Cette leçon pose les fondations : déclarer, typer, calculer et assembler du texte. On verra aussi une petite ligne magique, Option Explicit, qui transforme la qualité de ton code.

Déclarer une variable avec Dim

On déclare une variable avec Dim, suivi du nom, puis As et le type. On lui affecte une valeur avec le signe =.

En Visual Basic, le signe = sert à la fois à affecter et à comparer (le contexte les distingue) — contrairement à des langages qui utilisent := ou ==. Ici, age = 20 donne 20 à age.

Les types de base

Visual Basic propose les types courants :

  • Integer / Long — nombres entiers ;
  • Double / Single — nombres à virgule ;
  • String — du texte ;
  • Boolean — True ou False ;
  • Date — une date et heure.

Les opérateurs

Les opérations arithmétiques sont classiques : +, -, *, / (division), avec en plus \ (division entière), Mod (reste) et ^ (puissance).

Attention : / donne un résultat à virgule (7 / 2 vaut 3.5), tandis que \ (la barre inversée) fait la division entière (7 \ 2 vaut 3).

Concaténer du texte avec &

Pour assembler des chaînes, on utilise l'opérateur &. On l'emploie aussi pour mélanger texte et nombres dans un message.

Visual Basic convertit automatiquement le nombre age en texte lors de la concaténation. Évite l'opérateur + pour les chaînes : il existe mais peut prêter à confusion avec l'addition. Préfère &, sans ambiguïté.

Option Explicit : une bonne habitude essentielle

Par défaut, Visual Basic permet d'utiliser une variable sans la déclarer — pratique mais dangereux : une faute de frappe crée silencieusement une nouvelle variable vide. La ligne Option Explicit, placée tout en haut, oblige à déclarer chaque variable. C'est un réflexe de pro.

Cas réel — le total faux qui coûte cher

Dans une macro de calcul de commissions, un développeur écrit par erreur montnt au lieu de montant dans une seule ligne. Sans Option Explicit, VBA crée une variable montnt vide : la commission de ce cas tombe à zéro, mais le programme ne signale rien. L'erreur n'est découverte que des semaines plus tard, après des versements erronés. Avec Option Explicit en tête de module, la macro aurait refusé de tourner tant que la faute n'était pas corrigée. Une seule ligne pour transformer un bug silencieux et coûteux en erreur détectée en une seconde.

Pièges fréquents

Piège fréquent

Oublier Option Explicit et perdre des heures sur un bug causé par une simple faute de frappe dans un nom de variable. Sans cette option, compteur et compteurr sont deux variables distinctes, et VB ne dit rien. Mets toujours Option Explicit en tête de module — dans l'éditeur VBA, tu peux même activer son ajout automatique dans les options.

Pour aller plus loin

Pour aller plus loin

Il existe un type « fourre-tout », Variant (en VBA), qui peut contenir n'importe quoi : un nombre, du texte, une date… C'est commode mais à double tranchant : on perd la sécurité du typage et les performances. La bonne pratique est de typer explicitement chaque variable avec As dès qu'on connaît son contenu, et de réserver Variant aux rares cas où le type est vraiment inconnu.

Glossaire

Variable
Case nommée en mémoire qui contient une valeur pouvant changer au fil du programme.
Déclaration
Action de créer une variable et de lui donner un type ; en VB, Dim nom As Type.
Type
Nature du contenu d'une variable (Integer, Double, String, Boolean, Date…), qui fixe ce qu'elle peut stocker.
Affectation
Fait de ranger une valeur dans une variable avec le signe =.
Division entière
Opération \ qui garde seulement le quotient entier (7 \ 2 = 3), par opposition à / qui garde la virgule.
Mod (modulo)
Opérateur qui renvoie le reste d'une division entière (7 Mod 2 = 1).
Option Explicit
Directive à placer en première ligne qui oblige à déclarer chaque variable, évitant les bugs de fautes de frappe.
Variant
Type « fourre-tout » de VBA acceptant n'importe quelle valeur ; commode mais moins sûr et plus lent qu'un type explicite.

Récap et vérification

  • Dim nom As Type déclare ; = affecte (et compare selon le contexte).
  • Types : Integer/Long, Double, String, Boolean, Date.
  • Opérateurs : / (réel), \ (entier), Mod, ^ ; & concatène.
  • Option Explicit oblige à déclarer : à mettre toujours en première ligne.

Vérifie ta compréhension

  1. Comment déclare-t-on une variable entière nommée n ?
  2. Que vaut 7 \ 2 et 7 Mod 2 ?
  3. À quoi sert Option Explicit ?
