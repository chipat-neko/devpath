Le pattern matching

~50 min Avancé Prérequis : leçon 4

À la fin de cette leçon, tu sauras

  • filtrer avec match ... with et la déstructuration ;
  • profiter de l'exhaustivité vérifiée par le compilateur ;
  • utiliser les gardes (when) ;
  • découvrir les active patterns.
Sommaire de la leçon

Le pattern matching est le compagnon naturel des unions discriminées : il déstructure les données, vérifie l'exhaustivité, et rend le code à la fois concis et sûr. F# y ajoute une fonctionnalité unique : les active patterns. C'est l'outil le plus expressif du langage.

match ... with

On compare une valeur à des motifs ; chaque cas commence par |. Le compilateur vérifie que tous les cas sont couverts et avertit si tu en oublies un.

Déstructurer unions et records

Le filtrage extrait directement les données portées par une union ou les champs d'un record.

Les listes

On filtre une liste par tête et queue — l'idiome des fonctions récursives.

Les gardes (when)

On affine un motif avec une condition when : la branche ne s'applique que si le motif correspond et que la garde est vraie.

Le mot-clé function

Raccourci pratique : function est un fun + match sur l'argument, pour des fonctions définies par cas.

Les active patterns

Fonctionnalité signature de F# : les active patterns permettent de définir tes propres motifs, en encapsulant une logique de décomposition. On obtient un filtrage lisible sur des données qui n'ont pas de structure de DU.

L'active pattern (|Pair|Impair|) s'utilise comme un cas de DU dans le match.

Astuce

Combine motif et garde pour affiner sans multiplier les cas : | x when x > 0 -> …. Et méfie-toi de l'ordre : un motif trop général placé tôt (comme _) « mange » les branches suivantes. Le compilateur signale d'ailleurs les branches devenues inatteignables.

Cas réel

Le pattern matching, popularisé par la famille ML (dont F#), s'est révélé si utile qu'il a été adopté par les grands langages grand public : switch expressions et motifs de C# 8+, match/case de Python 3.10 (PEP 634), pattern matching for switch de Java. Sur le terrain, il est la colonne vertébrale des compilateurs et interpréteurs, qui parcourent un arbre syntaxique en filtrant chaque type de nœud — exactement le match exhaustif sur une union récursive vu à la leçon précédente.

Pièges fréquents

Piège fréquent

Ignorer l'avertissement « incomplete match » : si tu oublies un cas, le compilateur le signale, et ton programme plantera à l'exécution sur ce cas non géré. Traite tous les cas (ou ajoute un _ explicite si c'est volontaire).

Pour aller plus loin

Pour aller plus loin

Les active patterns partiels ((|Entier|_|)) renvoient une option et servent à parser : tester si une chaîne est un entier, une date… Ils transforment le pattern matching en un outil de validation et d'analyse très élégant.

Antisèche

Glossaire

Pattern matching
Comparaison d'une valeur à des motifs, avec déstructuration et vérification d'exhaustivité.
Motif (pattern)
Forme testée dans un match (un littéral, un cas d'union, tete :: queue, _…).
Exhaustivité
Couverture de tous les cas possibles ; F# avertit à la compilation si un cas manque.
Joker (_)
Motif universel qui correspond à n'importe quelle valeur sans la lier à un nom.
Garde (when)
Condition booléenne ajoutée à un motif ; la branche s'applique si le motif et la garde sont vrais.
function
Raccourci pour fun x -> match x with … : une fonction définie directement par cas.
Active pattern
Motif défini par l'utilisateur ((|Pair|Impair|)), utilisable comme un cas d'union.
Active pattern partiel
Variante (|Nom|_|) renvoyant une option, utile pour analyser ou valider (parsing).

Récap et vérification

  • match ... with | motif -> ... déstructure et vérifie l'exhaustivité.
  • On filtre unions, records, listes ; les gardes (when) affinent ; | regroupe.
  • function est un raccourci pour une fonction définie par cas.
  • Les active patterns définissent tes propres motifs réutilisables.
