Module 1 · Les bases de F# — Leçon 01

Découvrir F#

~45 min Avancé Prérequis : savoir programmer dans un autre langage

À la fin de cette leçon, tu sauras

  • comprendre la philosophie de F# : fonctionnel-first sur .NET ;
  • utiliser le REPL (dotnet fsi) et exécuter un script ;
  • afficher avec printfn et l'indentation significative ;
  • situer F# face à C# et OCaml.
Sommaire de la leçon

F# (prononce « F sharp ») est un langage fonctionnel d'abord qui tourne sur la plateforme .NET de Microsoft. Conçu par Don Syme et inspiré directement d'OCaml, il combine deux mondes : l'élégance et la sûreté de la programmation fonctionnelle, et l'immense écosystème de .NET (toutes les bibliothèques de C#, Azure, le web…). C'est le choix idéal pour qui veut écrire du code concis et fiable tout en restant dans un environnement d'entreprise.

« Fonctionnel-first » signifie que F# t'encourage vers l'immuabilité, les fonctions pures et le pattern matching — mais sans dogmatisme : quand l'objet ou l'impératif sert mieux, F# les permet sans friction.

Installer et lancer F#

F# vient avec le SDK .NET (gratuit, multiplateforme). Le REPL s'appelle fsi (F# Interactive) : on évalue des expressions interactivement, terminées par ;;.

Comme OCaml, le REPL affiche la valeur et son type inféré.

Ton premier programme

Dans un fichier .fsx (script) ou .fs (projet), on affiche avec printfn. Le %s, %d sont des spécificateurs de format typés (vérifiés à la compilation !).

Si tu écris printfn "%d" nom (un nombre attendu, une chaîne fournie), le compilateur refuse : la sûreté jusque dans le formatage.

Astuce

Dans le REPL fsi, n'oublie pas le ;; final : c'est lui qui déclenche l'évaluation. Sans lui, fsi attend la suite de ton expression. Dans un fichier .fsx, en revanche, le ;; est inutile.

L'indentation significative

Comme Python, F# utilise l'indentation pour délimiter les blocs (pas d'accolades). Un code bien aligné est un code valide ; un décalage change le sens.

Les commentaires

Commentaire de ligne avec //, de bloc avec (* ... *) (héritage OCaml).

F# face à C# et OCaml

Trois cousins éclairants. C# est l'autre grand langage .NET, orienté objet et impératif : F# partage sa plateforme mais privilégie le fonctionnel. OCaml est le père spirituel de F# : même esprit (inférence, variants, pattern matching), mais F# vit dans l'écosystème Microsoft. F# = « OCaml sur .NET, avec quelques ajouts modernes ».

Cas réel

F# n'est pas qu'un langage d'école. Jet.com, plateforme d'e-commerce rachetée par Walmart en 2016 pour environ 3,3 milliards de dollars, a bâti l'essentiel de son back-end en F# : l'immuabilité et le pattern matching réduisent les bugs sur des systèmes de commande critiques. Le langage est aussi très prisé en finance quantitative, où la sûreté des calculs (types, unités de mesure) évite des erreurs coûteuses. La concision fonctionnelle y est un avantage concret, pas un luxe académique.

Pièges fréquents

Piège fréquent

Mélanger les indentations (espaces et tabulations) ou mal aligner un bloc : comme l'indentation est significative, une erreur d'alignement change le sens ou provoque une erreur. Configure ton éditeur pour des espaces cohérents (4 par défaut).

Pour aller plus loin

Pour aller plus loin

F# bénéficie de tout l'écosystème .NET : tu peux appeler n'importe quelle bibliothèque C#, utiliser ASP.NET pour le web, Azure pour le cloud. C'est sa grande force par rapport à OCaml : la sûreté fonctionnelle plus un écosystème industriel complet.

Glossaire

F#
Langage fonctionnel-first de la famille ML, créé par Don Syme, tournant sur la plateforme .NET.
.NET
Plateforme d'exécution de Microsoft (runtime CLR + bibliothèques), partagée par F#, C# et VB.
Fonctionnel-first
Approche qui privilégie l'immuabilité et les fonctions par défaut, tout en autorisant l'objet et l'impératif.
fsi (REPL)
F# Interactive : boucle lire-évaluer-afficher où chaque expression se termine par ;;.
printfn
Fonction d'affichage à format typé (%s, %d) vérifié à la compilation.
Inférence de types
Le compilateur déduit seul le type des valeurs ; le REPL affiche val it : type.
Indentation significative
L'alignement du code délimite les blocs (offside rule), sans accolades.
Immuabilité
Une valeur définie avec let ne change pas ; on en crée de nouvelles plutôt que de la modifier.

Récap et vérification

  • F# est fonctionnel-first, sur .NET, inspiré d'OCaml ; il accède à tout l'écosystème C#.
  • REPL dotnet fsi ; printfn avec des formats typés (%s, %d).
  • L'indentation délimite les blocs (pas d'accolades).
  • F# = « OCaml sur .NET » ; cousin fonctionnel de C#.
