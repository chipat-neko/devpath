Les active patterns

~50 min Avancé Prérequis : leçon 5

À la fin de cette leçon, tu sauras

  • comprendre ce qu'apporte un active pattern ;
  • définir un motif total à plusieurs cas ;
  • définir un motif partiel (|X|_|) pour parser ou valider ;
  • rendre un match lisible sur des données non structurées.
Sommaire de la leçon

Le pattern matching classique reconnaît la structure des données : les cas d'une union, la forme d'un tuple, une constante. Mais comment filtrer sur une propriété calculée — « ce nombre est-il pair ? », « cette chaîne est-elle un entier valide ? » — sans retomber dans des cascades de if/elif ? Les active patterns transforment une fonction en motif : on étend le vocabulaire du match.

Rappel : la limite du match ordinaire

Pour classer un entier, on écrit souvent une cascade de conditions. Ça marche, mais on perd l'élégance et l'exhaustivité du match.

Un active pattern total

Un active pattern encadre ses noms de cas entre « banana clips » (| ... |). Il calcule, à partir de la valeur, quel cas s'applique — exactement comme s'il s'agissait des cas d'une union.

Le match retrouve toute sa lisibilité, et le compilateur vérifie qu'on couvre bien les trois cas.

Un active pattern partiel (|X|_|)

Quand un motif peut ne pas s'appliquer (parser, valider), on utilise la forme partielle (|X|_|), qui renvoie un option : Some quand il reconnaît, None sinon. Le _ signale « peut échouer ».

Composer : gardes et motifs paramétrés

On combine les active patterns avec des gardes when, et on peut leur passer des paramètres. Le fameux FizzBuzz devient limpide :

DivisiblePar 3 passe l'argument 3 au motif, et & exige que les deux motifs s'appliquent.

Cas réel

Les active patterns brillent dans les parseurs et l'analyse de données. Un idiome très répandu est (|Regex|_|) : un motif partiel qui teste une chaîne contre une expression régulière et capture ses groupes. Le traitement d'un fichier de configuration ou de logs, d'ordinaire truffé de if et de découpages fragiles, se réécrit en un match propre : | Regex "(\\d+)-(\\d+)" [ a; b ] -> .... Le compilateur F# lui-même s'appuie sur les active patterns pour analyser le code.

Pièges fréquents

Piège fréquent

Un active pattern est recalculé à chaque essai dans un match. Un motif coûteux (requête, gros calcul) essayé sur de nombreuses branches peut surprendre côté performance. Garde-les légers, ou mémorise le résultat en amont. Attention aussi à la casse : un nom de cas commence par une majuscule (comme les cas d'union).

Pour aller plus loin

Pour aller plus loin

Un active pattern peut capturer plusieurs valeurs à la fois en renvoyant un tuple (Some (x, y)). Il en existe un intégré très utile : (|KeyValue|) décompose une entrée de dictionnaire en (clé, valeur). On peut aussi les employer hors d'un match, directement dans un let pour déconstruire : let (Entier n) = "7" (à réserver aux motifs qui ne peuvent pas échouer).

Antisèche

Glossaire

Active pattern
Fonction utilisable comme un motif dans un match : elle calcule, à partir de la valeur, quel cas s'applique. Étend le vocabulaire du pattern matching.
Active pattern total
Motif à plusieurs cas nommés couvrant toutes les valeurs : (|A|B|C|). Le compilateur vérifie l'exhaustivité.
Active pattern partiel
Motif (|X|_|) qui peut échouer : renvoie Some (reconnu) ou None (on passe au cas suivant). Idéal pour parser/valider.
Banana clips
Surnom des délimiteurs (| ... |) qui encadrent les noms de cas d'un active pattern.
Garde (when)
Condition booléenne ajoutée à un motif : la branche n'est prise que si elle est vraie.
Motif paramétré
Active pattern acceptant un argument avant la valeur testée : DivisiblePar 3.
& (motif)
Combine deux motifs : la branche s'applique seulement si les deux réussissent.
Exhaustivité
Garantie que toutes les valeurs possibles sont couvertes par les branches d'un match. Avec un active pattern total, le compilateur F# la vérifie et prévient si un cas manque.

Récap et vérification

  • Un active pattern fait d'une fonction un motif de match.
  • Le motif total (|A|B|C|) classe une valeur en cas exhaustifs.
  • Le motif partiel (|X|_|) renvoie Some/None : parfait pour parser et valider.
  • Gardes when, motifs paramétrés et & composent des filtres puissants et lisibles.

Vérifie ta compréhension

  1. Quelle forme d'active pattern utilise-t-on pour un motif qui peut échouer ?
  2. Que renvoie un active pattern partiel quand il reconnaît la valeur ?
  3. Comment passer un paramètre à un active pattern dans un match ?
