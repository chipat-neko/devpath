Module 08 · Données & calcul scientifique — Leçon 23

Visualiser avec matplotlib

~40 min Intermédiaire Leçons 21-22 recommandées

À la fin de cette leçon, tu sauras

  • tracer des courbes, histogrammes et nuages de points ;
  • personnaliser un graphique (titre, axes, légende, couleurs) ;
  • tracer directement depuis un DataFrame pandas et enregistrer une figure ;
  • situer les notebooks Jupyter dans le flux de travail data.
Sommaire de la leçon

Analyser des données, c'est bien ; les voir, c'est mieux. Un graphique révèle en un instant une tendance, une anomalie ou une corrélation qu'un tableau de chiffres cache. matplotlib est la bibliothèque de visualisation historique et universelle de Python : presque tout l'écosystème data (pandas, seaborn…) s'appuie sur elle. Cette leçon te montre comment transformer des données en figures lisibles.

Convention : import matplotlib.pyplot as plt. Le sous-module pyplot (alias plt) offre une interface simple, proche de celle d'un carnet de croquis.

Tracer une première courbe

La fonction de base est plot : on lui donne les abscisses et les ordonnées, puis show affiche la figure.

Le schéma est toujours le même : on trace (une ou plusieurs fois), on habille (titre, étiquettes), puis on affiche avec show (ou on enregistre).

Plusieurs courbes et une légende

On peut empiler plusieurs tracés sur la même figure, et les distinguer par une légende.

Chaque plot reçoit un label ; legend() les rassemble. Des options comme color, linestyle ou linewidth personnalisent l'apparence.

Histogrammes et nuages de points

Au-delà des courbes, deux graphiques sont essentiels en analyse : l'histogramme (distribution d'une variable) et le nuage de points (relation entre deux variables).

Le bon graphique dépend de la question : hist pour « comment se répartissent mes valeurs ? », scatter pour « ces deux variables sont-elles liées ? », bar pour comparer des catégories.

Cas réel — le rapport mensuel automatique

Dans beaucoup d'entreprises, un même script tourne chaque début de mois : pandas lit l'export des ventes (read_csv), un groupby résume le chiffre d'affaires par région, puis matplotlib en fait un diagramme en barres enregistré avec savefig. L'image est ensuite insérée dans un rapport PDF envoyé par courriel — sans qu'une seule cellule de tableur ne soit ouverte à la main. La même chaîne alimente les tableaux de bord publics : les courbes de suivi d'une épidémie ou les graphiques d'un article de presse « data » sont souvent produits par ce trio NumPy / pandas / matplotlib.

Tracer depuis un DataFrame

pandas intègre matplotlib : un DataFrame ou une Series a une méthode plot qui produit directement la figure. C'est le chemin le plus court du tableau au graphique.

Le paramètre kind ("line", "bar", "hist", "scatter"…) choisit le type. Combiner groupby et .plot permet de visualiser une agrégation en une seule expression.

Enregistrer une figure

Pour intégrer un graphique dans un rapport, on l'enregistre en image avec savefig (à appeler avant show).

Erreur fréquente : la figure qui s'accumule

Tant que tu n'appelles pas plt.show() (ou plt.figure() pour repartir d'une figure vierge), les tracés successifs s'empilent sur la même figure : deux plt.plot() d'affilée dessinent deux courbes ensemble — parfois voulu, parfois non. Autre piège classique : appeler plt.savefig() après plt.show() enregistre une image vide, car show() « vide » la figure. Retiens l'ordre : tracer → habiller → savefig → show.

Les notebooks Jupyter

En pratique, le travail data se fait souvent dans un notebook Jupyter : un document interactif mêlant cellules de code, résultats (y compris les graphiques, affichés sous la cellule) et texte explicatif. On exécute les cellules une à une, on visualise immédiatement, on ajuste. C'est l'environnement idéal pour explorer un jeu de données pas à pas, et le format de partage standard en science des données.

Astuce

Pour des graphiques statistiques plus jolis avec moins de code, regarde seaborn (construit sur matplotlib) : sns.histplot, sns.scatterplot, sns.boxplot gèrent automatiquement couleurs, légendes et groupements depuis un DataFrame. matplotlib reste dessous pour les réglages fins.

Pour aller plus loin

matplotlib a deux interfaces : l'interface « pyplot » (rapide, vue ici) et l'interface « orientée objet » (fig, ax = plt.subplots() puis ax.plot(...)), recommandée pour les figures complexes à plusieurs sous-graphiques. Tu croiseras les deux ; la seconde donne un contrôle total quand un graphique devient sérieux. Tu as désormais bouclé la chaîne data : NumPy pour calculer, pandas pour manipuler, matplotlib pour visualiser.

Glossaire

matplotlib
Bibliothèque de visualisation historique de Python. Presque tout l'écosystème data (pandas, seaborn…) s'appuie sur elle pour produire des figures.
pyplot (plt)
Le sous-module à interface simple de matplotlib, importé par convention sous l'alias plt : import matplotlib.pyplot as plt.
Figure & Axes
La figure est la fenêtre entière ; les axes sont la zone de tracé (avec ses graduations). L'interface objet fig, ax = plt.subplots() les manipule explicitement.
plot / show
plot(x, y) trace une courbe ; show() affiche la fenêtre. Entre les deux, on habille avec title, xlabel, legend…
hist / bins
L'histogramme (hist) répartit les valeurs en intervalles ; bins fixe le nombre de barres (la finesse de la répartition).
scatter
Le nuage de points : un point par observation, pour révéler une relation (ou son absence) entre deux variables.
savefig
Enregistre la figure courante en image (.png, .svg…). À appeler avant show(), avec dpi et bbox_inches="tight" pour un rendu net.
Notebook Jupyter
Document interactif mêlant cellules de code, résultats (dont les graphiques) et texte : l'atelier standard de l'analyse exploratoire en science des données.

Récap et vérification

  • plt.plot(x, y) trace ; on habille (title, xlabel, legend) puis show.
  • hist (distribution), scatter (relation), bar (catégories) : chaque graphique répond à une question.
  • Un DataFrame a une méthode .plot(kind=...) ; savefig enregistre une image (avant show).
  • Les notebooks Jupyter mêlent code, résultats et texte : l'atelier de l'analyse exploratoire.
