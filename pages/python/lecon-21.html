Module 08 · Données & calcul scientifique — Leçon 21

NumPy : tableaux et calcul vectoriel

~35 min Intermédiaire Bases de Python requises

À la fin de cette leçon, tu sauras

  • créer des tableaux ndarray (array, arange, zeros, linspace) ;
  • exploiter la vectorisation et le broadcasting au lieu des boucles ;
  • indexer avec des masques booléens et agréger par axe ;
  • éviter le piège vues vs copies.
Sommaire de la leçon

NumPy (Numerical Python) est la fondation de tout l'écosystème scientifique de Python : pandas, scikit-learn, matplotlib, et la quasi-totalité des bibliothèques de données reposent dessus. Son objet central, le tableau homogène (ndarray), permet de manipuler des milliers, voire des millions de nombres d'un seul geste — et bien plus vite qu'avec des listes Python. Cette leçon t'apprend à penser « en tableaux ».

Par convention, on importe NumPy sous l'alias np. Tu verras ce import numpy as np dans absolument tout le code scientifique Python.

Pourquoi NumPy plutôt qu'une liste ?

Une liste Python peut contenir n'importe quoi : elle est souple, mais lente pour le calcul numérique. Un ndarray stocke des éléments d'un même type (des float64, par exemple) dans un bloc de mémoire contigu, ce qui permet à NumPy de déléguer les calculs à du code C optimisé. Résultat : additionner deux tableaux d'un million d'éléments est des dizaines de fois plus rapide qu'une boucle Python — et le code est plus court.

Créer des tableaux

On crée un tableau à partir d'une liste, ou avec des fabriques dédiées.

Trois attributs reviennent sans cesse : dtype (le type des éléments), shape (les dimensions, sous forme de tuple) et ndim (le nombre d'axes : 1 pour un vecteur, 2 pour une matrice).

La vectorisation : calculer sans boucle

Voici l'idée centrale. Les opérations s'appliquent élément par élément, sur tout le tableau d'un coup. On n'écrit pas de boucle : on opère sur le tableau entier.

Cette écriture n'est pas qu'élégante : elle est rapide, car la boucle se déroule en C sous le capot. Règle d'or du calcul scientifique en Python : vectorise avant d'écrire une boucle.

Astuce

Avant d'écrire une boucle for sur un tableau, demande-toi s'il existe une opération vectorisée équivalente. La plupart du temps, oui : tableau * 2, np.sqrt(tableau), a + b… Une boucle Python qui parcourt un grand tableau élément par élément est souvent le signe qu'on n'exploite pas encore NumPy.

Indexation, tranches et masques booléens

On accède aux éléments comme avec une liste, mais aussi par masque booléen — une façon très puissante de sélectionner.

Le masque booléen est l'outil de filtrage par excellence : x[x > 10] se lit « les éléments de x supérieurs à 10 ». On peut combiner des conditions avec & (et) et | (ou), en parenthésant chaque comparaison.

Le broadcasting

Le broadcasting permet d'opérer entre tableaux de formes différentes : NumPy « étire » automatiquement le plus petit pour qu'il s'aligne sur le plus grand, sans copier les données.

Le broadcasting évite de dupliquer manuellement des données et rend le code concis. La règle : les dimensions sont compatibles si elles sont égales, ou si l'une vaut 1.

Agrégations et axes

Les fonctions de réduction (sum, mean, max…) résument un tableau. Le paramètre axis choisit la direction : axis=0 réduit les lignes (résultat par colonne), axis=1 réduit les colonnes (résultat par ligne).

Bien choisir l'axe est la clé : axis=0 « écrase » les lignes, axis=1 « écrase » les colonnes. Une astuce : l'axe indiqué est celui qui disparaît du résultat.

Cas réel

Une photo numérique est un ndarray : un tableau de forme (hauteur, largeur, 3) — trois canaux rouge/vert/bleu. Éclaircir l'image, c'est image * 1.2 (vectorisation) ; la passer en niveaux de gris, c'est image.mean(axis=2) (agrégation sur l'axe des couleurs) ; en recadrer un morceau, c'est une tranche image[100:300, 50:200] (une vue !). Des bibliothèques comme Pillow, OpenCV ou scikit-image travaillent toutes sur des tableaux NumPy : les trois idées de cette leçon suffisent à manipuler des millions de pixels d'un seul geste.

Vues et copies : un piège mémoire

Détail subtil mais important : une tranche d'un tableau NumPy est une vue — elle partage la mémoire avec l'original. Modifier la vue modifie l'original. Pour un tableau indépendant, il faut copy().

Piège fréquent

Croire qu'une tranche est une copie (comme pour les listes Python !). En NumPy, x[1:4] est une vue qui partage la mémoire : la modifier modifie x. Si tu veux travailler sur des données indépendantes, ajoute .copy(). À l'inverse, l'indexation booléenne et l'indexation fancy (par liste d'indices) renvoient, elles, des copies.

Pour aller plus loin

Les opérations vectorisées de NumPy sont des ufuncs (fonctions universelles) : np.sqrt, np.exp, np.sin… s'appliquent élément par élément à toute forme de tableau. Pour l'algèbre linéaire (produit matriciel @, np.linalg.inv, résolution de systèmes), NumPy s'appuie sur des bibliothèques BLAS/LAPACK ultra-optimisées : c'est ce qui rend Python compétitif pour le calcul lourd, à condition de rester vectorisé.

Glossaire

ndarray
Le tableau N-dimensionnel de NumPy : des éléments d'un même type rangés dans un bloc de mémoire contigu. Objet central de tout le calcul scientifique en Python.
dtype
Le type des éléments d'un tableau (int64, float64, bool…). Homogène : toutes les cases partagent le même dtype.
shape / ndim
shape donne les dimensions sous forme de tuple (ex. (2, 3)) ; ndim donne le nombre d'axes (1 = vecteur, 2 = matrice).
Vectorisation
Appliquer une opération à tout le tableau d'un coup, sans boucle Python : la boucle se déroule en C, donc c'est plus court et plus rapide.
Broadcasting (diffusion)
Mécanisme qui aligne des tableaux de formes différentes en « étirant » le plus petit, sans copier les données. Compatibles si les dimensions sont égales ou valent 1.
Masque booléen
Un tableau de True/False issu d'une condition (a > 10), utilisé pour sélectionner ou modifier des éléments : a[a > 10].
axis
La direction d'une agrégation. axis=0 réduit les lignes (résultat par colonne), axis=1 réduit les colonnes (résultat par ligne) : l'axe passé disparaît du résultat.
Vue vs copie
Une tranche (a[1:4]) est une vue qui partage la mémoire de l'original ; la modifier modifie l'original. .copy() crée un tableau indépendant.

Récap et vérification

  • Le ndarray stocke des éléments homogènes contigus : rapide et compact (dtype, shape, ndim).
  • La vectorisation applique les opérations à tout le tableau, sans boucle.
  • Les masques booléens filtrent (x[x > 10]) ; le broadcasting aligne des formes différentes.
  • Les agrégations utilisent axis ; une tranche est une vue (utiliser .copy() pour isoler).
