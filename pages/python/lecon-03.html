Opérateurs et expressions

~31 min Débutant Leçon 02 recommandée

À la fin de cette leçon, tu sauras

  • calculer avec les opérateurs arithmétiques (+ - * / // % **) en maîtrisant la priorité et les parenthèses ;
  • comparer des valeurs et combiner des conditions avec and, or, not et le court-circuit ;
  • reconnaître les valeurs truthy/falsy et utiliser +=, in ainsi que les comparaisons chaînées (0 <= x < 10) ;
  • distinguer == (valeur) de is (identité) et tester correctement avec is None.
Sommaire de la leçon

Maintenant que tu sais créer des variables et afficher des valeurs, il est temps de les faire travailler ensemble : calculer, comparer, combiner. C'est le cœur de tout programme — décider, mesurer, accumuler. On appelle expression tout morceau de code qui produit une valeur, et opérateur le symbole qui relie ces valeurs (+, ==, and…).

On part du plus familier — les calculs comme à l'école — puis on monte d'un cran : comparer deux valeurs, combiner plusieurs conditions, et découvrir quelques outils propres à Python qui rendront ton code plus court et plus lisible. Garde un interpréteur ouvert et recopie chaque exemple.

Les opérateurs arithmétiques

Python sait calculer comme une calculatrice. Tu retrouves les quatre opérations classiques, plus trois opérateurs très utiles : la division entière, le modulo (le reste) et la puissance.

Deux pièges à mémoriser tout de suite. La division / renvoie toujours un float (donc 4 / 2 donne 2.0, pas 2). Et la division entière // garde la partie entière du quotient. Le modulo %, lui, donne le reste : il sert par exemple à savoir si un nombre est pair (n % 2 == 0).

Cas réel

Le modulo est partout dans les vraies applications. Un tableau qui alterne la couleur des lignes teste numero % 2 (pair/impair) ; une horloge repasse à 0 après 23 h avec (heure + 1) % 24 ; un carrousel revient à la première image via (index + 1) % nombre_images. À chaque fois, % fait « tourner » un compteur à l'intérieur d'un intervalle.

Comme en maths, Python applique une priorité : la puissance d'abord, puis * / // %, et enfin + -. En cas de doute, mets des parenthèses : elles lèvent l'ambiguïté et rendent ton intention claire.

Astuce

N'essaie jamais de retenir toute la table de priorité par cœur. Mets des parenthèses dès que la lecture n'est pas évidente : un relecteur (toi inclus) te remerciera.

Les opérateurs de comparaison

Comparer deux valeurs produit un booléen : True ou False. Ce sont eux qui alimenteront tes conditions (les if) à la leçon suivante.

Attention à ne pas confondre = et ==. Un seul signe égal affecte une valeur à une variable (x = 3) ; deux signes comparent deux valeurs (x == 3). C'est l'une des confusions les plus fréquentes au début.

Les opérateurs booléens et le court-circuit

Pour combiner plusieurs conditions, tu disposes de trois mots-clés en toutes lettres : and (et), or (ou), not (négation). Bien plus lisibles que les symboles d'autres langages.

Python évalue ces opérateurs en court-circuit (évaluation paresseuse) : il s'arrête dès que le résultat est connu. Avec and, si le premier opérande est faux, le second n'est même pas évalué (le résultat sera faux de toute façon). Avec or, si le premier est vrai, il s'arrête là. C'est utile pour éviter une opération coûteuse ou risquée.

Truthy et falsy

En Python, n'importe quelle valeur peut être considérée comme vraie ou fausse dans un contexte booléen (un if, un and…). On parle de valeurs truthy (vraies) et falsy (fausses).

Sont falsy : False, le nombre 0, 0.0, la chaîne vide "", la liste vide [], le dictionnaire vide {} et None. Tout le reste est truthy : un nombre non nul, une chaîne non vide, une liste avec au moins un élément…

Cela permet d'écrire if liste: au lieu de if len(liste) > 0: — plus court et idiomatique pour tester « est-ce que ma liste contient quelque chose ? ».

Note

Subtilité : and et or ne renvoient pas forcément True/False, mais l'un des opérandes. 0 or "défaut" renvoie "défaut" (la première valeur truthy), et "a" and "b" renvoie "b". Dans un if, ça revient au même ; mais sache que la valeur retournée n'est pas toujours un booléen pur.

L'affectation composée

Quand tu veux modifier une variable à partir de sa propre valeur — typiquement l'augmenter — il existe un raccourci. x += 1 est l'écriture courte de x = x + 1.

Tous les opérateurs arithmétiques ont leur version composée : +=, -=, *=, /=, //=, %=, **=. C'est l'outil de base pour cumuler une somme ou un compteur dans une boucle (tu verras ça très bientôt).

L'appartenance : in et not in

L'opérateur in teste si une valeur est présente dans une séquence : une chaîne, une liste, et d'autres structures à venir. Il renvoie un booléen.

C'est lisible comme une phrase : « est-ce que "kiwi" est dans fruits ? ». La forme négative not in teste l'absence.

L'identité : is, et le cas de None

Il existe une autre comparaison, is, qui ne teste pas l'égalité des valeurs mais l'identité : « est-ce exactement le même objet en mémoire ? ». La règle pratique à retenir tout de suite : on l'utilise pour None.

Pourquoi is None et non == None ? Parce que None est unique : il n'existe qu'un seul None dans tout le programme. Tester l'identité est donc plus fiable, plus rapide, et c'est la convention universelle en Python. Réserve == à la comparaison de valeurs (nombres, chaînes…) et is à None.

Les comparaisons chaînées

Voici une élégance bien à Python : tu peux enchaîner des comparaisons comme en mathématiques. Pour tester qu'une valeur est dans un intervalle, écris-le directement.

L'expression 0 <= x < 10 se lit « x est entre 0 et 10 » et fait exactement ce qu'on attend. Python évalue x une seule fois. La plupart des autres langages ne le permettent pas : profites-en, c'est plus clair.

Mention rapide : il existe aussi des opérateurs bit-à-bit qui travaillent sur la représentation binaire des entiers — & (et), | (ou), ^ (ou exclusif). Tu les croiseras rarement comme débutant ; ne les confonds pas avec and et or, qui sont leurs équivalents logiques.

Pièges fréquents

  • Confondre == et is. == compare les valeurs, is compare l'identité. Pour None, écris toujours x is None (jamais x == None).
  • Oublier la priorité. 2 + 3 * 4 vaut 14, pas 20. En cas de doute, parenthèse.
  • Croire que and/or renvoient un booléen. Ils renvoient l'un des opérandes : "" or "x" donne "x". Pratique, mais à connaître.
  • Comparer à True explicitement. Écris if x: et non if x == True:. C'est plus court, plus sûr (grâce au truthy/falsy) et plus pythonique.

Piège fréquent

Pour tester si une variable vaut None, n'écris jamais if resultat == None: mais if resultat is None:. C'est la règle d'or, et les outils d'analyse de code te le rappelleront.

Pour aller plus loin

Quand une condition doit produire l'une de deux valeurs, l'expression ternaire condense un if en une ligne : valeur_si_vrai if condition else valeur_si_faux.

Tu rencontreras aussi le match-case (depuis Python 3.10) pour comparer une valeur à plusieurs motifs, et l'opérateur morse := qui affecte et renvoie une valeur dans la même expression. Ce sont des outils avancés : on les reverra le moment venu.

Pour aller plus loin

Ces opérateurs prennent tout leur sens avec les conditions et les boucles, qui arrivent dans les prochaines leçons. Pour l'instant, retiens surtout l'arithmétique, les comparaisons, and/or/not et le réflexe is None.

Glossaire

Expression
Tout morceau de code qui produit une valeur : 3 + 4, x == 5, "py" in nom.
Opérateur / opérande
L'opérateur est le symbole (+, and…) ; les opérandes sont les valeurs qu'il relie.
Modulo (%)
Reste de la division entière : 17 % 5 vaut 2. Sert à tester la parité ou créer des cycles.
Court-circuit
Évaluation paresseuse : and et or s'arrêtent dès que le résultat est connu, sans évaluer la suite.
Truthy / falsy
Véracité d'une valeur dans un contexte booléen ; 0, "", [], None sont falsy, le reste truthy.
Affectation composée
Raccourci x += 1 pour x = x + 1 (de même -=, *=, //=…).
Identité (is)
Teste si deux noms désignent le même objet en mémoire ; on l'utilise pour is None.
Comparaison chaînée
Enchaîner des comparaisons comme en maths : 0 <= x < 10.

Récap et vérification

  • Arithmétique : + - * /, plus // (division entière), % (reste), ** (puissance) ; / donne toujours un float.
  • La priorité suit les maths ; les parenthèses lèvent tout doute.
  • Les comparaisons (==, !=, <, >, <=, >=) renvoient un booléen ; and/or/not les combinent, en court-circuit.
  • 0, 0.0, "", [], {}, None sont falsy ; tout le reste est truthy.
  • += et compagnie cumulent ; in teste l'appartenance ; is None teste l'identité ; 0 <= x < 10 chaîne les comparaisons.

Vérifie ta compréhension

  1. Que vaut 17 % 5, et à quoi sert le modulo dans la vie réelle ?
  2. Pourquoi écrit-on if resultat is None: plutôt que if resultat == None: ?
  3. Quelle est la valeur de 0 or "secours", et pourquoi n'est-ce pas True ?
