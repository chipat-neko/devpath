Python : des bases au niveau confirmé

Python est un langage lisible et accueillant. Ce cours te mène des tout premiers pas jusqu'au niveau confirmé : variables, logique, structures de données, fonctions, fichiers, programmation orientée objet et générateurs — un concept à la fois.

Bien s'équiper

Les extensions VS Code pour Python

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Python

  • Python (Microsoft) — support officiel : exécution, débogage, environnements.
  • Pylance (Microsoft) — auto-complétion rapide et vérification de types.
  • Black Formatter (Microsoft) — formatage automatique standard.
  • Ruff (Astral Software) — analyseur (linter) ultra-rapide.
  • Jupyter (Microsoft) — exécuter des notebooks dans l'éditeur.

Cours complet

Les 50 leçons sont rédigées, des variables jusqu'à la programmation orientée objet, aux générateurs, aux dates, et désormais à la data science (NumPy, pandas, matplotlib). Chaque notion est illustrée par du code commenté que tu peux recopier dans un interpréteur Python.

Ce que tu vas apprendre

Objectifs du cours

À la fin du cours, tu sauras

  • manipuler les variables, les types et les opérateurs, et diriger un programme avec conditions et boucles ;
  • découper ton code en fonctions réutilisables (paramètres, portée, annotations) ;
  • organiser des données avec listes, tuples, dictionnaires, ensembles et compréhensions ;
  • utiliser les modules et la bibliothèque standard, lire/écrire des fichiers et gérer les exceptions ;
  • modéliser avec des classes (POO) et écrire du code pythonique avec générateurs et outils fonctionnels ;
  • aborder la data science : tableaux NumPy, analyse de données avec pandas et visualisation avec matplotlib.

Pour qui, et pourquoi

Ce cours s'adresse aux grands débutants : tu n'as jamais programmé, ou presque, et tu veux comprendre comment on donne des instructions à une machine. Aucun prérequis n'est demandé, ni en informatique ni en mathématiques. Si tu sais utiliser un ordinateur au quotidien, tu as tout ce qu'il faut pour commencer.

On a choisi Python parce que sa syntaxe ressemble presque à de l'anglais ordinaire : tu passes moins de temps à te battre contre le langage, et plus de temps à comprendre les idées de la programmation. La philosophie ici est simple : on avance du connu vers l'inconnu, un concept à la fois, et chaque notion se concrétise par un petit script utile que tu exécutes toi-même.

Astuce

Tape toi-même chaque exemple plutôt que de le copier-coller, et n'hésite pas à le modifier pour voir ce qui change : c'est en testant que l'on comprend vraiment.

Le programme détaillé ci-dessous te guide pas à pas, des premiers affichages jusqu'à la lecture de fichiers. À la fin, tu seras capable d'écrire de petits programmes complets et autonomes, et d'aborder sereinement des sujets plus avancés.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Une variable se crée par simple affectation (x = 5) : pas de déclaration de type.
  • L'indentation (4 espaces) délimite les blocs — il n'y a pas d'accolades.
  • Les structures clés : listes [ ], dictionnaires { }, tuples ( ).
  • for parcourt un itérable ; while répète tant qu'une condition est vraie.
  • Les fonctions se définissent avec def et peuvent renvoyer une valeur (return).
  • Les exceptions se gèrent avec try / except / finally.
  • Tout est objet ; on crée ses propres types avec class.
Variable
Un nom qui référence une valeur en mémoire (créé par affectation).
Indentation
Le décalage en début de ligne qui structure le code ; en Python, 4 espaces par niveau.
Liste
Collection ordonnée et modifiable d'éléments, notée entre crochets : [1, 2, 3].
Dictionnaire
Collection de paires clé → valeur : {"nom": "Ana"}.
Fonction
Bloc de code nommé et réutilisable, défini avec def.
Boucle
Répétition d'instructions, avec for (sur un itérable) ou while (sous condition).
Exception
Erreur survenant à l'exécution, que l'on peut intercepter avec try / except.
Module
Fichier Python réutilisable que l'on charge avec import.
Compréhension de liste
Syntaxe concise pour construire une liste : [x * x for x in range(5)].
f-string
Chaîne formatée préfixée par f, où l'on interpole des variables entre accolades : f"Bonjour {nom}".
