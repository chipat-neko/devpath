Variables et types

~30 min Débutant Leçon 01 recommandée

À la fin de cette leçon, tu sauras

  • créer des variables avec = en respectant le snake_case, et comprendre qu'une variable est une étiquette posée sur une valeur ;
  • reconnaître les types de base (int, float, str, bool, None), les inspecter avec type() et les convertir avec int(), float(), str(), bool() ;
  • calculer avec + - * / // % ** en sachant que / renvoie toujours un float, et manipuler des chaînes (concaténation, répétition, len()) ;
  • comprendre le typage dynamique mais fort de Python et convertir le résultat d'input() avant tout calcul.
Sommaire de la leçon

Dans la leçon précédente, tu as affiché du texte avec print() et croisé une première variable. Cette fois, on s'attaque au cœur du sujet : stocker des données et les nommer. C'est la brique de base de tout programme — sans variables, impossible de retenir un âge, un nom ou un total à réutiliser plus loin.

On part du plus simple (poser une étiquette sur une valeur) et on ajoute une notion à la fois : les types de données, comment les inspecter et les convertir, puis les calculs et les chaînes de caractères. Garde un interpréteur Python ouvert et recopie chaque exemple : c'est en tapant que ça rentre.

L'affectation avec =

Pour créer une variable, tu écris son nom, le signe =, puis la valeur. Pas de mot-clé comme let ou const (ça, c'est JavaScript), pas de point-virgule en fin de ligne : juste nom = valeur.

Le bon modèle mental : une variable est une étiquette posée sur une valeur, pas une « boîte » qui contient la valeur. Le nom age pointe vers le nombre 25. Si tu réaffectes, tu déplaces simplement l'étiquette vers une autre valeur.

Côté nommage, la convention Python est le snake_case : tout en minuscules, les mots séparés par des tirets bas. On écrit prix_total, nombre_de_joueurs, et non prixTotal ni PrixTotal. Un nom de variable commence par une lettre ou un _, jamais par un chiffre.

Astuce

Choisis des noms qui décrivent le contenu : prix_ttc vaut bien mieux que x ou truc. Ton code de demain (et tes coéquipiers) te remercieront.

Les types de base

Chaque valeur a un type qui décrit sa nature. Cinq types reviennent constamment au début :

  • int — un entier, comme 25 ou -7. En Python, les entiers ont une taille illimitée : pas de débordement.
  • float — un nombre à virgule, comme 3.14 (avec un point, pas une virgule).
  • str — une chaîne de caractères, du texte entre guillemets : "Lyon".
  • bool — un booléen, vrai ou faux : True ou False (avec une majuscule).
  • NoneType — un seul cas, None, qui représente l'absence de valeur.

Inspecter et convertir les types

Quand tu doutes de ce que contient une variable, la fonction type() te renvoie son type.

Pour passer d'un type à un autre, on utilise une conversion explicite (le « casting ») : int(), float(), str() et bool(). Chacune fabrique une nouvelle valeur dans le type voulu.

La conversion en booléen suit une règle simple : 0, 0.0, la chaîne vide "" et None deviennent False ; presque tout le reste devient True.

Les nombres et leurs opérateurs

Les opérations arithmétiques de base sont + (addition), - (soustraction), * (multiplication) et / (division). Point important : la division / renvoie toujours un float, même quand le résultat « tombe juste ».

Trois opérateurs complètent la panoplie : // la division entière (le quotient, sans la partie décimale), % le modulo (le reste de la division) et ** la puissance.

Comme en maths, les opérateurs ont une priorité : ** d'abord, puis *, /, //, %, et enfin + et -. Les parenthèses forcent l'ordre quand tu veux lever toute ambiguïté.

Les chaînes de caractères

Une chaîne (str) s'écrit entre guillemets simples ou doubles, au choix : 'Lyon' et "Lyon" sont identiques. Pratique pour inclure une apostrophe sans souci : "l'été".

Retiens trois outils ici : + assemble (concatène), * répète, et len() mesure. On creusera bien davantage les chaînes dans une leçon dédiée.

Typage dynamique mais fort

Python a un typage dynamique : une variable n'a pas de type figé, elle peut changer de type au fil du programme.

Mais ce typage est aussi fort : Python ne mélange jamais les types « en douce ». Tenter d'additionner une chaîne et un nombre lève une TypeError au lieu de deviner ce que tu voulais.

input() renvoie toujours une str

Pour lire une saisie, on utilise input(). Point capital, qui découle directement du typage fort : input() renvoie toujours une chaîne (str), même si la personne tape un nombre. Pour calculer, tu dois convertir.

Sans la conversion, texte + 1 lèverait la fameuse TypeError : on additionnerait une str et un int.

Cas réel

Toute donnée qui vient de l'extérieur arrive en texte : une saisie input(), une cellule de fichier CSV, un champ de formulaire web, une valeur lue dans une base. Un tableur qui importe une colonne « prix » reçoit des chaînes comme "19.90" ; pour en calculer la somme, le programme doit d'abord les convertir en float. Oublier cette conversion est le bug le plus fréquent du débutant : "10" + "20" affiche "1020" au lieu de 30.

Pièges fréquents

  • Oublier de convertir input(). Le résultat est une str. Pour un calcul, entoure-le de int() ou float().
  • Additionner str et int. "5" + 1 lève une TypeError. Convertis l'un ou l'autre selon ce que tu veux : int("5") + 1 donne 6, "5" + str(1) donne "51".
  • Confondre = et ==. = affecte une valeur à une variable ; == compare deux valeurs et renvoie un booléen. age = 18 donne la valeur 18 à age ; age == 18 demande « est-ce que age vaut 18 ? ».
  • Croire que / donne un entier. 6 / 2 vaut 3.0 (un float). Pour un entier, utilise la division entière 6 // 2 qui vaut 3.

Piège fréquent

Le piège classique du débutant : demander deux nombres avec input() puis les « additionner » sans convertir. "3" + "4" ne fait pas 7 mais "34" (deux textes collés). Convertis avec int() avant tout calcul.

Pour aller plus loin

Quelques pistes pour quand tu seras à l'aise, à ne pas approfondir maintenant :

  • Les f-strings (vues en leçon 1, détaillées en leçon 9) évitent les + et les str() : f"âge : {age}" insère directement la valeur.
  • La précision des float réserve des surprises : 0.1 + 0.2 n'affiche pas 0.3 mais 0.30000000000000004. C'est normal — les float sont stockés en binaire et certains nombres décimaux n'ont pas de représentation exacte.
  • Les entiers illimités sont une particularité de Python : tu peux calculer 2 ** 1000 sans rien configurer.
  • Certaines valeurs sont immuables (non modifiables sur place), comme les nombres et les chaînes — une notion qui prendra tout son sens plus tard.

Pour aller plus loin

Essaie print(0.1 + 0.2) dans le REPL. Le résultat étonnant n'est pas un bug de Python : c'est ainsi que les ordinateurs stockent les nombres à virgule. On y reviendra dans une leçon dédiée aux nombres.

Antisèche : variables, types et calculs

Glossaire

Variable
Étiquette posée sur une valeur, créée avec nom = valeur.
Affectation
L'opération = qui associe une valeur à un nom (à ne pas confondre avec ==, la comparaison).
snake_case
Convention de nommage Python : minuscules et tirets bas, ex. prix_total.
Type
Nature d'une valeur : int, float, str, bool, None.
None
Valeur spéciale unique représentant l'absence de valeur (type NoneType).
Conversion (casting)
Fabriquer une valeur d'un autre type : int("42"), str(7), float("3.5").

Récap et vérification

  • Une variable se crée avec nom = valeur (snake_case, sans mot-clé) ; c'est une étiquette posée sur une valeur.
  • Types de base : int (illimité), float, str, bool (True/False), None ; type() les inspecte.
  • La conversion explicite — int(), float(), str(), bool() — fait passer une valeur d'un type à un autre.
  • Nombres : / donne toujours un float ; // divise en entier, % donne le reste, ** élève à la puissance.
  • Typage dynamique (le type peut changer) mais fort ("texte" + 30 lève une TypeError) ; input() renvoie toujours une str.
