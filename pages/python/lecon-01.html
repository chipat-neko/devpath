Module 01 · Premiers pas — Leçon 01

Premiers pas en Python

~32 min Débutant Aucun prérequis

À la fin de cette leçon, tu sauras

  • exécuter du code Python dans le REPL et dans un fichier .py ;
  • afficher des valeurs avec print() et créer des variables sans déclaration explicite ;
  • reconnaître les types de base (int, float, str, bool) et lire une saisie avec input() ;
  • composer des messages dynamiques avec les f-strings.
Sommaire de la leçon

Cette première leçon te fait écrire et exécuter tes tout premiers programmes Python. L'objectif est concret : à la fin, tu sauras afficher du texte, stocker des informations dans des variables, distinguer les types de données de base et fabriquer un message qui mélange du texte et un calcul.

Tu n'as besoin d'aucune connaissance préalable. On part du plus simple — afficher un mot à l'écran — puis on ajoute une notion à la fois. Garde un interpréteur Python ouvert à côté de toi et reproduis chaque exemple : c'est en tapant le code que ça rentre.

Qu'est-ce que Python

Python est un langage interprété : tu écris du texte (le code source) et un programme appelé interpréteur le lit puis l'exécute ligne après ligne, sans étape de compilation visible. C'est pratique pour débuter, car tu vois le résultat immédiatement.

Python est aussi réputé pour sa lisibilité : le code ressemble presque à de l'anglais, et la mise en page (les retours à la ligne, les espaces de début) fait partie de la syntaxe. Enfin, il est polyvalent : on l'utilise pour le développement web, l'analyse de données (data), l'intelligence artificielle et les petits scripts d'automatisation du quotidien.

Note

Il existe deux grandes familles, Python 2 et Python 3. Python 2 n'est plus maintenu : utilise toujours Python 3. Dans ce cours, « Python » signifie « Python 3 ».

Où exécuter du code

Tu as deux façons d'exécuter du Python. La première est le REPL (aussi appelé interpréteur interactif) : tu lances la commande python dans un terminal, tu obtiens une invite >>>, et chaque ligne tapée est exécutée tout de suite. C'est idéal pour tester une idée.

La seconde façon est d'écrire ton code dans un fichier portant l'extension .py, puis de l'exécuter d'un coup. C'est ce qu'on fait pour un vrai programme que l'on veut réutiliser.

Afficher avec print()

print() est la fonction qui affiche quelque chose à l'écran. Tu mets entre les parenthèses ce que tu veux montrer. Si c'est du texte, tu l'entoures de guillemets.

Observe la différence : "Bonjour" est du texte affiché tel quel, tandis que 2 + 3 est un calcul. Python évalue d'abord l'expression, puis print() affiche son résultat, 5.

Variables et typage dynamique

Une variable est une étiquette qui désigne une valeur. Pour en créer une, tu écris son nom, le signe =, puis la valeur. Pas de mot-clé pour déclarer, pas de point-virgule en fin de ligne : c'est tout.

On parle de typage dynamique : tu n'indiques jamais à l'avance le type d'une variable, Python le devine d'après la valeur. Tu peux même réassigner librement une variable, y compris avec un type différent.

Les types de base

Quatre types reviennent sans cesse au début. Le int (nombre entier, comme 25), le float (nombre à virgule, comme 3.14, avec un point et non une virgule), le str (du texte, ou chaîne de caractères, entre guillemets doubles "texte" ou simples 'texte') et le bool (booléen : True ou False).

La fonction type() te renvoie le type d'une valeur : très utile quand tu doutes de ce que contient une variable.

Piège fréquent

En Python, les booléens s'écrivent True et False avec une majuscule initiale, tout comme None (l'absence de valeur). Écrire true ou false en minuscules provoque une erreur.

Lire l'utilisateur avec input()

Pour demander quelque chose à la personne qui exécute le programme, on utilise input(). Le texte entre parenthèses est la question affichée, et la réponse tapée est renvoyée par la fonction.

Point crucial : input() renvoie toujours une chaîne de caractères (str), même si la personne tape un nombre. Pour faire un calcul, tu dois d'abord convertir avec int() (entier) ou float() (décimal).

Les f-strings

Pour fabriquer un message qui mélange du texte et des valeurs, le plus lisible est la f-string : une chaîne précédée de la lettre f, dans laquelle tu places des accolades { } contenant une variable ou une expression.

Tout ce qui est entre accolades est évalué : {nom} est remplacé par la valeur de la variable, et {10 + 2} par le résultat du calcul. Le reste de la chaîne est affiché tel quel.

Cas réel

Dès qu'un service envoie un e-mail de confirmation (« Bonjour Sam, ta commande n°1042 d'un montant de 36,50 € est validée »), il assemble ce texte avec des f-strings : une trame fixe dans laquelle on injecte le nom du client, le numéro de commande et le total. Les journaux d'un serveur (les logs) sont eux aussi presque toujours composés ainsi, par exemple f"[{heure}] utilisateur {identifiant} connecté".

Astuce

Les f-strings évitent d'enchaîner des + et des conversions. Avec elles, pas besoin de transformer un nombre en texte : f"J'ai {age} ans" fonctionne directement, même si age est un int.

Commentaires et indentation

Deux derniers réflexes avant de pratiquer. D'abord, le caractère # introduit un commentaire : tout ce qui suit sur la ligne est ignoré par Python et sert uniquement à expliquer ton code à un lecteur humain (toi compris, plus tard).

Ensuite, garde en tête que l'indentation (les espaces en début de ligne, par convention 4 espaces) est significative en Python : contrairement à beaucoup de langages, elle ne sert pas qu'à faire joli, elle délimitera bientôt des blocs (conditions, boucles, fonctions). Pour l'instant, écris simplement tes instructions les unes sous les autres, sans espace devant.

Note

Tu n'as pas encore besoin d'indenter quoi que ce soit dans cette leçon. On le mentionne juste pour que la règle ne te surprenne pas : dès la prochaine notion (les conditions), l'indentation deviendra ton principal outil de structure.

Pièges fréquents

  • Indentation incohérente. Un espace en trop ou en moins au début d'une ligne déclenche une IndentationError. Reste cohérent : pas d'espace devant tes lignes simples pour le moment.
  • Majuscules des littéraux. True, False et None prennent une majuscule ; true est inconnu de Python.
  • print() n'est pas return. print() affiche une valeur à l'écran, il ne la « renvoie » pas pour être réutilisée plus tard. La nuance deviendra importante avec les fonctions.
  • Le résultat d'input() est du texte. "5" + 1 plante car on ne peut pas additionner une chaîne et un nombre. Convertis d'abord : int("5") + 1.

Piège fréquent

Additionner une chaîne et un nombre lève une erreur : "5" + 1 renvoie une TypeError. C'est volontaire — on en parle juste en dessous.

Pour aller plus loin

Python a une philosophie revendiquée autour de la lisibilité. Tape import this dans le REPL pour lire « Le Zen de Python », une liste de principes comme « la lisibilité compte ».

Autre point qui surprend ceux qui viennent de JavaScript : Python a un typage dynamique mais fort. Concrètement, il ne mélange pas les types en douce. En JavaScript, "3" + 4 donne silencieusement "34" ; en Python, "3" + 4 lève une erreur (TypeError) au lieu de deviner. C'est une bonne nouvelle : Python t'avertit tôt au lieu de produire un résultat inattendu.

Antisèche : les bases de Python

Les gestes de cette leçon, en un coup d'œil.

Glossaire

Interpréteur
Programme qui lit le code source et l'exécute ligne après ligne, sans étape de compilation visible.
REPL
Read-Eval-Print Loop : l'invite interactive >>> qui évalue et affiche chaque ligne aussitôt.
Variable
Étiquette qui désigne une valeur, créée avec nom = valeur, sans déclaration de type.
Typage dynamique
Le type n'est pas déclaré : Python le déduit de la valeur, et une variable peut changer de type.
Type
Nature d'une valeur : int (entier), float (décimal), str (texte), bool (vrai/faux).
Conversion
Changer le type d'une valeur : int("5") donne l'entier 5 ; str(5) donne "5".
f-string
Chaîne préfixée de f où chaque {expression} est évaluée puis insérée dans le texte.
Indentation
Espaces en début de ligne ; en Python elle est significative et délimitera les blocs.

Récap et vérification

  • Python est interprété, lisible et polyvalent ; on utilise Python 3, dans le REPL ou via python fichier.py.
  • print() affiche ; une variable se crée avec nom = valeur, sans déclaration ni point-virgule.
  • Types de base : int, float, str, bool (True/False) ; type() donne le type.
  • input() renvoie toujours une str ; convertir avec int() pour calculer.
  • Une f-string (f"... {variable} ...") compose un message mêlant texte et expressions.

Vérifie ta compréhension

  1. Quelle est la différence entre exécuter du code dans le REPL et dans un fichier .py ?
  2. Pourquoi int(input("Âge : ")) + 1 fonctionne-t-il alors que input("Âge : ") + 1 échoue ?
  3. Que va afficher print(f"{3 * 4} points"), et pourquoi ?
