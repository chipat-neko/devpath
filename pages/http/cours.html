HTTP : comment marche le web

Derrière chaque page se cache un dialogue : une requête et une réponse, en HTTP. Ce cours t'explique tout le voyage : client-serveur et DNS, structure des messages, méthodes et codes de statut, en-têtes, cookies et sessions, HTTPS et CORS. Le socle indispensable de tout développeur web.

Bien s'équiper

Les extensions VS Code pour le web et HTTP

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils te permettent d'envoyer des requêtes et d'observer les réponses, directement dans l'éditeur.

À installer pour ce cours

  • REST Client (Huachao Mao) — envoyer des requêtes HTTP depuis un simple fichier .http.
  • Thunder Client (Ranga Vadhineni) — client HTTP graphique léger, pour tester des requêtes.
  • Live Preview (Microsoft) — servir et prévisualiser une page en local.
  • DotENV (mikestead) — coloration des fichiers .env (URL, jetons).

Pour qui ?

Pour tous ceux qui touchent au web : aucun prérequis de programmation. Le cours éclaire et complète HTML, API REST (même protocole, corps en JSON) et Sécurité (cookies, HTTPS, CORS).

Ce que tu vas apprendre

Le web, sans boîte noire

À la fin du cours, tu sauras

  • raconter le voyage d'une page (client-serveur, IP, DNS, URL) ;
  • lire une requête et une réponse, choisir la bonne méthode et décoder les statuts ;
  • expliquer cookies et sessions par-dessus un protocole sans état ;
  • comprendre HTTPS, la politique de même origine et CORS.

Pourquoi apprendre HTTP

On peut faire un site sans comprendre HTTP… jusqu'au premier bug réseau, à la première erreur CORS, au premier souci de cookie ou de cache. Comprendre le protocole transforme ces énigmes en problèmes clairs, et c'est la base commune à tout : front-end, back-end, API, sécurité. C'est l'un des savoirs les plus rentables du métier.

Le cours est concret : garde l'onglet Réseau de ton navigateur ouvert (F12) et observe, à chaque leçon, le dialogue réel que tu viens d'apprendre à lire.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Modèle requête-réponse entre client et serveur.
  • Méthodes : GET (lire), POST (envoyer)…
  • Statuts : 200 OK, 3xx redirection, 4xx/5xx erreurs.
  • En-têtes (Content-Type…) ; cookies pour la session.
  • HTTPS chiffre les échanges (TLS).
Requête / réponse
Message envoyé par le client / renvoyé par le serveur.
Méthode
Action demandée (GET, POST, PUT, DELETE).
Code de statut
Résultat de la requête (200, 404, 500…).
En-tête
Métadonnée d'une requête ou d'une réponse.
Cookie
Petite donnée stockée pour suivre une session.
HTTPS
Version chiffrée d'HTTP (via TLS).
