Module 3 · Zig en pratique — Leçon 09

Interopérabilité C et build

~50 min Avancé Prérequis : leçon 8

À la fin de cette leçon, tu sauras

  • importer et appeler du code C (@cImport) ;
  • utiliser Zig comme compilateur C ;
  • faire de la compilation croisée sans effort ;
  • écrire un build.zig.
Sommaire de la leçon

Zig ne vit pas en vase clos : l'un de ses arguments les plus forts est sa relation exceptionnelle avec le C. Il peut importer des en-têtes C directement, compiler du code C, et faire de la compilation croisée sans configuration. Beaucoup adoptent Zig d'abord… comme un meilleur compilateur C ! Cette leçon couvre l'interopérabilité et le système de build.

Importer du C

La fonction intégrée @cImport lit un en-tête C et rend ses fonctions et types disponibles en Zig — sans écrire de liaisons à la main.

On appelle printf du C aussi naturellement qu'une fonction Zig.

Zig comme compilateur C

Surprise : la commande zig cc est un compilateur C complet (basé sur Clang/LLVM), souvent plus simple à utiliser que GCC pour la compilation croisée. On peut donc utiliser Zig pour bâtir des projets C existants.

La compilation croisée

Atout phare : Zig embarque tout ce qu'il faut pour compiler vers n'importe quelle plateforme, depuis n'importe quelle machine, sans installer de chaîne d'outils. Une option -target suffit.

Ce que d'autres langages rendent pénible (installer des SDK, des sysroots), Zig le fait d'une ligne.

Le système de build : build.zig

Pour un vrai projet, on écrit la configuration de build… en Zig, dans un fichier build.zig. Pas de langage de build séparé (comme Make ou CMake) : c'est du Zig normal qui décrit comment construire le projet.

Les modes d'optimisation

Zig propose plusieurs modes : Debug (vérifications de sécurité, lent), ReleaseSafe (rapide + vérifications), ReleaseFast (vitesse maximale), ReleaseSmall (binaire minuscule). On choisit selon le besoin.

Cas réel — compiler du C portable avec zig cc

Plusieurs équipes d'ingénierie ont remplacé une chaîne de compilation croisée C/C++ complexe par un simple zig cc -target …. Comme Zig embarque les bibliothèques des cibles, on produit depuis une seule machine des binaires pour plusieurs architectures Linux, Windows ou macOS, sans jongler avec des sysroots ni une toolchain par plateforme. Beaucoup adoptent d'ailleurs Zig uniquement comme « meilleur compilateur C portable », avant même d'en écrire une ligne.

Pièges fréquents

Piège fréquent

Croire que les vérifications de sécurité de Zig sont toujours actives : en mode ReleaseFast, elles sont désactivées pour la vitesse. Un débordement qui plantait proprement en Debug devient un comportement indéfini. Utilise ReleaseSafe si tu veux garder les garde-fous en production.

Pour aller plus loin

Pour aller plus loin

Cette interop C exceptionnelle fait de Zig un excellent outil pour moderniser progressivement une base de code C : on remplace des fichiers un à un, en gardant le reste, puisque Zig compile et appelle le C sans friction.

Glossaire

@cImport
Fonction intégrée qui lit un en-tête C et expose ses fonctions et types à Zig, sans écrire de liaisons manuelles.
Interopérabilité (interop)
Capacité de deux langages à coopérer ; Zig appelle du C (et inversement) de façon native.
zig cc
Le compilateur C complet inclus dans Zig (basé sur Clang/LLVM), utilisable seul pour bâtir des projets C.
Compilation croisée
Produire un exécutable pour une autre plateforme que la machine de compilation ; en Zig, via l'option -target.
Cible (target)
Couple architecture-système visé (ex. x86_64-windows) ; désigné par -target.
build.zig
Fichier décrivant la construction du projet, écrit en Zig ; remplace Make ou CMake.
Mode d'optimisation
Compromis vitesse/sûreté/taille choisi à la construction : Debug, ReleaseSafe, ReleaseFast, ReleaseSmall.

Récap et vérification

  • @cImport/@cInclude importent des en-têtes C directement utilisables.
  • zig cc est un compilateur C ; on mélange Zig et C dans un projet.
  • La compilation croisée se fait avec -target, sans chaîne d'outils à installer.
  • Le build se décrit en Zig (build.zig) ; modes Debug/ReleaseSafe/ReleaseFast/ReleaseSmall.
