C : programmation système

Le C est le langage des systèmes d'exploitation, de l'embarqué et des moteurs de performance. Apprendre le C, c'est comprendre comment la machine fonctionne vraiment : la mémoire, les pointeurs, ce que coûte chaque octet. Ce cours te mène de la première compilation à l'allocation dynamique et au débogage mémoire — les fondations qui éclairent tous les autres langages.

Bien s'équiper

Les extensions VS Code pour C

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour C

  • C/C++ (Microsoft) — IntelliSense et débogage.
  • C/C++ Extension Pack (Microsoft) — l'ensemble de l'outillage.
  • CMake Tools (Microsoft) — configurer et lancer la compilation.
  • Code Runner (Jun Han) — compiler et exécuter rapidement.

Niveau

Cours exigeant : le C ne cache rien et ne pardonne pas grand-chose. Des bases en programmation (variables, boucles, fonctions, par ex. via le cours JavaScript) sont recommandées. En échange, tu comprendras la mémoire mieux que jamais.

Ce que tu vas apprendre

Comprendre la machine, un octet à la fois

À la fin du cours, tu sauras

  • compiler du C (gcc) et écrire types, opérateurs, conditions, boucles et fonctions ;
  • manier les pointeurs, les tableaux et les chaînes, et comprendre la relation entre eux ;
  • gérer la mémoire à la main : malloc/free, la pile vs le tas, éviter fuites et pointeurs fous ;
  • structurer des données (struct, union, enum), lire/écrire des fichiers et organiser un projet (préprocesseur, Makefile, gdb/valgrind).

Pour qui, et pourquoi

Ce cours s'adresse à qui veut programmer au plus près du matériel : systèmes, embarqué, jeux, ou simplement comprendre les fondations sur lesquelles reposent Python, Java ou JavaScript. Le C a plus de cinquante ans et reste incontournable ; il forme une intuition de la mémoire qui te servira partout.

Chaque leçon est illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties sont montrées en commentaire.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Afficher avec printf ; inclure #include <stdio.h>.
  • Bas niveau : on gère la mémoire (malloc / free) et les pointeurs.
  • Une chaîne est un tableau de char terminé par le caractère nul \0.
  • Passer un tableau à une fonction transmet en réalité un pointeur.
  • Point d'entrée : int main(void).
  • Pas d'objets : des structures (struct) et des fonctions.
  • Compilé en code natif très efficace.
Pointeur
Variable contenant une adresse (* déréférence, & donne l'adresse).
malloc / free
Allocation et libération manuelles de la mémoire dynamique.
struct
Type regroupant plusieurs champs sous un seul nom.
Tableau
Suite contiguë d'éléments de même type, en mémoire.
Chaîne
Tableau de char terminé par le caractère nul \0.
printf
Fonction d'affichage formaté (%d, %s…).
En-tête (.h)
Fichier déclarant des fonctions et types, à inclure avec #include.
Compilation
Traduction du code source en un exécutable natif.
