Module 1 · Les bases de Julia — Leçon 03

Conditions et boucles

~45 min Intermédiaire Prérequis : leçon 2

À la fin de cette leçon, tu sauras

  • écrire des conditions (if, ternaire, court-circuit) ;
  • boucler avec for (et les plages) et while ;
  • utiliser break et continue ;
  • écrire des compréhensions de tableau.
Sommaire de la leçon

Pour piloter un calcul, il faut décider et répéter. Julia offre des structures de contrôle classiques et lisibles, plus une fonctionnalité élégante héritée des mathématiques : les compréhensions de tableau. Tout bloc se ferme par end.

if / elseif / else

La condition n'a pas besoin de parenthèses. On ferme par end. Et comme presque tout est une expression, un if peut renvoyer une valeur.

Le ternaire et le court-circuit

Pour un choix court, l'opérateur ternaire condition ? a : b. Les opérateurs && et || court-circuitent — un idiome Julia courant pour exécuter conditionnellement.

La boucle for

for parcourt n'importe quel itérable : une plage, un tableau, une chaîne. Les plages s'écrivent début:fin ou début:pas:fin.

La boucle while

while répète tant qu'une condition tient.

Au niveau global d'un script, modifier une variable depuis une boucle exige global (dans une fonction, ce n'est pas nécessaire).

break et continue

Comme partout : break sort de la boucle, continue passe à l'itération suivante.

Les compréhensions

Magnifique héritage mathématique : une compréhension construit un tableau en décrivant ses éléments. Plus court et souvent plus rapide qu'une boucle.

Un cas réel

Cas réel — filtrer un jeu de données

En analyse de données, on retient sans cesse un sous-ensemble d'observations et on le transforme au passage : « les températures au-dessus de 30 °C, converties en Fahrenheit ». Écrit avec une compréhension, cela tient en une ligne : [c*9/5+32 for c in temps if c > 30]. C'est exactement l'esprit des list comprehensions de Python et du WHERE en SQL : décrire le résultat voulu plutôt que la mécanique de la boucle. En Julia, le compilateur transforme cette description en code natif rapide.

Pièges fréquents

Piège fréquent

Oublier global en modifiant une variable globale dans une boucle de script : tu obtiens une erreur ou un comportement inattendu. La vraie bonne pratique : mets ton code dans une fonction — là, le problème disparaît et le code est plus rapide (leçon 8).

Pour aller plus loin

Pour aller plus loin

Pour itérer avec l'indice et la valeur : for (i, v) in enumerate(tableau). Pour parcourir deux collections en parallèle : for (a, b) in zip(xs, ys). Deux idiomes très utiles.

Glossaire

Structure de contrôle
Construction qui pilote le déroulement du programme (décider, répéter) : if, for, while. En Julia, chaque bloc se ferme par end.
Ternaire (? :)
Forme condensée d'un if/else qui renvoie une valeur : condition ? valeur_si_vrai : valeur_si_faux.
Court-circuit
Évaluation paresseuse de && et || : le second membre n'est calculé que si nécessaire, ce qui sert d'idiome pour exécuter une action sous condition.
Plage (début:pas:fin)
Intervalle d'entiers parcouru par une boucle ; le pas central peut être négatif (10:-2:0).
Itérable
Toute valeur que for sait parcourir élément par élément : plage, tableau, chaîne…
break / continue
break quitte la boucle ; continue abandonne l'itération courante et passe à la suivante.
Compréhension
Expression [expr for x in itérable if cond] qui construit un tableau en décrivant ses éléments, à la manière des mathématiques.
global
Mot-clé requis pour modifier une variable globale depuis une boucle au niveau d'un script ; inutile (et à éviter) dans une fonction.

Récap et vérification

  • if/elseif/else … end décide ; le ternaire et &&/|| pour les cas courts.
  • for x in itérable et while ; plages début:pas:fin.
  • break et continue contrôlent le flux.
  • Les compréhensions [expr for x in … if …] construisent des tableaux élégamment.

Vérifie ta compréhension

  1. Comment écrire une plage de 10 à 0 par pas de -2 ?
  2. Écris une compréhension donnant les cubes de 1 à 4.
  3. Pourquoi vaut-il mieux mettre une boucle dans une fonction ?
