Module 1 · Les bases de Julia — Leçon 04

Les fonctions

~50 min Intermédiaire Prérequis : leçon 3

À la fin de cette leçon, tu sauras

  • définir des fonctions (forme courte et longue) ;
  • écrire des fonctions anonymes (->) et les passer en argument ;
  • utiliser arguments par défaut, nommés et variadiques ;
  • maîtriser map, filter, reduce et l'opérateur |>.
Sommaire de la leçon

Les fonctions sont l'unité de base de Julia — et, on le verra, le terrain de jeu du multiple dispatch. Julia offre une syntaxe légère, des fonctions anonymes élégantes et des arguments flexibles. C'est aussi là que le code devient rapide : mets toujours ton travail dans des fonctions.

Définir une fonction

Deux formes : la forme longue (function … end) et la forme courte, presque mathématique. La dernière expression est renvoyée automatiquement (return est optionnel).

Julia autorise la multiplication implicite : 2x signifie 2*x, comme en maths.

Fonctions anonymes

Pour une fonction jetable, la flèche ->. Indispensable pour les fonctions d'ordre supérieur.

Arguments par défaut et nommés

On donne des valeurs par défaut, et on sépare les arguments nommés par un point-virgule (ils s'écrivent avec leur nom à l'appel).

Arguments variadiques

Trois points (...) après un paramètre captent un nombre quelconque d'arguments dans un tuple.

Fonctions d'ordre supérieur

Les fonctions sont des valeurs de première classe : on les passe et les renvoie. map, filter et reduce transforment des collections.

L'opérateur pipe

L'opérateur |> chaîne les transformations en passant le résultat à gauche comme argument à droite : lisible pour un pipeline.

Un cas réel

Cas réel — un pipeline de traitement de données

Sur un vrai jeu de mesures, une analyse s'enchaîne souvent en étapes : charger → nettoyer → filtrer → agréger. Le pipe rend ce cheminement littéral : données |> nettoyer |> filtrer_valides |> moyenne. C'est l'esprit des %>% de R (tidyverse) et des pipelines Unix (cat | grep | sort) : chaque brique fait une chose, et on les compose. Comme les fonctions sont des valeurs en Julia, on peut aussi stocker une étape dans une variable ou la choisir dynamiquement.

Pièges fréquents

Piège fréquent

Une convention Julia importante : une fonction dont le nom finit par ! (comme push!, sort!) modifie son argument. sort(v) renvoie un tableau trié ; sort!(v) trie v sur place. Respecte cette convention dans tes propres fonctions.

Pour aller plus loin

Pour aller plus loin

Une même fonction peut avoir plusieurs méthodes selon les types de ses arguments : c'est le multiple dispatch, le concept le plus puissant de Julia, que nous verrons en détail à la leçon 7. Tes fonctions y sont déjà préparées.

Glossaire

Forme courte
Définition d'une fonction en une expression : nom(args) = expression, sans function ni end.
Fonction anonyme
Fonction sans nom créée avec -> (x -> x + 1) ; utile pour la passer à map, filter…
Retour implicite
La valeur de la dernière expression d'une fonction est renvoyée automatiquement ; return reste facultatif.
Argument nommé
Paramètre placé après un ; et fourni par son nom à l'appel : indépendant de l'ordre, souvent avec une valeur par défaut.
Argument variadique (...)
Paramètre qui capte un nombre quelconque d'arguments, rassemblés dans un tuple.
Fonction d'ordre supérieur
Fonction qui prend ou renvoie une autre fonction (map, filter, reduce).
Pipe (|>)
Opérateur qui passe la valeur de gauche comme argument à la fonction de droite : x |> f vaut f(x).
Convention !
Un nom terminé par ! signale une fonction qui modifie son argument sur place (push!, sort!).

Récap et vérification

  • Forme longue function … end ou courte f(x) = … ; retour implicite.
  • Fonctions anonymes avec -> ; arguments par défaut, nommés (après ;) et variadiques (...).
  • map, filter, reduce et l'opérateur |> pour les pipelines.
  • Convention ! : une fonction f! modifie son argument.

Vérifie ta compréhension

  1. Que signifie double(x) = 2x ?
  2. Comment passer un argument nommé ?
  3. Que dit la convention du ! en fin de nom ?
