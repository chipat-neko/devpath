Julia : le calcul scientifique moderne

Julia tient une promesse audacieuse : la vitesse du C avec la syntaxe d'un langage de script. Fini le « problème des deux langages » : on prototype et on déploie dans le même. Son multiple dispatch, son broadcasting et sa compilation JIT en font un favori de la recherche, de la finance et du machine learning scientifique. Ce cours te mène des bases au calcul numérique.

Bien s'équiper

Les extensions VS Code pour Julia

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Julia

  • Julia (julialang) — IntelliSense, REPL intégré, débogage et tracé.

Pour qui ?

Idéal si tu sais déjà programmer et que les données ou les sciences t'intéressent. Le cours Python est un bon point de comparaison : Julia répond aux mêmes besoins, en visant la performance native.

Ce que tu vas apprendre

Du REPL au calcul scientifique

À la fin du cours, tu sauras

  • écrire du Julia idiomatique : types, fonctions, conditions, compréhensions ;
  • exploiter les tableaux et le broadcasting, structurer avec dicts et structs ;
  • maîtriser le multiple dispatch et écrire du code performant (stabilité de type) ;
  • utiliser l'écosystème (Pkg, DataFrames, Plots) et le calcul scientifique (équations, autodiff, ML).

Pour qui, et pourquoi

Ce cours s'adresse aux scientifiques, ingénieurs, analystes de données et à tous ceux qui veulent un langage rapide et expressif pour le calcul. Julia gagne du terrain partout où il faut prototyper vite sans sacrifier la vitesse : un seul langage du brouillon à la production.

Chaque leçon est autonome et illustrée par du code commenté que tu peux exécuter dans le REPL. Les sorties sont montrées en commentaire.

À retenir

  • Tableaux indexés à partir de 1.
  • function … end ; types avec struct.

Multiple dispatch
Choix de la méthode selon les types de TOUS les arguments.
JIT
Compilation à la volée (vitesse proche du C).
struct
Type composite à champs.
Tableau
Collection numérique indexée à partir de 1.
Broadcast (.)
Applique une opération élément par élément sur un tableau.
Type
Chaque valeur a un type, exploité par le dispatch.
