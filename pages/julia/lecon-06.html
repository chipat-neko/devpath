Module 2 · Données et performance — Leçon 06

Dictionnaires, tuples et structures

~50 min Intermédiaire Prérequis : leçon 5

À la fin de cette leçon, tu sauras

  • manier tuples et tuples nommés ;
  • associer clés et valeurs avec les dictionnaires ;
  • définir ses propres types avec struct ;
  • comprendre l'immutabilité par défaut des structs.
Sommaire de la leçon

Au-delà des tableaux, Julia offre plusieurs façons de structurer des données : les tuples (groupes figés), les dictionnaires (associations clé-valeur), et surtout les struct pour définir tes propres types. Bien modéliser ses données prépare le terrain au multiple dispatch.

Les tuples

Un tuple regroupe des valeurs dans un paquet ordonné et immuable. Idéal pour renvoyer plusieurs résultats d'une fonction.

Les tuples nommés

Un tuple nommé ajoute des noms de champs : plus lisible qu'un tuple positionnel, sans le poids d'un type complet.

Les dictionnaires

Un Dict associe des clés à des valeurs. On crée avec =>, on accède par clé.

Comme partout, l'ordre d'un dictionnaire n'est pas garanti.

Définir ses types : struct

Un struct définit un nouveau type avec des champs. Par défaut, il est immuable (ses champs ne changent pas après création) — un choix qui favorise la performance et la sûreté.

Structs mutables

Si tu as besoin de modifier les champs, déclare mutable struct. À n'utiliser que si nécessaire : l'immuabilité est plus rapide.

Types paramétriques

Un struct peut être générique sur un type, comme les conteneurs de la stdlib. Le paramètre T est déterminé à la construction.

Ces types paramétriques sont à la fois flexibles et rapides : Julia compile une version spécialisée pour chaque T.

Un cas réel

Cas réel — modéliser un domaine scientifique

Dans une simulation de physique, on représente une particule par un struct Particule (position, vitesse, masse). L'immuabilité par défaut y est précieuse : à chaque pas de temps, on produit un nouvel état plutôt que de muter l'ancien, ce qui rend le calcul reproductible et parallélisable sans risque de données partagées corrompues. Le paramétrage Particule{Float32} vs {Float64} laisse choisir la précision selon le besoin — vitesse contre exactitude. C'est exactement ainsi que des bibliothèques comme DifferentialEquations.jl obtiennent lisibilité et performance de pointe.

Pièges fréquents

Piège fréquent

Déclarer mutable struct par réflexe : l'immuabilité est le bon défaut (plus sûr et plus rapide). Beaucoup de besoins de « modification » se résolvent en créant un nouvel objet plutôt qu'en mutant l'ancien.

Pour aller plus loin

Pour aller plus loin

Un struct peut être un sous-type d'un type abstrait : struct Cercle <: Forme. C'est ainsi qu'on bâtit des hiérarchies pour le multiple dispatch (leçon 7) — l'équivalent Julia de l'héritage, sans la rigidité de la POO classique.

Glossaire

Tuple
Groupe ordonné et immuable de valeurs, accédées par position (t[1]) ; pratique pour renvoyer plusieurs résultats.
Tuple nommé (NamedTuple)
Tuple dont les champs portent un nom, lus par t.nom : plus lisible, toujours immuable.
Déstructuration
Affectation qui répartit les éléments d'un tuple dans plusieurs variables : x, y = point.
Dictionnaire (Dict)
Collection associant des clés à des valeurs (=>) ; l'ordre n'est pas garanti.
struct
Type composite défini par l'utilisateur, aux champs immuables par défaut.
mutable struct
Variante d'un struct dont les champs peuvent être réaffectés après création.
Type paramétrique
Type générique sur un paramètre (Paire{T}) ; Julia compile une version spécialisée pour chaque T.
Immuabilité
Propriété d'une valeur qui ne change pas après sa création : défaut sûr et performant en Julia.

Récap et vérification

  • Les tuples regroupent des valeurs immuables ; les tuples nommés ajoutent des noms.
  • Les dictionnaires (Dict) associent clés et valeurs (=>, get, haskey).
  • struct définit un type (immuable par défaut) ; mutable struct si besoin.
  • Les types paramétriques (Paire{T}) sont génériques et rapides.
