Module 2 · Données et performance — Leçon 05

Tableaux et broadcasting

~55 min Intermédiaire Prérequis : leçon 4

À la fin de cette leçon, tu sauras

  • créer et indexer des tableaux (1D et matrices) ;
  • appliquer une opération à tout un tableau avec le broadcasting (.) ;
  • utiliser les fonctions de tableau et l'algèbre linéaire ;
  • extraire des sections (slicing) et comprendre vues vs copies.
Sommaire de la leçon

Julia est né pour le calcul numérique, et les tableaux en sont le cœur. Sa fonctionnalité signature, le broadcasting (l'opérateur point), applique n'importe quelle opération élément par élément, de façon vectorisée et rapide. Cette leçon est centrale.

Créer et indexer des tableaux

Un tableau s'écrit entre crochets. Les indices commencent à 1 (comme en maths). end désigne le dernier élément.

Les matrices

Les espaces séparent les colonnes, les points-virgules séparent les lignes. Julia est nativement orienté algèbre linéaire.

Le broadcasting : l'opérateur point

Voici la star. Un point . avant une opération l'applique élément par élément à tout un tableau — sans boucle, et compilé en code rapide.

Le point se met sur les opérateurs (.+, .^) et après les fonctions (sqrt.()).

Fusionner les broadcasts

Quand on enchaîne plusieurs opérations pointées, Julia les fusionne en une seule passe (pas de tableaux intermédiaires) : c'est à la fois élégant et très performant.

Fonctions de tableau et algèbre linéaire

De nombreuses fonctions résument ou transforment : sum, maximum, sort, prod. Avec le module LinearAlgebra, on dispose des opérations matricielles.

L'opérateur \ résout un système linéaire : une ligne là où d'autres langages demandent une bibliothèque.

Vues et copies

Une tranche v[2:3] crée une copie par défaut. Pour travailler sur les données d'origine sans copier (performance), utilise une vue avec @view.

Un cas réel

Cas réel — pourquoi Julia existe

C'est pour ce genre de calcul que Julia a été créé. En traitement d'images, une photo est une matrice de pixels : éclaircir l'image, c'est image .* 1.2 — une ligne, exécutée à la vitesse du C. En finance, appliquer un taux à un portefeuille entier, c'est montants .* (1 .+ taux). Là où NumPy (Python) doit tout vectoriser pour rester rapide, Julia laisse le choix : broadcasting pour la lisibilité, boucle explicite quand elle est plus claire — les deux sont compilées en code natif. Le broadcasting a d'ailleurs inspiré des bibliothèques bien au-delà de Julia.

Pièges fréquents

Piège fréquent

Oublier le point pour une opération vectorielle : v + 10 (sans point) sur un tableau et un scalaire échoue, alors que v .+ 10 fonctionne. Dès que tu veux « élément par élément », pense au point.

Pour aller plus loin

Pour aller plus loin

En Julia, les boucles écrites à la main sont rapides (contrairement à Python ou R) : tu n'es pas obligé de tout vectoriser pour la performance. Le broadcasting est surtout là pour la lisibilité — choisis ce qui est le plus clair.

Glossaire

Tableau
Collection ordonnée d'éléments, écrite entre crochets ; en Julia, indexée à partir de 1.
Matrice
Tableau à deux dimensions : les espaces séparent les colonnes, les ; les lignes ([1 2; 3 4]).
Broadcasting (diffusion)
Application d'une opération élément par élément via le point (.+, sqrt.()), sans écrire de boucle.
Fusion (@.)
Enchaînement de plusieurs broadcasts compilé en une seule passe, sans tableau intermédiaire.
Tranche (slice)
Sous-partie d'un tableau désignée par une plage d'indices (v[2:3]) ; par défaut, c'est une copie.
Vue (@view)
Fenêtre sur les données d'un tableau existant, sans allocation ; la modifier modifie l'original.
Opérateur \
Division à gauche qui résout un système linéaire A x = b sans inverser A.
LinearAlgebra
Module standard fournissant les opérations matricielles (transposée, déterminant, décompositions…).

Récap et vérification

  • Tableaux indexés à partir de 1 ; matrices avec espaces (colonnes) et ; (lignes).
  • Le broadcasting (point) applique une opération élément par élément (.+, sqrt.(), @.).
  • Fonctions de réduction et algèbre linéaire (\ résout un système).
  • @view évite une copie ; les boucles manuelles sont rapides en Julia.

Vérifie ta compréhension

  1. À quoi sert le point dans v .^ 2 ?
  2. Quelle différence entre v[2:4] et @view v[2:4] ?
  3. Comment résoudre le système A x = b ?
