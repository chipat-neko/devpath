Module 1 · Les bases de Julia — Leçon 01

Découvrir Julia

~40 min Intermédiaire Prérequis : savoir programmer dans un autre langage

À la fin de cette leçon, tu sauras

  • comprendre pourquoi Julia résout le « problème des deux langages » ;
  • utiliser le REPL et exécuter un script .jl ;
  • afficher avec println et manier les variables ;
  • saisir la compilation JIT qui rend Julia rapide.
Sommaire de la leçon

Julia est un langage jeune (2012) né d'une ambition claire : en finir avec le « problème des deux langages ». En science des données, on prototype souvent dans un langage agréable mais lent (Python, R), puis on réécrit les parties critiques dans un langage rapide mais pénible (C, Fortran). Julia veut les deux à la fois : la syntaxe d'un langage de script et la vitesse du C. Pari tenu, grâce à une compilation à la volée (JIT) astucieuse.

Résultat : Julia gagne du terrain en calcul scientifique, finance quantitative, machine learning et partout où il faut allier expressivité et performance.

Installer et lancer Julia

On télécharge Julia depuis julialang.org. La façon interactive d'explorer, c'est le REPL (la console). On peut aussi exécuter un fichier .jl.

Ton premier programme

Pas de cérémonie : on écrit directement. println affiche avec un saut de ligne.

Comme dans beaucoup de langages modernes, $variable insère une valeur dans une chaîne.

Des variables sans déclaration

On affecte directement ; Julia déduit le type. Le typage est dynamique (les variables peuvent changer de type) mais fort (pas de conversions implicites hasardeuses).

Petit plaisir : Julia accepte l'Unicode. On peut écrire π (déjà défini !) ou nommer une variable α.

Le REPL, un laboratoire

Le REPL est central dans la culture Julia. Tape une expression, vois le résultat immédiatement. Quelques modes utiles : ? ouvre l'aide, ] passe au gestionnaire de packages, ; exécute une commande shell.

Pourquoi Julia est rapide : le JIT

La magie : à la première exécution d'une fonction, Julia la compile en code machine optimisé, spécialisé pour les types des arguments. Les appels suivants sont aussi rapides que du C. C'est pourquoi le premier appel peut sembler lent (le « temps de compilation »), puis tout s'accélère.

Note

Le fameux « temps de démarrage » (time to first plot) vient de cette compilation. Une fois chaud, Julia rivalise avec les langages compilés.

Cas réel — un modèle de banque centrale en Julia

La Federal Reserve Bank of New York a porté ses modèles macroéconomiques (DSGE) depuis MATLAB vers Julia. Résultat : une estimation nettement plus rapide, un code lisible par les économistes (pas besoin de le réécrire en C pour la vitesse) et publié en logiciel libre. C'est exactement la promesse « un seul langage » : prototyper et calculer vite au même endroit.

Pièges fréquents

Piège fréquent

Mesurer la vitesse d'une fonction au premier appel : tu mesures alors la compilation, pas l'exécution ! Appelle-la une fois pour « chauffer », puis chronomètre le second appel (on verra @benchmark à la leçon 8).

Pour aller plus loin

Pour aller plus loin

Pour un environnement de travail confortable, installe l'extension Julia de VS Code : REPL intégré, complétion, débogage et inspection des variables. C'est l'outil de référence de la communauté.

Glossaire

Julia
Langage de programmation (2012) conçu pour le calcul scientifique, réunissant la syntaxe d'un langage de script et la vitesse d'un langage compilé.
Problème des deux langages
Le fait de prototyper dans un langage facile mais lent (Python, R), puis de réécrire les parties critiques dans un langage rapide mais pénible (C, Fortran) ; Julia vise à l'éliminer.
REPL
« Read-Eval-Print Loop » : la console interactive où l'on tape une expression et voit aussitôt le résultat ; modes ? (aide), ] (packages), ; (shell).
JIT (compilation à la volée)
Julia compile chaque fonction en code machine au premier appel, spécialisé selon les types des arguments ; les appels suivants sont natifs.
Time to first plot
Le délai ressenti au tout premier appel, dû à la compilation JIT ; il ne se paie qu'une fois, ensuite tout est rapide.
Interpolation
Insérer une valeur dans une chaîne avec $ ("Bonjour $nom") ou une expression avec $( … ).
Typage dynamique
Une variable peut changer de type au fil du programme ; le type n'est pas déclaré à l'avance.
Typage fort
Julia n'effectue pas de conversions implicites hasardeuses entre types : les opérations incompatibles lèvent une erreur claire.

Récap et vérification

  • Julia vise la vitesse du C avec la syntaxe d'un script (fin du « problème des deux langages »).
  • Le REPL est le laboratoire ; println affiche, $ interpole.
  • Typage dynamique mais fort ; l'Unicode est autorisé.
  • La compilation JIT rend Julia rapide après un premier appel.
