Lua : scripting léger et embarqué

Lua est un tout petit langage — rapide, élégant, et conçu pour se glisser dans d'autres programmes. Il pilote des jeux (Roblox, World of Warcraft), des éditeurs (Neovim), des serveurs (Redis, nginx). Son secret : une unique structure, la table, d'où découlent tableaux, objets et modules. Ce cours t'emmène du premier print aux métatables et au Lua embarqué.

Bien s'équiper

Les extensions VS Code pour Lua

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Lua

  • Lua (sumneko) — IntelliSense et diagnostics (Lua Language Server).
  • Lua Debug (actboy168) — débogueur pas à pas.

Pour qui ?

Idéal si tu connais déjà les bases de la programmation dans un autre langage — par exemple via le cours JavaScript ou le cours Python. Chaque particularité de Lua (indices à partir de 1, la table unique) est expliquée depuis le début.

Ce que tu vas apprendre

Du premier script au Lua embarqué

À la fin du cours, tu sauras

  • écrire du Lua idiomatique : local, la règle de vérité, retours multiples et closures ;
  • tout faire avec la table : tableaux, dictionnaires, structures et namespaces ;
  • exploiter les métatables : surcharge d'opérateurs, valeurs par défaut et POO sur mesure ;
  • passer à la pratique : modules, bibliothèque standard, coroutines, et comprendre le Lua embarqué dans les jeux et outils.

Pour qui, et pourquoi

Ce cours s'adresse à ceux qui veulent scripter des jeux (Roblox, Love2D, mods), configurer des outils modernes (Neovim), ou comprendre un langage minimaliste et élégant qui en apprend beaucoup sur la conception. Lua est partout où il faut de la légèreté et de la vitesse.

Chaque leçon est autonome et illustrée par du code commenté. Le code ne s'exécute pas dans l'éditeur du site : les sorties sont montrées en commentaire (--).

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Léger, conçu pour être embarqué (jeux, configurations).
  • La table est LA structure de données (tableau ET dictionnaire).
  • Les tableaux sont indexés à partir de 1.
  • Variables locales avec local (sinon, elles sont globales).
  • Fonctions : function … end ; nil = absence de valeur.
  • Parcourir : ipairs (séquences), pairs (toutes les clés).
  • Afficher avec print ; formater avec string.format.
Table
Structure unique servant à la fois de tableau et de dictionnaire.
nil
Valeur représentant l'absence (variable non définie).
local
Déclare une variable de portée locale (sinon globale).
ipairs
Itère un tableau séquentiel, dans l'ordre des indices.
pairs
Itère toutes les paires clé-valeur (ordre non garanti).
Métatable
Table décrivant le comportement d'une autre (opérateurs, héritage…).
Fonction
Valeur de première classe en Lua (stockable, passable).
Coroutine
Fil d'exécution coopératif, que l'on peut suspendre et reprendre.
