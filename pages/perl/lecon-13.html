Traiter des formats de données : CSV et JSON

~40 min Intermédiaire Prérequis : leçons 8 et 9

À la fin de cette leçon, tu sauras

  • lire et écrire du CSV sans te faire piéger par les guillemets ;
  • employer Text::CSV plutôt qu'un split naïf ;
  • décoder et encoder du JSON avec JSON::PP ;
  • convertir un format vers l'autre en gérant l'encodage.
Sommaire de la leçon

Dans la vraie vie, les données arrivent rarement sous forme de texte libre : ce sont des exports CSV de tableur, des réponses JSON d'API. Perl brille pour les transformer — à condition d'utiliser les bons modules CPAN plutôt que de réinventer un analyseur fragile.

Le piège du CSV « fait main »

Un fichier CSV a l'air simple : des valeurs séparées par des virgules. La tentation est grande d'écrire my @champs = split /,/, $ligne;. Mauvaise idée : dès qu'un champ contient une virgule (protégée par des guillemets), le découpage naïf explose.

Lire du CSV avec Text::CSV

Le module Text::CSV (sur CPAN) fait le travail correctement. On crée un objet, puis on lui donne les lignes une à une ; il renvoie un tableau de champs propres.

Encore mieux : column_names + getline_hr renvoient chaque ligne comme un hachage clé → valeur, indexé par les en-têtes.

Astuce

L'option binary => 1 autorise les caractères accentués et les sauts de ligne dans un champ ; auto_diag => 1 fait mourir le script avec un message clair en cas de CSV malformé, au lieu d'échouer en silence.

Produire du CSV

Pour écrire, on emploie say avec la méthode combine… ou plus directement print avec un tableau de champs : Text::CSV ajoute les guillemets nécessaires tout seul.

Le JSON avec JSON::PP

JSON::PP est fourni avec Perl (pas besoin de CPAN). Deux fonctions suffisent : decode_json (texte JSON → structure Perl) et encode_json (l'inverse). Un objet JSON devient une référence de hachage, un tableau JSON une référence de tableau.

Astuce : canonical pour une sortie reproductible

Sans canonical, l'ordre des clés d'un hachage Perl est imprévisible : deux exécutions peuvent produire un JSON différent pour la même donnée. Le drapeau canonical trie les clés par ordre alphabétique ; la sortie devient déterministe. Précieux pour comparer deux fichiers avec diff, écrire un test qui vérifie une sortie exacte, ou versionner un JSON dans Git sans faux changements à chaque commit.

Attention à l'encodage

encode_json / decode_json travaillent sur des octets UTF-8, pas sur des chaînes décodées. Si tu lis un fichier avec :encoding(utf8), utilise plutôt la forme objet JSON::PP->new->utf8(0)->decode(...), ou reste cohérent d'un bout à l'autre. Cas réel : du CSV de tableur au JSON d'API

Un service marketing exporte ses contacts depuis un tableur (CSV) mais l'API du CRM n'accepte que du JSON. En quinze lignes, Perl lit le CSV avec Text::CSV, transforme chaque ligne en hachage (getline_hr), empile le tout dans un tableau, puis encode_json produit le corps de la requête. Ce genre de « pont » entre formats est l'un des usages les plus courants de Perl en entreprise : on branche deux systèmes qui ne se parlaient pas.

Pour aller plus loin

Pour de gros volumes, préfère Cpanel::JSON::XS (bien plus rapide, écrit en C) — même interface. Pour le YAML, il y a YAML::PP ; pour le XML, XML::LibXML. Le réflexe Perl : un format = un module éprouvé sur CPAN.

Glossaire

CSV
Comma-Separated Values : valeurs séparées par des virgules, avec guillemets pour protéger les champs contenant une virgule ou un saut de ligne.
Text::CSV
Module CPAN qui lit et écrit du CSV en respectant les règles de guillemets et d'échappement.
getline_hr
Méthode qui renvoie une ligne CSV sous forme de hachage, indexé par les en-têtes déclarés avec column_names.
JSON
JavaScript Object Notation : format d'échange léger ; objets, tableaux, nombres, chaînes, booléens.
decode_json / encode_json
Fonctions de JSON::PP qui convertissent entre texte JSON (octets UTF-8) et structure Perl.
canonical
Option qui trie les clés à la sortie : JSON reproductible, pratique pour comparer ou versionner.
Sérialisation
Transformation d'une structure en mémoire (hachages, tableaux) en une suite d'octets texte échangeable ou stockable : encode_json, ou l'écriture d'un CSV.
Désérialisation
Opération inverse : reconstruire une structure Perl manipulable à partir d'un texte : decode_json, ou la lecture d'un CSV avec Text::CSV.
Échappement
Mécanisme qui protège un caractère spécial pour qu'il soit pris comme donnée : en CSV, un champ contenant une virgule est entouré de guillemets, et un guillemet interne est doublé ("").

Récap et vérification

  • Ne découpe jamais un CSV au split : utilise Text::CSV.
  • getline_hr te donne chaque ligne en hachage clé → valeur.
  • decode_json et encode_json font le pont JSON ⇄ références Perl.
  • Reste cohérent sur l'encodage UTF-8 d'un bout à l'autre.

Vérifie ta compréhension

  1. Pourquoi split /,/ est-il dangereux sur du CSV ?
  2. Que renvoie decode_json pour un objet JSON ?
  3. À quoi sert l'option canonical ?
