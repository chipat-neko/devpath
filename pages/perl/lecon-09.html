Modules et CPAN

~45 min Avancé Prérequis : leçon 8

À la fin de cette leçon, tu sauras

  • utiliser des modules avec use (de la bibliothèque standard) ;
  • puiser dans CPAN, l'immense dépôt de modules ;
  • écrire ton propre module (package, fichier .pm) ;
  • installer des dépendances (cpanm).
Sommaire de la leçon

Tu n'as presque jamais besoin de tout réécrire : l'immense force de Perl, c'est CPAN, son dépôt de modules. Plus de 200 000 modules prêts à l'emploi couvrent à peu près tout : réseau, bases de données, formats de fichiers, web… Cette leçon t'apprend à utiliser des modules, à puiser dans CPAN, et à écrire les tiens.

Cas réel : dialoguer avec une API web

Un script d'astreinte interroge l'état d'un service via une API qui répond en JSON. Avec HTTP::Tiny pour la requête et JSON pour le décodage, tout tient en trois lignes : my $rep = HTTP::Tiny->new->get($url);, my $data = decode_json($rep->{content});, say $data->{status};. Aucune de ces briques n'est réécrite — elles viennent de CPAN, testées et maintenues par la communauté. C'est le quotidien de l'automatisation en Perl.

Pièges fréquents

Piège fréquent

Oublier le 1; à la fin d'un module : Perl croit que le chargement a échoué et lève une erreur « did not return a true value ». C'est l'erreur la plus déroutante du débutant qui écrit son premier module.

Pour aller plus loin

Pour aller plus loin

Avant d'écrire du code, cherche sur metacpan.org : il y a souvent déjà un module testé et maintenu pour ton besoin. Réutiliser CPAN plutôt que réinventer, c'est l'esprit Perl par excellence.

Glossaire

Module
Unité de code réutilisable : un fichier .pm contenant un package, chargé par use.
CPAN
Comprehensive Perl Archive Network : dépôt central de plus de 200 000 modules Perl publics.
use
Instruction qui charge un module à la compilation et importe éventuellement ses symboles.
cpanm
cpanminus : outil en ligne de commande qui installe un module CPAN et ses dépendances.
Package
Espace de noms Perl ; regroupe variables et sous-programmes sous un nom (ex. List::Util).
Exporter
Module standard qui gère l'import des fonctions d'un package vers le code appelant (@EXPORT_OK).
qw(...)
quote words : liste de mots sans guillemets ni virgules, souvent utilisée pour lister les imports.

Récap et vérification

  • use Module qw(fonctions); charge un module et importe ses fonctions.
  • La bibliothèque standard (List::Util, POSIX…) couvre déjà beaucoup.
  • CPAN (via cpanm) fournit des dizaines de milliers de modules.
  • Un module est un package dans un .pm, terminé par 1;.

Vérifie ta compréhension

  1. À quoi sert qw(...) dans un use ?
  2. Quelle commande installe un module depuis CPAN ?
  3. Pourquoi un module se termine-t-il par 1; ?
