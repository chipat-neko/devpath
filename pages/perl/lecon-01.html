Module 1 · Les bases de Perl — Leçon 01

Découvrir Perl

~40 min Intermédiaire Prérequis : savoir programmer dans un autre langage

À la fin de cette leçon, tu sauras

  • lancer un script Perl et activer use strict et use warnings ;
  • afficher avec print et say ;
  • comprendre la philosophie TIMTOWTDI et la culture Perl ;
  • reconnaître les trois sigils $, @, %.
Sommaire de la leçon

Perl a été créé en 1987 par Larry Wall, un linguiste devenu programmeur. Son objectif : un langage pratique pour traiter du texte sans douleur, là où les outils Unix de l'époque montraient leurs limites. Le résultat est un langage expressif, parfois déroutant, mais redoutablement efficace pour manipuler des chaînes, analyser des journaux et automatiser des tâches. On le surnomme le « couteau suisse » des langages de script.

Perl est souvent déjà installé sur les systèmes Unix, macOS et Linux. Vérifie avec perl -v. Sur Windows, Strawberry Perl est la distribution recommandée.

Ton premier script

Un script Perl est un fichier .pl. La première ligne (le « shebang ») indique où trouver l'interpréteur sur les systèmes Unix.

Lance-le avec perl bonjour.pl. Le \n ajoute un saut de ligne.

Astuce

Pour un test express sans créer de fichier, utilise l'option -e : perl -e 'print "Salut\n"'. Combinée à -n ou -p (boucler sur chaque ligne d'un fichier), elle fait de Perl un outil en ligne de commande redoutable.

use strict et use warnings : non négociables

Ces deux lignes sont la première règle du Perl moderne. use strict t'oblige à déclarer tes variables (et attrape quantité de fautes de frappe) ; use warnings signale les comportements douteux. Mets-les en tête de chaque script.

print et say

print affiche sans rien ajouter. Si tu actives la fonctionnalité say (Perl 5.10+), tu obtiens un say qui ajoute le saut de ligne tout seul.

Les trois sigils

Voici LA particularité visuelle de Perl : le type d'une variable se lit à son sigil, le symbole qui la précède. $ pour une valeur unique (scalaire), @ pour une liste (tableau), % pour des paires clé-valeur (hachage). On les détaillera à la leçon suivante.

Le sigil dit immédiatement à quoi on a affaire : c'est déroutant au début, puis pratique.

Cas réel : dépouiller un journal de serveur

Un·e administrateur·rice système reçoit un fichier access.log de 2 Go et doit compter les erreurs 500. Plutôt qu'un programme complet, une seule ligne suffit : perl -ne 'print if / 500 /' access.log | wc -l. C'est exactement ce pour quoi Perl a été conçu : extraire et transformer du texte, vite, sans cérémonie. Des décennies de scripts d'exploitation reposent encore là-dessus.

Les commentaires et la documentation

Un commentaire commence par # jusqu'à la fin de la ligne. Pour la documentation longue, Perl a son format POD (Plain Old Documentation), inséré directement dans le code.

TIMTOWTDI : plusieurs façons de faire

La devise de Perl est « There's more than one way to do it » — il y a plusieurs façons de faire. C'est une force (liberté d'expression) et un piège (du code illisible si on en abuse). Ce cours privilégie les façons claires.

Pièges fréquents

Piège fréquent

Oublier use strict; use warnings;. Sans eux, une variable mal orthographiée est créée silencieusement et ton script « marche » en produisant n'importe quoi. C'est la première cause de bugs mystérieux en Perl.

Pour aller plus loin

Pour aller plus loin

La commande perldoc est ta meilleure amie : perldoc perlintro pour une introduction, perldoc -f print pour une fonction, perldoc Module::Name pour un module. Toute la documentation Perl est hors ligne, sur ta machine.

Glossaire

Perl
Langage de script créé en 1987 par Larry Wall, spécialisé dans le traitement de texte et l'automatisation ; surnommé le « couteau suisse ».
Shebang
Première ligne #!/usr/bin/perl qui indique aux systèmes Unix quel interpréteur utiliser pour lancer le fichier.
use strict
Directive qui rend le code rigoureux : variables déclarées avec my, pas de références symboliques ni de barewords hasardeux.
use warnings
Directive qui émet des avertissements sur les pièges courants (valeur indéfinie, conversion douteuse…) sans arrêter le programme.
Sigil
Symbole placé devant un nom de variable pour en indiquer le type : $ scalaire, @ tableau, % hachage.
say
Comme print, mais ajoute automatiquement le saut de ligne ; nécessite use feature 'say' (ou use v5.10).
POD
Plain Old Documentation : format de documentation intégré au code, entre =pod et =cut, lisible avec perldoc.
TIMTOWTDI
« There's more than one way to do it » : la devise de Perl, qui offre plusieurs façons d'écrire une même chose.

Récap et vérification

  • Perl est taillé pour le traitement de texte ; un script est un fichier .pl lancé par perl.
  • use strict; et use warnings; sont obligatoires dans tout code sérieux.
  • print et say affichent ; my déclare une variable.
  • Les sigils $, @, % distinguent scalaires, tableaux et hachages.

Vérifie ta compréhension

  1. Pourquoi met-on use strict; use warnings; en tête de chaque script ?
  2. Quelle est la différence entre print et say ?
  3. Que signifie le sigil @ devant un nom de variable ?
