Module 1 · Les bases de Perl — Leçon 02

Scalaires, tableaux et hachages

~50 min Intermédiaire Prérequis : leçon 1

À la fin de cette leçon, tu sauras

  • manier les scalaires (nombres, chaînes) et leurs sigils $ ;
  • créer et parcourir des tableaux (@) avec push, pop, sort ;
  • associer des clés à des valeurs avec les hachages (%) ;
  • comprendre le passage d'un type à l'autre (clés, valeurs, tranches).
Sommaire de la leçon

Perl repose sur trois types de données, chacun signalé par son sigil. Les comprendre — et savoir passer de l'un à l'autre — c'est l'essentiel de la pratique quotidienne. Voyons les scalaires, les tableaux et les hachages.

Les scalaires : une valeur à la fois

Un scalaire (sigil $) contient une valeur unique : un nombre, une chaîne, ou une référence (plus tard). Perl ne distingue pas vraiment nombres et chaînes : il convertit selon le besoin.

L'opérateur . concatène ; + additionne. Ne les confonds pas.

Interpolation dans les chaînes

Comme en shell, les guillemets doubles interpolent les variables, les simples prennent le texte littéral.

Les tableaux : des listes ordonnées

Un tableau (sigil @) contient une liste ordonnée de scalaires. On y accède par index (à partir de 0), et — détail important — l'accès à un élément utilise le sigil $, car cet élément est un scalaire.

Ajouter, retirer, parcourir

Les fonctions de tableau sont nombreuses : push/pop (à la fin), shift/unshift (au début), sort, reverse, grep (filtrer), map (transformer).

Le <=> compare numériquement, cmp compare des chaînes. Sans bloc, sort trie par ordre alphabétique.

Les hachages : des paires clé-valeur

Un hachage (sigil %) associe des clés à des valeurs, sans ordre garanti. L'accès à une valeur utilise $ et des accolades.

La flèche grasse => est un séparateur clé-valeur lisible (et met automatiquement la clé entre guillemets).

Parcourir un hachage

keys donne les clés, values les valeurs. On boucle avec foreach.

Cas réel : compter les occurrences

Le hachage est l'outil idéal pour compter. Pour dénombrer les mots d'un texte, on incrémente une case par mot rencontré — le hachage crée la clé au vol : $compte{$mot}++;. Ce mini-idiome (« autovivification » + incrément) est au cœur des scripts d'analyse de logs, de statistiques de fréquence ou de détection de doublons. Trois lignes remplacent un long programme.

Tranches : plusieurs éléments d'un coup

On peut extraire plusieurs éléments — une tranche — qui est elle-même une liste, donc avec le sigil @.

Pièges fréquents

Piège fréquent

Le sigil change selon ce qu'on accède, pas selon la variable ! Le tableau est @fruits, mais un élément est $fruits[0] (scalaire). De même %ages mais $ages{Ada}. C'est la confusion numéro un des débutants.

Pour aller plus loin

Pour aller plus loin

Pour trier un hachage par valeur (et non par clé) : sort { $ages{$a} <=> $ages{$b} } keys %ages. Cette combinaison sort+keys est un idiome Perl à connaître.

Glossaire

Scalaire
Valeur unique (nombre, chaîne ou référence), sigil $. Perl convertit nombre↔chaîne selon l'opérateur employé.
Tableau
Liste ordonnée de scalaires, sigil @ ; indexée à partir de 0, les indices négatifs comptent depuis la fin.
Hachage
Ensemble de paires clé→valeur sans ordre garanti, sigil % ; accès par $h{cle}.
Interpolation
Insertion de la valeur d'une variable dans une chaîne à guillemets doubles ; les guillemets simples restent littéraux.
Tranche (slice)
Extraction de plusieurs éléments d'un coup : @t[0,2] ou @h{"a","b"} ; le résultat est une liste, d'où le sigil @.
=> (fat comma)
Séparateur clé-valeur lisible ; met automatiquement le mot de gauche entre guillemets.
<=> vs cmp
Opérateurs de comparaison pour sort : <=> compare des nombres, cmp des chaînes.
Autovivification
Création automatique d'une clé (ou structure) dès qu'on y accède en écriture, ex. $compte{$mot}++.

Récap et vérification

  • Scalaire $x : une valeur (nombre, chaîne) ; . concatène.
  • Tableau @a : liste ordonnée ; un élément est $a[i] ; push, sort, map, grep.
  • Hachage %h : paires clé-valeur ; une valeur est $h{cle} ; keys, values, exists, delete.
  • Le sigil suit ce qu'on accède : $ pour un élément, @ pour une tranche.
