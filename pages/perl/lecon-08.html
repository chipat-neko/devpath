Module 3 · Perl structuré — Leçon 08

Références et structures de données

~55 min Avancé Prérequis : leçon 7

À la fin de cette leçon, tu sauras

  • créer des références vers scalaires, tableaux et hachages (\) ;
  • construire des structures imbriquées (tableau de hachages…) ;
  • déréférencer (flèche ->, déréférencement complet) ;
  • passer des structures complexes à des sous-programmes.
Sommaire de la leçon

Les scalaires, tableaux et hachages sont plats. Pour construire des structures riches — une liste d'enregistrements, un dictionnaire de listes, un arbre — il faut les références. Une référence est un scalaire qui « pointe vers » une autre donnée. C'est la clé des structures imbriquées en Perl, et de la programmation objet à venir.

Créer une référence

L'opérateur \ crée une référence vers une variable. La référence est un scalaire : on peut la stocker, la passer, la ranger dans un tableau.

La flèche -> est la façon lisible de déréférencer un élément.

Références anonymes

Plus courant : créer directement une référence vers un tableau ou un hachage anonyme, avec [ ] (tableau) ou { } (hachage).

Déréférencer entièrement

Pour retrouver le tableau ou le hachage complet, on entoure la référence du sigil voulu.

Entre deux crochets/accolades successifs, la flèche est facultative : $groupes{fruits}[0] équivaut à $groupes{fruits}->[0].

Passer des structures aux fonctions

On résout ici le piège de la leçon 7 : pour passer un tableau (ou plusieurs) sans l'aplatir, on passe sa référence.

Astuce

Perl crée automatiquement les niveaux manquants d'une structure quand tu y écris : c'est l'autovivification. push @{ $index{$mot} }, $ligne; fonctionne même si $index{$mot} n'existait pas encore — le tableau anonyme naît à la volée. Idéal pour bâtir un index sans initialiser chaque clé.

Inspecter une référence

ref dit le type pointé (ARRAY, HASH, CODE…). Utile pour écrire du code générique ou déboguer une structure avec Data::Dumper.

Cas réel : un index de recherche

Pour retrouver dans quel fichier apparaît chaque mot d'un dossier, on construit un hachage de listes : push @{ $index{$mot} }, $fichier; pour chaque mot rencontré. Le résultat est une structure imbriquée — clé = mot, valeur = référence vers la liste des fichiers — qui répond instantanément à « où ai-je écrit “facture” ? ». C'est le principe, en miniature, d'un index inversé de moteur de recherche, et le genre de tâche où les références de Perl brillent.

Pièges fréquents

Piège fréquent

Confondre $ref->[0] (l'élément 0 du tableau pointé) et $ref[0] (l'élément 0 d'un tableau @ref qui n'existe peut-être pas !). Avec une référence, garde toujours la flèche pour accéder aux éléments.

Pour aller plus loin

Pour aller plus loin

Le déréférencement postfixé (Perl 5.20+) est souvent plus clair : $ref->@* pour tout le tableau, $ref->%* pour tout le hachage, $ref->$* pour un scalaire. Une syntaxe moderne à adopter.

Glossaire

Référence
Scalaire qui « pointe vers » une autre donnée (tableau, hachage, sous-programme) ; base des structures imbriquées.
Déréférencer
Suivre la référence pour retrouver la donnée pointée, via la flèche -> ou le sigil approprié (@$r, %$r).
Référence anonyme
Structure créée directement sans variable nommée : [ … ] (tableau) ou { … } (hachage).
Structure imbriquée
Donnée composée de références : tableau de hachages, hachage de listes, arbre…
Flèche (->)
Opérateur d'accès à travers une référence ; facultatif entre deux indices successifs.
Autovivification
Création automatique des niveaux intermédiaires d'une structure lorsqu'on y écrit pour la première fois.
ref
Fonction renvoyant le type pointé (ARRAY, HASH, CODE…) ou une chaîne vide si l'argument n'est pas une référence.

Récap et vérification

  • \@a, \%h créent des références ; [ ] et { } des références anonymes.
  • On accède aux éléments avec la flèche : $ref->[i], $ref->{cle}.
  • Les références permettent les structures imbriquées (tableau de hachages…).
  • On passe une structure à une fonction par sa référence, sans l'aplatir.

Vérifie ta compréhension

  1. Comment accéder au premier élément d'un tableau référencé par $ref ?
  2. Pourquoi passe-t-on une référence plutôt qu'un tableau à une fonction ?
  3. Que renvoie ref($x) ?
