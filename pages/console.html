Bac à sable

Écris et exécute du Python et du SQL

Un espace pour expérimenter librement, au-delà des exemples des cours. Clique sur « Tester » puis modifie le code et « Exécute ». Tout tourne dans ton navigateur.

Connexion requise

Python et SQL s'exécutent grâce à des moteurs WebAssembly chargés depuis Internet. Cette page a donc besoin d'une connexion et que le site soit servi en HTTP (elle ne fonctionne pas en file://). Le premier lancement prend quelques secondes.

Python

Un interpréteur Python complet (Pyodide). Listes, fonctions, modules de la bibliothèque standard…

SQL

Une base SQLite (sql.js) avec un jeu de données de démonstration déjà chargé : clients, produits, commandes et lignes_commande. Écris tes propres requêtes !
