Module 2 · Le paradigme fonctionnel — Leçon 04

Définir et appeler des fonctions

~50 min Intermédiaire Prérequis : leçon 3

À la fin de cette leçon, tu sauras

  • définir des fonctions avec define ;
  • créer des fonctions anonymes avec lambda ;
  • comprendre que les fonctions sont des valeurs ;
  • écrire des fonctions pures.
Sommaire de la leçon

Lisp est le berceau de la programmation fonctionnelle : les fonctions y sont la brique centrale, et — idée révolutionnaire pour 1958 — ce sont des valeurs comme les autres, qu'on peut nommer, passer en argument, renvoyer. Cette leçon t'apprend à définir et utiliser des fonctions.

Définir une fonction : define

On nomme une fonction avec define : le nom et ses paramètres entre parenthèses, puis le corps. La valeur du corps est renvoyée (pas de return).

La forme (define (nom params...) corps) est le sucre habituel pour définir une fonction.

Plusieurs expressions dans le corps

Le corps peut contenir plusieurs expressions ; elles s'évaluent dans l'ordre, et c'est la dernière qui fournit la valeur de retour.

Les fonctions anonymes : lambda

lambda crée une fonction sans nom. C'est la forme fondamentale : define n'est qu'un raccourci pour lier un nom à un lambda.

define pour réutiliser, lambda pour l'instant

Nomme une fonction avec define quand tu l'appelles à plusieurs endroits, ou qu'un bon nom clarifie l'intention. Réserve lambda aux fonctions jetables passées à map, filter ou sort : les nommer alourdirait le code sans rien apporter.

Les fonctions sont des valeurs

Conséquence majeure : une fonction peut être stockée dans une variable, rangée dans une liste, passée en argument. C'est ce qui rend Lisp si expressif (et que la leçon 6 exploitera).

Cas réel — lambda a conquis tous les langages

L'idée née en Lisp — traiter les fonctions comme des valeurs — a essaimé partout. JavaScript en a fait le cœur de ses callbacks ; Python lui a réservé un mot-clé, lambda, tandis que Java 8 (2014) et C++11 ont ajouté des expressions lambda sans mot-clé (x -> x*2 en Java, [](int x) { return x*2; } en C++) ; le service AWS Lambda tire son nom du lambda-calcul. Quand tu écris [1,2,3].map(x => x*2) en JavaScript, tu passes une fonction à une autre fonction : tu fais du Lisp sans le savoir.

Les fonctions pures

L'idéal fonctionnel : une fonction pure renvoie toujours le même résultat pour les mêmes arguments, sans effet de bord (elle ne modifie rien d'extérieur). Le code en devient prévisible, testable et composable. La plupart des fonctions de ce cours sont pures.

Paramètres variables

Certaines fonctions acceptent un nombre quelconque d'arguments. En Scheme, on capture le reste avec un point ; en Common Lisp, avec &rest.

apply applique une fonction à une liste d'arguments : (apply + '(1 2 3)) vaut 6.

Pièges fréquents

Piège fréquent

Confondre une fonction et son appel : carre est la fonction (une valeur), (carre 5) est son application. Passer carre en argument (sans parenthèses) est volontaire ; écrire (carre) tenterait de l'appeler sans argument.

Pour aller plus loin

Pour aller plus loin

Le lambda-calcul, dont Lisp descend, a montré que tout calcul peut s'exprimer avec des fonctions seules. C'est la racine théorique de la programmation fonctionnelle ; les lambdas de Python (mot-clé lambda), de JS (=>) et de Java (->) en viennent directement.

Antisèche

Glossaire

define
Lie un nom à une valeur (souvent une fonction). (define (f x) …) est un raccourci pour (define f (lambda (x) …)).
lambda
Crée une fonction anonyme. C'est la brique fondamentale ; les autres formes de définition s'y ramènent.
Valeur de première classe
Statut des fonctions en Lisp : on peut les stocker, les passer en argument et les renvoyer, comme n'importe quelle donnée.
Fonction d'ordre supérieur
Une fonction qui reçoit ou renvoie une autre fonction (map, filter, appliquer…). Rendue possible par le statut de première classe.
Fonction pure
Pour les mêmes arguments, renvoie toujours le même résultat et sans effet de bord. Prévisible, testable, composable.
Effet de bord
Toute action d'une fonction sur le monde extérieur : affichage, écriture de fichier, modification d'une variable globale.
apply
Applique une fonction à une liste d'arguments : (apply + '(1 2 3)) vaut 6.
Paramètre variadique
Un paramètre qui capture un nombre quelconque d'arguments : . reste en Scheme, &rest en Common Lisp.

Récap et vérification

  • (define (nom params) corps) définit une fonction ; le corps renvoie sa dernière valeur.
  • lambda crée une fonction anonyme ; define n'en est qu'un raccourci nommé.
  • Les fonctions sont des valeurs : on les stocke, les passe, les renvoie.
  • Vise des fonctions pures (sans effet de bord) pour un code prévisible.

Vérifie ta compréhension

  1. Quelle est la relation entre define et lambda ?
  2. Que signifie « les fonctions sont des valeurs » ?
  3. Qu'est-ce qu'une fonction pure ?
