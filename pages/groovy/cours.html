Groovy : le script de la JVM

Groovy, c'est Java sans la cérémonie : même JVM, mêmes bibliothèques, mais débarrassé de la lourdeur — typage optionnel, closures, interpolation de chaînes, collections augmentées. C'est aussi le langage de Gradle et Jenkins, que tout développeur JVM croise un jour. Ce cours te mène de la concision du script jusqu'à la métaprogrammation et les DSL.

Bien s'équiper

Les extensions VS Code pour Groovy

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Groovy

  • Groovy Lint (Nicolas Vuillamy) — analyse et formatage du code Groovy.
  • Extension Pack for Java (Microsoft) — Groovy tourne sur la JVM.

Pour qui ?

Idéal si tu connais déjà les bases de la programmation (Java aide, mais n'est pas requis). Parfait pour qui travaille dans l'écosystème JVM et veut un langage de scripts concis, ou simplement comprendre les fichiers build.gradle et les pipelines Jenkins qu'on croise partout.

Ce que tu vas apprendre

La concision et la puissance dynamique de la JVM

À la fin du cours, tu sauras

  • écrire du Groovy concis : def, GString, opérateurs Elvis et navigation sûre ;
  • maîtriser les closures et les collections augmentées (each, collect, findAll) ;
  • définir des classes et des POGO, choisir typage dynamique ou statique ;
  • comprendre la métaprogrammation, les DSL, et lire/écrire pour Gradle et Jenkins.

Pour qui, et pourquoi

Groovy offre un rapport effort/résultat remarquable : la puissance de l'écosystème Java, avec une syntaxe bien plus légère. On le croise forcément sur la JVM — Gradle, Jenkins, Spock — et il reste irremplaçable pour le scripting dynamique et les langages dédiés. Ses concepts (closures, DSL) éclairent aussi d'autres langages modernes.

Chaque leçon est autonome et illustrée par du code commenté. Le code ne s'exécute pas dans l'éditeur du site : les exemples montrent la syntaxe et les sorties attendues en commentaire.
