Module 2 · Groovy expressif — Leçon 05

Collections : listes et maps

~55 min Intermédiaire Prérequis : leçon 4

À la fin de cette leçon, tu sauras

  • créer des listes et des maps littérales ;
  • parcourir avec each ;
  • transformer avec collect et filtrer avec findAll ;
  • chaîner les opérations sur les collections.
Sommaire de la leçon

Groovy transforme la manipulation de données en un plaisir. Là où Java demande des déclarations verbeuses, Groovy offre des listes et maps littérales, et surtout une collection de méthodes « augmentées » — each, collect, findAll — qui, combinées aux closures (leçon 4), rendent le traitement de données concis et lisible. Cette leçon en fait le tour.

Les listes

Une liste s'écrit entre crochets, comme en Python ou JavaScript. Elle est dynamique (taille variable) et accepte des éléments de types mêlés.

L'opérateur << ajoute un élément ; les index négatifs comptent depuis la fin ([-1] = dernier). Groovy ajoute des dizaines de méthodes pratiques aux listes.

Parcourir avec each

each exécute une closure pour chaque élément : c'est la façon idiomatique de parcourir une liste.

Transformer avec collect

collect applique une closure à chaque élément et renvoie une nouvelle liste des résultats. C'est l'équivalent de map dans d'autres langages.

collect ne modifie pas la liste d'origine : il en produit une nouvelle, transformée. C'est la base du style fonctionnel sur les collections.

Astuce

Quand la transformation est un simple appel de méthode, l'opérateur d'étalement *. raccourcit encore : fruits*.toUpperCase() équivaut à fruits.collect { it.toUpperCase() }. Idem gens*.nom pour extraire un champ de chaque élément. Concis, mais réserve-le aux cas « un appel par élément » ; dès qu'il y a une vraie logique, reviens à collect { … }.

Filtrer avec findAll et find

findAll garde les éléments qui satisfont une condition (comme filter) ; find renvoie le premier qui correspond.

any et every testent respectivement « au moins un » et « tous » — pratiques pour des vérifications globales.

Chaîner les opérations

La vraie élégance vient de l'enchaînement : on combine ces méthodes en un pipeline lisible.

Chaque méthode renvoie une collection sur laquelle on appelle la suivante. Ce style — filtrer, transformer, réduire — exprime un traitement de données complexe en quelques lignes claires.

Les maps

Une map associe des clés à des valeurs, entre crochets avec des deux-points. L'accès se fait par clé, avec une notation pointée bien pratique.

Particularité agréable : on accède à une valeur de map avec un point (ages.ada), comme une propriété. Les clés sont ici des chaînes implicites ; pour une clé variable, on utilise les crochets.

Cas réel

C'est exactement ainsi qu'on calcule un chiffre d'affaires depuis une liste de commandes. Imagine des commandes sous forme de maps :

Filtrer → extraire → additionner : le même pipeline que sur des nombres, appliqué à des données métier. Les tableaux de bord, rapports de ventes et exports comptables se construisent sur ce trio findAll/collect/sum. En Java « classique », il aurait fallu une boucle, une variable accumulateur et un if ; ici, trois lignes qui se lisent comme la phrase « somme des montants des commandes payées ».

Pièges fréquents

Piège fréquent

Confondre each et collect. each parcourt pour produire des effets (afficher, accumuler) et renvoie la liste d'origine ; collect transforme et renvoie une nouvelle liste des résultats. Si tu veux récupérer une liste transformée, c'est collect qu'il te faut : each ne renvoie pas tes transformations. Beaucoup de débutants utilisent each en espérant un résultat qui n'arrive jamais.

Pour aller plus loin

Pour aller plus loin

Groovy ajoute ces méthodes à toutes les collections Java existantes, via ce qu'on appelle le GDK (Groovy Development Kit) : il « enrichit » les classes standard de Java avec des centaines de méthodes pratiques (collect, findAll, groupBy, sum…). C'est de la métaprogrammation (leçon 7) : Groovy greffe ses fonctionnalités sur les classes Java sans les modifier, ce qui explique pourquoi même une ArrayList Java « classique » gagne ces super-pouvoirs en Groovy.

Antisèche : méthodes de collections

Glossaire

Liste
Collection ordonnée notée [a, b, c], de taille variable ; accès par index ([0], [-1]).
Map
Collection de paires clé→valeur notée [cle: valeur] ; accès par m.cle ou m["cle"].
each
Parcourt une collection en exécutant une closure par élément, pour ses effets ; renvoie la collection d'origine.
collect
Applique une closure à chaque élément et renvoie une nouvelle liste des résultats (le map d'autres langages).
findAll / find
findAll garde tous les éléments satisfaisant la condition ; find renvoie le premier.
Pipeline (chaînage)
Enchaînement de méthodes où chaque appel passe son résultat au suivant : filtrer → transformer → réduire.
GDK
Groovy Development Kit : enrichissement des classes standard de Java avec des centaines de méthodes pratiques (collect, findAll, groupBy…).

Récap et vérification

  • Listes [a, b, c] : << ajoute, index négatifs, size(), last().
  • each parcourt ; collect transforme (nouvelle liste) ; findAll/find filtrent.
  • any/every testent ; on chaîne les opérations en pipeline.
  • Maps [cle: valeur] : accès par m.cle ou m["cle"].
