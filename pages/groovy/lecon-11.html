Module 4 · Groovy avancé — Leçon 11

JSON, XML et le web

~50 min Avancé Prérequis : leçon 5

À la fin de cette leçon, tu sauras

  • lire du JSON avec JsonSlurper et le produire avec JsonOutput ;
  • naviguer dans du XML avec GPath (XmlSlurper) ;
  • générer du balisage avec MarkupBuilder ;
  • consommer une API web en quelques lignes.
Sommaire de la leçon

Groovy est né pour le scripting, et une bonne part du scripting consiste à lire, transformer et écrire des données. Là où Java demande des bibliothèques et du code cérémonieux, Groovy embarque tout ce qu'il faut pour JSON et XML — et transforme une réponse d'API en objets manipulables en une ligne.

Lire du JSON

JsonSlurper transforme une chaîne JSON en structures Groovy familières : les objets deviennent des maps, les tableaux des listes (leçon 5). On y accède ensuite avec la notation pointée.

Produire du JSON

Dans l'autre sens, JsonOutput.toJson sérialise n'importe quelle map ou liste, et prettyPrint l'indente lisiblement.

Cas réel

Cette concision fait de Groovy un langage de colle très prisé pour l'intégration. Dans un pipeline Jenkins (leçon 8), on lit couramment la réponse JSON d'une API — statut d'un déploiement, liste de tickets — en deux lignes : readJSON ou new JsonSlurper().parseText(...), puis on branche la logique dessus. Des milliers de scripts d'ops manipulent ainsi des configurations et des réponses d'API sans jamais quitter la JVM.

Naviguer dans du XML : GPath

Pour le XML, XmlSlurper parse le document, puis on le parcourt avec GPath — le même esprit que l'accès pointé, étendu aux nœuds et attributs. Un attribut se lit avec @.

Générer du balisage : MarkupBuilder

MarkupBuilder est un builder (leçon 7) : chaque appel de méthode devient une balise, chaque closure imbriquée un sous-arbre. Idéal pour produire du XML ou du HTML sans concaténer des chaînes à la main.

Consommer une API en quelques lignes

Groovy ajoute une propriété .text sur URL : elle récupère le contenu distant. Couplée à JsonSlurper, elle transforme une API en objets en deux lignes.

Astuce

Combine ce que tu connais : le résultat de parseText est une liste de maps, donc findAll, collect, groupBy et les autres méthodes de collections (leçon 5) s'appliquent directement. C'est là que Groovy brille : récupérer → filtrer → transformer en une seule chaîne d'appels fluide.

Pièges fréquents

Piège fréquent

Confondre le texte d'un nœud XML et le nœud lui-même : equipe.membre[0] est un nœud, il faut .text() pour obtenir la chaîne. Et attention : JsonSlurper renvoie parfois des types « paresseux » (LazyMap) ; si tu dois stocker le résultat durablement, convertis-le en new HashMap(...) ou reconstruis-le.

Glossaire

JsonSlurper
Classe Groovy qui parse une chaîne JSON en maps et listes manipulables.
JsonOutput
Classe qui sérialise une structure Groovy en chaîne JSON ; prettyPrint l'indente.
XmlSlurper
Parseur XML de Groovy renvoyant un arbre navigable via GPath.
GPath
Notation de chemin (proche de XPath) pour naviguer dans un arbre XML ou JSON avec l'accès pointé.
MarkupBuilder
Builder qui transforme des appels de méthodes et closures imbriquées en balisage XML/HTML.
Sérialiser
Convertir une structure en mémoire en texte (ici JSON) transmissible ou stockable.
Parser
Opération inverse : lire un texte structuré et le reconstituer en objets.
Langage de colle (glue)
Langage employé pour relier des systèmes — lire une API, transformer les données, réémettre ; usage phare de Groovy en intégration et en scripts d'exploitation.

Récap et vérification

  • JsonSlurper lit le JSON ; JsonOutput le produit.
  • GPath parcourt un arbre XML/JSON ; @ lit un attribut, text() le contenu.
  • MarkupBuilder génère du balisage par appels de méthodes et closures.
  • new URL(u).text + JsonSlurper = consommer une API en deux lignes.
