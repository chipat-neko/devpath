Module 1 · Les bases de Groovy — Leçon 02

Variables, types et GString

~45 min Intermédiaire Prérequis : leçon 1

À la fin de cette leçon, tu sauras

  • déclarer avec def (typage optionnel) ;
  • comprendre le typage dynamique et statique ;
  • utiliser les GString ("$variable") ;
  • manier nombres, chaînes et booléens.
Sommaire de la leçon

Groovy offre un compromis rare : tu peux typer tes variables comme en Java, ou laisser Groovy gérer les types pour toi avec le mot-clé def. Cette flexibilité, couplée aux GString (les chaînes interpolées), rend le code à la fois souple et lisible. Cette leçon pose ces fondations : déclarer, typer (ou non), et composer du texte avec élégance.

Déclarer avec def ou un type

Deux façons de déclarer une variable. Avec un type explicite (comme en Java), ou avec def qui laisse Groovy déduire le type à l'exécution.

Avec def, la variable peut même changer de type au fil du code (typage dynamique). On choisit selon le besoin : def pour la souplesse des scripts, un type explicite pour la clarté et la sécurité dans le code durable.

Les types de base

Groovy s'appuie sur les types de Java, mais les manipule en douceur : les nombres entiers, les décimaux (par défaut des BigDecimal, précis), les chaînes, les booléens. Tout est en réalité un objet en Groovy : même un int a des méthodes.

Détail apprécié : les décimaux littéraux sont des BigDecimal par défaut, donc 0.1 + 0.2 donne exactement 0.3 (pas l'approximation des flottants). Pratique pour les calculs monétaires.

Cas réel

Les calculs d'argent en virgule flottante ont piégé bien des logiciels. En Java ou en JavaScript avec des double, 0.1 + 0.2 vaut 0.30000000000000004 ; répété sur des milliers de prix, l'écart finit par fausser une facture ou un solde. Groovy évite ce piège par défaut : ses décimaux littéraux sont des BigDecimal exacts. C'est l'une des raisons pour lesquelles on l'apprécie pour scripter des traitements financiers ou des rapports où chaque centime compte — sans avoir à penser à envelopper chaque nombre.

Les GString : l'interpolation de chaînes

La fonctionnalité la plus emblématique : les GString. Dans une chaîne entre guillemets doubles, on insère des variables avec $ et des expressions avec ${...}.

Pour une variable simple, $nom suffit ; pour une expression (un calcul, un appel de méthode), on utilise les accolades ${...}. Fini la concaténation laborieuse avec des + : le texte se lit naturellement.

Guillemets simples vs doubles

Distinction importante : les guillemets simples donnent une chaîne littérale (pas d'interpolation), les doubles activent les GString.

Les triples guillemets ("""...""") permettent des chaînes multilignes, pratiques pour du texte long, du SQL ou du HTML.

La concision des accès

Groovy simplifie aussi l'accès aux propriétés et méthodes. On verra les objets en détail leçon 6, mais déjà : on lit une propriété avec un simple point, sans getXxx().

Pièges fréquents

Piège fréquent

Utiliser des guillemets simples en s'attendant à l'interpolation. 'Bonjour $nom' affiche littéralement Bonjour $nom, car les guillemets simples ne sont pas des GString. Pour interpoler, il faut des guillemets doubles : "Bonjour $nom". C'est une confusion très fréquente — retiens : doubles = interpolation, simples = littéral.

Pour aller plus loin

Pour aller plus loin

Une GString n'est pas tout à fait une String Java : c'est un objet GString qui ne calcule sa valeur textuelle qu'au moment où on en a besoin (évaluation paresseuse). Dans la quasi-totalité des cas, c'est transparent. Mais cette subtilité peut surprendre quand on compare une GString à une String avec == dans certains contextes : au moindre doute, force la conversion avec .toString().

Antisèche : variables, types & chaînes

Glossaire

def
Mot-clé de déclaration au type non précisé ; Groovy déduit le type à l'exécution (typage dynamique).
Typage dynamique
Le type d'une variable est déterminé à l'exécution et peut changer ; souple, idéal pour les scripts.
Typage statique
Le type est fixé à l'écriture (ex. String, int) et vérifié à la compilation ; plus sûr pour le code durable.
GString
Chaîne à guillemets doubles qui interpole $variable et ${expression} ; techniquement un objet distinct de String.
Interpolation
Insertion de la valeur d'une variable ou d'une expression dans une chaîne, sans concaténation.
BigDecimal
Type décimal à précision exacte, choisi par défaut par Groovy pour les littéraux décimaux ; évite les erreurs des flottants.
Guillemets triples
"""…""" : chaîne sur plusieurs lignes, pratique pour du SQL, du HTML ou du texte long.
Évaluation paresseuse
Une GString ne calcule son texte final qu'au moment où il est requis ; en cas de doute, forcer avec .toString().

Récap et vérification

  • def = typage dynamique (souple) ; type explicite = comme Java (clair et sûr).
  • Tout est objet ; les décimaux littéraux sont des BigDecimal (précis).
  • GString : guillemets doubles, $variable et ${expression}.
  • Guillemets simples = littéral ; triples = multilignes.
