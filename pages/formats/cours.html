Formats de données : JSON, CSV, YAML, XML

Dès qu'on sauvegarde, échange ou configure, on manipule un format de données. Ce cours transversal couvre les formats que tu croises tous les jours — JSON, CSV, YAML/TOML, XML — et t'apprend à les lire, les écrire, les choisir et les valider.

Bien s'équiper

Les extensions VS Code pour les formats de données

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent coloration, validation et mise en forme des formats courants.

À installer pour les formats de données

  • YAML (Red Hat) — coloration et validation YAML.
  • Even Better TOML (tamasfe) — support complet du TOML.
  • XML (Red Hat) — édition et validation XML.
  • Rainbow CSV (mechatroner) — colore les colonnes d'un CSV.
  • Prettier - Code formatter (Prettier) — met le JSON en forme.

Pour qui ?

Pour tout le monde : dès qu'on programme, on lit du JSON, un CSV ou une config YAML. Le cours complète idéalement API REST (qui échange en JSON) et les cours back-end. Aucune connaissance préalable des formats n'est requise.

Ce que tu vas apprendre

Lire, écrire, choisir et valider

À la fin du cours, tu sauras

  • expliquer la sérialisation et l'échange de données entre programmes ;
  • maîtriser JSON et CSV (syntaxe, règles, pièges) ;
  • lire et écrire des configurations en YAML, TOML et XML ;
  • choisir le bon format et valider des données (schémas, encodage UTF-8).

Pour qui, et pourquoi

Les formats de données sont le tissu invisible qui relie les programmes : une API renvoie du JSON, un tableur exporte un CSV, un outil se configure en YAML. Savoir les manipuler — et éviter leurs pièges classiques — est une compétence quotidienne, quel que soit ton domaine.

Ce cours est indépendant d'un langage : on y montre les formats eux-mêmes et les principes pour bien les utiliser. Tu appliqueras ensuite ces acquis avec les bibliothèques de ton langage.
