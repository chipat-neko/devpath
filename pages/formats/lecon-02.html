JSON, le format roi

~37 min Débutant Leçon 01 requise

À la fin de cette leçon, tu sauras

  • écrire et lire un document JSON ;
  • utiliser ses types (objet, tableau, valeurs) ;
  • respecter ses règles strictes ;
  • parser et sérialiser du JSON.
Sommaire de la leçon

JSON (JavaScript Object Notation) est le format d'échange de données le plus répandu au monde. Né de la syntaxe des objets JavaScript, il s'est imposé partout : API web, fichiers de configuration, bases de données, stockage local. Sa force : il est simple, lisible, et compris nativement par presque tous les langages. Le maîtriser est indispensable.

La syntaxe en deux structures

Tout JSON se construit à partir de deux structures imbricables : l'objet (des paires clé-valeur entre accolades) et le tableau (une liste ordonnée entre crochets).

Un objet { } associe des clés (toujours des chaînes entre guillemets) à des valeurs. Un tableau [ ] est une liste ordonnée de valeurs. Et ces structures s'imbriquent librement : ici, adresse est un objet dans un objet, competences un tableau de chaînes. C'est cette imbrication qui permet de représenter des données complexes.

Trois règles d'or : les clés et les chaînes sont entre guillemets doubles (jamais simples) ; pas de virgule après le dernier élément (trailing comma) ; pas de commentaires. Ces contraintes rendent JSON sans ambiguïté — n'importe quel analyseur le lit de la même façon.

Parser et sérialiser

Chaque langage offre deux opérations symétriques : parser (texte JSON → données en mémoire) et sérialiser (données → texte JSON). En JavaScript, ce sont JSON.parse et JSON.stringify.

L'idée est universelle : Python a json.loads/json.dumps, Java/C#/Go/Rust ont leurs bibliothèques. Le nom change, le principe est identique. Et comme JSON dérive des objets JavaScript, le parsing y est particulièrement naturel.

Cas réel

Le fichier package.json, à la racine de tout projet JavaScript, est du JSON pur. Le même fichier est lu par une foule d'outils qui ne se connaissent pas : npm installe les dépendances qui y sont listées, l'éditeur propose les scripts, la CI lit le numéro de version, le site npmjs.com l'affiche. Aucun ne se parle : ils s'accordent seulement sur le format. Une simple virgule en trop après le dernier champ, et npm install s'arrête net sur une erreur de parsing : c'est la rançon — et la garantie — de la rigueur de JSON.

Valider et formater son JSON

Une virgule en trop ou un guillemet manquant casse tout un document — et l'erreur est parfois loin de sa cause. Garde un validateur JSON à portée (jsonlint.com, ou l'outil de ton éditeur) pour repérer instantanément les erreurs de syntaxe. La plupart des éditeurs colorent et reformatent le JSON, ce qui rend les fautes évidentes : profites-en.

Attention

JSON.parse lève une exception si le texte est invalide (virgule en trop, guillemet manquant) : entoure-le d'un try…catch dès que la source n'est pas sûre (réponse réseau, fichier, saisie utilisateur). Autre piège : les grands entiers. JSON accepte n'importe quel nombre, mais JavaScript les stocke en flottant ; au-delà de 2⁵³, un identifiant comme 9007199254740993 est arrondi silencieusement. Pour ces identifiants, transporte-les en chaîne.

Pour aller plus loin

Autour de JSON gravitent des variantes utiles : NDJSON / JSON Lines (un objet JSON par ligne) pour diffuser de gros jeux de données ligne à ligne ; JSON5, qui réautorise commentaires et virgules finales pour les fichiers édités à la main ; et surtout JSON Schema, qui décrit la forme attendue d'un JSON (quels champs, quels types) et permet de le valider automatiquement — le sujet de la dernière leçon du cours.

Glossaire

JSON
JavaScript Object Notation : format texte d'échange de données né de la syntaxe des objets JavaScript, aujourd'hui universel.
Objet
Ensemble de paires clé : valeur entre accolades { } ; la clé est toujours une chaîne entre guillemets doubles.
Tableau
Liste ordonnée de valeurs entre crochets [ ], accessibles par leur position (index 0, 1, 2…).
Parser (désérialiser)
Analyser un texte JSON pour reconstruire un objet en mémoire : JSON.parse en JavaScript.
Sérialiser
Transformer un objet en mémoire en texte JSON : JSON.stringify en JavaScript.
Trailing comma
Virgule placée après le dernier élément d'un objet ou d'un tableau : interdite en JSON, elle invalide le document.
UTF-8
Encodage de caractères standard ; un fichier JSON s'écrit et se relit en UTF-8 pour éviter le mojibake.
JSON Schema
Langage qui décrit la structure attendue d'un JSON (champs, types) afin de le valider automatiquement.

Récap et vérification

  • JSON se construit avec deux structures imbricables : l'objet { } (clé-valeur) et le tableau [ ].
  • Six types : chaîne, nombre, booléen, null, tableau, objet ; pas de date ni de commentaire.
  • Règles strictes : guillemets doubles pour clés et chaînes, pas de virgule finale, pas de commentaire.
  • Parser (texte → données) et sérialiser (données → texte) : JSON.parse/stringify et leurs équivalents.

Exercice 2Application

Corrige les erreurs de ce JSON : { nom: 'Lou', age: 30, }

Voir une solution

Trois corrections : la clé nom doit être entre guillemets doubles ; 'Lou' (guillemets simples) devient "Lou" (doubles) ; la virgule finale après 30 est supprimée.

Exercice 3Défi

En JavaScript, écris le code qui parse '{"produits":[{"nom":"A","prix":10}]}' et affiche le prix du premier produit.

Voir une solution

Après JSON.parse, on navigue dans la structure comme un objet/tableau normal : data.produits est un tableau, [0] le premier élément, .prix sa valeur.
