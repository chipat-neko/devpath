Swift : développer pour l'écosystème Apple

Swift est le langage d'iOS, macOS et de tout l'univers Apple : rapide, sûr et expressif. Ses optionnels bannissent les plantages liés au nil, ses protocoles et value types dessinent une autre façon de concevoir, et sa concurrence moderne attrape les data races à la compilation. Ce cours te mène du premier print jusqu'aux portes de SwiftUI.

Bien s'équiper

Les extensions VS Code pour Swift

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) : ces outils apportent l'IntelliSense et le débogage. Sur macOS, Xcode reste l'environnement de référence pour les apps Apple.

À installer pour Swift

  • Swift (Swift Server Work Group) — support officiel du langage.
  • CodeLLDB (Vadim Chugunov) — débogueur pas à pas.

Pour qui ?

Idéal si tu connais déjà les bases d'un langage (variables, boucles, fonctions) — par exemple via le cours JavaScript ou le cours Python. Chaque notion propre à Swift est expliquée depuis le début.

Ce que tu vas apprendre

Du premier print à SwiftUI

À la fin du cours, tu sauras

  • écrire du Swift sûr : let/var, optionnels (if let, guard, ??), switch exhaustif et closures ;
  • modéliser avec des value types : structs vs classes, énumérations à valeurs associées et pattern matching ;
  • concevoir « protocol-oriented » : protocoles, extensions par défaut, génériques et gestion mémoire (ARC) ;
  • passer à la pratique : concurrence (async/await, actors), Swift Package Manager, tests et premiers pas SwiftUI.

Pour qui, et pourquoi

Ce cours s'adresse à ceux qui visent le développement iOS/macOS, ou qui veulent découvrir un langage moderne où la sûreté et l'expressivité priment. Swift est aussi une belle école de conception : l'approche orientée protocoles et la sémantique de valeur changent la manière de structurer un programme, partout.

Chaque leçon est autonome et illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties sont montrées en commentaire.
