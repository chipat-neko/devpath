Regex et Unicode : accents, propriétés et émojis

~42 min Avancé Prérequis : leçons 2 et 6

À la fin de cette leçon, tu sauras

  • comprendre pourquoi \w, \d et [a-z] ratent les caractères accentués et non latins ;
  • activer le mode Unicode (le drapeau u en JavaScript) ;
  • cibler par propriété Unicode avec \p{L}, \p{N}, \p{Script=…} ;
  • distinguer unité de code et point de code pour ne plus casser les émojis.
Sommaire de la leçon

Tes motifs marchent parfaitement… sur du texte anglais. Puis arrive un « café », un « naïf », un prénom grec ou un émoji, et tout se fissure : \w+ s'arrête avant l'accent, un compteur de caractères se trompe, un émoji ressort coupé en deux. La raison est historique : les briques de base des regex sont nées à l'époque de l'ASCII. Cette leçon te montre comment leur faire parler le monde entier.

Le piège : \w et [a-z] pensent en ASCII

Par défaut, dans beaucoup de moteurs, \w vaut exactement [A-Za-z0-9_] et \d vaut [0-9]. Aucune place pour é, ñ, ß ou les chiffres arabes-indiens. Résultat : un motif « un mot » tronque les mots accentués.

Activer Unicode : le drapeau u

En JavaScript, les propriétés \p{…} et le traitement correct des caractères hors du plan de base exigent le drapeau u (pour unicode). Sans lui, \p{L} est même une erreur de syntaxe.

Selon le langage

Chaque écosystème gère Unicode à sa façon. En Python 3, le module re rend \w Unicode par défaut (\w+ matche déjà « café »), mais \p{…} n'existe que dans le module tiers regex. En PCRE (PHP, grep -P), \p{L} fonctionne avec l'option UTF-8 activée. Le drapeau u est donc une spécificité surtout visible en JavaScript.

Cibler par propriété : \p{…}

Chaque caractère Unicode porte des propriétés : est-ce une lettre ? une majuscule ? un chiffre ? de quel alphabet ? \p{Propriété} sélectionne selon ces attributs ; \P{…} (P majuscule) prend le complément.

Astuce

Pour « un identifiant de mot international », remplace le vieux [A-Za-z0-9_]+ par [\p{L}\p{N}_]+ avec le drapeau u. Il accepte alors « prénom », « Straße » ou « Москва » sans que tu aies à lister le moindre accent.

Émojis : unité de code contre point de code

Un caractère comme 😀 dépasse le « plan de base » : en mémoire (UTF-16), il occupe deux unités de code. Sans le drapeau u, le moteur raisonne unité par unité : . ne matche que la moitié de l'émoji. Avec u, il raisonne en points de code et traite l'émoji comme un tout.

Le piège de \p{Emoji}

Contre toute attente, /\p{Emoji}/u.test("3") renvoie true ! Unicode marque les chiffres 0-9, ainsi que # et *, de la propriété « Emoji », car ils servent de base aux émojis en forme de touche. Pour ne cibler que les vrais pictogrammes, préfère \p{Extended_Pictographic}.

Cas réel

Cas réel

Un réseau social veut extraire les hashtags d'un message. Version naïve : /#\w+/g. Elle marche pour #regex… mais tronque #écologie en #cologie (l'accent casse) et rate #日本 en entier. La correction tient en deux gestes : passer à /#[\p{L}\p{N}_]+/gu. Désormais, les hashtags accentués, cyrilliques ou japonais sont capturés correctement. Ce bug — « ça marche chez moi, en anglais » — est l'un des plus fréquents dès qu'un service s'internationalise ; la connaissance des propriétés Unicode le fait disparaître d'un coup.

Pour aller plus loin

Pour aller plus loin

Certaines lettres accentuées existent sous deux formes : é peut être un point de code (U+00E9) ou deux (un e + un accent combinant U+0301). Visuellement identiques, mais différents pour une regex ! Avant de comparer ou de matcher, on normalise le texte avec "…".normalize("NFC") pour tout ramener à la forme composée. Les émojis modernes (drapeaux, familles, teintes de peau) sont même des séquences de plusieurs points de code jointes par un liant : les compter correctement relève de l'API Intl.Segmenter plutôt que d'une simple regex.

Antisèche

Glossaire

ASCII
Jeu de 128 caractères (lettres latines non accentuées, chiffres, ponctuation) hérité des débuts de l'informatique.
Unicode
Norme qui attribue un numéro unique (point de code) à chaque caractère de (presque) toutes les écritures.
Point de code
Le numéro d'un caractère Unicode (ex. : é = U+00E9).
Unité de code
Le morceau de stockage ; en UTF-16, un caractère hors plan de base occupe deux unités.
Graphème
Ce qu'un lecteur perçoit comme « un caractère » (une lettre accentuée, un émoji drapeau) ; il peut regrouper plusieurs points de code, que Intl.Segmenter compte correctement.
Propriété Unicode
Attribut d'un caractère (lettre, chiffre, écriture…) ciblable avec \p{…}.
Drapeau u
Option JavaScript qui active l'interprétation Unicode d'une regex.
Normalisation
Réécriture d'un texte sous une forme canonique (NFC/NFD) pour rendre comparables des accents équivalents.

Récap et vérification

  • \w, \d et [a-z] sont des raccourcis ASCII : ils ratent les accents et les autres écritures.
  • En JavaScript, le drapeau u active Unicode et débloque \p{…}.
  • \p{L} (lettre), \p{N} (chiffre), \p{Script=…} ciblent par propriété ; \P{…} prend le complément.
  • Un émoji occupe deux unités de code : sans u, . le coupe en deux.
  • Remplace \w+ par [\p{L}\p{N}_]+ pour un « mot » réellement international.

Vérifie ta compréhension

  1. Pourquoi /\w+/ ne capture-t-il que caf dans le mot « café » ?
  2. Quel drapeau faut-il, en JavaScript, pour utiliser \p{L} ?
  3. Que se passe-t-il si l'on applique /./ (sans u) à un émoji ?
