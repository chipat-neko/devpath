Module 5 · Projet — Leçon 11

Projet : un valideur-extracteur de données

~45 min Projet Prérequis : tout le cours

À la fin de cette leçon, tu sauras

  • rassembler motifs, groupes nommés, drapeaux et backréférences dans un vrai mini-projet ;
  • écrire un moteur de validation de champs de formulaire ;
  • construire une fonction d'extraction de données depuis un texte libre ;
  • faire les bons choix de rigueur et de sûreté (pas de ReDoS).
Sommaire de la leçon

Onze leçons plus tard, tu connais les littéraux, les classes, les quantificateurs, les ancres, les groupes (nommés compris), les regards, les drapeaux, Unicode et les pièges de performance. Il est temps de tout assembler. On va construire un petit module qui fait deux choses que tout logiciel réclame : valider des saisies et extraire des informations d'un texte.

Ce qu'on construit

Un objet motifs (une regex par type de champ), une fonction valider(champ, valeur) qui répond vrai/faux, et une fonction extraire(texte) qui renvoie les hashtags, montants et dates trouvés.

Étape par étape

Étapes

Les motifs

Un objet motifs avec email, telephone, codePostal et une date nommée (?<annee>…). Motifs ancrés ^…$.

Valider

valider(champ, valeur) applique .test() du bon motif et renvoie un booléen.

Extraire les hashtags

Version Unicode : /#[\p{L}\p{N}_]+/gu pour accepter les accents (leçon 7).

Extraire les montants

Un nombre suivi de € : /(\d+(?:[.,]\d{2})?)\s*€/g, capture du montant.

Rester sûr

Vérifie qu'aucun motif n'imbrique de quantificateur : teste sur une longue entrée invalide (leçon 9).

Astuce : matchAll pour l'extraction

Avec le drapeau g, [...texte.matchAll(motif)] renvoie toutes les correspondances avec leurs groupes capturés : parfait pour récupérer d'un coup les montants et leur valeur numérique. match seul, avec g, ne rend que les textes complets, sans les captures.

matchAll exige le drapeau g

Appeler matchAll avec une regex sans g lève une TypeError en JavaScript : la méthode n'a de sens que pour parcourir toutes les occurrences. Pense donc à /…/g — voire /…/gu pour les hashtags accentués (leçon 7).

Exercices

Exercice 1Échauffement

Écris le motif ancré qui valide exactement un code postal français : 5 chiffres, rien de plus, rien de moins.

Voir une solution

Les ancres ^ et $ sont indispensables : sans elles, \d{5} trouverait cinq chiffres n'importe où dans la chaîne et accepterait "750010".

Exercice 2Application

Écris le motif d'un slug d'URL : minuscules et chiffres uniquement, séparés par des tirets, sans tiret en début ni en fin, et sans deux tirets consécutifs.

Voir une solution

Un premier bloc alphanumérique obligatoire, suivi de zéro ou plusieurs blocs « tiret + alphanumérique » : le tiret ne peut jamais se retrouver isolé aux extrémités ni se doubler.

Exercice 3Défi

Dans le motif de date /^(\d{4})-(\d{2})-(\d{2})$/, remplace les groupes numérotés par des groupes nommés annee, mois et jour, et montre comment accéder à chaque partie dans le résultat de .exec().

Voir une solution

La syntaxe (?<nom>…) nomme un groupe. On lit ensuite chaque partie via match.groups.nom : plus lisible et plus robuste que m[1], m[2]… si l'on réordonne les groupes.

Cas réel

Cas réel

Ce petit moteur est exactement ce qui vit derrière un champ de formulaire moderne, une messagerie qui met les #hashtags en couleur, ou un outil comptable qui repère les montants dans un e-mail. Les mêmes deux gestes — valider une saisie, extraire des motifs d'un texte — reviennent dans presque toutes les applications. En sachant les écrire toi-même, lisiblement et sans risque de ReDoS, tu tiens l'un des outils les plus rentables du métier : quelques caractères qui remplacent des dizaines de lignes de code manuel.

Glossaire

Valider
Vérifier qu'une saisie respecte un format attendu (vrai/faux) avec .test().
Extraire
Récupérer toutes les occurrences d'un motif dans un texte, souvent via matchAll.
matchAll
Renvoie un itérateur de toutes les correspondances avec leurs groupes capturés.
Drapeau g (global)
Fait chercher toutes les occurrences et non la première ; requis par matchAll, sinon TypeError.
Groupe nommé ((?<nom>…))
Capture repérée par une étiquette (annee, mois…) plutôt que par un numéro, relue via match.groups.nom : plus lisible si les groupes changent d'ordre.
Dictionnaire de motifs
Objet associant chaque type de champ à sa regex, partagé par tout le module.
Ancrage
^…$ : force le motif à couvrir toute la valeur — indispensable pour valider.
Capstone
Projet de synthèse qui mobilise l'ensemble des notions d'un cours.

Récap et vérification

  • Un dictionnaire de motifs centralise les regex ; valider teste, extraire collecte.
  • Pour valider : motifs ancrés ^…$ et .test().
  • Pour extraire : drapeau g et matchAll pour récupérer aussi les captures.
  • Réutilise les acquis : groupes nommés, Unicode pour les hashtags, sûreté anti-ReDoS.
  • La regex remplace des dizaines de lignes de code manuel : c'est un outil du quotidien.

  2. Quelle méthode récupère toutes les correspondances avec leurs groupes ?
  3. Quel drapeau rend l'extraction des hashtags accentués correcte ?
