Module 05 · Go en pratique — Leçon 15

Manipuler le texte : chaînes, runes et conversions

~35 min Intermédiaire Leçon 3 recommandée

À la fin de cette leçon, tu sauras

  • utiliser les fonctions clés du package strings (recherche, découpe, remplacement, nettoyage) ;
  • distinguer un octet d'une rune et parcourir correctement une chaîne UTF-8 ;
  • convertir entre nombres et texte avec strconv (Atoi, Itoa, ParseFloat…) ;
  • concaténer efficacement avec strings.Builder au lieu du + en boucle.
Sommaire de la leçon

Presque tout programme manipule du texte : lire une entrée, découper une ligne, formater un rapport. En Go, une string est une séquence d'octets immuable, encodée en UTF-8. Cette leçon te donne les outils du quotidien — le package strings, la distinction octet/rune, les conversions de strconv — et le bon réflexe pour ne pas ramer sur les caractères accentués ni sur les grosses concaténations.

Tout se compile avec go run main.go ; les sorties sont en commentaire.

La quasi-totalité des opérations courantes sur le texte vit dans strings. Les fonctions ne modifient jamais la chaîne d'origine (elle est immuable) — elles en renvoient une nouvelle.

Octets et runes : le piège des accents

Voici le point qui surprend tout le monde. Une string est indexée en octets, pas en caractères. Comme l'UTF-8 encode certains caractères sur plusieurs octets, len(s) compte des octets, et s[i] renvoie un octet (byte).

Une rune est un point de code Unicode (un « vrai » caractère), stockée sur un int32. Pour parcourir les caractères, une boucle range décode l'UTF-8 pour toi et renvoie la position en octets et la rune :

Piège fréquent

Ne fais jamais s[i:j] ni len(s) en croyant compter des caractères dès qu'il peut y avoir des accents, des emojis ou du texte non latin. Tu compterais des octets et risquerais de couper une rune en deux (produisant un caractère de remplacement �). Passe par range, []rune ou utf8.RuneCountInString.

strconv : convertir nombres et texte

Un formulaire, un fichier, une variable d'environnement : tout arrive en texte. Le package strconv fait le pont avec les types numériques, en renvoyant toujours une erreur quand la conversion échoue.

Astuce

Ne confonds pas strconv.Itoa(42) (→ "42", le nombre écrit en toutes lettres) avec string(42) (→ "*", le caractère de point de code 42 !). Convertir un int par string(n) est une erreur classique : go vet t'avertit d'ailleurs. Pour un nombre → texte, c'est strconv (ou fmt.Sprint).

strings.Builder : concaténer sans gaspiller

Comme les chaînes sont immuables, chaque s = s + "x" crée une nouvelle chaîne et recopie tout le contenu précédent. Dans une boucle, ce coût devient quadratique (O(n²)) : catastrophique pour construire un gros texte.

strings.Builder accumule dans un tampon qui grandit et ne produit la chaîne finale qu'une fois, avec String().

Un cas réel : le rapport qui rampait

Cas réel

Un outil interne générait un rapport CSV de plusieurs dizaines de milliers de lignes en concaténant rapport += ligne + "\n" dans une boucle. Sur un petit jeu de données, personne n'avait rien remarqué ; sur un export réel, la génération prenait plus de trente secondes et saturait la mémoire. La cause : chaque += recopiait l'intégralité du rapport déjà construit, un coût qui grimpe en carré du nombre de lignes. Le remède a tenu en trois lignes : remplacer la chaîne par un strings.Builder et écrire dedans avec WriteString. Le temps est tombé sous la demi-seconde. Retiens la règle : dès qu'on assemble du texte dans une boucle, c'est strings.Builder (ou bytes.Buffer), jamais le +.

Glossaire

Chaîne (string)
Séquence d'octets immuable en Go, encodée en UTF-8 ; toute « modification » produit une nouvelle chaîne.
UTF-8
Encodage qui représente chaque caractère Unicode sur 1 à 4 octets ; l'ASCII y tient sur 1 octet, les accents sur 2.
Octet (byte)
Unité de s[i] et de len(s) ; alias de uint8. Un caractère accentué occupe plusieurs octets.
Rune
Un point de code Unicode (un « vrai » caractère), de type int32 ; ce que renvoie une boucle range sur une chaîne.
Package strings
Boîte à outils du texte : recherche (Contains), découpe (Split/Fields), remplacement, nettoyage (TrimSpace).
Package strconv
Conversions entre texte et types numériques : Atoi, Itoa, ParseFloat, ParseBool, Quote.
strings.Builder
Tampon d'assemblage de texte qui implémente io.Writer ; évite les recopies du += et produit la chaîne finale via String().
utf8.RuneCountInString
Compte les caractères (runes) d'une chaîne, là où len compte les octets.

Récap et vérification

  • Le package strings couvre recherche, découpe (Split/Fields), assemblage (Join), nettoyage et remplacement — sans jamais muter l'original.
  • Une chaîne est indexée en octets ; pour raisonner en caractères, utilise range, []rune ou utf8.RuneCountInString.
  • strconv convertit texte ⇄ nombres et renvoie une erreur ; Itoa pour un int → texte, jamais string(n).
  • Pour assembler du texte en boucle, strings.Builder évite le coût quadratique du +.
