JavaScript : des bases au niveau confirmé

De ta toute première ligne de code jusqu'à une vraie application web. Ce cours t'apprend à penser en JavaScript : la logique, les données, la manipulation de la page, puis la POO, l'asynchrone, les API, les modules et l'outillage — le tout consolidé par un projet fil rouge qui grandit au fil des dix modules.

Bien s'équiper

Les extensions VS Code pour JavaScript

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour JavaScript

  • ESLint (Microsoft) — repère erreurs et mauvaises pratiques pendant que tu écris.
  • Prettier - Code formatter (Prettier) — met le code en forme automatiquement à l'enregistrement.
  • JavaScript (ES6) code snippets (charalampos karypidis) — raccourcis pour le code courant.
  • Live Server (Ritwick Dey) — recharge ta page web à chaque sauvegarde.
  • Path Intellisense (Christian Kohler) — complète les chemins de fichiers.

Ce que tu vas apprendre

Des compétences concrètes et vérifiables

À la fin du cours, tu sauras

  • maîtriser les fondations : variables, logique, fonctions, tableaux et objets ;
  • transformer des collections avec map, filter, reduce ;
  • rendre une page vivante : DOM, événements et formulaires ;
  • exploiter les fermetures, this et les fonctions d'ordre supérieur ;
  • structurer ton code en POO : prototypes, classes, héritage et encapsulation ;
  • gérer l'asynchrone (boucle d'événements, promesses) et consommer une API avec fetch ;
  • fiabiliser : gestion d'erreurs, modules ES, expressions régulières, Map/Set ;
  • déboguer, tester, et assembler une application complète.

Le projet fil rouge

Apprendre la syntaxe ne suffit pas : il faut construire. Tout au long du cours, tu développes un gestionnaire de tâches. Il commence par une simple liste affichée dans la console, puis gagne des fonctions (ajouter, filtrer), une vraie structure de données, un rendu dans la page, des interactions au clic, et enfin la persistance : tes tâches sont sauvegardées et rechargées automatiquement.

Fil rouge

Chaque leçon ajoute un « épisode » au projet. À la fin du module 4, tu auras une petite application web complète, écrite entièrement en JavaScript vanilla.

Public & prérequis

Ce cours s'adresse aux débutants. Aucune expérience de programmation n'est nécessaire. Il est utile (mais pas obligatoire) de connaître les bases du HTML et de savoir ouvrir la console de son navigateur — ce que la première leçon explique justement.

Bon à savoir

Tu n'as rien à installer : un navigateur récent suffit. Suis les leçons dans l'ordre, le niveau monte progressivement, un concept à la fois.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Déclare avec const (par défaut) ou let ; évite var.
  • Compare avec === (valeur ET type), pas ==.
  • Les fonctions sont des valeurs ; une closure retient sa portée.
  • Transforme les tableaux avec map, filter, reduce, forEach.
  • Le DOM se sélectionne (querySelector) et s'écoute (addEventListener).
  • L'asynchrone : Promise + async/await, erreurs avec try/catch.
  • Organise le code en modules (import / export).
Variable
Un nom lié à une valeur ; déclarée avec const ou let.
Closure
Fonction qui retient les variables de son contexte de définition.
Callback
Fonction passée en argument, appelée plus tard par une autre.
Promise
Objet représentant une valeur future (résultat d'une opération asynchrone).
DOM
Représentation arborescente de la page, manipulable en JavaScript.
Événement
Action (clic, saisie…) à laquelle on réagit via addEventListener.
Hoisting
Remontée des déclarations en haut de leur portée par le moteur.
this
Référence à l'objet courant ; sa valeur dépend de la façon d'appeler la fonction.
JSON
Format texte d'échange de données (JSON.parse / JSON.stringify).
Module
Fichier qui expose et importe des valeurs avec export / import.
