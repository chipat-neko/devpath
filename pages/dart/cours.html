Dart & Flutter : applications multiplateformes

Dart est un langage typé et sain, conçu par Google pour le client : sa sound null safety bannit les plantages liés au null, et son modèle asynchrone (Future, Streams) est limpide. C'est le moteur de Flutter, qui dessine des applications iOS, Android, web et desktop depuis une seule base de code. Ce cours te mène du premier main jusqu'à une petite app Flutter.

Bien s'équiper

Les extensions VS Code pour Dart

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Dart

  • Dart (Dart Code) — support du langage et débogage.
  • Flutter (Dart Code) — pour développer des applications Flutter.
  • Awesome Flutter Snippets (Neevash Ramdial) — raccourcis de widgets.

Pour qui ?

Idéal si tu connais déjà un langage à accolades (le cours JavaScript ou le cours Java suffisent). Chaque notion propre à Dart est expliquée depuis le début, jusqu'aux premiers widgets Flutter.

Ce que tu vas apprendre

De Dart à une app Flutter

À la fin du cours, tu sauras

  • écrire du Dart sûr : sound null safety, collections, fonctions à paramètres nommés et closures ;
  • modéliser en objets : classes et const constructors, mixins, sealed classes et génériques ;
  • maîtriser l'asynchrone : Future, async/await, Streams et gestion d'erreurs ;
  • passer à Flutter : widgets, état (setState), navigation et une petite application multiplateforme.

Pour qui, et pourquoi

Ce cours s'adresse à ceux qui visent le développement mobile multiplateforme avec Flutter — un seul code pour iOS et Android — ou qui veulent un langage client moderne et agréable. Flutter est très demandé pour les applications, et Dart se transpose aussi au web et au desktop.

Chaque leçon est autonome et illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties sont montrées en commentaire.
