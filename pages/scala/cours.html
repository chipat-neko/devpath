Scala : objet et fonctionnel sur la JVM

Scala réconcilie deux mondes : l'objet et le fonctionnel, avec un typage fort et inféré, sur la JVM (tout Java à portée de main). Ses case classes, son pattern matching et ses collections immuables rendent le code expressif et sûr. C'est le langage d'Apache Spark et du big data. Ce cours te mène des bases jusqu'aux given et aux Futures.

Bien s'équiper

Les extensions VS Code pour Scala

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Scala

  • Metals (Scalameta) — IntelliSense Scala complet, build et tests.

Pour qui ?

Idéal si tu connais déjà un langage à objets — le cours Java est un tremplin naturel (Scala tourne sur la même JVM). Chaque notion fonctionnelle est expliquée depuis le début.

Ce que tu vas apprendre

Deux paradigmes, un seul langage

À la fin du cours, tu sauras

  • écrire du Scala idiomatique : val, expressions, fonctions d'ordre supérieur et collections immuables ;
  • modéliser proprement : case classes, traits, types algébriques et pattern matching exhaustif ;
  • gérer l'absence et l'erreur sans null : Option, Either, Try ;
  • aller plus loin : génériques et given/using, Futures, sbt, tests, et le lien avec Spark.

Pour qui, et pourquoi

Ce cours s'adresse aux développeurs qui visent le data engineering (Spark), le back-end exigeant ou la fintech, et à ceux qui veulent un langage à la fois objet et fonctionnel, sûr et expressif. Scala donne accès à tout l'écosystème JVM tout en élevant le niveau d'abstraction.

Chaque leçon est autonome et illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties sont montrées en commentaire.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • val (immuable, privilégié) ou var.
  • case class pour les données + pattern matching.
  • Fonctionnel ET objet ; fonctions de première classe.
  • Tourne sur la JVM (interopérabilité Java).
  • Collections immuables par défaut (List, Map).
  • Option pour l'absence de valeur ; match pour filtrer.
  • def pour les méthodes.
val / var
Valeur immuable / variable réassignable.
case class
Classe concise pour des données (immuable, comparable, déstructurable).
Pattern matching
Filtrage par forme avec match / case.
Option
Valeur présente (Some) ou absente (None).
Trait
Équivalent d'une interface, pouvant porter du comportement.
Immuabilité
Les structures ne changent pas après leur création.
Fonction de première classe
Fonction manipulable comme une valeur ordinaire.
JVM
Machine virtuelle Java sur laquelle s'exécute Scala.
