C# : applications .NET

Le C# est un langage objet moderne, élégant et productif, au cœur de la plateforme .NET. Il sert à tout : web (ASP.NET), bureau, mobile, et jeux vidéo avec Unity. Ce cours te mène des bases à la programmation orientée objet, puis à LINQ et à l'asynchrone : un langage à la fois rigoureux et agréable.

Bien s'équiper

Les extensions VS Code pour C#

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour C#

  • C# Dev Kit (Microsoft) — outillage C# complet (projets, tests).
  • C# (Microsoft) — langage, IntelliSense et débogage.
  • IntelliCode for C# Dev Kit (Microsoft) — suggestions assistées par IA.
  • .NET Install Tool (Microsoft) — gère les SDK .NET requis.

Pour qui ?

Aucun prérequis strict : si tu connais les variables et les boucles (par ex. via le cours JavaScript), tu suivras facilement. C# ressemble à Java : l'un éclaire l'autre.

Ce que tu vas apprendre

Des bases à .NET moderne

À la fin du cours, tu sauras

  • compiler et exécuter du C# avec .NET (dotnet), avec types, conditions, boucles et méthodes ;
  • maîtriser la programmation orientée objet : classes, propriétés, héritage, interfaces et record ;
  • écrire du code robuste : exceptions, génériques et collections (List, Dictionary) ;
  • exploiter les outils phares de C# : LINQ, les délégués/lambdas et l'asynchrone (async/await).

Pour qui, et pourquoi

Ce cours s'adresse à qui vise le développement web/bureau d'entreprise, les services cloud Azure, ou le jeu vidéo avec Unity. C# combine la rigueur d'un langage typé et objet avec une ergonomie remarquable (propriétés, LINQ, async) ; il est multiplateforme et très demandé.

Chaque leçon est autonome et illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties console sont montrées en commentaire.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Plateforme .NET ; point d'entrée Main.
  • Fortement typé et orienté objet (classes, héritage, interfaces).
  • Propriétés automatiques : { get; set; }.
  • Collections génériques : List<…>, Dictionary<…>.
  • LINQ pour interroger les collections (Where, Select…).
  • Exceptions : try / catch / finally.
  • Compilé en IL, exécuté par le CLR.
Classe / objet
Le modèle et son instance créée avec new.
Propriété
Accès contrôlé à un champ : { get; set; }.
LINQ
Requêtes intégrées au langage sur les collections.
Générique
Type paramétré, ex. List<T>.
Interface
Contrat de méthodes qu'un type doit fournir.
IL
Code intermédiaire compilé à l'exécution par le CLR.
CLR
Environnement d'exécution de .NET.
namespace
Espace de noms organisant le code.
Interpolation
Chaîne préfixée par $ insérant des variables entre accolades.
