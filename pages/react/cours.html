React : interfaces à composants

Tu connais déjà JavaScript et tu veux passer du DOM manipulé à la main à des interfaces construites en composants ? Ce cours t'apprend à penser en React et à composer une vraie petite application, une brique à la fois.

Bien s'équiper

Les extensions VS Code pour React

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour React

  • ES7+ React/Redux/React-Native snippets (dsznajder) — raccourcis JSX.
  • ESLint (Microsoft) — qualité du code et règles React.
  • Prettier - Code formatter (Prettier) — mise en forme du JSX.
  • Auto Rename Tag (Jun Han) — synchronise les balises JSX.
  • Simple React Snippets (Burke Holland) — squelettes de composants.

Cours complet

Les 26 leçons sont rédigées, du JSX jusqu'aux hooks avancés (useReducer, hooks personnalisés), puis au routage (React Router), à la performance (mémoïsation, lazy) et à la robustesse (error boundaries, portals, tests). Prérequis : le cours JavaScript.

Ce que tu vas apprendre

Objectifs du cours

À la fin du cours, tu sauras

  • maîtriser le JSX, les props et l'affichage de listes (avec clés) ;
  • gérer l'état (useState), le rendu conditionnel, les événements et les formulaires contrôlés ;
  • synchroniser l'extérieur avec useEffect, récupérer des données et lever l'état entre composants ;
  • utiliser les hooks avancés (useRef, useContext, useReducer, hooks personnalisés) et organiser une application.

Pour qui, et pourquoi

Ce cours s'adresse à toi si tu écris déjà du JavaScript sans réfléchir trop longtemps : tu manipules des tableaux, tu connais les fonctions fléchées, la déstructuration et les modules. Tu as peut-être déjà bricolé une page avec document.querySelector et tu as senti que, dès qu'une interface grandit, garder le DOM et tes données synchronisés devient vite ingérable. C'est exactement le problème que React résout, et c'est de là que nous allons partir.

L'idée centrale est simple : au lieu de décrire comment modifier l'écran étape par étape, tu décris à quoi l'interface doit ressembler pour un état donné, et React se charge de mettre l'affichage à jour quand cet état change. Nous construisons ce raisonnement progressivement, un concept à la fois : d'abord les composants et le JSX, puis les props, puis l'état, et enfin les effets, sans jamais empiler trois nouveautés d'un coup.

Note

Prérequis conseillé : être à l'aise avec JavaScript moderne. Si certaines notions (fonctions fléchées, map, déstructuration, modules import/export) te semblent floues, le cours JavaScript de Syntaxe est la bonne marche à franchir avant celui-ci.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • L'interface est faite de composants ; le JSX mêle balisage et JS.
  • État local avec useState ; effets avec useEffect.
  • Données de parent à enfant via les props.
  • key obligatoire en affichant une liste avec map.
  • Contexte (ou store) pour partager un état entre composants éloignés.
Composant
Fonction qui renvoie du JSX (une portion d'interface).
JSX
Syntaxe mêlant balisage et JavaScript.
Hook
Fonction useXxx ajoutant une capacité (état, effet…).
Props
Données passées d'un composant parent à son enfant.
État (state)
Données internes d'un composant (useState).
Rendu
Production de l'interface à partir de l'état courant.
