Rust : sûreté mémoire sans GC

Rust offre les performances du C avec une garantie unique : la sûreté mémoire vérifiée à la compilation, sans ramasse-miettes. Son système de possession élimine des classes entières de bugs avant même l'exécution. Plébiscité par les développeurs, il sert aux systèmes, au web (WebAssembly) et à l'embarqué. Ce cours t'emmène jusqu'à la concurrence sans peur.

Bien s'équiper

Les extensions VS Code pour Rust

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Rust

  • rust-analyzer (The Rust Programming Language) — IntelliSense Rust complet.
  • CodeLLDB (Vadim Chugunov) — débogueur natif.
  • Even Better TOML (tamasfe) — pour le fichier Cargo.toml.
  • Dependi (fill-labs) — gérer les versions des crates.

Niveau

Cours avancé. Le système de possession demande un petit effort au début (le fameux « combat avec le borrow checker »), puis devient une seconde nature. Des bases en programmation, et idéalement des notions de C (mémoire), aident à apprécier ce que Rust résout.

Ce que tu vas apprendre

Du premier programme à la concurrence sûre

À la fin du cours, tu sauras

  • compiler du Rust avec Cargo, et écrire types, fonctions, structures, enum et match ;
  • maîtriser le cœur de Rust : la possession, les emprunts et les durées de vie ;
  • abstraire avec les traits et les génériques, et gérer les erreurs avec Result et ? ;
  • exploiter itérateurs et closures, puis écrire de la concurrence sans peur et organiser un projet (crates, tests).

Pour qui, et pourquoi

Ce cours s'adresse à qui veut la performance du bas niveau sans les pièges mémoire : systèmes, moteurs, outils en ligne de commande, WebAssembly, embarqué, blockchain. Rust est régulièrement élu langage le plus apprécié ; son compilateur exigeant t'apprend à écrire du code correct par construction.

Chaque leçon est illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties et les erreurs du compilateur sont montrées en commentaire.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Immuable par défaut ; let mut pour pouvoir modifier.
  • La propriété et l'emprunt (&) garantissent la mémoire, sans ramasse-miettes.
  • Pas de null : Option (Some/None) ; erreurs avec Result (Ok/Err).
  • Vec pour les collections ; itérateurs (iter, map, sum).
  • Méthodes dans un bloc impl ; traits pour le comportement partagé.
  • Le compilateur strict attrape beaucoup de bugs à la compilation.
  • Très performant, proche du C.
Propriété (ownership)
Chaque valeur a un unique propriétaire responsable de sa libération.
Emprunt
Accès temporaire à une valeur via une référence (&).
Durée de vie
Portée pendant laquelle une référence reste valide.
Option
Valeur présente (Some) ou absente (None) — remplace null.
Result
Succès (Ok) ou erreur (Err).
Trait
Ensemble de méthodes partagé entre plusieurs types.
Vec
Tableau dynamique, créé avec vec!.
Borrow checker
Vérificateur d'emprunts du compilateur, garant de la sûreté mémoire.
