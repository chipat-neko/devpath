Module 01 · Les bases de Rust — Leçon 01

Découvrir Rust et Cargo

~31 min Avancé Des bases en programmation aident

À la fin de cette leçon, tu sauras

  • comprendre la promesse de Rust : performance native et sûreté mémoire garantie à la compilation, sans ramasse-miettes ;
  • installer Rust via rustup et créer, compiler et exécuter un projet avec cargo new, cargo run, cargo build et cargo check ;
  • écrire un premier programme avec fn main() et la macro println!, et utiliser les formateurs {} et {:?} ;
  • soigner ton code avec cargo fmt et clippy, et adopter la philosophie du compilateur-allié.
Sommaire de la leçon

Bienvenue dans le monde de Rust. Tu vas y découvrir un langage qui tient une promesse longtemps jugée impossible : la vitesse du C et la sûreté mémoire d'un langage à ramasse-miettes, mais sans ramasse-miettes. Tout repose sur des vérifications faites à la compilation : une fois ton programme compilé, des classes entières de bugs (accès hors limites, double libération, données partagées entre threads sans protection) ont déjà été éliminées.

Dans cette première leçon, on pose les fondations : pourquoi Rust existe, comment l'installer, et comment Cargo — son outil tout-en-un — t'accompagne à chaque étape. Pas de panique si le compilateur te gronde au début : en Rust, le compilateur est un allié, et ses messages sont réputés parmi les plus pédagogiques de tout l'écosystème logiciel. Le « combat avec le borrow checker » se gagne, et tu vas apprendre à le gagner.

Rust en bref : rapide, sûr, sans GC

Rust vise trois objectifs simultanés, là où la plupart des langages doivent en sacrifier un :

  • Performance : code compilé en natif, aussi rapide que du C ou C++, sans surcoût caché à l'exécution (pas de machine virtuelle, pas de pauses de ramasse-miettes).
  • Sûreté mémoire garantie à la compilation : grâce au système de possession (que tu découvriras bientôt), le compilateur prouve que ton code n'accède jamais à de la mémoire invalide. Sans ramasse-miettes (« GC »).
  • Concurrence sûre : les mêmes règles qui sécurisent la mémoire empêchent aussi les data races. Le slogan officiel parle de « fearless concurrency » — la concurrence sans peur.

On retrouve Rust là où ces garanties comptent : programmation système (noyaux, pilotes, navigateurs), WebAssembly, embarqué, outils en ligne de commande (CLI rapides comme ripgrep ou fd), services réseau performants, et blockchain.

Note

« Sans ramasse-miettes » ne veut pas dire « gestion manuelle dangereuse comme en C ». Rust libère la mémoire automatiquement, au bon moment, mais ce moment est déterminé à la compilation par les règles de possession — pas par un processus qui tourne en arrière-plan pendant l'exécution.

Le formatage avec println!

println! insère des valeurs dans la chaîne grâce à des accolades {}. Deux formateurs essentiels à connaître dès maintenant :

  • {} — l'affichage Display, lisible par un humain (pour les nombres, le texte…).
  • {:?} — l'affichage Debug, destiné au développeur (pour inspecter structures, listes, etc.). Le :? demande la version « débogage ».

La syntaxe {nom} (variable capturée directement) fonctionne depuis l'édition 2021 et est très lisible.

Astuce

Si tu essaies d'afficher un tableau avec {}, le compilateur refusera : [i32; 3] n'implémente pas Display. Il te suggérera lui-même d'utiliser {:?}. Lis la suggestion — elle est presque toujours la bonne réponse.

cargo fmt et clippy : un code propre

Rust fournit deux outils qui élèvent la qualité de ton code sans effort :

  • cargo fmt reformate automatiquement ton code selon le style officiel. Fini les débats sur les espaces et l'indentation : tout le monde dans l'écosystème écrit pareil.
  • cargo clippy est le linter : il repère les tournures maladroites, les anti-patterns, et propose des versions plus idiomatiques.

La philosophie : le compilateur est ton allié

En Rust, on dit souvent : « si ça compile, ça marche souvent ». Ce n'est pas magique : le compilateur déplace une grande partie de la détection des bugs avant l'exécution. Là où d'autres langages te laissent planter en production, Rust refuse de compiler et t'explique pourquoi.

Au début, ça frustre — tu te bats contre des erreurs que tu n'avais jamais rencontrées ailleurs. Mais change de perspective : chaque erreur de compilation est un bug qui n'atteindra jamais tes utilisateurs. Les messages d'erreur Rust pointent la ligne fautive, expliquent la règle violée, et suggèrent souvent un correctif. Prends l'habitude de les lire en entier.

Même une faute de débutant déclenche une suggestion précise : println! avec le !.

Crates.io : l'écosystème

Les bibliothèques Rust s'appellent des crates (caisses) et se publient sur crates.io, le dépôt central. Pour ajouter une dépendance, une seule commande suffit : Cargo l'inscrit dans Cargo.toml et la télécharge à la prochaine compilation.

Plus besoin d'éditer le manifeste à la main : cargo add s'en charge.

Pièges fréquents

Piège fréquent

Oublier le ! des macros. println("...") ne compile pas : c'est println!("..."). Pareil pour print!, format!, vec!, panic!… Le ! distingue une macro d'une fonction. Heureusement, le compilateur te le rappelle.

Piège fréquent

Confondre cargo run et cargo build. build compile mais ne lance pas le programme ; tu dois ensuite exécuter le binaire toi-même. run compile puis exécute en une seule étape. Pour juste vérifier la compilation sans binaire, préfère cargo check.

Piège fréquent

Ignorer les warnings et ne pas lire les messages. Un avertissement (variable inutilisée, code mort…) signale souvent une vraie erreur de logique. Les messages du compilateur Rust sont une mine d'or : lis-les jusqu'au bout avant de chercher ailleurs.

Piège fréquent

Oublier --release pour mesurer la performance. Le mode debug par défaut n'optimise pas et inclut des vérifications supplémentaires : un programme peut y être 10 à 100 fois plus lent. Pour toute mesure de vitesse, compile avec cargo build --release ou cargo run --release.

Pour aller plus loin

Pour aller plus loin

Quelques ressources pour creuser :

  • Rust Playground (play.rust-lang.org) : exécute de petits programmes Rust dans le navigateur, sans rien installer — parfait pour tester une idée vite.
  • cargo doc --open : génère et ouvre la documentation HTML de ton projet et de toutes ses dépendances. Indispensable pour explorer une crate.
  • rust-analyzer : l'extension d'éditeur qui apporte autocomplétion, erreurs en direct et refactorings. À installer dès aujourd'hui dans ton éditeur.
  • Les éditions (2015, 2018, 2021) : des paliers d'évolution du langage. Choisir edition = "2021" active les idiomes modernes (comme {nom} dans println!) sans casser l'ancien code.

Un cas réel : 70 % des failles, et Android qui bascule

Cas réel

Microsoft comme Google l'ont chiffré indépendamment : environ 70 % des vulnérabilités de sécurité corrigées dans leurs gros logiciels écrits en C/C++ étaient des erreurs de gestion mémoire (débordements de tampon, use-after-free, doubles libérations…) — exactement les classes de bugs que Rust élimine à la compilation. Google a donc commencé à écrire les nouveaux composants bas niveau d'Android en Rust : la part de code natif neuf en Rust a grimpé année après année, et Google a rapporté que la proportion de vulnérabilités mémoire dans le nouveau code était passée sous les 20 %, sans une seule faille de sûreté mémoire imputable au code Rust livré. La promesse de cette leçon — « des classes entières de bugs éliminées avant l'exécution » — n'est pas un slogan marketing : c'est ce qui a fait entrer Rust jusque dans le noyau Linux (2022).

Glossaire

Cargo
L'outil tout-en-un de Rust : système de build, gestionnaire de dépendances et lanceur de tâches. C'est lui qui appelle rustc pour toi.
Crate
Une bibliothèque (ou un binaire) Rust. Les crates externes se publient sur crates.io et se déclarent dans Cargo.toml.
rustup
L'installateur officiel qui gère les versions de Rust et les composants (compilateur, clippy, rustfmt…).
rustc
Le compilateur brut de Rust. On l'appelle rarement à la main : Cargo s'en charge.
Macro
Du code expansé à la compilation, signalé par un ! (comme println!, vec!, panic!). Ce n'est pas une fonction ordinaire.
Display / Debug
Deux façons d'afficher une valeur : {} (Display, lisible pour l'humain) et {:?} (Debug, pour inspecter structures et collections).
clippy
Le linter officiel : il repère les tournures maladroites et propose des versions plus idiomatiques.
Édition
Un palier d'évolution du langage (2015, 2018, 2021…) fixé dans Cargo.toml ; active des idiomes modernes sans casser l'ancien code.

Récap et vérification

  • Rust offre la performance du C, la sûreté mémoire à la compilation et la concurrence sûre, sans ramasse-miettes.
  • rustup installe Rust ; rustc est le compilateur, Cargo l'outil de projet à tout faire.
  • cargo new, cargo check, cargo build (--release), cargo run couvrent ton cycle de travail.
  • fn main() est le point d'entrée ; println! est une macro (d'où le !), avec {} (Display) et {:?} (Debug).
  • cargo fmt formate, clippy conseille ; les messages du compilateur sont tes meilleurs alliés.

  2. Pourquoi écrit-on println! avec un point d'exclamation, et que désigne ce ! ?
