Docker : conteneuriser ses applications

Docker emballe une application avec tout son environnement dans un conteneur qui tourne à l'identique partout : fini le « ça marche sur ma machine ». Un savoir-faire transversal, devenu incontournable du développement au déploiement. Ce cours part de zéro et te mène jusqu'aux images de production.

Bien s'équiper

Les extensions VS Code pour Docker

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Docker

  • Docker (Microsoft) — Dockerfiles, images et conteneurs depuis l'éditeur.
  • Container Tools (Microsoft) — gestion moderne des conteneurs.
  • Dev Containers (Microsoft) — développer à l'intérieur d'un conteneur.
  • YAML (Red Hat) — pour les fichiers docker-compose.

Pour qui ?

Aucune connaissance d'administration système requise : juste un terminal. Les bases de la ligne de commande aident, et les exemples conteneurisent des applications comme on en construit dans les cours Node.js ou Python.

Ce que tu vas apprendre

Des conteneurs à la production

À la fin du cours, tu sauras

  • expliquer ce qu'est un conteneur et lancer des images avec docker run ;
  • écrire un Dockerfile pour conteneuriser ta propre application ;
  • persister des données (volumes) et relier des services (réseaux, ports) ;
  • orchestrer plusieurs conteneurs avec Docker Compose et produire des images optimisées ;
  • aller plus loin : ENTRYPOINT/ARG/ENV, BuildKit et multi-plateforme, pile multi-services et gestion de l'espace.

Pour qui, et pourquoi

Docker est aujourd'hui un standard du métier : il sert à monter un environnement de développement reproductible, à exécuter des tests dans un cadre propre, et à déployer en production. Ses images suivent un format standard (OCI, Open Container Initiative) : ce sont aussi celles que déploient les orchestrateurs comme Kubernetes.

Chaque leçon est autonome et illustrée par des commandes et des fichiers commentés. Installe Docker Desktop (ou le moteur Docker) pour pratiquer en parallèle : rien ne vaut le fait de lancer ses propres conteneurs.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Une image est un modèle ; un conteneur en est une instance.
  • Le Dockerfile décrit la construction (FROM, COPY, RUN…).
  • Les volumes persistent les données.
  • Docker Compose orchestre plusieurs services.
  • Build multi-étapes pour des images légères ; USER non-root.
Image

Conteneur

Volume
Stockage persistant, hors du conteneur.
Compose
