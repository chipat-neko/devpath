Variables et types

~27 min Intermédiaire Leçon 01 conseillée

À la fin de cette leçon, tu sauras

  • déclarer et utiliser une variable Sass ;
  • reconnaître les types de données ;
  • injecter une variable avec l'interpolation #{} ;
  • comprendre la portée globale ou locale.
Sommaire de la leçon

Le premier super-pouvoir de Sass, et le plus immédiatement utile, ce sont les variables : nommer une valeur une fois, puis la réutiliser partout. Change la définition, et tout le site suit. Cette leçon couvre la déclaration des variables, les types de valeurs que Sass manipule, et un mécanisme clé pour les insérer n'importe où : l'interpolation.

Déclarer une variable

L'avantage saute aux yeux le jour où la charte change : une couleur de marque utilisée à cinquante endroits se modifie en une seule ligne. La variable devient la source unique de vérité. Par convention, on regroupe les variables globales en haut d'un fichier dédié (on verra l'organisation en partials plus loin).

Les types de données

Sass distingue plusieurs types, ce qui lui permet de faire des calculs sensés :

  • nombres, avec ou sans unité : 16px, 1.5, 50%, 2rem ;
  • chaînes, avec ou sans guillemets : "Inter", sans-serif ;
  • couleurs : #2563c8, red, rgb(0 0 0 / 50%) ;
  • booléens : true, false ;
  • null : l'absence de valeur (une propriété valant null n'est pas générée) ;
  • listes : une suite de valeurs, 1px 2px 4px ou Inter, Arial, sans-serif ;
  • maps : des paires clé-valeur, (primaire: #2563c8, danger: #c0392b).

Les maps et les listes sont très pratiques pour ranger un thème ; on les exploitera avec les boucles (leçon 07). Pour l'instant, retiens que Sass comprend ce qu'est un nombre ou une couleur, et peut donc les manipuler.

L'interpolation : #{}

On ne peut pas toujours mettre une variable directement : parfois il faut l'insérer dans un texte, un nom de propriété ou un sélecteur. C'est le rôle de l'interpolation #{ }, qui « colle » la valeur d'une expression à l'endroit voulu.

Sans interpolation, margin-$cote n'aurait aucun sens pour Sass. Avec #{$cote}, la valeur est injectée et la propriété margin-left est construite. C'est l'outil indispensable dès qu'une variable doit apparaître à l'intérieur d'autre chose plutôt que comme simple valeur.

Variables Sass ou variables CSS ?

Une variable Sass ($x) est résolue à la compilation et disparaît du CSS produit. Une propriété personnalisée CSS (--x) vit dans le navigateur et peut changer à l'exécution (thème, JavaScript). Choisis selon le besoin : valeur figée au build → variable Sass ; valeur qui doit changer côté client → variable CSS. Les deux cohabitent sans souci.

Portée : global ou local

Une variable déclarée au niveau racine (hors de tout bloc) est globale : utilisable partout. Déclarée à l'intérieur d'un bloc { }, elle est locale : elle n'existe que dans ce bloc.

Si tu veux qu'une affectation faite dans un bloc modifie la variable globale, ajoute le drapeau !global. Et pour qu'une variable ne soit définie que si elle ne l'est pas déjà (utile pour les valeurs configurables d'une bibliothèque), on utilise !default — on y reviendra avec les partials.

Cas réel — un thème piloté par une map de variables

Dans un design system d'entreprise, on ne dissémine pas les couleurs : on les range dans une map Sass, par exemple $couleurs: (primaire: #2563c8, danger: #c0392b, succès: #1e8e3e), source unique de tous les composants. Quand le service marketing impose une nouvelle couleur de marque, un designer change une seule entrée de la map et recompile : boutons, liens, badges, bordures, états de survol — tout le produit adopte la nouvelle teinte d'un coup, sans risque d'en oublier un. C'est la variable « source unique de vérité » poussée à l'échelle d'un produit entier.

Glossaire

Variable Sass
Nom préfixé de $ associé à une valeur, résolu à la compilation : $primaire: #2563c8;.
Interpolation
#{ } : injecte la valeur d'une expression à l'intérieur d'un sélecteur, d'un nom de propriété ou d'une chaîne.
Type
La nature d'une valeur (nombre, chaîne, couleur, booléen, liste, map…), qui détermine les opérations possibles.
Liste
Une suite ordonnée de valeurs : 1px 2px 4px ou Inter, Arial, sans-serif.
Map
Une collection de paires clé-valeur : (primaire: #2563c8, danger: #c0392b), idéale pour ranger un thème.
Portée
La zone où une variable existe : globale (déclarée à la racine) ou locale (déclarée dans un bloc).
!global
Drapeau qui force une affectation faite dans un bloc à modifier la variable globale.
!default
Drapeau qui n'attribue la valeur que si la variable n'est pas déjà définie : la base des bibliothèques configurables.

Récap et vérification

  • Une variable Sass s'écrit $nom: valeur; et donne une source unique de vérité.
  • Sass a des types : nombres (avec unité), chaînes, couleurs, booléens, null, listes, maps.
  • L'interpolation #{ } injecte une valeur dans un sélecteur, un nom de propriété ou une chaîne.
  • La portée est globale (racine) ou locale (dans un bloc) ; !global et !default ajustent ce comportement.

Exercices

Exercice 1Échauffement

Déclare trois variables : une couleur primaire, un rayon de bordure et une police de base. Utilise-les dans une règle .carte.

Voir une solution

Chaque valeur est nommée une fois ; on pourra la réutiliser dans d'autres règles et la modifier d'un seul endroit.

Exercice 2Application

À partir d'une variable $i: 3;, génère une classe .col-3 avec width: 25%; (soit 100% / 4) en utilisant l'interpolation pour le nom de classe. (On verra les vrais calculs plus tard ; ici, concentre-toi sur l'interpolation du sélecteur.)

Voir une solution

L'interpolation #{$i} construit le nom de sélecteur .col-3. C'est exactement ce mécanisme qui, combiné à une boucle (leçon 07), permettra de générer .col-1 à .col-12 automatiquement.

Exercice 3Défi

Tu construis une bibliothèque de composants. Tu veux une variable $rayon que l'utilisateur de ta bibliothèque puisse redéfinir avant de l'inclure, sinon une valeur par défaut s'applique. Quel mécanisme Sass utiliser, et pourquoi ?

Voir une solution

On déclare la variable avec le drapeau !default :

!default signifie « n'affecte cette valeur que si la variable n'a pas déjà été définie ». Ainsi, si l'utilisateur a écrit $rayon: 4px; avant d'importer ta bibliothèque, sa valeur (4px) est conservée ; sinon, le défaut (8px) s'applique. C'est le mécanisme standard pour rendre une bibliothèque Sass configurable sans forcer l'utilisateur à modifier ton code. On le reverra avec @use ... with (leçon 04).
