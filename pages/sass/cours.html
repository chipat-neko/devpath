Sass : du CSS, en mieux

Sass est le préprocesseur CSS le plus utilisé : il ajoute au CSS des variables, l'imbrication, des mixins, des fonctions, des boucles et un vrai système de modules, puis se compile en CSS classique. De quoi écrire des feuilles de style plus concises, mieux organisées et réutilisables.

Bien s'équiper

Les extensions VS Code pour Sass

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et la compilation adaptées à ce cours.

À installer pour Sass

  • Live Sass Compiler (Glenn Marks) — compile ton .scss en .css à chaque sauvegarde.
  • SCSS IntelliSense (mrmlnc) — auto-complétion des variables, mixins et fonctions.
  • SCSS Formatter (Sibiraj) — met le SCSS en forme automatiquement.
  • Prettier - Code formatter (Prettier) — mise en forme cohérente du style.

Pour qui ?

Pour qui connaît déjà le CSS et veut l'écrire plus efficacement. Le cours prolonge naturellement CSS ; un compilateur Sass (ou l'extension Live Sass Compiler) suffit pour tout essayer.

Ce que tu vas apprendre

Le préprocesseur, de bout en bout

À la fin du cours, tu sauras

  • expliquer ce qu'est un préprocesseur et utiliser variables et types ;
  • imbriquer proprement et manier le sélecteur parent & ;
  • organiser le style en partials avec @use/@forward ;
  • réutiliser avec mixins et fonctions, et générer du CSS avec boucles et conditions.

Pourquoi apprendre Sass

Le CSS, sur un vrai projet, devient vite répétitif et difficile à maintenir. Sass répond à ce problème depuis plus de quinze ans et reste un standard de l'industrie : variables, mixins, fonctions, modules. Même si le CSS moderne a rattrapé une partie du terrain (variables, imbrication native), Sass garde des atouts décisifs pour structurer un gros projet — et savoir le lire est indispensable, tant il est répandu.

Ce cours est court et pratique : chaque leçon montre le Sass écrit et le CSS produit, pour que tu voies toujours ce que l'outil génère. Garde un compilateur sous la main et teste chaque exemple.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Variables ($nom), imbrication, mixins, fonctions.
  • & pour le sélecteur parent ; #{} pour interpoler.
  • @each / @for pour générer des règles.
  • Partials (_nom) reliés par @use / @forward.
  • À compiler en CSS (le navigateur ne lit pas le SCSS).
Variable Sass
Valeur réutilisable, préfixée par $.
Imbrication
Écrire des règles à l'intérieur d'autres règles.
&
Référence au sélecteur parent (ex. &:hover).
Mixin
Bloc de styles réutilisable (@mixin / @include).
Interpolation
Insérer une valeur avec #{}.
Partial
Fichier _nom inclus via @use / @forward.
