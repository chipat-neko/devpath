Module 1 · Les bases de Fortran — Leçon 01

Découvrir Fortran

~45 min Intermédiaire Prérequis : savoir programmer dans un autre langage

À la fin de cette leçon, tu sauras

  • comprendre pourquoi Fortran domine encore le calcul haute performance ;
  • compiler et exécuter un premier programme (gfortran) ;
  • reconnaître la structure program / end program ;
  • distinguer le Fortran ancien du Fortran moderne (90+).
Sommaire de la leçon

Fortran (de FORmula TRANslation) est le plus ancien langage de haut niveau encore en usage : sa première version date de 1957. Loin d'être une relique, il reste le roi du calcul scientifique et du HPC (calcul haute performance). Les modèles météo, les simulations de physique nucléaire, la dynamique des fluides, l'astrophysique : une grande part tourne en Fortran, parce qu'il est conçu pour une chose — calculer vite sur de gros tableaux de nombres — et qu'il le fait mieux que presque tout le monde.

Le Fortran d'aujourd'hui n'a plus grand-chose à voir avec le Fortran 77 des cartes perforées. Les normes modernes (90, 2003, 2008, 2018, 2023) en ont fait un langage propre : format libre, modules, allocation dynamique. C'est ce Fortran moderne que nous apprenons.

Installer et compiler

Le compilateur libre gfortran (de GCC) suffit. On compile un fichier .f90 (format libre) en exécutable.

Ton premier programme

La structure de base : program, un nom, le code, puis end program. print * affiche.

L'astérisque dans print * signifie « format libre » : Fortran choisit la présentation.

implicit none : la première règle

Par héritage historique, Fortran devine le type d'une variable selon son initiale (i à n = entier, sinon réel). C'est une source de bugs redoutable. La directive implicit none, à mettre systématiquement, désactive cette magie et oblige à tout déclarer.

Cas réel

Quand tu multiplies deux matrices avec NumPy (Python), MATLAB, R ou Julia, le calcul lourd n'est pas fait dans ces langages : il est délégué à BLAS et LAPACK, des bibliothèques d'algèbre linéaire écrites en Fortran et affinées depuis les années 1970. Des pans entiers de la science des données moderne reposent, tout en bas de la pile, sur du Fortran éprouvé.

Déclarer une variable

La forme moderne : le type, deux points doubles ::, le nom. On peut initialiser à la déclaration.

Commentaires et format libre

En format libre (.f90), un commentaire commence par ! et court jusqu'à la fin de la ligne. Fini les contraintes de colonnes du vieux Fortran 77.

Astuce

Compile avec les avertissements activés : gfortran -Wall -O2 bonjour.f90 -o bonjour. L'option -Wall signale les erreurs probables (variable non utilisée, conversion douteuse) et complète bien implicit none ; -O2 active les optimisations. En calcul scientifique, on pousse souvent jusqu'à -O3 pour gagner en vitesse.

Pièges fréquents

Piège fréquent

Oublier implicit none : une faute de frappe dans un nom de variable crée alors silencieusement une nouvelle variable (typée selon son initiale), et ton calcul donne un résultat faux sans la moindre erreur. Mets implicit none dans chaque programme et chaque module.

Pour aller plus loin

Pour aller plus loin

Tu croiseras des fichiers .f (Fortran 77, format fixe à colonnes) et .f90 (format libre). Le code scientifique en production mélange souvent les deux : savoir lire le format fixe aide, mais écris ton nouveau code en format libre moderne.

Glossaire

Fortran
FORmula TRANslation : langage compilé de 1957, référence du calcul scientifique et du HPC.
HPC
High-Performance Computing : calcul haute performance sur de gros volumes de nombres (météo, physique, fluides).
gfortran
Compilateur Fortran libre de GCC ; traduit un .f90 en exécutable.
implicit none
Directive qui désactive le typage implicite et impose de déclarer toutes les variables.
Typage implicite
Règle historique attribuant un type d'après l'initiale du nom (i–n : entier, sinon réel).
Format libre
Écriture moderne (.f90) sans contrainte de colonnes, commentaires par !.
::
Double deux-points séparant le type (et ses attributs) de la liste des variables déclarées.
Fortran moderne
Normes 90 et suivantes (2003, 2008, 2018, 2023) : modules, allocation dynamique, format libre.

Récap et vérification

  • Fortran reste le langage de référence du calcul scientifique et du HPC.
  • Un programme va de program à end program ; print * affiche.
  • implicit none est obligatoire : il force la déclaration de toutes les variables.
  • On déclare avec type :: nom ; le format libre (.f90) utilise ! pour les commentaires.

  2. Que fait implicit none et pourquoi est-ce essentiel ?
