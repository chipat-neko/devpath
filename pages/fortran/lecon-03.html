Module 1 · Les bases de Fortran — Leçon 03

Conditions et boucles

~50 min Intermédiaire Prérequis : leçon 2

À la fin de cette leçon, tu sauras

  • écrire des conditions avec if et select case ;
  • répéter avec la boucle do indexée et do while ;
  • contrôler le flux (cycle, exit) ;
  • utiliser les opérateurs relationnels modernes.
Sommaire de la leçon

Pour piloter un calcul, il faut décider et répéter. Fortran offre des structures de contrôle claires et modernes : if, select case, et surtout la boucle do, omniprésente dans le calcul numérique. Cette leçon te donne le contrôle du flux d'exécution.

if / else if / else

La condition se met entre parenthèses, suivie de then ; on ferme par end if. Les opérateurs relationnels modernes sont <, >, <=, >=, ==, /=.

Les anciens opérateurs .lt., .gt., .eq. existent encore dans le vieux code ; préfère <, >, ==.

Opérateurs logiques

Pour combiner des conditions : .and., .or., .not. (avec leurs points).

select case : le branchement multiple

Pour comparer une valeur à plusieurs cas, select case est plus clair qu'une cascade de if. Il accepte des intervalles.

La boucle do indexée

La boucle reine du calcul : do variable = début, fin, pas. Le pas est facultatif (1 par défaut).

do while et boucles infinies

do while répète tant qu'une condition tient. Un do sans en-tête boucle indéfiniment : on en sort avec exit.

Astuce

Quand tu connais le nombre d'itérations, préfère une boucle do bornée à un do while. L'intention est plus claire, et surtout le compilateur, connaissant les bornes à l'avance, peut mieux l'optimiser (dérouler, vectoriser). Réserve do while aux cas où la condition d'arrêt se calcule en cours de route.

cycle et exit

exit sort de la boucle ; cycle passe directement à l'itération suivante.

Cas réel

Dans un modèle météo ou climatique, l'atmosphère est découpée en millions de cellules d'une grille 3D, et le programme passe l'essentiel de son temps dans des boucles do imbriquées qui parcourent cette grille à chaque pas de temps. C'est précisément là que les compilateurs Fortran excellent : ils déroulent et vectorisent ces boucles pour saturer le processeur. Optimiser la boucle do centrale, c'est optimiser toute la simulation.

Pièges fréquents

Piège fréquent

Comparer deux réels avec == : à cause des arrondis flottants, 0.1 + 0.2 == 0.3 peut être faux ! Compare plutôt la différence à une petite tolérance : abs(a - b) < 1.0e-9.

Pour aller plus loin

Pour aller plus loin

On peut nommer une boucle : externe: do i = … puis exit externe pour sortir directement d'une boucle imbriquée. Très pratique pour quitter un double parcours d'un coup.

Glossaire

Structure de contrôle
Construction qui pilote le flux d'exécution : décision (if, select case) ou répétition (do).
select case
Branchement multiple comparant une valeur à plusieurs cas (dont des intervalles a:b), plus clair qu'une cascade de if.
Boucle do
Boucle comptée : do i = début, fin, pas ; nombre d'itérations connu à l'avance.
do while
Boucle qui se répète tant qu'une condition reste vraie.
exit
Interrompt la boucle et poursuit après elle (équivalent d'un break).
cycle
Abandonne l'itération courante et passe à la suivante (équivalent d'un continue).
Opérateur relationnel
Comparaison renvoyant un booléen : <, >, <=, >=, ==, /=.
Opérateur logique
Combine des conditions : .and., .or., .not. (notés avec des points).

Récap et vérification

  • if … then … end if et select case gèrent les décisions ; opérateurs <, >, ==, /=.
  • Logique : .and., .or., .not..
  • La boucle do i = début, fin, pas est centrale ; do while pour une condition.
  • exit sort, cycle saute à l'itération suivante.

Vérifie ta compréhension

  1. Comment écrire une boucle de 10 à 1 par pas de -1 ?
  2. Quelle différence entre exit et cycle ?
  3. Pourquoi éviter == entre deux réels ?
