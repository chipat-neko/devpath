Machine Learning : initiation avec Python

Le Machine Learning, c'est apprendre à un programme à prédire à partir d'exemples, au lieu de lui dicter chaque règle. Ce cours t'emmène du vocabulaire et du workflow d'un projet jusqu'à tes premiers modèles (régression, classification) et leur évaluation honnête — en Python, avec scikit-learn.

Bien s'équiper

Les extensions VS Code pour le Machine Learning

Le ML se pratique surtout en Python, souvent dans des notebooks. Ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe :

À installer pour le ML

  • Python (Microsoft) — le support du langage, l'exécution et le débogage.
  • Pylance (Microsoft) — autocomplétion et vérification de types.
  • Jupyter (Microsoft) — exécuter des notebooks .ipynb cellule par cellule.
  • Data Wrangler (Microsoft) — explorer et nettoyer un jeu de données visuellement.
  • Rainbow CSV — lire confortablement les fichiers de données CSV.

Prérequis

Ce cours suppose les bases de Python (variables, listes, fonctions). Si besoin, fais d'abord le cours Python. Aucune notion mathématique avancée n'est exigée : on explique les idées avec des mots avant les formules.

Ce que tu vas apprendre

Objectifs du cours

À la fin du cours, tu sauras

  • expliquer ce qu'est le ML et distinguer apprentissage supervisé et non supervisé ;
  • dérouler le workflow d'un projet : données → modèle → évaluation ;
  • préparer des données (caractéristiques, nettoyage, normalisation, découpage) ;
  • entraîner une régression (prédire un nombre) et une classification (prédire une classe) ;
  • évaluer un modèle avec les bonnes métriques et reconnaître le surapprentissage ;
  • mener un petit projet de bout en bout avec scikit-learn.

Pour qui, et pourquoi

Ce cours s'adresse à toi si tu connais un peu Python et que tu veux comprendre, concrètement, comment une machine « apprend ». Pas de jargon inutile : chaque notion est introduite par un exemple parlant, puis mise en pratique avec scikit-learn, la bibliothèque de référence pour débuter.

Le fil conducteur est l'honnêteté de l'évaluation. Un modèle qui « marche » sur ses données d'entraînement peut être nul en vrai : tu apprendras à mesurer sa vraie performance et à éviter le piège du surapprentissage.

Astuce

Le ML n'est pas qu'une affaire de modèles : l'essentiel du travail, c'est la donnée. Un bon modèle sur de mauvaises données ne vaut rien — on insiste donc beaucoup sur la préparation.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Le ML apprend de données au lieu de suivre des règles écrites à la main.
  • En supervisé, on apprend à partir d'exemples étiquetés (entrée → bonne réponse).
  • Le workflow : collecter → préparer les données → entraîner → évaluer.
  • On sépare toujours les données en entraînement et test.
  • Régression = prédire un nombre ; classification = prédire une catégorie.
  • Le surapprentissage guette : un modèle peut mémoriser au lieu de généraliser.
Machine Learning
Apprendre à un programme à prédire à partir d'exemples, sans coder chaque règle.
Supervisé
Apprentissage à partir de données étiquetées (chaque exemple a sa bonne réponse).
Non supervisé
Trouver une structure dans des données sans étiquettes (ex. regroupement).
Caractéristique (feature)
Une variable d'entrée décrivant un exemple (ex. surface, prix au m²).
Étiquette (label)
La valeur à prédire, fournie pendant l'entraînement supervisé.
Entraînement
Phase où le modèle ajuste ses paramètres à partir des données.
Jeu de test
Données mises de côté pour mesurer la performance réelle du modèle.
Régression
Prédire une valeur numérique continue (ex. un prix).
Classification
Prédire une catégorie parmi un ensemble fini (ex. spam / non-spam).
Surapprentissage
Le modèle colle trop aux données d'entraînement et généralise mal.
scikit-learn
La bibliothèque Python de référence pour débuter en ML.
