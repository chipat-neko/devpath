Exécution pas à pas

Regarde le programme tourner, ligne par ligne

Le site explique la pile d'appels dans cinquante leçons ; ici, tu la vois monter et redescendre. À chaque pas : la ligne en cours, les variables de chaque portée avec leur valeur, et ce qui a été affiché jusque-là. Le programme est vraiment exécuté — par un interpréteur écrit pour l'occasion, sans eval.

Voir et modifier le code

Sous-ensemble de JavaScript : variables, fonctions, fermetures, objets, tableaux, classes, try/catch, promesses et setTimeout. Ce qui n'est pas géré est refusé avec la ligne fautive, jamais exécuté de travers.
