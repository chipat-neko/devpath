Bac à sable Git

Tape des commandes Git, et vois le graphe bouger

Un dépôt Git est un graphe de commits. Ici, les commandes ne sont pas simulées à moitié : les empreintes sont de vraies empreintes SHA-1, les objets ont le format binaire de Git, et les sorties sont celles que tu liras dans ton terminal. Rien n'est envoyé nulle part : tout se passe dans cette page, et ton dépôt est gardé dans ce navigateur.

Terminal

branche main

$

Le graphe des commits

Le plus récent en haut, comme git log --graph. Clique un commit pour voir sa fiche.

Où sont tes fichiers, à cet instant

Les trois zones de Git. Un fichier passe du répertoire de travail à l'index avec git add, puis de l'index au commit avec git commit. La moitié des surprises de Git vient d'un fichier qui n'est pas dans la zone qu'on croyait.

Ce que ce bac à sable fait vraiment

Les empreintes affichées sont calculées comme Git les calcule : le contenu est encodé, préfixé par son type et sa taille, puis passé dans SHA-1. Les commits, les arbres et les blobs ont le format réel. Un contrôle rejoue chaque scénario dans un vrai dépôt Git et compare, commande après commande, la sortie, l'état des trois zones, les références et le graphe.

Ce qui n'est pas simulé est dit franchement : pas de dépôt distant (donc ni push, ni pull, ni fetch), pas de stash, pas de reflog, pas de détection de renommage, pas de rebase -i. Ces commandes-là sont refusées avec un message qui l'explique, plutôt qu'exécutées de travers.
