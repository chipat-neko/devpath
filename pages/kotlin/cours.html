Kotlin : le JVM moderne et Android

Kotlin, c'est la sécurité d'un typage fort sans la cérémonie de Java : la null-safety attrape les erreurs avant l'exécution, les data classes modélisent en une ligne, et les coroutines apaisent l'asynchrone. Langage officiel d'Android, il fait aussi tourner des serveurs entiers. Ce cours te mène du premier fun main() jusqu'à Compose.

Bien s'équiper

Les extensions VS Code pour Kotlin

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Kotlin

  • Kotlin (fwcd) — coloration et IntelliSense (Kotlin Language Server).
  • Gradle for Java (Microsoft) — gérer la compilation Gradle.
  • Extension Pack for Java (Microsoft) — Kotlin tourne sur la JVM.

Pour qui ?

Idéal si tu es à l'aise avec les bases d'un langage à accolades — le cours Java ou le cours JavaScript suffisent largement. Chaque notion propre à Kotlin est expliquée depuis le début, et les comparaisons avec Java éclairent le chemin.

Ce que tu vas apprendre

De val aux coroutines

À la fin du cours, tu sauras

  • écrire du Kotlin idiomatique : val/var, null-safety (?., ?:), when et fonctions à arguments nommés ;
  • manipuler les données avec les collections, les lambdas et les séquences paresseuses ;
  • modéliser finement : data classes, sealed classes, génériques, extensions et scope functions ;
  • passer à la pratique : coroutines, interopérabilité Java, Gradle et premiers pas Android (Compose).

Pour qui, et pourquoi

Ce cours s'adresse à ceux qui visent le développement Android, le back-end JVM moderne (Ktor, Spring), ou qui veulent simplement un langage typé expressif et sûr. Kotlin est 100 % interopérable avec Java : tout l'écosystème JVM est disponible, et la migration peut se faire classe par classe.

Chaque leçon est autonome et illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties sont montrées en commentaire (// =>).

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • val (immuable) ou var (modifiable) ; les types sont inférés.
  • Sécurité du null : types nullables (String?), opérateurs ?. et ?:.
  • data class pour les données (equals, toString, copy générés).
  • Fonctions avec fun ; lambdas et fonctions d'ordre supérieur.
  • Interopère pleinement avec Java (même JVM).
  • Coroutines pour l'asynchrone léger.
  • Collections : listOf (immuable), mutableListOf.
val / var
Liaison immuable (lecture seule) / modifiable.
Type nullable
Type pouvant valoir null, marqué d'un ? (String?).
Opérateur Elvis (?:)
Fournit une valeur de repli quand le côté gauche est null.
data class
Classe générant automatiquement equals, toString, copy…
Lambda
Fonction anonyme, ex. { x -> x * 2 }.
Coroutine
Tâche concurrente légère, suspendable.
Extension
Fonction ajoutée à un type existant sans le modifier.
Smart cast
Conversion de type automatique après une vérification.
