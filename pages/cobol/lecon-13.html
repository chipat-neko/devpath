Module 4 · COBOL en production — Leçon 13

Manipuler le texte : STRING, UNSTRING, INSPECT

~44 min Intermédiaire Prérequis : leçon 4

À la fin de cette leçon, tu sauras

  • extraire une tranche avec la référence de sous-chaîne champ(pos:long) ;
  • concaténer plusieurs champs avec STRING ;
  • éclater une ligne en morceaux avec UNSTRING ;
  • compter, remplacer et convertir des caractères avec INSPECT.
Sommaire de la leçon

En gestion, on passe un temps fou à découper et recoller du texte : extraire l'année d'une date, fabriquer une ligne d'état « NOM, Prénom », éclater un enregistrement séparé par des points-virgules, nettoyer un champ saisi n'importe comment. COBOL ne laisse pas ça au hasard : il offre des verbes dédiés, précis et sûrs sur la longueur. Voici les quatre outils indispensables.

Prendre une tranche : la référence de sous-chaîne

La référence de sous-chaîne (reference modification) désigne une portion d'un champ par sa position de départ et sa longueur : champ(position:longueur). Les positions se comptent à partir de 1.

Astuce

La tranche fonctionne aussi à gauche d'un MOVE : MOVE "X" TO LIGNE(10:1) écrit un seul caractère à la position 10, sans toucher au reste. Pratique pour poser un drapeau dans une zone.

Assembler : STRING

STRING concatène plusieurs sources dans une cible. Chaque source précise jusqu'où la copier avec DELIMITED BY : SPACE (jusqu'au premier blanc), SIZE (toute la longueur), ou un caractère donné.

  • DELIMITED BY SPACE : copie DURAND sans les blancs de bourrage ;
  • DELIMITED BY SIZE : copie le séparateur ", " en entier ;
  • ON OVERFLOW : se déclenche si la cible est trop petite — à tester toujours.

Éclater : UNSTRING

UNSTRING fait l'inverse : il découpe une chaîne selon un ou plusieurs délimiteurs et range les morceaux dans plusieurs champs. COUNT IN mesure chaque morceau, TALLYING IN compte combien de champs ont été remplis.

Attention

Si un morceau est plus long que son champ cible, il est tronqué silencieusement ; s'il y a plus de morceaux que de champs, le reste est ignoré. Prévois des cibles assez larges et récupère un compteur avec TALLYING IN pour détecter les lignes mal formées.

Inspecter : INSPECT

INSPECT parcourt une chaîne caractère par caractère. Trois usages : TALLYING pour compter, REPLACING pour remplacer, CONVERTING pour traduire caractère à caractère (par exemple mettre en majuscules).

Cas réel

Les banques échangent des fichiers plats par millions : relevés, virements SEPA, remises de chèques. Chaque ligne est un enregistrement à découper (UNSTRING ou tranches à position fixe) puis à normaliser (INSPECT pour passer les noms en majuscules, retirer les caractères parasites) avant d'entrer dans le système. Ce travail d'import — peu spectaculaire mais critique — occupe une bonne part du COBOL de production : une erreur de découpage, et c'est un virement envoyé au mauvais compte.

Pour aller plus loin

Pour aller plus loin

Le COBOL moderne ajoute des fonctions intrinsèques qui simplifient tout ceci : FUNCTION UPPER-CASE et LOWER-CASE pour la casse, FUNCTION TRIM pour ôter les blancs, FUNCTION LENGTH pour la taille utile. Regarde aussi STRING … WITH POINTER (position d'écriture courante) et le UNSTRING … DELIMITED BY ALL ";" qui fusionne les délimiteurs consécutifs.

Glossaire

Référence de sous-chaîne
Notation champ(position:longueur) qui désigne une portion d'un champ, en lecture comme en écriture.
STRING
Verbe qui concatène plusieurs sources dans une cible unique, chaque source bornée par DELIMITED BY.
UNSTRING
Verbe qui éclate une chaîne en plusieurs champs selon un ou des délimiteurs : l'inverse de STRING.
DELIMITED BY
Précise jusqu'où copier (ou où couper) : SPACE, SIZE (tout), ou un caractère donné.
ON OVERFLOW
Clause déclenchée quand la cible d'un STRING est trop courte pour tout recevoir.
INSPECT
Verbe qui parcourt une chaîne pour TALLYING (compter), REPLACING (remplacer) ou CONVERTING (traduire).
TALLYING
Option d'INSPECT (ou d'UNSTRING) qui accumule un comptage dans un champ numérique.
Fichier plat
Fichier texte où chaque ligne est un enregistrement, champs séparés ou à positions fixes ; format d'échange courant en gestion.

Récap et vérification

  • La référence de sous-chaîne champ(pos:long) lit ou écrit une tranche ; les positions démarrent à 1.
  • STRING concatène, UNSTRING éclate : deux verbes inverses, bornés par DELIMITED BY.
  • INSPECT compte (TALLYING), remplace (REPLACING) ou convertit (CONVERTING).
  • Toujours prévoir des cibles assez larges et tester ON OVERFLOW.

Vérifie ta compréhension

  1. Que vaut "BONJOUR"(2:3) ?
  2. Quelle différence entre STRING et UNSTRING ?
  3. Quel usage d'INSPECT met un champ en majuscules ?

Exercices

Exercice 1Échauffement

À partir de DATE-ISO PIC X(8) VALUE "20260715", écris l'instruction qui range le jour dans JOUR PIC X(2).

Voir une solution

Le jour occupe les positions 7 et 8 : on prend 2 caractères à partir de la position 7.

Exercice 2Application

Une ligne "MARTIN/Alice/LYON" utilise / comme séparateur. Écris l'UNSTRING qui remplit NOM, PRENOM, VILLE.

Voir une solution
Exercice 3Défi

Compte le nombre de virgules dans LIGNE, puis remplace-les toutes par des points-virgules.

Voir une solution

On compte d'abord (TALLYING), puis on substitue (REPLACING). Les deux INSPECT sont indépendants : l'ordre compte si tu veux le total avant transformation.
