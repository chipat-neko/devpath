R : statistiques et analyse de données

R est né pour les statistiques et reste le langage de référence des analystes, chercheurs et data scientists. Même un nombre seul y est un vecteur, le data frame est roi, et l'écosystème tidyverse (dplyr, ggplot2) rend l'exploration de données fluide et expressive. Ce cours te mène des premiers vecteurs jusqu'à la régression et aux rapports reproductibles.

Bien s'équiper

Les extensions VS Code pour R

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour R

  • R (REditorSupport) — exécution, IntelliSense et aide intégrée.
  • R Debugger (R Debugger) — débogage pas à pas.
  • Quarto (Quarto) — documents et rapports reproductibles.

Pour qui ?

Idéal si tu connais les bases de la programmation et que les données t'intéressent — aucune statistique avancée n'est supposée, chaque notion est expliquée. Le cours Python est un bon complément côté science des données.

Ce que tu vas apprendre

Du vecteur au rapport reproductible

À la fin du cours, tu sauras

  • manier le langage : vecteurs, indexation logique, vectorisation, data frames et facteurs ;
  • manipuler des données réelles avec dplyr et tidyr (filtrer, agréger, joindre, remodeler) ;
  • visualiser avec ggplot2 et décrire honnêtement un jeu de données (stats descriptives) ;
  • aller vers l'analyse : tests, régression, programmation avec purrr et rapports reproductibles (Quarto).

Pour qui, et pourquoi

Ce cours s'adresse aux futurs data analysts, chercheurs, biostatisticiens, ou à toute personne qui veut tirer du sens de données. R excelle là où l'analyse statistique et la visualisation comptent, et ses rapports reproductibles ont transformé la façon de faire de la science.

Chaque leçon est autonome et illustrée par du code commenté. Le code ne s'exécute pas dans l'éditeur du site : les sorties (y compris les tableaux) sont montrées en commentaire.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Le langage des statistiques et de l'analyse de données.
  • Affectation idiomatique avec <- ; structure de base : le vecteur (c()).
  • data.frame pour les tableaux de données (colonnes nommées).
  • Indexation à partir de 1.
  • Agréger avec aggregate en R de base, group_by + summarise avec dplyr ; tracer avec plot ou ggplot.
  • Enchaîner les étapes avec le pipe |> ; tester et modéliser avec t.test et lm.
  • Livrer un rapport reproductible avec Quarto.
  • Paquets installés depuis CRAN.
  • Programmation vectorisée : opérer sur tout un vecteur d'un coup.
Vecteur
Structure de base : suite de valeurs de même type (c(1, 2, 3)).
data.frame
Tableau de données aux colonnes nommées et typées.
Facteur
Variable catégorielle (ensemble fini de modalités).
Vectorisation
Appliquer une opération à tout un vecteur, sans boucle.
aggregate
Calcul d'agrégats par groupe.
CRAN
Dépôt officiel des paquets R.
Formule (~)
Décrit une relation, ex. y ~ x.
NA
Valeur manquante.
tidyverse
Famille de paquets (dplyr, tidyr, ggplot2, purrr…) conçus pour travailler ensemble.
Pipe (|>)
Passe le résultat de gauche en premier argument de la fonction de droite.
Régression
Modèle qui chiffre le lien entre une variable et une ou plusieurs autres (lm).
Quarto
Format de document mêlant texte, code et résultats, régénérable d'un geste.
