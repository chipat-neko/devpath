Java : programmation orientée objet

Java fait tourner des banques, des applications Android et d'innombrables serveurs d'entreprise. C'est un langage orienté objet, au typage fort, qui s'exécute partout grâce à la JVM. Ce cours te mène du premier main jusqu'aux collections, aux génériques et aux streams du Java moderne : des fondations solides et un style robuste.

Bien s'équiper

Les extensions VS Code pour Java

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Java

  • Extension Pack for Java (Microsoft) — tout l'outillage Java en un paquet.
  • Spring Boot Extension Pack (VMware) — pour les projets Spring.
  • Debugger for Java (Microsoft) — débogage pas à pas.
  • Checkstyle for Java (ShengChen) — style et conventions de code.

Pour qui ?

Aucun prérequis strict : si tu sais ce qu'est une variable et une boucle (par exemple via le cours JavaScript), tu suivras sans peine. Sinon, le cours pose chaque notion depuis le début.

Ce que tu vas apprendre

Des fondations à Java moderne

À la fin du cours, tu sauras

  • compiler et exécuter du Java (javac/java, la JVM), avec types, conditions, boucles et méthodes ;
  • maîtriser la programmation orientée objet : classes, héritage, polymorphisme, interfaces, enum et record ;
  • écrire du code robuste : exceptions, génériques et les collections (List, Set, Map) ;
  • adopter le Java moderne : lambdas, streams, Optional, dates, fichiers et organisation d'un projet ;
  • aller plus loin avec le module Java en profondeur : concurrence (virtual threads / Loom), sealed et pattern matching, et le fonctionnement de la JVM (GC, JIT, JMH, GraalVM).

Pour qui, et pourquoi

Ce cours s'adresse à ceux qui visent le développement back-end d'entreprise, les applications Android, ou simplement un langage objet rigoureux qui apprend les bonnes habitudes. Java est partout, stable depuis des décennies, et l'une des compétences les plus demandées du marché.

Chaque leçon est autonome et illustrée par du code commenté. Le code se compile (il ne s'exécute pas dans l'éditeur du site) : les sorties console sont montrées en commentaire.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Tout vit dans une classe ; le point d'entrée est public static void main(String[] args).
  • Fortement typé : on déclare le type (int, double, String…).
  • POO : classes, objets, héritage (extends), interfaces (implements).
  • Encapsulation : champs private exposés par des getters/setters.
  • Collections génériques : List<…>, Map<…> plutôt que des tableaux bruts.
  • Exceptions : try / catch / finally.
  • Compilé en bytecode, exécuté par la JVM (portable).
Classe
Modèle décrivant des objets (champs + méthodes).
Objet
Instance d'une classe, créée avec new.
Héritage
Réutilisation d'une classe parente avec extends.
Interface
Contrat de méthodes qu'une classe s'engage à fournir.
Encapsulation
Masquer l'état (private) derrière des méthodes publiques.
Bytecode
Code intermédiaire produit par la compilation, exécuté par la JVM.
JVM
Machine virtuelle Java qui exécute le bytecode (« write once, run anywhere »).
Générique
Type paramétré, ex. List<String>.
Exception
Erreur survenant à l'exécution, gérée par try / catch.
package
Espace de noms regroupant des classes liées.
