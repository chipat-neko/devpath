Audio et vidéo

~30 min Débutant Leçon 05 recommandée

À la fin de cette leçon, tu sauras

  • savoir intégrer une vidéo avec <video controls>, un poster et une largeur ;
  • savoir ajouter un lecteur audio avec <audio controls> ;
  • savoir proposer plusieurs formats avec <source> et un texte de repli ;
  • savoir rendre une vidéo accessible avec des sous-titres <track> et choisir les bons attributs.
Sommaire de la leçon

Tu sais déjà insérer une image avec <img>. Le son et la vidéo suivent la même logique : une balise dédiée, des attributs pour régler le comportement, et un contenu de secours. Bonne nouvelle, plus besoin de greffon (plugin) compliqué : le HTML moderne lit la vidéo et l'audio nativement, directement dans le navigateur.

Dans cette leçon, tu vas apprendre à poser un lecteur vidéo et un lecteur audio, à proposer plusieurs formats pour que tout le monde puisse lire ton média, à ajouter des sous-titres, et à choisir les attributs sans tomber dans les pièges classiques (coucou, l'autoplay avec le son). Pense à cliquer sur le bouton 👁 Aperçu de chaque exemple pour voir le résultat en direct.

La vidéo : la balise video

Pour afficher une vidéo, tu utilises la balise <video>. Trois attributs reviennent tout le temps : controls affiche les commandes (lecture, pause, volume, plein écran) ; width fixe la largeur ; poster indique une image d'aperçu visible avant que la lecture démarre.

Une vidéo avec ses commandes et une image d'aperçu. Sans controls, le lecteur serait muet et figé.

Astuce

Clique sur 👁 Aperçu au-dessus de chaque bloc de code pour voir le rendu en direct dans l'éditeur intégré. Lance vraiment la vidéo, change le volume, passe en plein écran : tu comprendras mieux à quoi sert chaque attribut en le manipulant.

L'audio : la balise audio

Pour le son, c'est exactement le même principe avec <audio>. Pas de width ni de poster ici (il n'y a rien à montrer visuellement), mais controls reste indispensable, sinon le lecteur est invisible.

Un lecteur audio minimal. La phrase à l'intérieur s'affiche seulement si le navigateur ne peut pas lire le son.

Plusieurs formats avec source

Tous les navigateurs ne lisent pas les mêmes formats de fichier. Pour mettre toutes les chances de ton côté, tu retires l'attribut src de la balise et tu proposes plusieurs <source> à l'intérieur. Le navigateur essaie chaque source dans l'ordre et garde la première qu'il sait lire. L'attribut type lui dit le format sans même télécharger le fichier.

Deux formats proposés, plus un texte (avec un lien de téléchargement) si rien ne marche. Le même mécanisme fonctionne avec <audio>.

Note

Le texte placé entre <video> et </video> n'est pas un sous-titre : c'est un message de secours, affiché uniquement quand le navigateur ne sait rien lire. Mets-y une phrase utile et, si possible, un lien de téléchargement.

Les sous-titres avec track

Une vidéo sans sous-titres exclut les personnes sourdes ou malentendantes, et celles qui regardent sans le son. La balise <track> charge un fichier de sous-titres (au format .vtt) et l'associe à la vidéo. Elle se place à l'intérieur de <video>, après les <source>.

kind="subtitles" pour des sous-titres, srclang pour la langue, label pour le nom dans le menu, default pour l'activer d'office.

Cas réel

Les sous-titres que tu actives sur Netflix ou YouTube reposent sur le même principe : une piste de texte synchronisée, séparée de la vidéo. En HTML, c'est exactement le rôle de <track> avec un fichier .vtt. C'est ce qui permet de regarder une vidéo dans le métro sans le son, ou de la rendre accessible aux personnes sourdes ou malentendantes.

Les attributs autoplay, muted, loop, preload

Quelques attributs ajustent le comportement du lecteur. À utiliser avec discernement : ils peuvent vite agacer le visiteur. Ici, on garde controls et un poster pour que l'aperçu reste visible et maîtrisable.

autoplay démarre seul, muted coupe le son, loop rejoue en boucle. Il existe aussi preload (valeurs none, metadata ou auto) pour indiquer au navigateur ce qu'il peut charger d'avance.

Note

Les navigateurs n'autorisent autoplay que si la vidéo est aussi muted. C'est pour ça qu'une vidéo de décor qui se lance toute seule est toujours muette : pas de son surprise pour le visiteur.

Un exemple complet

Mettons tout ensemble : une vidéo avec ses commandes, une image d'aperçu, une source, un texte de repli, et un titre clair autour. Clique sur 👁 Aperçu pour la regarder tourner.

La vidéo est enveloppée dans <figure> avec une <figcaption>, comme tu l'as vu pour les images : un média + sa légende.

Pièges fréquents

Piège fréquent

Lancer une vidéo avec le son tout seul. L'autoplay non muet est rejeté par les navigateurs et perçu comme agressif. Si tu veux un démarrage automatique, ajoute toujours muted. Un seul format peut rendre ton média illisible sur certains appareils : propose plusieurs <source>. Pas de sous-titres rend la vidéo inaccessible : ajoute un <track>. Enfin, méfie-toi des fichiers trop lourds : compresse tes vidéos, sinon la page rame.

Pour aller plus loin

Pour aller plus loin

Pour de gros volumes, on passe au streaming (la vidéo arrive par petits morceaux). Pour intégrer une vidéo YouTube, on utilise une <iframe> — ce sera le sujet de la leçon suivante. Côté formats, renseigne-toi sur les codecs (H.264, VP9, AV1) qui déterminent la compatibilité et le poids. Et plus tard, l'API média en JavaScript te laissera piloter lecture, pause et volume par code.

Antisèche : audio & vidéo

Les balises et attributs pour intégrer un média, en un coup d'œil.

Glossaire

controls
Attribut affichant les commandes du lecteur (lecture, pause, volume, plein écran).
poster
Image d'aperçu d'une vidéo, montrée avant le lancement de la lecture.
<source>
Variante de format d'un média ; le navigateur garde la première qu'il sait lire.
<track> / .vtt
Piste de sous-titres associée à une vidéo, au format WebVTT.
autoplay / muted
Démarrage automatique ; les navigateurs l'exigent muet (muted).
Texte de repli
Contenu entre <video>…</video>, affiché si aucun format n'est lisible.
Codec
Méthode de compression d'un média (H.264, VP9, AV1) déterminant son poids et sa compatibilité.

Récap et vérification

  • <video> et <audio> intègrent un média ; controls affiche les commandes.
  • poster et width règlent l'aperçu et la largeur d'une vidéo.
  • Plusieurs <source> avec type couvrent plusieurs formats ; le texte interne sert de repli.
  • <track kind="subtitles"> ajoute des sous-titres : c'est un réflexe d'accessibilité.
  • autoplay exige muted ; loop rejoue, preload gère le chargement.
