Module 05 · Accessibilité, métadonnées & qualité — Leçon 14

Métadonnées, SEO et partage

~32 min Débutant Leçon 13 recommandée

À la fin de cette leçon, tu sauras

  • Comprendre le rôle du <head> et écrire un <title> et une meta description efficaces ;
  • Ajouter les meta techniques indispensables : charset, viewport et l'attribut lang ;
  • Relier des ressources avec <link> : favicon, feuille de style et URL canonique ;
  • Soigner le partage social d'un lien avec les balises Open Graph.
Sommaire de la leçon

Dans la leçon 1, tu as monté le squelette d'une page : <!DOCTYPE html>, puis <html> qui contient un <head> et un <body>. Jusqu'ici tu as surtout travaillé dans le <body>, la partie visible. Il est temps d'ouvrir l'autre coffre : le <head>.

Le <head> ne dessine rien à l'écran, mais c'est lui qui décide du titre dans l'onglet, de ce qu'affiche Google, de l'aperçu quand tu colles ton lien sur les réseaux, et du fait que ta page soit lisible sur mobile. Autrement dit : du contenu invisible, mais qui change tout. On y va du connu (le titre) vers l'inconnu (Open Graph).

Le rôle du <head>

Le <head> contient des informations sur la page : son titre, sa langue, son encodage, des liens vers des fichiers. Ces informations ne sont pas affichées dans le corps ; elles sont lues par le navigateur et les moteurs de recherche.

Regarde l'onglet de l'aperçu : son nom vient du <title>, alors que le <h1> s'affiche, lui, dans la page.

Cas réel

Quand tu colles un lien d'article sur WhatsApp ou LinkedIn et qu'apparaît une vignette avec image et titre, ou quand tu lis le petit texte sous chaque résultat Google : tout cela vient du <head>, jamais affiché sur la page elle-même. Le <head> est invisible pour le visiteur, mais décisif pour la diffusion.

Astuce

Sur chaque bloc de code, clique le bouton « 👁 Aperçu » pour voir le rendu en direct : pour les exemples du <head>, observe surtout le nom de l'onglet, qui change selon le <title>.

<title> : le titre qui compte

Le <title> sert à deux endroits : le nom de l'onglet du navigateur et le titre cliquable dans les résultats de Google. C'est l'un des éléments les plus importants pour le référencement (SEO). Règle d'or : un titre unique et descriptif par page.

Vise environ 50 à 60 caractères : assez pour être clair, pas trop pour ne pas être coupé dans Google.

<meta name="description"> : le résumé

La balise <meta name="description"> donne un résumé de la page. Google l'affiche souvent sous le titre dans ses résultats. Elle n'influence pas directement le classement, mais une bonne description donne envie de cliquer.

Garde la description sous ~155 caractères : au-delà, Google la coupe.

Les meta techniques : charset, viewport, lang

Trois réglages techniques sont indispensables. <meta charset="utf-8"> dit au navigateur comment décoder les caractères (sans lui, les accents deviennent du charabia). <meta name="viewport"> rend la page responsive sur mobile. Et l'attribut lang sur <html> annonce la langue, utile pour l'accessibilité et le SEO.

charset doit être tout en haut du <head>, dans les 1024 premiers octets de la page.

Note

Les balises <meta> et <link> sont des éléments vides : pas de balise fermante, pas de contenu entre des balises. Tout passe par les attributs (name, content, rel, href…).

Les <link> : favicon, CSS, canonical

La balise <link> relie ta page à des ressources externes. L'attribut rel précise le type de lien. Les trois plus courants : rel="icon" pour le favicon (la petite icône de l'onglet), rel="stylesheet" pour une feuille de style CSS, et rel="canonical" pour indiquer l'URL de référence quand une même page est accessible par plusieurs adresses.

Le navigateur va chercher chaque fichier indiqué : l'icône, le CSS, etc. Ici les fichiers sont fictifs.

Le partage social : Open Graph

Quand tu colles un lien sur les réseaux ou dans une messagerie, un joli aperçu apparaît : une image, un titre, une description. Ce n'est pas magique : ce sont les balises Open Graph (préfixe og:) qui le pilotent. Sans elles, l'aperçu est moche ou vide. Note que les balises Open Graph utilisent l'attribut property (et non name).

Twitter/X lit aussi Open Graph ; tu peux ajouter <meta name="twitter:card" content="summary_large_image"> pour une grande vignette, et og:image:alt décrit l'image pour l'accessibilité.

<meta name="robots"> : indexation

La balise <meta name="robots"> dit aux moteurs s'ils peuvent indexer la page et suivre ses liens. La plupart du temps tu n'en as pas besoin (par défaut, tout est autorisé). Tu l'utilises surtout pour cacher une page des résultats, par exemple une page de remerciement.

Pour aller plus loin, on peut décrire le contenu en JSON-LD (données structurées) afin d'obtenir des résultats enrichis ; on en reparle plus bas.

Pièges fréquents

Piège fréquent

Un <title> générique (« Accueil ») ou identique sur toutes les pages ; une meta description absente (Google bricole alors un résumé) ou dupliquée ; le viewport manquant, qui donne une page minuscule et non responsive sur mobile ; une og:image absente, qui rend le partage moche ; et le charset placé trop bas dans le <head>, ce qui casse les accents.

Pour aller plus loin

Pour aller plus loin

Explore les données structurées (schema.org en JSON-LD) pour décrire recette, article ou produit et obtenir des résultats enrichis ; le sitemap.xml qui liste tes pages pour les moteurs ; le fichier robots.txt qui régule l'exploration du site ; et les performances (vitesse de chargement, Core Web Vitals), devenues un vrai facteur de référencement.

Antisèche : le <head> et le SEO

Glossaire

<head>
Partie non visible de la page contenant les métadonnées (titre, encodage, liens).
SEO
Référencement naturel : rendre une page bien comprise et bien classée par les moteurs de recherche.
meta description
Résumé affiché par Google sous le titre ; n'affecte pas le classement mais le taux de clic.
viewport
Meta qui adapte l'affichage à la largeur de l'écran (indispensable sur mobile).
canonical
URL de référence déclarée quand une même page existe sous plusieurs adresses.
Open Graph (og:)
Balises décrivant l'aperçu d'un lien partagé sur les réseaux (image, titre, description).
Élément vide
Balise sans contenu ni fermeture (<meta>, <link>) ; tout passe par les attributs.
robots / noindex
Meta indiquant aux moteurs s'ils peuvent indexer la page et suivre ses liens.

Récap et vérification

  • Le <head> contient des informations sur la page, non affichées dans le corps.
  • <title> : nom de l'onglet et titre dans Google ; unique et descriptif par page.
  • <meta name="description"> : le résumé sous le titre dans les résultats.
  • Indispensables : charset="utf-8" (en haut), viewport (responsive), lang sur <html>.
  • <link> : icon (favicon), stylesheet (CSS), canonical (URL de référence).
  • Open Graph (og:title, og:description, og:image, og:url) : l'aperçu au partage.

Vérifie ta compréhension

  1. À quels deux endroits le contenu du <title> apparaît-il ?
  2. Que se passe-t-il si tu oublies la balise viewport et que quelqu'un ouvre ta page sur mobile ?
  3. Quelle famille de balises faut-il ajouter pour obtenir un bel aperçu quand on partage ton lien, et quel attribut utilisent-elles ?
