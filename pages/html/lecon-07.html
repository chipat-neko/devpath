Contenu intégré (iframe, SVG)

~30 min Débutant Leçon 06 recommandée

À la fin de cette leçon, tu sauras

  • savoir intégrer une page externe (carte, vidéo) avec une <iframe> munie d'un title et de loading="lazy" ;
  • savoir dessiner une icône simple en SVG inline directement dans le HTML ;
  • savoir choisir entre SVG inline et <img src="icone.svg"> selon le besoin ;
  • savoir sécuriser une intégration tierce avec l'attribut sandbox.
Sommaire de la leçon

Jusqu'ici, tu as appris à remplir tes pages avec ton contenu : du texte, des listes, des images, des liens. Mais le web est interconnecté. Parfois, tu veux afficher une carte, une vidéo ou un formulaire hébergé ailleurs, sans le recoder. Et parfois tu veux dessiner une petite icône nette directement dans ton HTML.

Cette leçon couvre deux outils pour cela : l'<iframe>, qui intègre une autre page dans la tienne, et le SVG inline, qui dessine des formes vectorielles. On survolera aussi <object>, <embed> et <canvas>. Allons-y du connu vers l'inconnu.

L'iframe : une page dans la page

Une <iframe> (cadre en ligne, ou inline frame) est comme une petite fenêtre : elle affiche une autre page web à l'intérieur de la tienne. Tu indiques l'adresse à charger avec l'attribut src, exactement comme le src d'une image.

L'attribut title décrit la fenêtre intégrée pour les lecteurs d'écran : il n'est jamais optionnel.

Astuce

Sur chaque bloc de code de ce cours, clique le bouton 👁 Aperçu pour voir le rendu en direct dans l'éditeur intégré. Modifie le code, re-clique, et observe ce qui change : c'est la meilleure façon d'apprendre.

Les attributs essentiels d'une iframe

Quelques attributs reviennent tout le temps. Retiens surtout les quatre premiers.

  • src : l'adresse de la page à charger.
  • title : une description courte, obligatoire pour l'accessibilité.
  • width / height : la taille du cadre, en pixels.
  • loading="lazy" : ne charge l'iframe que lorsqu'elle approche de l'écran (gain de performance).
  • sandbox : restreint ce que la page intégrée a le droit de faire (sécurité).
  • allow : autorise des fonctions précises (caméra, plein écran, etc.).

Intégrer une carte ou une vidéo

Le cas le plus courant : afficher une vidéo ou une carte. Le fournisseur te donne souvent un code « à copier-coller ». Voici à quoi il ressemble, avec un title bien rempli.

Le title décrit le contenu de la vidéo, pas juste « vidéo YouTube » : sois précis.

Cas réel

Quand un site affiche une carte Google Maps de son adresse, une vidéo YouTube ou un formulaire de réservation d'un service tiers, c'est presque toujours une <iframe>. Le fournisseur donne un code « à copier-coller » : pense à vérifier qu'il contient un title clair et, idéalement, loading="lazy".

Le SVG inline : dessiner dans le HTML

Le SVG (Scalable Vector Graphics) décrit des dessins avec des formes : cercles, rectangles, tracés. « Inline » veut dire que tu écris le dessin directement dans ton HTML, sans fichier séparé. Gros avantage : c'est net à toute taille (vectoriel) et tu peux le styler en CSS comme n'importe quel élément.

Clique 👁 Aperçu : tu vois un disque rouge avec une étoile dorée. Change fill="crimson" en fill="teal" et recommence.

Note

Le viewBox définit le « système de coordonnées » du dessin (ici un carré de 24×24 unités). Le width/height définit la taille affichée. Comme c'est vectoriel, tu peux agrandir sans pixelliser.

SVG inline ou <img src="icone.svg"> ?

Un fichier .svg peut aussi s'afficher comme une image classique. Lequel choisir ?

  • SVG inline : quand tu veux styler ou animer les formes en CSS (changer la couleur au survol), ou réagir au clic. Le code est dans la page.
  • <img src="icone.svg" alt="…"> : quand l'image est décorative ou réutilisée à plusieurs endroits. Plus simple, mise en cache, mais tu ne peux pas en modifier l'intérieur depuis ton CSS.

Avec fill="currentColor", le SVG inline prend la couleur de texte définie en CSS : très pratique pour les icônes.

object, embed et canvas en bref

Trois autres éléments existent, plus rares pour un débutant :

  • <object> et <embed> : intègrent des ressources externes comme un PDF. <object> permet un contenu de repli entre ses balises si le fichier ne se charge pas.
  • <canvas> : une zone de dessin pilotée par JavaScript (jeux, graphiques). Sans JS, elle reste vide.

Le contenu entre <object> et </object> ne s'affiche que si le PDF ne se charge pas : un bon filet de sécurité.

Sécuriser avec sandbox

Une page intégrée par iframe peut tenter des choses indésirables (ouvrir des pop-ups, exécuter des scripts). L'attribut sandbox la met « en bac à sable » : par défaut, presque tout est bloqué, et tu rouvres seulement ce dont tu as besoin.

Plus la liste après sandbox= est courte, plus c'est sûr. N'ajoute une permission que si le widget en a réellement besoin.

Pièges fréquents

Piège fréquent

Iframe sans title : la page devient inaccessible (un lecteur d'écran annonce un cadre anonyme). Contenu tiers sans sandbox : tu fais confiance aveuglément à du code que tu ne contrôles pas. Trop d'iframes : chacune charge une page entière, la performance s'effondre. SVG inline géant (des centaines de lignes de tracé) : il rend ton HTML illisible — dans ce cas, préfère un fichier .svg via <img>.

Pour aller plus loin

Pour aller plus loin

Explore les valeurs détaillées de sandbox (allow-popups, allow-same-origin…) et leurs implications. Mesure l'effet de loading="lazy" sur une page riche en iframes. Anime un SVG (rotation, pulsation) en CSS ou en JavaScript. Approfondis l'accessibilité du SVG : role="img", balise <title> interne, et aria-label.

Glossaire

iframe
Cadre en ligne affichant une autre page web (src) à l'intérieur de la page courante.
title (iframe)
Description courte et obligatoire d'une iframe, lue par les lecteurs d'écran.
sandbox
Attribut qui verrouille une iframe ; on rouvre des permissions une à une (allow-scripts…).
SVG inline
Dessin vectoriel écrit directement dans le HTML, stylable et animable en CSS.
viewBox
Système de coordonnées d'un SVG, indépendant de sa taille d'affichage.
currentColor
Valeur qui fait prendre à un SVG la couleur de texte (color) héritée du CSS.
canvas
Zone de dessin en mode point, pilotée par JavaScript (jeux, graphiques).

Récap et vérification

  • <iframe> intègre une autre page ; src et title sont indispensables, title pour l'accessibilité.
  • loading="lazy" diffère le chargement ; sandbox verrouille le contenu tiers par sécurité.
  • Le SVG inline dessine des formes nettes à toute taille et stylables en CSS.
  • Choisis le SVG inline pour styler/animer, <img src="…svg"> pour une icône simple et réutilisée.
  • <object>/<embed> intègrent des fichiers (PDF) ; <canvas> dessine via JavaScript.

Vérifie ta compréhension

  1. Quel attribut d'une <iframe> est obligatoire pour l'accessibilité, et pourquoi ?
  2. Dans quel cas préfères-tu un SVG inline plutôt qu'une image <img src="icone.svg"> ?
  3. À quoi sert l'attribut sandbox sur une iframe, et que se passe-t-il si tu l'écris vide ?
