HTML : des fondations au niveau expert

Le HTML est le squelette de toute page web : c'est lui qui décrit le contenu et son sens — un titre, un paragraphe, une image, un formulaire. Ce cours t'apprend à écrire un HTML propre, sémantique et accessible, la fondation indispensable avant la mise en forme. Il te conduit ensuite jusqu'au niveau expert : éléments interactifs natifs, Web Components, ARIA, données structurées, PWA, performance, sécurité (CSP/SRI) et API modernes du navigateur.

Bien s'équiper

Les extensions VS Code pour HTML

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour HTML

  • Auto Rename Tag (Jun Han) — renomme la balise fermante en même temps.
  • Auto Close Tag (Jun Han) — ferme les balises automatiquement.
  • Live Server (Ritwick Dey) — aperçu live de la page dans le navigateur.
  • HTML CSS Support (ecmel) — complète les classes et id CSS.
  • Prettier - Code formatter (Prettier) — met le HTML en forme.

Aperçu en direct

Sur chaque exemple de code HTML, un bouton « 👁 Aperçu » permet de modifier le code et de voir le rendu instantanément dans la page — la meilleure façon d'apprendre le HTML, en expérimentant.

Ce que tu vas apprendre

Objectifs du cours

À la fin du cours, tu sauras

  • écrire le squelette d'une page HTML valide (doctype, head, body) ;
  • structurer le texte avec les bonnes balises : titres, paragraphes et listes ;
  • ajouter des liens et des images (avec un alt utile) ;
  • présenter des données dans des tableaux et recueillir des saisies via des formulaires ;
  • employer les balises sémantiques (header, nav, main, article…) plutôt qu'une « soupe de div » ;
  • soigner l'accessibilité et les métadonnées de tes pages ;
  • concevoir des composants natifs et réutilisables (<dialog>, popover, Web Components) ;
  • atteindre le niveau expert : patterns ARIA, données structurées, PWA, performance et sécurité côté client.

Pour qui, et pourquoi

Ce cours s'adresse à toi si tu pars de zéro et que tu veux comprendre comment se fabrique une page web. Aucun prérequis : si tu sais utiliser un navigateur et créer un fichier sur ton ordinateur, tu as tout ce qu'il faut. Pas besoin de connaître la programmation ni d'installer quoi que ce soit pour démarrer.

Le fil conducteur de ce cours est la séparation du fond et de la forme. Le HTML décrit le contenu et sa structure ; il ne s'occupe pas de l'apparence. Les couleurs, les espacements et la mise en page relèvent du CSS, qui fait l'objet d'un cours à part entière — c'est l'étape naturelle juste après celui-ci (voir « Cours liés » plus bas).

Astuce

Garde un éditeur de texte et ton navigateur ouverts côte à côte : chaque notion est faite pour être essayée tout de suite. C'est en modifiant le code et en rechargeant la page que tout devient concret.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Un document commence par <!DOCTYPE html> et <html lang="…">.
  • Le <head> porte les métadonnées ; le <body>, le contenu visible.
  • Structure avec des balises sémantiques (<header>, <nav>, <main>, <footer>).
  • Hiérarchise les titres : un seul <h1>, puis <h2>, <h3>…
  • Les images ont un attribut alt ; les liens un href.
  • Les formulaires associent <label> et champs (<input>, <textarea>).
  • Pense d'abord au sens (sémantique) ; la présentation revient au CSS.
Balise
Élément du langage, écrit entre chevrons : <p>…</p>.
Attribut
Information ajoutée à une balise : <img src="…" alt="…">.
Élément sémantique
Balise qui décrit le rôle du contenu (<header>, <main>…).
Lien hypertexte
Balise <a href="…"> menant vers une autre ressource.
Formulaire
<form> regroupant des champs de saisie envoyés au serveur.
Accessibilité
Rendre le contenu utilisable par tous, dont les lecteurs d'écran.
Métadonnée
Information sur la page, placée dans le <head> (charset, viewport…).
Liste
<ul> (à puces) ou <ol> (numérotée), avec des <li>.
Tableau
<table> avec des lignes <tr>, en-têtes <th> et cellules <td>.
DOCTYPE
Déclaration en tête de fichier indiquant la version d'HTML.
