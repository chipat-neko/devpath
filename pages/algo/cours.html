Algorithmes & structures de données

Savoir coder, c'est bien ; savoir résoudre des problèmes efficacement, c'est mieux. Ce cours t'enseigne les fondamentaux d'informatique en JavaScript : analyser la complexité, choisir la bonne structure de données et le bon algorithme. La base attendue en entretien technique comme en production.

Bien s'équiper

Les extensions VS Code pour l'algorithmique

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour l'algorithmique

  • Code Runner (Jun Han) — exécute un extrait de code en un clic.
  • Quokka.js (Wallaby.js) — voir les valeurs intermédiaires en direct.
  • ESLint (Microsoft) — repère les erreurs à la frappe.
  • Prettier - Code formatter (Prettier) — garde un code lisible.

Prérequis

Ce cours utilise JavaScript comme langage d'illustration. Il suppose que tu es à l'aise avec les fonctions, les tableaux, les objets, les classes et la récursion de base — ce que couvre le cours « des bases au niveau confirmé ». Ici, on se concentre sur l'algorithmique, pas sur la syntaxe.

Ce que tu vas apprendre

Penser comme un informaticien

À la fin du cours, tu sauras

  • analyser la complexité d'un algorithme en temps et en espace (notation Big O) ;
  • maîtriser la récursion, la recherche (binaire) et les grands tris ;
  • implémenter les structures linéaires : listes chaînées, piles, files, tables de hachage ;
  • manipuler arbres, tas (files de priorité) et graphes (parcours BFS/DFS) ;
  • appliquer les grandes techniques : glouton et programmation dynamique ;
  • reconnaître les patterns d'entretien (deux pointeurs, fenêtre glissante) et choisir la bonne approche.

Pour qui, et pourquoi

Ce cours s'adresse aux développeurs qui savent programmer mais veulent comprendre pourquoi une solution est plus efficace qu'une autre. C'est le socle des entretiens techniques, mais aussi ce qui te permet, au quotidien, d'éviter le code qui rame dès que les données grossissent.

Chaque leçon est autonome et suit la même rigueur : l'intuition, un déroulé pas à pas sur un petit exemple, une implémentation JavaScript commentée, et surtout l'analyse de complexité. Tu repartiras avec une boîte à outils — et le réflexe d'évaluer le coût de ce que tu écris.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • La complexité (grand O) mesure comment le coût croît avec la taille.
  • Recherche binaire : O(log n) ; parcours simple : O(n) ; double boucle : O(n²).
  • Pile (LIFO) et file (FIFO) pour organiser les traitements.
  • Table de hachage : accès quasi instantané par clé.
  • Diviser pour régner (ex. le tri fusion).
Complexité

Pile
Structure LIFO (dernier entré, premier sorti).
File
Structure FIFO (premier entré, premier sorti).
Table de hachage
Accès par clé en temps quasi constant.
