Ruby : un langage pensé pour le développeur

Ruby a été conçu avec une obsession : le bonheur du développeur. Tout y est objet, le code se lit presque comme une phrase, et les blocs rendent la manipulation de données d'une élégance rare. Ce cours te mène du premier puts dans irb jusqu'à la métaprogrammation, aux gems, aux tests — et aux portes de Rails.

Bien s'équiper

Les extensions VS Code pour Ruby

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Ruby

  • Ruby LSP (Shopify) — IntelliSense, navigation et formatage.
  • Endwise (kaiwood) — ferme automatiquement les blocs par end.
  • ruby-rubocop (misogi) — analyseur de style RuboCop.

Pour qui ?

Idéal si tu connais déjà les bases de la programmation (variables, boucles) dans n'importe quel langage — par exemple via le cours Python ou le cours JavaScript. Chaque notion propre à Ruby est expliquée depuis le début.

Ce que tu vas apprendre

Du premier script à l'écosystème Rails

À la fin du cours, tu sauras

  • écrire du Ruby idiomatique : irb, chaînes et symboles, conditions, et la règle de vérité (nil/false) ;
  • manipuler les données avec tableaux, hachages, blocs et toute la puissance d'Enumerable ;
  • modéliser en objets : classes, mixins (Comparable, Enumerable) et métaprogrammation démystifiée ;
  • travailler en pro : fichiers et exceptions, gems et Bundler, tests (Minitest, RSpec) et la route vers Rails.

Pour qui, et pourquoi

Ce cours s'adresse à ceux qui veulent un langage productif et expressif pour le web (Rails fait tourner Shopify, GitHub et GitLab), les scripts et l'outillage. Ruby est aussi une école de style : ses idiomes — blocs, mixins, méthodes qui se lisent comme du texte — changent la façon d'écrire du code dans tous les langages.

Chaque leçon est autonome et illustrée par du code commenté. Le code ne s'exécute pas dans l'éditeur du site : les sorties sont montrées en commentaire (# =>).

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Tout est objet (même les nombres).
  • Afficher avec puts.
  • Méthodes : def … end ; variables d'instance @nom.
  • Blocs { |x| … } ou do … end.
  • attr_reader / attr_accessor pour les attributs.
  • Interpolation #{ } en guillemets doubles.
Objet
En Ruby, tout en est un, y compris les nombres et nil.
Bloc
Morceau de code passé à une méthode ({ } ou do … end).
Symbole
Identifiant léger et immuable (:nom).
@variable
Variable d'instance, propre à chaque objet.
attr_accessor
Génère le lecteur ET l'écrivain d'un attribut.
Itérateur
Méthode qui parcourt une collection (each, map…).
