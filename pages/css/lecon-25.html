Le défilement maîtrisé : scroll-snap et ancres douces

~35 min Intermédiaire Positionnement & ancres requis

À la fin de cette leçon, tu sauras

  • rendre le défilement vers les ancres doux avec scroll-behavior ;
  • aimanter un défilement par sections avec scroll-snap-type et scroll-snap-align ;
  • choisir entre mandatory et proximity ;
  • éviter qu'une ancre atterrisse cachée sous une barre fixe (scroll-margin-top, scroll-padding).
Sommaire de la leçon

Longtemps, tout ce qui touchait au défilement passait par du JavaScript. Aujourd'hui, le CSS pilote seul les gestes les plus courants : faire glisser la page jusqu'à une ancre, aimanter l'arrêt sur chaque photo d'un carrousel, ou empêcher un titre visé de se retrouver caché sous une barre collante. Trois familles de propriétés, aucune ligne de script, et un défilement qui semble soudain « pensé ».

Le défilement doux : scroll-behavior

Par défaut, cliquer sur un lien d'ancre (<a href="#tarifs">) fait sauter la page d'un coup jusqu'à la cible. En posant scroll-behavior: smooth sur la racine, ce saut devient un glissement animé — plus agréable et moins désorientant.

Cela s'applique aux clics d'ancres comme aux appels JavaScript (element.scrollIntoView()). Une seule ligne, effet immédiat sur toute la page.

Respecter « réduire les animations »

Certaines personnes règlent leur système sur « réduire les animations » (mal des transports, vertiges). Encadre le défilement doux dans une requête qui le respecte : @media (prefers-reduced-motion: no-preference) { html { scroll-behavior: smooth; } }. Ainsi, le glissement n'est activé que pour qui ne l'a pas désactivé.

L'aimantation : scroll-snap

scroll-snap fait « s'accrocher » le défilement à des points précis : chaque section, chaque diapositive s'aligne toute seule quand on relâche le doigt ou la molette. On le règle en deux temps : scroll-snap-type sur le conteneur qui défile (dans quel sens et à quel point aimanter), et scroll-snap-align sur chaque enfant (par quel bord il s'aligne).

Pour des sections verticales plein écran, le principe est le même sur l'axe y : le conteneur qui défile reçoit scroll-snap-type: y mandatory, et chaque section scroll-snap-align: start avec une hauteur de 100vh.

mandatory ou proximity ?

Le deuxième mot de scroll-snap-type règle la force de l'aimant :

  • mandatory — le défilement doit finir sur un point d'accroche. Parfait quand chaque élément fait la taille de l'écran (diaporama).
  • proximity — il s'accroche seulement si on s'arrête près d'un point. Plus souple : on peut lire tranquillement entre deux accroches.

Le piège de la barre fixe : scroll-margin-top

Voici l'agacement classique. Une barre de navigation collante (position: sticky) reste en haut de l'écran. On clique sur une ancre : la page glisse jusqu'au titre visé… qui se retrouve caché derrière la barre. La cause : le navigateur amène le haut de la cible pile en haut de la fenêtre, sans savoir qu'une barre l'occupe déjà.

La solution tient en une propriété posée sur la cible (ou globalement via scroll-padding-top sur la racine) : scroll-margin-top réserve une marge d'arrêt au-dessus de l'élément quand on l'atteint par défilement.

Cas réel : le sommaire qui pointait dans le vide

Sur une page de documentation, un sommaire latéral renvoyait vers chaque titre via des ancres. La barre supérieure, sticky et haute de 64 px, masquait systématiquement le titre visé : le lecteur cliquait sur « Installation » et tombait sur le paragraphe suivant, le titre étant coincé derrière la barre. Le correctif a tenu en une ligne globale : html { scroll-padding-top: 80px; } (les 64 px de la barre plus un peu d'air). Aucun JavaScript, aucun recalcul manuel de position : chaque ancre s'arrête désormais juste sous la barre, titre bien visible. Cette propriété fonctionne aussi pour le focus clavier, donc l'accessibilité en profite au passage.

scroll-padding sur le conteneur, scroll-margin sur l'élément

Deux façons d'obtenir le même décalage : scroll-padding-top se met une fois sur le conteneur qui défile (souvent html) et vaut pour toutes les cibles ; scroll-margin-top se met sur un élément précis pour l'ajuster au cas par cas. En pratique, on pose scroll-padding-top global pour la barre, et scroll-margin-top ponctuel là où un élément a besoin d'un réglage différent.

mandatory peut piéger le lecteur

scroll-snap-type: y mandatory force l'arrêt sur un point d'accroche : si une section est plus haute que l'écran, son bas peut devenir inaccessible, car le défilement « resaute » vers l'accroche suivante. Pour des contenus de hauteur variable, préfère proximity, ou assure-toi que chaque section tient dans la fenêtre.

Pour aller plus loin

La propriété scroll-snap-stop: always empêche de « sauter » plusieurs diapositives d'un seul geste (utile pour un onboarding étape par étape). Et pour animer des éléments au fil du défilement (apparitions, barres de progression) sans JavaScript, le niveau expert de ce cours présente les animations liées au défilement (scroll-timeline, view-timeline).

Antisèche

Glossaire

scroll-behavior
Propriété qui rend le défilement programmé (clic d'ancre, scrollIntoView) doux (smooth) au lieu d'instantané (auto).
scroll-snap-type
Sur le conteneur qui défile : active l'aimantation, précise l'axe (x/y) et la force (mandatory/proximity).
scroll-snap-align
Sur chaque enfant : par quel bord il s'aligne au point d'accroche (start, center, end).
mandatory
Aimantation stricte : le défilement finit toujours sur un point d'accroche.
proximity
Aimantation souple : l'accroche n'a lieu que si l'on s'arrête près d'un point.
scroll-margin-top
Marge réservée au-dessus d'un élément quand on l'atteint par défilement ; corrige les ancres cachées sous une barre fixe.
scroll-padding-top
Équivalent global posé sur le conteneur de défilement : décale toutes les cibles d'un même retrait.

Récap et vérification

  • scroll-behavior: smooth transforme les sauts d'ancres en glissements (à encadrer dans prefers-reduced-motion).
  • L'aimantation se règle en deux temps : scroll-snap-type sur le conteneur, scroll-snap-align sur les enfants.
  • mandatory force l'arrêt sur un point ; proximity ne le fait que si on s'en approche.
  • Une ancre cachée sous une barre fixe se corrige avec scroll-margin-top (sur la cible) ou scroll-padding-top (sur le conteneur).
  • Tout cela est du CSS pur — aucun JavaScript nécessaire.

Vérifie ta compréhension

  1. Sur quel élément met-on scroll-snap-type, et sur lequel scroll-snap-align ?
  2. Quelle différence entre mandatory et proximity ?
  3. Comment empêcher un titre visé de se cacher sous une barre sticky ?

Exercices

Exercice 1Échauffement

Active le défilement doux sur toute la page, mais uniquement pour les personnes qui n'ont pas demandé de réduire les animations.

Voir une solution

La requête prefers-reduced-motion: no-preference n'active le glissement que si l'utilisateur n'a pas coché « réduire les animations ».

Exercice 2Application

Transforme .galerie (défilement horizontal) en carrousel aimanté : chaque .photo s'accroche par son bord gauche.

Voir une solution

Le conteneur aimante l'axe X ; chaque photo occupe toute la largeur et s'aligne à gauche. On fait défiler d'une photo à l'autre, net.

Exercice 3Défi

Une barre de navigation sticky haute de 72 px masque les titres visés par les ancres. Corrige le problème pour toutes les cibles d'un coup, et explique pourquoi margin-top ne conviendrait pas.

Voir une solution

scroll-padding-top sur le conteneur de défilement décale le point d'arrêt de toutes les ancres, sans rien changer à la mise en page. Un margin-top classique, lui, décalerait réellement chaque titre dans le flux (créant des trous visibles partout), alors qu'on veut seulement changer où le défilement s'arrête. scroll-padding agit uniquement sur l'arrêt du scroll (et le focus clavier), pas sur la disposition.
