Module 11 · Mouvement & effets visuels — Leçon 34

Filtres, fusion, découpe et masques

~33 min Avancé Leçon 08 recommandée

À la fin de cette leçon, tu sauras

  • savoir composer des effets avec filter et distinguer drop-shadow() de box-shadow ;
  • savoir créer un effet « verre dépoli » avec backdrop-filter et un repli via @supports ;
  • savoir fusionner des éléments avec mix-blend-mode et background-blend-mode ;
  • savoir découper et masquer avec clip-path et mask-image (dégradés, icônes recolorables).
Sommaire de la leçon

Le CSS moderne offre une boîte à outils graphique qui rivalise avec un éditeur d'image : flouter, recolorer, fusionner, découper, faire des fondus, le tout en quelques propriétés et sans toucher au DOM. Ces effets s'appliquent au moment du rendu (compositing), donc ils respectent la mise en page et restent animables.

Dans cette leçon, on enchaîne filter, backdrop-filter, les modes de fusion, clip-path et mask. Tu connais déjà box-shadow, opacity et les dégradés : on va voir ce qu'ils ne savent pas faire.

filter : retoucher le rendu d'un élément

La propriété filter applique une liste de fonctions dans l'ordre à l'élément et à son contenu. Les principales : blur(8px), brightness(1.2), contrast(1.4), grayscale(1), saturate(2), hue-rotate(90deg). L'ordre compte : grayscale(1) brightness(1.5) n'est pas brightness(1.5) grayscale(1).

Le cas le plus intéressant est drop-shadow() : contrairement à box-shadow qui dessine toujours un rectangle (la boîte), drop-shadow() calcule l'ombre sur la forme réelle — l'alpha d'un PNG, le tracé d'un clip-path, les bords d'un SVG.

Clique « 👁 Aperçu » : survole l'image pour la recolorer ; l'ombre de l'étoile suit ses pointes.

Astuce

Ouvre l'aperçu et change les valeurs : remplace saturate(1.4) par hue-rotate(120deg), ou empile blur(2px) brightness(.7). Tu vois instantanément l'effet de l'ordre des fonctions.

backdrop-filter : le verre dépoli

Là où filter retouche l'élément, backdrop-filter retouche ce qui est derrière lui, à travers ses zones transparentes. C'est la base du glassmorphism : un panneau semi-transparent qui floute le contenu situé dessous.

Le panneau floute la photo derrière lui. Safari n'accepte encore que la forme préfixée, d'où le couple -webkit- + standard et le test combiné dans @supports.

Note

Garde toujours un fond semi-transparent (ici rgba(255,255,255,.12)) en plus du flou : sans lui, le verre n'a aucune teinte et le texte risque de manquer de contraste sur les zones claires de l'image.

mix-blend-mode et background-blend-mode

Les modes de fusion décident comment les pixels d'un élément se combinent avec ceux situés dessous, comme les calques d'un logiciel d'image. mix-blend-mode fusionne un élément avec son arrière-plan (les éléments derrière) ; background-blend-mode fusionne les couches de background d'un même élément entre elles.

Les modes courants : multiply (assombrit, idéal pour poser un logo noir sur une image), screen (éclaircit), overlay (contraste), difference (inversion créative), luminosity.

Le titre se fond dans l'image (mix-blend-mode) ; le bandeau colore une photo via un dégradé (background-blend-mode).

Piège fréquent

Un mix-blend-mode rend le contraste imprévisible selon l'arrière-plan : du texte en overlay peut devenir illisible sur certaines zones. Pour un contenu lisible, prévois une variante de secours (ombre, fond) ou réserve la fusion au décoratif. Attention aussi : appliquer un mix-blend-mode crée un contexte d'empilement (stacking context) qui peut isoler l'élément de ses voisins.

clip-path : découper une forme

clip-path ne masque pas par transparence : il découpe la boîte selon une géométrie. Les formes de base : inset(10px round 12px) (rectangle rogné, coins arrondis), circle(50% at 50% 50%), ellipse(), polygon(...) pour des contours libres, et path("...") pour un tracé SVG. Comme une forme s'anime vers une autre de même type (même nombre de points pour un polygone), clip-path sert aussi aux révélations animées.

Un coin diagonal qui bascule au survol : deux polygon() de même nombre de points s'interpolent.

Piège fréquent

clip-path coupe tout ce qui dépasse, y compris une box-shadow. Pour ombrer une forme découpée, applique l'ombre à un parent (ou utilise filter: drop-shadow() qui, lui, respecte la découpe).

mask-image : masquer avec un dégradé ou une image

Le masque utilise les valeurs alpha (ou la luminance) d'une image pour révéler ou cacher l'élément : opaque = visible, transparent = caché. Deux usages stars : le fondu de bord avec un dégradé, et l'icône recolorable (on masque un bloc coloré par la forme d'une icône, et on change la couleur en CSS).

En haut, une image qui se fond vers le bas. En bas, un cœur dont la couleur vient de background : change #e63946 pour recolorer l'icône.

Note

Pour les masques, double encore souvent la déclaration avec le préfixe -webkit- (WebKit et anciens Chromium) : écris -webkit-mask avant mask. La propriété non préfixée gagne là où elle est gérée. Note aussi que mask utilise par défaut l'alpha de l'image (mask-mode: alpha) ; pour masquer par clarté, passe à mask-mode: luminance.

shape-outside : habiller du texte autour d'une forme

Dernier outil de découpe, mais pour le flux du texte : shape-outside définit le contour autour duquel le texte d'un élément flottant s'enroule. Combiné à clip-path, on obtient une image ronde dont le texte épouse la courbe.

clip-path pour le visuel, shape-outside pour le flux : les deux ensemble pour un habillage net. shape-outside n'agit que sur un élément flottant.

Cas réel

Le verre dépoli est partout dans les interfaces système : le Centre de contrôle d'iOS, la barre des menus de macOS, les effets Acrylic et Mica de Windows 11 reposent tous sur un backdrop-filter translucide ; sur le web, on le retrouve sur les barres de navigation « collantes » qui laissent deviner le contenu qui défile dessous. Autre usage industriel : les systèmes d'icônes monochromes (barres d'outils, boutons) s'appuient sur mask-image pour recolorer une même forme SVG selon l'état (survol, actif, désactivé) sans dupliquer le fichier — une seule icône, recolorée à l'infini via background. Et les vignettes en niveaux de gris qui reprennent leurs couleurs au survol (galeries, portfolios) ne sont qu'un filter: grayscale() animé.

Pièges fréquents

  • backdrop-filter invisible : sans contenu derrière l'élément, ou si l'élément est opaque, l'effet ne se voit pas. Il faut un fond semi-transparent et quelque chose à flouter dessous. Sur Safari, n'oublie pas la forme -webkit-backdrop-filter.
  • Filtres coûteux : blur() et backdrop-filter sont chers, surtout animés ou sur de grandes surfaces. Préfère animer opacity/transform et limite la zone floutée ; teste sur mobile.
  • clip-path et l'ombre : une box-shadow sur un élément clippé disparaît. Utilise drop-shadow() ou ombre un parent.
  • Préfixes mask : déclare -webkit-mask en plus de mask pour une couverture large.
  • Contraste sous un blend-mode : le rendu dépend de l'arrière-plan ; vérifie la lisibilité sur les zones claires et sombres.

Antisèche : filtres, fusion, découpe, masques

Glossaire

filter
Applique une liste de fonctions (blur, brightness, grayscale, drop-shadow…) au rendu de l'élément ; l'ordre des fonctions change le résultat.
drop-shadow()
Fonction de filter qui ombre la silhouette réelle (canal alpha, tracé clip-path), là où box-shadow ombre toujours la boîte rectangulaire.
backdrop-filter
Filtre appliqué à ce qui se trouve derrière l'élément, à travers ses zones translucides ; base du verre dépoli. Requiert un fond semi-transparent et souvent le préfixe -webkit-.
Glassmorphism
Style d'interface fait de panneaux translucides floutés (verre dépoli), obtenu par backdrop-filter: blur() + fond semi-transparent.
Mode de fusion (blend mode)
Règle de mélange des pixels avec les couches inférieures (multiply, screen, overlay…). mix-blend-mode agit entre éléments ; background-blend-mode entre couches d'un même fond.
clip-path
Découpe la boîte selon une géométrie (inset, circle, polygon, path) : dedans visible, dehors coupé, sans dégradé. Anime entre formes de même type.
mask-image
Masque par transparence : l'alpha (ou la luminance) d'une image révèle ou cache l'élément. Sert aux fondus de bord et aux icônes recolorables.
shape-outside
Définit le contour autour duquel le texte s'enroule ; n'agit que sur un élément flottant, souvent couplé à clip-path.

Récap et vérification

  • filter retouche l'élément ; drop-shadow() ombre la forme réelle, pas la boîte.
  • backdrop-filter floute l'arrière-plan → verre dépoli, avec préfixe -webkit- et repli @supports.
  • mix-blend-mode fusionne avec le fond ; background-blend-mode fusionne les couches d'un même fond.
  • clip-path découpe une géométrie (et anime entre formes de même type) ; mask-image masque par alpha (fondus, icônes recolorables).
  • shape-outside habille le texte autour d'une forme flottante.
