Module 01 · Fondations CSS — Leçon 01

Premiers pas en CSS

~30 min Débutant Bases du HTML utiles

À la fin de cette leçon, tu sauras

  • expliquer le rôle du CSS et sa séparation d'avec le HTML ;
  • relier une feuille de style externe à une page HTML ;
  • lire et écrire une règle CSS (sélecteur, propriété, valeur) ;
  • cibler des éléments par balise, par class et par id.
Sommaire de la leçon

Tu sais désormais structurer une page avec le HTML : des titres, des paragraphes, des listes, des liens. Mais cette page est… grise et austère. C'est normal : le HTML décrit le contenu, pas son apparence. Pour les couleurs, les polices, les espacements et la mise en page, on utilise un autre langage : le CSS.

Dans cette leçon, tu vas comprendre ce qu'est le CSS, apprendre à le relier à une page HTML, et écrire tes toutes premières règles de style.

Qu'est-ce que le CSS ?

CSS signifie Cascading Style Sheets : « feuilles de style en cascade ». C'est le langage qui décrit la présentation d'une page web. Là où le HTML répond à la question « qu'est-ce que c'est ? » (un titre, un paragraphe), le CSS répond à « à quoi ça ressemble ? » (ce titre est bleu, centré, en gros).

Cette division du travail porte un nom : la séparation du contenu et de la présentation. Elle a un immense avantage : un même fichier CSS peut habiller des dizaines de pages HTML, et changer le style de tout un site revient à modifier un seul endroit.

Le CSS s'ajoute au HTML

Le CSS ne remplace jamais le HTML : il vient l'habiller. Il te faut donc d'abord une page HTML à mettre en forme. Si la structure d'une page n'est pas claire pour toi, c'est le moment de faire un détour par le cours HTML.

Cas réel

Sur un vrai site de dizaines de pages, toutes pointent vers le même styles.css. Changer la couleur principale ou la police de tout le site revient alors à modifier une seule ligne, à un seul endroit. C'est tout le pouvoir de la séparation contenu / présentation — et c'est exactement ainsi que ce site Syntaxe gère son thème clair/sombre.

Relier HTML et CSS — le détail

La connexion entre les deux langages se fait entièrement côté HTML, via cette balise <link>. C'est un point charnière entre les deux cours : la première leçon du cours HTML explique la structure du <head> où se place ce lien. HTML pour structurer, CSS pour mettre en forme : les deux se complètent.

L'anatomie d'une règle CSS

Tout le CSS repose sur une brique unique : la règle. Une règle dit « pour tels éléments, applique tels styles ». Elle a toujours la même forme :

Décortiquons-la :

  • h1 est le sélecteur : il choisit les éléments visés (ici, tous les <h1>).
  • Entre accolades { } se trouve le bloc de déclarations.
  • color: crimson; est une déclaration : une propriété (color), deux points, une valeur (crimson), un point-virgule.

On peut empiler autant de déclarations qu'on veut dans le bloc, chacune terminée par un point-virgule.

Cascade et héritage, en bref

Le « C » de CSS signifie Cascading : quand plusieurs règles concernent le même élément, le navigateur les combine selon des priorités. Deux idées à retenir dès maintenant :

  • L'héritage : certaines propriétés (comme color ou font-family) se transmettent des parents aux enfants. Définir la police sur body la donne à toute la page.
  • La spécificité : un sélecteur plus précis l'emporte. Un id bat une class, qui bat une balise. En cas d'égalité, la dernière règle écrite gagne.

Pièges fréquents

  • Oublier de relier le fichier. Sans la balise <link> (ou un mauvais href), aucun style ne s'applique. Vérifie le chemin en premier.
  • Oublier un point-virgule ou une accolade. Une déclaration non terminée par ;, ou un bloc { } mal fermé, et la suite des règles peut être ignorée.
  • Confondre . et #. Le point cible une classe, le dièse un id. Se tromper, c'est ne rien sélectionner.
  • Abuser du style en ligne. L'attribut style sur les balises est difficile à maintenir et l'emporte sur presque tout : réserve-le aux cas exceptionnels.

Pour aller plus loin

Pour aller plus loin

Les outils de développement du navigateur (F12, onglet « Éléments ») permettent d'inspecter n'importe quel élément et de voir, en direct, quelles règles CSS s'y appliquent. C'est l'outil n°1 pour comprendre et déboguer un style. Plus tard, tu découvriras aussi les variables CSS (--ma-couleur), qui rendent une feuille de style bien plus facile à maintenir.

Antisèche : les bases du CSS

Glossaire

CSS
Cascading Style Sheets : langage décrivant la présentation (couleurs, polices, mise en page) d'une page.
Règle
Une instruction CSS : un sélecteur suivi d'un bloc de déclarations entre accolades.
Sélecteur
La partie qui choisit les éléments visés (par balise, classe ou id).
Déclaration
Un couple propriété: valeur; (ex. color: navy;).
Classe / id
Points d'accroche : .classe réutilisable sur plusieurs éléments, #id unique par page.
Héritage
Transmission de certaines propriétés (color, font) des éléments parents aux enfants.
Spécificité
Priorité d'un sélecteur : un id l'emporte sur une classe, qui l'emporte sur une balise.
Séparation contenu / présentation
Principe : le HTML structure, le CSS met en forme, dans des fichiers distincts.

Récap et vérification

En résumé :

  • Le CSS décrit la présentation ; le HTML décrit le contenu.
  • On relie une feuille externe avec <link rel="stylesheet" href="styles.css" /> dans le <head>.
  • Une règle = un sélecteur + un bloc de déclarations (propriété: valeur;).
  • On cible par balise (p), par classe (.intro) ou par id (#entete).

Vérifie ta compréhension

  1. Quelle est la différence de rôle entre le HTML et le CSS ?
  2. Quelle balise, et dans quelle partie du document, relie une feuille de style externe ?
  3. Dans .intro { color: navy; }, identifie le sélecteur, la propriété et la valeur.
