Les pseudo-éléments ::before et ::after

~34 min Intermédiaire Sélecteurs & boîte requis

À la fin de cette leçon, tu sauras

  • générer du contenu décoratif avec ::before et ::after ;
  • utiliser la propriété content, y compris attr() ;
  • distinguer un pseudo-élément d'une pseudo-classe ;
  • construire une info-bulle en pur CSS, sans JavaScript.
Sommaire de la leçon

Jusqu'ici, styler un élément voulait dire styler quelque chose d'écrit dans le HTML. Mais le CSS sait aussi fabriquer du contenu qui n'existe pas dans la page : une flèche devant un lien, des guillemets autour d'une citation, un badge « Nouveau » dans un coin. Ce sont les pseudo-éléments ::before et ::after : deux enfants virtuels que tu ajoutes à un élément, sans toucher à son HTML. Ils sont l'un des outils les plus utilisés du CSS décoratif.

Un enfant virtuel au début et à la fin

::before insère un contenu juste avant le contenu de l'élément ; ::after, juste après. Attention : à l'intérieur de l'élément, pas avant ou après l'élément lui-même. La règle d'or : sans la propriété content, un pseudo-élément n'apparaît pas du tout. C'est ce qui les déclenche.

Le HTML ne contient aucun guillemet : ils sont entièrement générés par le CSS. Une fois créés, ces pseudo-éléments se stylent comme n'importe quel élément — couleur, taille, marge, position, arrière-plan.

Le cas content: "" est le plus fréquent en pratique : on ne veut aucun texte, seulement une boîte décorative (un point, un trait, un triangle) qu'on dimensionne ensuite avec width, height et background. Et attr(href) lit un attribut HTML : très pratique pour, en impression, afficher l'adresse d'un lien à côté de son texte.

Positionner un pseudo-élément

Pour placer librement une décoration (un badge dans un coin, par exemple), la recette classique : position: relative sur le parent, puis position: absolute sur le ::after. Le pseudo-élément se cale alors par rapport au parent avec top, right, etc. N'oublie pas content: "", sinon rien ne s'affiche.

Pseudo-élément ou pseudo-classe ?

Deux notions se ressemblent et se confondent souvent. Une pseudo-classe (:hover, :first-child) cible un élément déjà existant selon son état ou sa position. Un pseudo-élément (::before, ::first-line) cible une partie virtuelle qui n'est pas un élément du HTML. La convention moderne les distingue par le nombre de deux-points : un pour les pseudo-classes, deux pour les pseudo-éléments.

Cas réel : une info-bulle sans une ligne de JavaScript

Sur un tableau de bord, il fallait afficher une explication au survol de petites icônes « ? ». La première version chargeait une bibliothèque JavaScript de tooltips — plusieurs kilo-octets, et un délai avant que ça marche. La version finale : zéro JavaScript. Le texte est mis dans un attribut data-info, et un ::after le lit avec attr(data-info), caché par défaut et révélé au survol : [data-info]:hover::after { content: attr(data-info); … }. C'est plus léger, plus rapide, et le contenu de l'info-bulle vit dans le HTML là où on le lit. Une combinaison typique : une pseudo-classe d'état (:hover) qui déclenche un pseudo-élément généré (::after).

Contenu généré = décoratif, pas essentiel

Le texte injecté par content est décoratif : il n'est pas fiable pour les lecteurs d'écran (le support varie) et ne peut être ni sélectionné, ni traduit, ni indexé. Règle : n'y mets jamais d'information indispensable (un prix, un statut, un libellé de bouton). Réserve ::before/::after aux flèches, puces, traits et badges purement visuels. Autre limite : les pseudo-éléments ne marchent pas sur les éléments remplacés comme <img> ou <input>.

Pour aller plus loin

D'autres pseudo-éléments valent le détour : ::first-line et ::first-letter (lettrines de magazine), ::marker (styler la puce d'une liste), ::selection (couleur du texte sélectionné), et ::placeholder (texte d'aide d'un champ). Pour des formes plus riches à partir d'un content: "", combine-les avec clip-path ou des dégradés — c'est le pont vers le niveau expert de ce cours.

Antisèche

Glossaire

Pseudo-élément
Partie virtuelle d'un élément que l'on peut styler sans qu'elle existe dans le HTML ; s'écrit avec deux deux-points (::before).
::before
Pseudo-élément inséré au début du contenu de l'élément (à l'intérieur), avant son contenu réel.
::after
Pseudo-élément inséré à la fin du contenu de l'élément (à l'intérieur), après son contenu réel.
content
Propriété qui définit ce qu'affiche un pseudo-élément ; indispensable — sans elle, ::before/::after ne sont pas générés.
attr()
Fonction de content qui insère la valeur d'un attribut HTML de l'élément (ex. attr(href)).
Contenu généré
Texte ou boîte produit par le CSS (via content) plutôt qu'écrit dans le HTML ; décoratif, à ne pas utiliser pour de l'information essentielle.
Pseudo-classe
Sélecteur ciblant un élément existant selon son état ou sa position (:hover, :first-child) ; un seul deux-points.
Élément remplacé
Élément dont le contenu vient d'une source externe (<img>, <input>) ; il n'accepte pas ::before/::after.

Récap et vérification

  • ::before et ::after insèrent un contenu à l'intérieur de l'élément, en tête et en fin.
  • La propriété content est obligatoire : texte, "" (forme), attr() ou un code de caractère.
  • On les positionne librement avec position: absolute (parent en relative).
  • Une pseudo-classe (un « : ») cible un élément réel ; un pseudo-élément (deux « :: ») crée un fragment.
  • Le contenu généré est décoratif : jamais d'information essentielle, et rien sur <img>/<input>.

Exercices

Exercice 1Échauffement

Ajoute une flèche → (suivie d'une espace) devant chaque lien de classe lien-fleche, en violet.

Voir une solution

::before place la flèche au début du lien, sans l'écrire dans le HTML.

Exercice 2Application

Crée un point séparateur décoratif : un ::after sur .item, une petite boîte ronde de 4 px, grise. (Indice : content: "", display: inline-block.)

Voir une solution

Le content: "" crée une boîte vide qu'on dimensionne et arrondit en un point.

Exercice 3Défi

Explique pourquoi une info-bulle en pur CSS combine une pseudo-classe et un pseudo-élément, et pourquoi c'est préférable à une bibliothèque JavaScript pour un cas simple.

Voir une solution

La pseudo-classe :hover détecte l'état « survolé » d'un élément réel ; le pseudo-élément ::after fournit la boîte de l'info-bulle, dont le texte vient de attr(data-info). On écrit donc [data-info]:hover::after { content: attr(data-info); } : l'état déclenche l'affichage du fragment généré. Pour un besoin simple, c'est préférable à une bibliothèque JavaScript car c'est plus léger (aucun octet de script à télécharger ni exécuter), plus rapide (le navigateur gère le survol nativement), et le texte reste dans le HTML (dans data-info), là où on le lit et le maintient. On réserve le JavaScript aux info-bulles riches (positionnement intelligent près des bords, contenu interactif).
