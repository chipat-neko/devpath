Impression et compteurs CSS

~32 min Intermédiaire Leçon 16 recommandée

À la fin de cette leçon, tu sauras

  • savoir styliser une page pour l'impression avec @media print (masquer la navigation, afficher l'URL des liens) ;
  • savoir contrôler la mise en page papier avec @page et les coupures (break-inside: avoid) ;
  • savoir numéroter automatiquement en CSS avec counter-reset, counter-increment et counter() ;
  • savoir créer une numérotation hiérarchique (1.1, 2.3) avec counters().
Sommaire de la leçon

Deux fonctionnalités passent souvent sous le radar parce qu'elles ne se voient pas à l'écran : la mise en forme pour l'impression et les compteurs CSS. La première transforme une page web bavarde (menus, pubs, boutons) en un document papier propre. La seconde numérote automatiquement des sections ou des étapes sans rien ajouter au HTML. Ce sont deux outils discrets mais qui font tout de suite « pro ».

On va d'abord apprendre à parler au papier : @media print, @page, les coupures de page et l'impression des fonds. Puis on génère des numéros en CSS pur avec les compteurs, jusqu'à la numérotation hiérarchique façon table des matières.

1. Styliser pour l'impression avec @media print

L'impression est juste un type de média, comme la largeur d'écran. Tu enveloppes tes règles « papier » dans @media print { … }. Le réflexe numéro un : masquer tout ce qui n'a aucun sens sur papier (navigation, pubs, boutons interactifs) avec display: none.

En impression, on utilise volontiers les unités physiques comme pt ou cm.

Astuce classique : sur papier, un lien souligné en bleu ne sert à rien puisqu'on ne peut pas cliquer. Affiche plutôt l'adresse réelle juste après le texte, grâce à attr() qui lit un attribut HTML.

« En savoir plus » devient « En savoir plus (https://exemple.fr/page) » sur le papier.

Cas réel

Le bouton « Imprimer » ou « Télécharger en PDF » d'une facture, d'un billet de train ou d'un CV s'appuie sur @media print : à l'écran tu vois le site complet, mais l'impression ne garde que l'essentiel, en noir sur blanc, bien mis en page. C'est aussi ce qui permet à ce site Syntaxe de proposer un certificat imprimable propre.

Note

L'aperçu en iframe ne simule pas l'impression. Pour voir le rendu papier, ouvre la page dans ton navigateur puis Ctrl+P (ou Cmd+P) : l'aperçu d'impression applique tes règles @media print.

2. La règle @page : marges du papier

@media print stylise le contenu. La règle @page stylise la page elle-même : ses marges physiques. On peut aussi cibler la première page avec @page :first, ou les pages gauches/droites avec :left et :right (pratique pour relier un document).

@page vit en dehors de @media print et ne concerne que l'impression. Toutes les propriétés CSS n'y sont pas permises : on s'en tient surtout aux marges et à la taille.

3. Maîtriser les coupures de page

Sur plusieurs pages, le navigateur coupe où il veut — parfois en plein milieu d'un titre ou d'un tableau. Les propriétés break-before, break-after et break-inside reprennent la main.

break-inside: avoid garde l'élément entier sur une même page.

Note

Les propriétés break-* remplacent les anciennes page-break-before / page-break-inside. Garde les versions modernes : elles sont aujourd'hui bien supportées pour l'impression.

4. Forcer l'impression des couleurs et des fonds

Par défaut, les navigateurs n'impriment pas les couleurs de fond (pour économiser l'encre). Si ton badge coloré ou ton fond de tableau doit absolument apparaître, demande-le explicitement avec print-color-adjust: exact.

À réserver aux éléments où la couleur porte du sens (alertes, codes couleur).

5. Les compteurs CSS : numéroter sans HTML

Changeons de sujet. Tu veux numéroter des sections « 1, 2, 3 » mais sans écrire les chiffres dans le HTML ? Les compteurs CSS font ça automatiquement. Trois ingrédients :

  • counter-reset: nom sur le parent : crée et remet à zéro le compteur.
  • counter-increment: nom sur chaque élément à compter : +1 à chaque fois.
  • content: counter(nom) dans un ::before : affiche la valeur.

Clique sur « 👁 Aperçu » : chaque ligne reçoit « Étape 1 : », « Étape 2 : »… sans aucun chiffre dans le HTML.

Astuce

Tu peux changer le style des chiffres avec un second argument : counter(etape, upper-roman) donne I, II, III… et counter(etape, lower-alpha) donne a, b, c…

6. Numérotation hiérarchique avec counters()

Pour une table des matières du type 1, 1.1, 1.2, 2, 2.1, il faut la fonction counters() (avec un s) qui concatène tous les niveaux d'un même compteur avec un séparateur. L'idiome robuste : réinitialiser le compteur sur chaque <li> (qui devient le parent de sa sous-liste), puis l'incrémenter.

Aperçu : 1 Introduction, 2 Installation, 2.1 Prérequis, 2.2 Téléchargement, 3 Conclusion.

La clé : chaque sous-liste <ol> réinitialise un nouveau compteur section, qui « vit » à l'intérieur du compteur parent. counters() remonte alors toute la chaîne d'ancêtres et joint les valeurs avec le point.

Pièges fréquents

Piège fréquent

Oublier @media print tout court : ta navigation, ta bannière de cookies et tes pubs s'impriment alors sur le document. Pense toujours à un bloc print, même minimal, qui masque ces éléments.

Piège fréquent

Un compteur sans counter-reset ne repart jamais à zéro : il continue d'incrémenter sur toute la page. Et un content: counter(...) n'affiche rien s'il n'est pas posé dans un ::before ou ::after — c'est du contenu généré.

Piège fréquent

Pour la numérotation hiérarchique, ne mets pas le counter-reset uniquement sur le conteneur racine : chaque sous-liste doit relancer son propre compteur, sinon tu obtiens 1, 2, 3, 4… à plat au lieu de 1.1, 1.2.

Glossaire

@media print
Bloc de styles appliqués uniquement à l'impression (ou l'aperçu avant impression).
@page
Règle qui stylise la page imprimée elle-même (marges, première page…).
attr()
Fonction CSS qui lit la valeur d'un attribut HTML (ex. attr(href)).
break-inside / break-before
Contrôlent les coupures de page (ou de colonne) : éviter ou forcer.
print-color-adjust
exact force le navigateur à imprimer les fonds et couleurs (sinon supprimés).
Compteur CSS
Variable de numérotation gérée par CSS, affichée sans écrire de chiffre dans le HTML.
counter-reset / -increment
Initialise un compteur (sur le parent) / l'augmente de 1 (sur chaque élément).
counter() / counters()
Affiche un compteur ; counters() gère la numérotation hiérarchique imbriquée.

Récap et vérification

  • @media print { … } regroupe les styles papier ; display: none masque navigation, pubs et boutons.
  • a::after { content: " (" attr(href) ")" } affiche l'URL des liens sur papier.
  • @page règle les marges ; @page :first cible la première page.
  • break-before / break-after: page et break-inside: avoid contrôlent les coupures.
  • print-color-adjust: exact force l'impression des fonds et couleurs.
  • Compteurs : counter-reset (parent) + counter-increment (élément) + content: counter(nom) (sur ::before).
  • counters(nom, ".") produit une numérotation hiérarchique (1.1, 2.3).
