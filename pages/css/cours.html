CSS : des fondations au niveau expert

Si le HTML est le squelette d'une page, le CSS en est l'habillage : couleurs, typographie, espacements et mise en page. Ce cours t'apprend à donner vie à tes pages, des premiers sélecteurs jusqu'aux mises en page modernes et responsive, puis te conduit jusqu'au niveau expert : couches de cascade (@layer), :has(), container queries, couleurs modernes (oklch), animations au scroll et View Transitions.

Bien s'équiper

Les extensions VS Code pour CSS

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour CSS

  • Prettier - Code formatter (Prettier) — met le CSS en forme automatiquement.
  • Live Server (Ritwick Dey) — voir le rendu se mettre à jour en direct.
  • CSS Peek (Pranay Prakash) — saute à la définition d'une classe.
  • Color Highlight (Sergii Naumov) — affiche les couleurs dans le code.
  • IntelliSense for CSS class names in HTML (Zignd) — complète les classes.

Cours complet

Les 47 leçons sont rédigées, des sélecteurs aux variables CSS jusqu'au CSS moderne expert (couches de cascade, :has(), container queries, animations au scroll), organisées en trois niveaux — débutant, intermédiaire et expert —, avec un aperçu en direct de chaque exemple visuel.

Ce que tu vas apprendre

Objectifs du cours

À la fin du cours, tu sauras

  • relier une feuille de style CSS à une page HTML proprement ;
  • cibler les bons éléments avec les sélecteurs et comprendre la cascade ;
  • maîtriser le modèle de boîte (marges, bordures, remplissage) ;
  • travailler les couleurs, les unités et la typographie ;
  • disposer tes éléments avec Flexbox et Grid ;
  • rendre une page responsive et ajouter transitions et animations.

Pour qui, et pourquoi

Ce cours s'adresse à toi si tu connais déjà les bases du HTML (ou si tu les apprends en parallèle) et que tu veux maintenant mettre en forme tes pages. Aucune autre connaissance n'est requise.

Le CSS ne remplace pas le HTML : il s'y ajoute. On garde le contenu et la structure dans le HTML, et on déporte toute la présentation dans des fichiers .css séparés. La toute première leçon montre justement comment relier les deux. Si tu débutes complètement, commence par le cours HTML (voir « Cours liés » plus bas), puis reviens ici.

Astuce

Le CSS s'apprend en expérimentant : change une couleur, une taille, une marge, et observe l'effet immédiatement dans le navigateur. C'est le meilleur moyen d'ancrer chaque propriété.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Une règle = un sélecteur + des déclarations { propriété: valeur; }.
  • Cible par balise, classe (.nom) ou id (#nom) ; l'id est plus spécifique.
  • Le modèle de boîte : contenu, padding, border, margin.
  • box-sizing: border-box simplifie le calcul des largeurs.
  • Mets en page avec Flexbox (1D) et Grid (2D).
  • Rends responsive avec les media queries (@media).
  • Les unités relatives (rem, %, vw) s'adaptent mieux que px.
Sélecteur
La partie d'une règle qui cible les éléments (.classe, #id, balise).
Spécificité
Priorité d'une règle en cas de conflit (id > classe > balise).
Modèle de boîte
Contenu + padding + bordure + marge d'un élément.
Flexbox
Disposition sur un axe (ligne ou colonne) : display: flex.
Grid
Disposition en grille à deux dimensions : display: grid.
Media query
Règle conditionnelle selon l'écran : @media (max-width: …).
Cascade
Mécanisme qui résout les conflits de styles (origine, spécificité, ordre).
rem
Unité relative à la taille de police de l'élément racine.
Pseudo-classe
État d'un élément, ex. :hover, :focus.
Variable CSS
Propriété personnalisée --nom, lue avec var(--nom).
