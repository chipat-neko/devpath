Performance & SEO web

Un site lent ou introuvable ne sert personne. Ce cours t'apprend à le rendre rapide (Web Vitals, chargement, rendu) et visible (SEO technique, données structurées), puis à le mesurer avec un audit Lighthouse. Performance et référencement vont de pair : Google récompense les sites rapides, et tes visiteurs aussi.

Bien s'équiper

Les extensions VS Code pour la performance

Ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe :

À installer pour ce cours

  • webhint — repère les problèmes de performance, d'accessibilité et de SEO.
  • Import Cost — affiche le poids des dépendances importées.
  • Image preview / Optimize — visualiser et alléger les images.
  • HTMLHint — valide les balises clés (meta, titres…).

Et dans le navigateur, l'audit Lighthouse (DevTools) et l'onglet Performance sont tes meilleurs alliés.

Prérequis

Connaître les bases de HTML, CSS et du fonctionnement de HTTP (requêtes, cache) suffit. Aucun outil à installer pour comprendre : un navigateur et ses DevTools permettent déjà de tout mesurer.

Ce que tu vas apprendre

Objectifs du cours

À la fin du cours, tu sauras

  • lire et viser les Web Vitals (LCP, CLS, INP) ;
  • optimiser le chargement (images, lazy-loading, cache) ;
  • réduire le coût du JavaScript et du rendu ;
  • poser les bases du SEO technique (balises, sitemap, robots) ;
  • ajouter des données structurées pour être mieux compris ;
  • auditer et optimiser un site avec Lighthouse.

Pour qui, et pourquoi

Ce cours est pour toi si tu construis des sites et veux qu'ils soient rapides et trouvés. La performance influence directement l'expérience, le taux de conversion et le référencement ; le SEO technique décide si tes pages apparaissent — et comment — dans les résultats de recherche.

Le fil conducteur est la mesure : on n'optimise pas au hasard. On mesure (Lighthouse, Web Vitals), on identifie le plus gros frein, on corrige, puis on re-mesure.

Astuce

La plus grosse part du poids d'une page, ce sont souvent les images et le JavaScript. Commence par là : c'est presque toujours le meilleur rapport effort/gain.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • On mesure avant d'optimiser : Web Vitals (LCP, CLS, INP) et Lighthouse.
  • Les images et le JavaScript sont les premiers leviers de poids.
  • Le cache et le bon format évitent de retélécharger pour rien.
  • Le SEO technique (titre, description, sitemap, robots) rend le site trouvable.
  • Les données structurées aident les moteurs à comprendre le contenu.
Web Vitals
Un petit ensemble d'indicateurs clés mesurant l'expérience réelle de chargement et d'interactivité.
LCP
Largest Contentful Paint : temps d'affichage du plus gros élément visible (cible ≤ 2,5 s).
CLS
Cumulative Layout Shift : mesure des sauts de mise en page imprévus (cible ≤ 0,1).
INP
Interaction to Next Paint : réactivité aux interactions (cible ≤ 200 ms).
Lazy-loading
Charger une ressource (image, iframe) seulement quand elle approche de l'écran.
Cache
Conserver une ressource pour ne pas la retélécharger à chaque visite.
Minification
Retirer espaces et caractères inutiles d'un fichier CSS/JS pour l'alléger.
Chemin critique
Les ressources nécessaires au premier affichage ; on cherche à le raccourcir.
SEO
Search Engine Optimization : optimiser un site pour les moteurs de recherche.
Sitemap
Un fichier listant les pages d'un site pour aider les moteurs à les découvrir.
robots.txt
Un fichier qui indique aux robots ce qu'ils peuvent ou non explorer.
Données structurées
Des annotations (schema.org) qui décrivent le contenu aux moteurs.
