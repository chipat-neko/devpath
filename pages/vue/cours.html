Vue.js : construire des interfaces réactives

Vue est un framework JavaScript progressif et réputé pour sa douceur d'apprentissage. On y décrit l'interface en fonction des données, et l'affichage suit tout seul. Ce cours (Vue 3, Composition API) te mène de la réactivité aux composants, jusqu'à l'écosystème (Router, Pinia).

Bien s'équiper

Les extensions VS Code pour Vue.js

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Vue.js

  • Vue - Official (Vue) — support officiel des fichiers .vue (ex-Volar).
  • ESLint (Microsoft) — qualité du code et règles Vue.
  • Prettier - Code formatter (Prettier) — mise en forme des composants.
  • Vue VSCode Snippets (sarah.drasner) — squelettes de composants.

Pour qui ?

Il faut connaître le JavaScript et les bases du HTML. Si tu as suivi le cours React, tu retrouveras des idées communes (composants, props, flux descendant) exprimées à la façon de Vue.

Ce que tu vas apprendre

De la réactivité à l'application

À la fin du cours, tu sauras

  • expliquer la réactivité et écrire un composant monofichier ;
  • utiliser le template et les directives (v-bind, v-if, v-for) ;
  • gérer l'état avec ref, computed et v-model ;
  • créer des composants (props, events, cycle de vie) et situer l'écosystème (Router, Pinia, Vite).

Pour qui, et pourquoi

Vue est l'un des trois grands frameworks front-end, très demandé et apprécié pour sa progressivité et sa clarté. Le connaître élargit tes possibilités d'emploi et complète idéalement ta maîtrise de React : deux approches du même problème, qui s'éclairent l'une l'autre.

Ce cours utilise Vue 3 et la Composition API (le style recommandé aujourd'hui). Les exemples se lisent comme du pseudo-code Vue : tu peux les comprendre sans rien installer, puis créer un vrai projet avec npm create vue@latest pour pratiquer.

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Réactivité : l'affichage suit les données.
  • ref / computed pour l'état ; v-model pour les formulaires.
  • Directives v-bind, v-if, v-for dans le template.
  • Composant monofichier .vue : template + script + style.
  • Écosystème : Vue Router, Pinia, Vite.
Réactivité
L'interface se met à jour quand les données changent.
ref
Référence réactive, lue et écrite via .value.
computed
Valeur dérivée, recalculée automatiquement.
Directive
Attribut spécial v-* (ex. v-for).
v-model
Liaison bidirectionnelle d'un champ de formulaire.
Pinia
Gestion d'état centralisée pour Vue.
