Module 4 · Productivité avancée — Leçon 08

Créer ses propres snippets

~34 min Intermédiaire Leçons 01 à 07 conseillées

À la fin de cette leçon, tu sauras

  • utiliser les snippets intégrés et Emmet ;
  • créer un snippet personnel (prefix, body, description) ;
  • ajouter des tabstops $1, des placeholders et des choix ;
  • insérer des variables comme la date ou le nom du fichier.
Sommaire de la leçon

Il y a du code qu'on réécrit sans cesse : l'en-tête d'un composant, un bloc try/catch, la structure d'un test. Les snippets (ou « fragments ») sont des morceaux de code prêts à insérer : tu tapes un petit mot-clé, tu appuies sur Tab, et le bloc complet apparaît, le curseur déjà placé au bon endroit. VS Code en fournit beaucoup ; surtout, tu peux créer les tiens.

Les snippets déjà présents

Chaque langage apporte ses snippets, enrichis par les extensions. Quand tu tapes, l'auto-complétion (leçon 02) affiche parfois une petite icône de fragment : choisis-la et le bloc se déploie. Pour le HTML et le CSS, VS Code intègre aussi Emmet : tape ul>li*3 puis Tab, tu obtiens une liste à trois éléments. C'est un langage d'abréviations très puissant ; retiens surtout que ! puis Tab génère le squelette complet d'une page HTML.

Créer son premier snippet

Ouvre la palette (Ctrl+Shift+P) et cherche « Configurer les snippets utilisateur » (Configure User Snippets). Choisis un langage (ex. javascript.json) pour un snippet propre à ce langage, ou « Nouveau fichier de snippets globaux » (.code-snippets) pour tous les langages. Décortiquons les quatre clés :

  • le nom (« Journaliser… ») s'affiche dans la liste d'auto-complétion ;
  • prefix : le mot que tu tapes pour déclencher le snippet (log) ;
  • body : le code inséré, sous forme de tableau de lignes (une chaîne par ligne) ;
  • description : le texte d'aide affiché à côté.

Enregistre : le snippet est immédiatement disponible dans les fichiers du langage choisi. Tape log + Tab.

Où vivent tes snippets ?

Les snippets utilisateur sont rangés dans ton profil VS Code : ils te suivent d'un projet à l'autre. Un fichier .code-snippets placé dans le dossier .vscode/ d'un projet, lui, est partagé avec l'équipe via Git — comme les réglages et les tâches qu'on verra ensuite.

Les tabstops : guider le curseur

C'est là que les snippets deviennent puissants. Les marques $1, $2, $3… sont des tabstops : après insertion, le curseur se pose sur $1 ; chaque Tab le fait sauter au suivant. La marque spéciale $0 désigne la position finale du curseur (là où tu sors du snippet).

  • Placeholder : ${1:Nom} pré-remplit le tabstop avec un texte par défaut, déjà sélectionné (tu tapes pour l'écraser, ou Tab pour le garder) ;
  • Miroir : réutilise le même numéro ($1 à deux endroits) et les deux se remplissent en même temps quand tu tapes ;
  • Choix : ${1|get,post,put|} propose un menu déroulant de valeurs.

Piège fréquent

Ne commence pas ta numérotation à $0. Ce n'est pas le premier arrêt mais la position finale : où qu'il soit écrit dans le body, VS Code y amène le curseur en dernier, après $1, $2…, et la saisie guidée s'y termine. Numérote donc tes arrêts à partir de $1 et réserve $0 à l'endroit où tu veux finir — ici, l'intérieur de la fonction.

Les variables : du contexte automatique

Un snippet peut aussi insérer des valeurs calculées par l'éditeur, appelées variables (préfixées par $) :

  • $TM_FILENAME / $TM_FILENAME_BASE : nom du fichier (avec / sans extension) ;
  • $CURRENT_YEAR, $CURRENT_MONTH, $CURRENT_DAY : la date du jour ;
  • $TM_SELECTED_TEXT : le texte sélectionné avant de déclencher le snippet (pour l'envelopper) ;
  • $CLIPBOARD : le contenu du presse-papiers.

Cas réel — l'en-tête de composant standardisé

Une équipe front-end impose que chaque composant commence par le même en-tête : nom, auteur, année, et un squelette de fonction. Recopié à la main, cet en-tête était toujours un peu différent d'un développeur à l'autre ; les revues de code s'écharpaient sur des broutilles de mise en forme. La lead crée un snippet comp dans un fichier .vscode/react.code-snippets versionné : prefix = comp, un body avec ${1:Nom} en miroir (nom du fichier ET nom de la fonction), l'année via $CURRENT_YEAR, et $0 dans le corps. Désormais chacun tape comp + Tab : l'en-tête est identique pour tout le monde, sans effort. Les revues se concentrent sur la logique, plus sur la forme.

Générer le snippet sans écrire de JSON

Pas envie d'échapper les guillemets à la main ? Sélectionne un bout de code existant, puis cherche dans la palette une commande comme « Generate Snippet from Selection » (fournie par des extensions dédiées). Elle pré-remplit le body pour toi ; tu n'as plus qu'à ajouter les tabstops $1.

Glossaire

Snippet (fragment)
Bloc de code prêt à insérer, déclenché par un mot-clé suivi de Tab.
prefix
Le mot qu'on tape pour appeler le snippet.
body
Le code inséré, décrit sous forme de tableau de lignes en JSON.
Tabstop
Arrêt du curseur ($1, $2…) où l'on saute avec Tab ; $0 est l'arrêt final.
Placeholder
Tabstop avec une valeur par défaut : ${1:texte}.
Miroir
Même numéro de tabstop répété : les deux se remplissent simultanément.
Variable de snippet
Valeur fournie par l'éditeur : $CURRENT_YEAR, $TM_FILENAME, $CLIPBOARD…
Emmet
Langage d'abréviations intégré pour générer du HTML/CSS (ex. ul>li*3).

Récap et vérification

  • Un snippet insère un bloc répétitif via un mot-clé + Tab ; Emmet fait de même pour HTML/CSS.
  • On les crée via « Configurer les snippets utilisateur » : clés prefix, body (tableau de lignes), description.
  • Les tabstops $1, $2, $0 guident le curseur ; ${1:x} pré-remplit, un numéro répété fait un miroir, ${1|a,b|} propose un choix.
  • Les variables ($CURRENT_YEAR, $TM_FILENAME…) injectent du contexte ; un .code-snippets dans .vscode/ se partage avec l'équipe.

Vérifie ta compréhension

  1. Quelles sont les trois clés essentielles d'un snippet ?
  2. À quoi servent $1 et $0 dans un body ?
  3. Comment insérer automatiquement l'année courante ?

Exercices

Exercice 1Échauffement

Écris un snippet minimal dont le préfixe est err et qui insère console.error(''); avec le curseur entre les guillemets.

Voir une solution

Le curseur se pose d'abord sur $1 (entre les guillemets) ; un Tab l'amène à $0, sur la ligne suivante. Enregistre le fichier et tape err + Tab dans un fichier .js.

Exercice 2Application

Crée un snippet fetchjson qui écrit un appel fetch où l'URL est un placeholder par défaut /api, et laisse le curseur final dans le .then.

Voir une solution

${1:/api} insère /api déjà sélectionné : tu tapes pour le remplacer, ou Tab pour le garder. $0 place le curseur final à l'intérieur du second .then, prêt à traiter data.

Exercice 3Défi

Conçois un snippet route qui commence par un choix de méthode HTTP (get, post, put, delete) et réutilise le nom de la ressource à deux endroits.

Voir une solution

${1|get,post,put,delete|} ouvre un menu déroulant de méthodes. ${2:ressource} apparaît deux fois avec le même numéro 2 : c'est un miroir, les deux occurrences se remplissent ensemble quand tu tapes le nom de la ressource. $0 pose le curseur final dans le corps du handler.
