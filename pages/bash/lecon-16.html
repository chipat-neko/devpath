Module 04 · Maîtrise du shell — Leçon 16

Projet : un script de sauvegarde robuste

~38 min Avancé Leçon 15 recommandée

À la fin de cette leçon, tu sauras

  • assembler tout le cours en un vrai outil : mode strict, tableau, journalisation ;
  • créer une archive tar.gz horodatée à partir de plusieurs sources ;
  • faire tourner les sauvegardes pour ne garder que les N plus récentes ;
  • planifier l'exécution automatique avec cron.
Sommaire de la leçon

Onze leçons d'outils, trois de maîtrise : il est temps de tout réunir dans un projet qui compte vraiment. La sauvegarde est le script d'administration par excellence — celui qui tourne seul, la nuit, et qu'on ne regarde que le jour où l'on en a besoin. Il doit donc être irréprochable : échouer proprement, ne rien laisser traîner, tracer ce qu'il fait, et ne jamais saturer le disque. On va le construire brique par brique.

Ce que tu vas construire

Un script sauvegarde.sh qui archive une liste de dossiers dans un fichier tar.gz horodaté, journalise chaque étape à l'écran et dans un fichier, puis supprime les archives les plus anciennes pour n'en garder qu'un nombre fixé. Enfin, on le planifie avec cron pour qu'il s'exécute chaque nuit.

Le flux de bout en bout

Avant de coder, visualisons la chaîne : des sources, une archive datée, une rotation, un journal. Chaque étape correspond à une brique déjà vue dans le cours.

Brique 1 — le préambule et les réglages

On démarre par le squelette robuste de la leçon 11, puis on déclare la configuration dans des variables et un tableau de sources (leçon 14). Regrouper les réglages en tête rend le script lisible et modifiable sans fouiller le code.

Brique 2 — journaliser avec tee

Une sauvegarde qui tourne sans témoin doit laisser une trace. On reprend la fonction log() de la leçon 11 (horodatage, envoi sur >&2), et on la double avec tee -a (leçon 15) pour écrire aussi dans un fichier journal.

Astuce

Le mkdir -p est idempotent : il crée le dossier s'il manque et ne se plaint pas s'il existe déjà. Un bon script de sauvegarde peut être relancé cent fois sans effet de bord : c'est la marque d'un outil de production.

Brique 3 — l'archive tar horodatée

Le cœur du script : tar regroupe les sources en une archive, -z la compresse (gzip), -c crée, -f nomme le fichier. Le nom contient la date : chaque exécution produit une archive distincte, sans écraser la précédente.

Note le "${sources[@]}" entre guillemets : chaque dossier reste un argument distinct, même si son chemin contient une espace. Les erreurs de tar sont ajoutées au journal via 2>>. Le if tar …; then teste le succès : sous set -e, c'est ainsi qu'on réagit à un échec au lieu de subir un arrêt brutal.

Brique 4 — la rotation

Sans ménage, le dossier de sauvegardes gonfle jusqu'à saturer le disque. La rotation ne garde que les garder archives les plus récentes. On liste les archives triées par date (ls -1t, la plus récente d'abord), on saute les garder premières, et on supprime le reste.

Piège fréquent

Une sauvegarde qu'on ne restaure jamais n'est pas une sauvegarde. Vérifie régulièrement qu'une archive s'ouvre bien : tar -tzf archive.tar.gz liste son contenu sans rien extraire. Le jour de l'incident est le pire moment pour découvrir que le fichier était corrompu ou vide.

Brique 5 — planifier avec cron

Un dernier maillon : l'automatisation. cron exécute des commandes à heure fixe. On édite sa table avec crontab -e et on décrit l'horaire avec cinq champs.

Cas réel

La règle de sauvegarde 3-2-1 guide les pros : 3 copies des données, sur 2 supports différents, dont 1 hors site. Notre script couvre la copie locale ; en production, on ajoute une étape rsync ou rclone vers un serveur distant ou un stockage objet. C'est aussi pourquoi cron compte : la meilleure sauvegarde est celle qui se fait toute seule, sans dépendre de la mémoire d'un humain un vendredi soir.

Le script complet

Voici les cinq briques assemblées. Lis-le en repérant chaque leçon du cours : mode strict (11), tableau (14), fonction et >&2 (08, 11), tee et redirections (15), tar/ls/xargs (04, 10).

Antisèche

Glossaire

tar
Regroupe plusieurs fichiers en une archive ; -c crée, -z compresse (gzip), -f nomme, -t liste, -x extrait.
Archive horodatée
Fichier de sauvegarde dont le nom contient la date (date +%F), pour ne pas écraser les précédentes.
Rotation
Suppression des sauvegardes les plus anciennes pour n'en conserver qu'un nombre fixé, afin de borner l'espace disque.
Idempotent
Se dit d'une opération relançable sans effet de bord : mkdir -p ne casse pas si le dossier existe déjà.
cron / crontab
Planificateur de tâches Unix ; crontab -e édite la table, cinq champs décrivent l'horaire avant la commande.
xargs -r
Construit une commande à partir de l'entrée ; -r ne la lance pas si l'entrée est vide (pas de rm à blanc).
Règle 3-2-1
3 copies, sur 2 supports, dont 1 hors site : le garde-fou classique contre la perte de données.
du -h
Affiche la taille d'un fichier ou dossier en unités lisibles (Ko, Mo, Go).

Récap et vérification

  • Un script de production réunit : préambule strict, configuration groupée, journal, action, ménage.
  • tar -czf crée l'archive ; un nom horodaté évite d'écraser les précédentes.
  • La rotation (ls -1t | tail -n +N | xargs -r rm) borne l'espace disque.
  • Journaliser avec tee -a pour voir et garder une trace ; vérifier une archive avec tar -tzf.
  • cron automatise : la meilleure sauvegarde est celle qui se lance seule.

Vérifie ta compréhension

  1. Pourquoi horodater le nom de l'archive plutôt que réutiliser un nom fixe ?
  2. À quoi sert xargs -r dans l'étape de rotation ?
  3. Que signifient les cinq champs d'une ligne cron comme 0 2 * * * ?

Mini-projet fil rouge — un état du stock

Pour clore ce cours, écrivons un petit script d'état du stock. Il réunit un tableau associatif, une fonction, la boucle for sur les clés, l'arithmétique $(( )) et printf — l'essentiel de Bash réuni, en mode robuste (set -euo pipefail).

Ce que tu vas construire

Un stock (article → quantité) dans un tableau associatif, une fonction qui l'affiche en colonnes alignées et calcule le nombre total d'articles.

Étapes

Le préambule robuste

Commence par le shebang et set -euo pipefail pour échouer vite et proprement.

Le stock

Déclare un tableau associatif avec declare -A stock=( [stylo]=10 ... ).

La fonction d'affichage

Écris une fonction qui parcourt les clés avec for article in "${!stock[@]}".

Aligner et cumuler

Affiche chaque ligne avec printf '%-10s %3d\n' et cumule avec total=$(( total + qte )).

Le total

Affiche le nombre total d'articles, puis appelle la fonction.
