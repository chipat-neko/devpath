Bash : le terminal et les scripts

Derrière chaque interface graphique se cache un terminal, et c'est souvent le chemin le plus rapide. Avec Bash, tu navigues dans tes fichiers, tu enchaînes des commandes comme des briques, et tu automatises les tâches répétitives en quelques lignes de script. Ce cours part de la toute première commande et te mène jusqu'à tes propres scripts robustes.

Bien s'équiper

Les extensions VS Code pour Bash

Avant de te lancer, ouvre le panneau Extensions de VS Code (Ctrl+Shift+X) et installe ces incontournables : ils apportent la coloration, l'auto-complétion (IntelliSense) et les outils adaptés à ce cours.

À installer pour Bash

  • Bash IDE (Mads Hartmann) — auto-complétion et survol des commandes.
  • ShellCheck (Timon Wong) — détecte les erreurs des scripts shell.
  • shell-format (foxundermoon) — met les scripts en forme.
  • Bash Debug (rogalmic) — débogueur pas à pas pour Bash.

Aucun prérequis

Pas besoin de savoir programmer. Il te suffit d'un terminal : déjà présent sur macOS et Linux, et disponible sur Windows via WSL ou Git Bash. Les commandes de ce cours fonctionnent partout où Bash est installé.

Ce que tu vas apprendre

De la première commande au script automatisé

À la fin du cours, tu sauras

  • te repérer et naviguer dans le système de fichiers (pwd, ls, cd, chemins) ;
  • créer, copier, déplacer, supprimer et inspecter fichiers et dossiers ;
  • chercher et filtrer du texte, et chaîner des commandes avec les pipes et les redirections ;
  • écrire de vrais scripts : variables, arguments, conditions, boucles, fonctions et bonnes pratiques de robustesse.

Pour qui, et pourquoi

Ce cours s'adresse à tous ceux qui veulent gagner en autonomie sur leur machine : développeurs débutants, étudiants, administrateurs en herbe ou curieux. Dès que tu touches à Git, à un serveur, à Docker ou au déploiement, le terminal devient incontournable — autant l'apprivoiser pour de bon.

Chaque leçon montre des commandes que tu peux reproduire chez toi, avec leur sortie en commentaire. On part de ce que tu connais (chercher un fichier, ranger un dossier) pour aller vers l'automatisation par scripts.

Récapitulatif

À retenir & glossaire

Les points clés du cours, puis les termes essentiels à connaître.

À retenir

  • Lire une variable avec $nom ; pas d'espace autour du = à l'affectation.
  • Première ligne : le shebang #!/usr/bin/env bash.
  • Mode robuste : set -euo pipefail.
  • Substitution de commande $(...) ; code de retour $?.
  • Tester avec [[ ... ]] ; boucler avec for ... do ... done.
  • Rendre exécutable : chmod +x.
  • Enchaîner les commandes par des pipes (|).
Variable
Lue avec $nom ; affectée sans $ (nom=valeur).
Shebang
Première ligne #! désignant l'interpréteur du script.
$?
Code de retour de la dernière commande (0 = succès).
Substitution de commande
Capturer une sortie avec $(...).
Pipe (|)
Envoie la sortie d'une commande à l'entrée de la suivante.
Tableau associatif
Clé-valeur, déclaré avec declare -A.
Redirection
Diriger l'entrée/sortie (>, <, >>).
set -e
Arrêter le script à la première commande en échec.
