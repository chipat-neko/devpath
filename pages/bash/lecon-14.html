Les tableaux : indexés et associatifs

~35 min Intermédiaire Leçon 7 recommandée

À la fin de cette leçon, tu sauras

  • créer et lire un tableau indexé : ${arr[@]}, ${#arr[@]}, ${!arr[@]} ;
  • parcourir un tableau avec le bon quoting et en extraire une tranche ;
  • remplir un tableau sans risque à partir d'un fichier ou d'une commande avec mapfile ;
  • utiliser un tableau associatif (clé-valeur) avec declare -A.
Sommaire de la leçon

Jusqu'ici, une variable Bash tient une valeur. Mais on a souvent besoin d'une collection : la liste des fichiers à traiter, les régions d'un déploiement, un compteur par catégorie. Bash offre pour cela deux structures : les tableaux indexés (numérotés à partir de 0) et les tableaux associatifs (des clés-valeurs, comme un dictionnaire). Bien maniés, ils remplacent des tas de bricolages fragiles à base de chaînes.

Créer et lire un tableau indexé

Un tableau indexé se déclare entre parenthèses, les éléments séparés par des espaces. On lit un élément par son indice, et l'ensemble avec [@].

Retiens les quatre expansions clés : ${arr[i]} un élément, ${arr[@]} tous, ${#arr[@]} le nombre, ${!arr[@]} les indices. Un tableau peut être « creux » : rien n'oblige les indices à se suivre.

Parcourir : le quoting fait tout

La boucle canonique parcourt "${arr[@]}". Les guillemets sont obligatoires : sans eux, un élément contenant un espace serait recoupé en plusieurs mots, et la boucle itérerait de travers.

Note

[@] et [*] se ressemblent mais diffèrent entre guillemets : "${arr[@]}" produit un mot par élément (ce que tu veux pour une boucle), tandis que "${arr[*]}" colle tous les éléments en une seule chaîne, séparés par le premier caractère de IFS. Utilise [*] seulement pour afficher un tableau joint, jamais pour itérer.

Tranches d'un tableau

On extrait un sous-ensemble avec la syntaxe ${arr[@]:début:nombre}, cousine de la sous-chaîne vue à la leçon précédente.

Remplir sans risque : mapfile

Écueil classique : for ligne in $(cat fichier). Cette forme découpe sur chaque espace, pas sur les lignes, et casse dès qu'un nom contient une espace. La bonne méthode est mapfile (alias readarray), qui lit un flux ligne par ligne dans un tableau.

Le drapeau -t (trim) enlève le \n de fin de chaque ligne : sans lui, chaque élément traînerait un retour à la ligne. La construction < <(commande) (substitution de processus, détaillée à la leçon 15) branche la sortie d'une commande là où mapfile attend un fichier.

Tableaux associatifs

Un tableau associatif fait correspondre des clés (texte) à des valeurs : c'est le dictionnaire de Bash. Il faut le déclarer explicitement avec declare -A (majuscule).

La logique est la même que pour les tableaux indexés, mais ${!ages[@]} renvoie ici des clés textuelles au lieu d'indices numériques. L'ordre de parcours n'est pas garanti : un tableau associatif n'est pas trié.

Cas réel

Compter les codes de réponse dans un log d'accès web est le cas d'école du tableau associatif. On lit le fichier ligne à ligne, on extrait le code HTTP, et on incrémente compte[$code] : declare -A compte; while read -r code; do (( compte[$code]++ )); done. À la fin, une boucle sur "${!compte[@]}" affiche « 200 : 18432, 404 : 57, 500 : 3 ». Sans tableau associatif, il faudrait trier puis uniq -c — le tableau garde le comptage en mémoire, prêt à être trié, filtré ou comparé à un seuil d'alerte.

Pièges fréquents

Piège fréquent

Écrire ${arr} sans indice pour désigner « tout le tableau ». En réalité, ${arr} vaut ${arr[0]} : seulement le premier élément ! Pour l'ensemble, il faut "${arr[@]}".

Piège fréquent

Oublier declare -A avant un tableau associatif. Sans lui, ages[alice]=30 est interprété comme un tableau indexé : la clé alice est évaluée arithmétiquement à 0, et toutes tes « clés » écrasent l'indice 0. La déclaration -A n'est pas optionnelle.

Pour aller plus loin

Pour aller plus loin

Explore declare -a (déclaration explicite d'un tableau indexé), la copie copie=("${source[@]}"), le passage d'un tableau à une fonction via local -n ref=$1 (nameref, Bash 4.3+), et ${arr[@]/motif/remp} qui applique un remplacement à chaque élément.

Antisèche

Glossaire

Tableau indexé
Collection ordonnée d'éléments repérés par un indice entier, à partir de 0 : arr=(a b c).
Tableau associatif
Collection clé-valeur (dictionnaire), déclarée avec declare -A ; les clés sont du texte.
${arr[@]}
Tous les éléments ; entre guillemets, un mot par élément (espaces préservés).
${#arr[@]}
Nombre d'éléments du tableau (pas le plus grand indice).
${!arr[@]}
Les indices (tableau indexé) ou les clés (tableau associatif).
[@] vs [*]
Entre guillemets, [@] = un mot par élément ; [*] = une seule chaîne jointe par IFS.
mapfile / readarray
Lit un flux ligne par ligne dans un tableau ; -t retire le saut de ligne final.
declare -A
Déclare un tableau associatif : obligatoire avant toute affectation par clé.

Récap et vérification

  • Indexé : arr=(a b c), éléments dès l'indice 0 ; ${arr[@]}, ${#arr[@]}, ${!arr[@]}.
  • Toujours parcourir avec "${arr[@]}" entre guillemets pour préserver les espaces.
  • "${arr[@]:i:n}" extrait une tranche ; arr+=(x) ajoute à la fin.
  • mapfile -t t < f remplit un tableau ligne par ligne, sans le piège de $(cat).
  • Associatif : declare -A obligatoire ; clés via ${!m[@]}, ordre non garanti.
  • ${arr} seul ne vaut que le premier élément, pas tout le tableau.

Vérifie ta compréhension

  1. Pourquoi faut-il des guillemets autour de "${arr[@]}" dans une boucle ?
  2. Qu'est-ce qui distingue declare -A de declare -a ?
  3. Pourquoi préférer mapfile à for x in $(cat fichier) ?
