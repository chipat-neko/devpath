# docs/reference/ — les documents de référence

Ce qui ne change pas à chaque chantier : l'identité visuelle, le fonctionnement du système, et
les choix pédagogiques.

| Fichier | Ce que c'est | Quand l'ouvrir |
|---|---|---|
| `DESIGN_SYSTEM.md` | La direction artistique « éditorial-technique » et ses jetons (couleurs, typo, espacements) | **Avant toute modification de CSS ou de gabarit** |
| `paramettre.md` | Comment fonctionne le système (contenu d'un cours + tous les réglages), pour le réutiliser dans un autre projet | Pour comprendre `js/data.js`, ou avec le kit `starter/` |
| `rap_peda.md` | Rapport pédagogique : comparaison de sites de cours de programmation avec l'approche de Syntaxe | Pour les choix pédagogiques (le site de référence est pierre-giraud.com) |

Le kit de démarrage (`starter/`) renvoie à `paramettre.md` : garder ce nom et cet emplacement, ou
mettre à jour `starter/README.md` et `starter/js/data.js`.
