# docs/ — les documents du projet

Tout ce qui **décrit** le projet, sans en faire partie : les plans de travail, les audits, les
chantiers d'ajout de contenu et les documents de référence. Rien ici n'est chargé par le site.

| Dossier | Contenu | Quand l'ouvrir |
|---|---|---|
| [`chantiers/`](chantiers/EXPLICATION.md) | Les plans de travail de l'autonomie, CHANTIER-V4 à V17 | Pour savoir ce qui a été fait, pourquoi, et ce qui reste (le V16 est le plan courant) |
| [`audits/`](audits/EXPLICATION.md) | Audits, inventaire, rapport de la passe de sécurité | Pour comprendre d'où vient un chantier, ou vérifier un constat |
| [`enrichissements/`](enrichissements/EXPLICATION.md) | Les chantiers d'ajout de contenu (cours, leçons, projets) | Avant d'ajouter un cours : `NOUVEAUX-COURS.md` donne la méthode |
| [`reference/`](reference/EXPLICATION.md) | Direction artistique, guide de réutilisation, rapport pédagogique | Avant de toucher au style, ou pour réutiliser le système ailleurs |

L'état **actuel** du travail n'est pas ici mais dans [`../en-cours/`](../en-cours/EN-COURS.md).

citent souvent par leur seul nom (« CHANTIER-V16.md », « VERIF-FINALE.md ») : ils sont ici.*
