# docs/enrichissements/ — les chantiers d'ajout de contenu

Les plans qui ont **construit** le catalogue, de juin à août 2026 : ajouts de cours, de leçons,
de projets. Ils sont tous terminés ; ils restent utiles pour leur **méthode**.

| Fichier | Ce que c'est |
|---|---|
| **`NOUVEAUX-COURS.md`** | **La méthode d'ajout d'un cours** (data.js, cours.html, leçons, accent CSS, catalogue, logo…). **Toujours valable : à lire avant d'ajouter un cours.** |
| `ENRICHISSEMENT.md` | Enrichissement v1 : 6 cours, fils rouges, certificat et badges (site 69 → 75 cours) |
| `ENRICHISSEMENT-2.md` | Enrichissement v2 : fils rouges, 5 cours, modules avancés, audit qualité (75 → 80 cours) |
| `ENRICHISSEMENT-3.md` | Enrichissement v3 : enrichir chaque leçon, niveaux, plus de leçons (188 cases) |
| `PLAN-AMELIORATIONS.md` | Premier plan d'amélioration du site (QCM, exercices, cours ajoutés) |
| `GROS-PROJETS.md` | Feuille de route des « gros projets » (47 pages-outils interactives) |
| `PROJETS-GENERALISATION.md` | Un brief de projet contextualisé pour chaque cours (`js/projets-data.js`) |
| `RECAP-COMPLET.md` | Récapitulatif de tout ce qui a été construit jusqu'aux gros projets |
| `PROGRESSION.md` | Suivi de production du tout premier cours complet (JavaScript), leçon par leçon |

Les chiffres cités (nombre de cours, de leçons) sont ceux **de leur époque** : le site compte
aujourd'hui 90 cours et 1 540 leçons (`node tools/mesures-prompt.js` donne la mesure du jour).
