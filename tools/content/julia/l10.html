Julia excelle dans l'analyse de données : charger un jeu de données, le transformer, le résumer, le visualiser. Cette leçon te fait découvrir DataFrames.jl (l'équivalent de pandas), la lecture de CSV, les statistiques et le tracé de graphiques avec Plots.jl.

Les DataFrames

Un DataFrame est un tableau de données à colonnes nommées — le format de référence de l'analyse. On le crée à partir de colonnes.

Filtrer et transformer

On sélectionne des lignes, ajoute des colonnes, trie. La syntaxe rappelle les verbes de manipulation de données.

Lire un fichier CSV

Le package CSV lit et écrit des fichiers, directement vers/depuis un DataFrame.

Grouper et agréger

Le pattern « split-apply-combine » : grouper par une colonne, puis calculer par groupe. groupby + combine.

Statistiques de base

Avec le module Statistics et les fonctions de tableau, on résume rapidement.

Tracer un graphique

Avec Plots.jl, une figure se fait en une ligne. plot pour une courbe, scatter pour un nuage, bar pour des barres, histogram pour une distribution.

La convention ! : plot crée une figure, plot! ajoute à la figure existante.

Pièges fréquents

Piège fréquent

S'étonner du temps du premier tracé : Plots compile beaucoup au premier appel (le fameux « time to first plot »). C'est normal et ne se reproduit pas : les graphiques suivants sont instantanés dans la même session.

Pour aller plus loin

Pour aller plus loin

Pour des manipulations de données plus expressives, le package DataFramesMeta.jl (avec @chain) offre une syntaxe en pipeline proche du tidyverse de R. Et Makie.jl propose des visualisations interactives et de qualité publication.

Récap et vérification

  • Un DataFrame structure des données tabulaires ; on filtre, ajoute, trie.
  • CSV.read/CSV.write pour les fichiers ; groupby+combine pour agréger.
  • Statistics fournit mean, median, std, extrema.
  • Plots trace en une ligne ; plot! ajoute à une figure existante.
