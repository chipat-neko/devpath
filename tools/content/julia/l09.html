Un langage ne vaut que par son écosystème. Celui de Julia est jeune mais dynamique, et son gestionnaire de packages intégré, Pkg, est l'un des meilleurs qui soient : installation simple, environnements reproductibles. Cette leçon t'apprend à exploiter les milliers de packages de la communauté.

Le gestionnaire Pkg

Pkg est intégré au REPL : la touche ] ouvre le mode package, où l'on installe avec add. On peut aussi l'utiliser comme une bibliothèque.

Charger un package : using

using charge un package et rend ses fonctions disponibles. import est une variante plus stricte (il faut préfixer les noms).

Les environnements : reproductibilité

Atout majeur de Julia : chaque projet peut avoir son environnement isolé, décrit par deux fichiers. Project.toml liste les dépendances ; Manifest.toml fige les versions exactes. Quiconque récupère ces fichiers obtient le même environnement.

instantiate recrée à l'identique l'environnement d'un projet partagé : la reproductibilité scientifique.

Écrire son propre module

Pour organiser son code, on le regroupe dans un module. export rend des noms publics.

Les grandes bibliothèques

L'écosystème couvre tous les usages scientifiques. Quelques piliers à connaître :

  • DataFrames.jl : manipulation de données tabulaires (comme pandas).
  • Plots.jl / Makie.jl : visualisation.
  • DifferentialEquations.jl : résolution d'équations (référence mondiale).
  • Flux.jl : machine learning et réseaux de neurones.
  • JuMP.jl : optimisation mathématique.

Pièges fréquents

Piège fréquent

Tout installer dans l'environnement global (@v1.10) : avec le temps, il devient un fouillis de dépendances incompatibles. Crée un environnement par projet (activate) — c'est la bonne hygiène, et ça garantit la reproductibilité.

Pour aller plus loin

Pour aller plus loin

Pour partager une analyse, les notebooks Pluto.jl sont une merveille : réactifs (changer une cellule met à jour les autres) et reproductibles (les dépendances sont incluses dans le fichier). Une alternative moderne aux notebooks Jupyter.

Récap et vérification

  • Pkg (touche ]) installe les packages (add, status).
  • using charge un package ; import est plus strict.
  • Les environnements (Project.toml/Manifest.toml) garantissent la reproductibilité.
  • Écosystème riche : DataFrames, Plots, DifferentialEquations, Flux, JuMP.
