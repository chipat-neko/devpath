On sait lire et écrire des données ; il est temps de leur donner vie avec des fonctions. En Clojure — langage fonctionnel — la fonction est l'unité centrale de construction. On en définit, on en passe en argument, on en renvoie. Cette leçon couvre les fonctions nommées et anonymes, les liaisons locales, les conditions, et un premier pas vers l'ordre supérieur.

Définir une fonction avec defn

defn définit une fonction nommée. Sa forme : le nom, un vecteur de paramètres entre crochets [], puis le corps. La dernière expression évaluée est la valeur de retour — pas de return.

str concatène en chaîne tout ce qu'on lui passe. Remarque l'absence de point-virgule, d'accolades, de return : tout est expression.

Les fonctions anonymes avec fn

Pour une fonction jetable, fn crée une fonction sans nom. Très utile pour la passer directement à une autre fonction.

La syntaxe #(…) est un raccourci : % (ou %1) désigne le premier argument, %2 le deuxième, etc. Pratique pour les petites fonctions.

Les liaisons locales avec let

let introduit des noms locaux, valables uniquement dans son corps. On passe un vecteur de paires nom/valeur, puis on utilise ces noms.

Les liaisons sont séquentielles : r2 peut utiliser r. Et elles sont immuables — pi ne changera pas. let ne crée pas de variables modifiables ; il nomme des valeurs pour clarifier le calcul.

Décider : if, when, cond

if prend une condition, une branche « vrai » et une branche « faux ». C'est une expression : elle renvoie une valeur.

Dans Clojure, seuls false et nil sont « faux » ; tout le reste est vrai (y compris 0 et la chaîne vide). Le :else de cond est simplement un keyword toujours vrai, conventionnellement utilisé comme cas par défaut.

Une même fonction peut accepter plusieurs nombres d'arguments (arités). On regroupe chaque cas dans ses propres parenthèses.

Pièges fréquents

Piège fréquent

Croire que 0 est « faux » comme dans d'autres langages. En Clojure, seuls false et nil sont faux : (if 0 "vrai" "faux") renvoie "vrai". C'est une source classique de surprise pour qui vient de C ou JavaScript.

Pour aller plus loin

Pour aller plus loin

Clojure n'a pas de boucle for impérative classique pour itérer en modifiant un compteur. À la place, on combine recur (récursion sans débordement de pile), map/reduce, ou la macro doseq pour les effets de bord. Penser « transformer une collection » plutôt que « répéter en mutant » est le réflexe à acquérir.

Récap et vérification

  • defn définit une fonction nommée ; fn (ou #(…)) une fonction anonyme.
  • La dernière expression est la valeur de retour ; pas de return.
  • let crée des liaisons locales immuables.
  • if/when/cond décident ; seuls false et nil sont faux.

Vérifie ta compréhension

  1. Comment une fonction Clojure renvoie-t-elle sa valeur ?
  2. Que vaut (if 0 "a" "b") et pourquoi ?
  3. Écris #(* % %) sous la forme fn équivalente.
