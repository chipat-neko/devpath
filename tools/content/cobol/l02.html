Tout programme COBOL suit une architecture rigide et immuable : quatre divisions, toujours dans le même ordre. Cette structure peut sembler lourde, mais elle rend n'importe quel programme COBOL prévisible : tu sais toujours où chercher. Comprendre ces divisions, c'est avoir la carte de tout programme.

Les quatre divisions

Dans l'ordre obligatoire : IDENTIFICATION (le nom du programme), ENVIRONMENT (le lien avec la machine et les fichiers), DATA (toutes les données), PROCEDURE (les instructions). Les deux premières sont souvent courtes ; le travail se concentre dans DATA et PROCEDURE.

IDENTIFICATION : la carte d'identité

Elle contient au minimum le PROGRAM-ID. On peut y ajouter des commentaires documentaires (AUTHOR, DATE-WRITTEN), aujourd'hui purement informatifs.

DATA : là où vivent les données

La division DATA déclare toutes les données avant de les utiliser. Sa section la plus courante est WORKING-STORAGE, qui contient les variables de travail. (Les données de fichiers iront dans FILE SECTION, vue plus tard.)

Le niveau 01 désigne une donnée de premier niveau ; la clause PIC décrit son format (leçon 3).

PROCEDURE : sections et paragraphes

La division PROCEDURE contient la logique, organisée en paragraphes (et éventuellement en sections). Un paragraphe est un bloc nommé d'instructions : c'est l'unité qu'on appelle avec PERFORM (l'équivalent d'une fonction).

Le format à colonnes

Le COBOL traditionnel impose un format fixe hérité des cartes perforées : les colonnes 1 à 6 sont réservées (numéros de ligne), la colonne 7 sert aux indicateurs (un * = commentaire), la zone A (colonnes 8-11) reçoit les divisions, sections et niveaux 01, et la zone B (colonnes 12-72) le reste.

Le format libre (option -free) supprime ces contraintes : pratique pour apprendre, mais le code historique respecte les colonnes.

Pièges fréquents

Piège fréquent

En format fixe, commencer une division ou un niveau 01 trop à droite (en zone B au lieu de la zone A) provoque une erreur de compilation. Si tu débutes, compile en -free pour t'affranchir des colonnes, puis apprends le format fixe pour lire l'existant.

Pour aller plus loin

Pour aller plus loin

La division ENVIRONMENT prend tout son sens avec les fichiers : c'est là, dans FILE-CONTROL, qu'on associe un nom logique de fichier à un fichier physique du système. Nous la retrouverons à la leçon 7.

Récap et vérification

  • Quatre divisions, toujours dans l'ordre : IDENTIFICATION, ENVIRONMENT, DATA, PROCEDURE.
  • WORKING-STORAGE (dans DATA) contient les variables de travail.
  • La logique s'organise en paragraphes, appelés par PERFORM.
  • Le format fixe réserve des colonnes (zones A et B) ; le format libre les ignore.

Vérifie ta compréhension

  1. Cite les quatre divisions dans l'ordre.
  2. Dans quelle section déclare-t-on les variables de travail ?
  3. Qu'est-ce qu'un paragraphe en COBOL ?
