Un programme doit décider et répéter. COBOL le fait avec IF et EVALUATE pour les conditions, et surtout avec PERFORM — un verbe central qui sert à la fois à appeler un paragraphe (comme une fonction) et à construire des boucles. Maîtriser PERFORM, c'est maîtriser la structure d'un programme COBOL.

IF / ELSE

La condition s'écrit lisiblement. On termine la structure par END-IF (recommandé) plutôt que par un point, pour éviter les ambiguïtés.

Les opérateurs s'écrivent en symboles (>, <, =) ou en toutes lettres (GREATER THAN, EQUAL TO, NOT, AND, OR).

EVALUATE : le switch de COBOL

Pour comparer une valeur à plusieurs cas, EVALUATE est plus clair qu'une cascade de IF.

THRU exprime un intervalle ; WHEN OTHER est le cas par défaut.

Les conditions nommées (niveau 88)

Idiome très « COBOL » : on donne un nom à une condition avec le niveau 88. Le code devient auto-documenté.

PERFORM : appeler un paragraphe

Sous sa forme la plus simple, PERFORM nom-paragraphe exécute ce paragraphe puis revient — exactement comme un appel de fonction.

PERFORM UNTIL : la boucle

PERFORM ... UNTIL condition répète un paragraphe (ou un bloc) jusqu'à ce que la condition devienne vraie.

PERFORM VARYING : la boucle compteur

Pour une boucle indexée, VARYING gère l'initialisation et l'incrément en une ligne — l'équivalent d'un for.

Pièges fréquents

Piège fréquent

Mélanger les points et les END-IF/END-PERFORM : un point clôt toutes les structures ouvertes d'un coup. Dans le code moderne, préfère les END-... explicites et réserve le point à la fin de la phrase complète.

Pour aller plus loin

Pour aller plus loin

Tu croiseras du GO TO dans le vieux code : il saute à un paragraphe sans retour. Il rend le programme difficile à suivre (« code spaghetti ») ; le COBOL structuré moderne le bannit au profit de PERFORM.

Récap et vérification

  • IF/ELSE/END-IF et EVALUATE (le switch) gèrent les décisions.
  • Les conditions nommées niveau 88 rendent le code auto-documenté.
  • PERFORM nom appelle un paragraphe ; PERFORM UNTIL et VARYING bouclent.
  • Préfère les END-... aux points pour délimiter les structures.
