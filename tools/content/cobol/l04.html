Décrire des données, c'est bien ; les transformer, c'est le travail réel. COBOL propose des verbes dédiés, lisibles comme des phrases : MOVE pour copier, COMPUTE et les verbes arithmétiques pour calculer. Cette leçon te donne les outils du traitement.

MOVE : copier une donnée

MOVE source TO destination copie une valeur. Si les formats diffèrent, COBOL applique des règles de cadrage : les nombres s'alignent sur la virgule, le texte se cale à gauche.

On peut copier vers plusieurs cibles : MOVE 0 TO A B C.

COMPUTE : l'arithmétique algébrique

COMPUTE ressemble aux autres langages : une formule avec +, -, *, / et ** (puissance).

Les verbes arithmétiques

COBOL propose aussi des verbes « en anglais » : ADD, SUBTRACT, MULTIPLY, DIVIDE. Plus verbeux que COMPUTE, mais très explicites — et omniprésents dans le code existant.

La clause GIVING place le résultat dans une autre variable sans modifier les opérandes.

L'arrondi avec ROUNDED

Par défaut, COBOL tronque les décimales excédentaires. Pour arrondir, on ajoute ROUNDED.

Détecter les débordements

Si un résultat ne tient pas dans le champ destination, on peut le détecter avec ON SIZE ERROR — précieux en finance, où une troncature silencieuse serait catastrophique.

Formater pour l'affichage

On reprend l'édition de la leçon 3 : calculer sur un champ numérique pur, puis MOVE vers un champ édité pour présenter le résultat.

Les $ flottants placent le symbole monétaire juste devant le premier chiffre.

Pièges fréquents

Piège fréquent

La troncature silencieuse : si SOLDE est PIC 9(3) et que le calcul donne 1250, COBOL garde « 250 » sans broncher. Dimensionne tes champs avec marge et utilise ON SIZE ERROR pour les montants sensibles.

Pour aller plus loin

Pour aller plus loin

COBOL gère nativement le décimal exact (pas de flottant binaire approximatif) : c'est pourquoi la finance lui fait confiance. 0,10 + 0,20 y vaut exactement 0,30, contrairement à beaucoup de langages.

Récap et vérification

  • MOVE source TO cible copie, avec des règles de cadrage.
  • COMPUTE calcule algébriquement ; ADD/SUBTRACT/MULTIPLY/DIVIDE sont les verbes équivalents.
  • GIVING range le résultat ailleurs ; ROUNDED arrondit ; ON SIZE ERROR détecte les débordements.
  • On calcule sur un champ numérique, puis on MOVE vers un champ édité pour l'affichage.
