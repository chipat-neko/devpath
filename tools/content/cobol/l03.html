Si COBOL a une idée centrale, c'est la description précise des données. Chaque champ est décrit au caractère près par une clause PICTURE (abrégée PIC), qui dit son type, sa taille, ses décimales, son signe. Cette rigueur explique pourquoi COBOL est si fiable pour la finance : rien n'est laissé au hasard.

Les niveaux

Les données s'organisent par niveaux, indiqués par des numéros. Le niveau 01 commence une donnée principale ; des niveaux plus élevés (05, 10…) décrivent ses sous-parties. Cela crée une hiérarchie.

CLIENT est un groupe ; NOM, AGE, SOLDE sont ses champs élémentaires.

La clause PICTURE

Les symboles de base : 9 pour un chiffre, X pour un caractère quelconque, A pour une lettre. Le nombre entre parenthèses indique la répétition.

Ainsi PIC 9(5) équivaut à PIC 99999 : cinq positions numériques.

Décimales et signe

Le V marque une virgule décimale implicite (elle n'occupe pas de place, c'est une position logique). Le S indique un nombre signé.

Le V est crucial : il dit où sont les centimes sans ajouter de caractère.

Initialiser avec VALUE

La clause VALUE donne une valeur de départ. Pour le texte, on utilise des guillemets ; le mot SPACES remplit d'espaces, ZEROS de zéros.

Champs de groupe vs élémentaires

Un champ de groupe (qui a des sous-niveaux) n'a pas de PIC : sa taille est la somme de ses parties. On peut manipuler le groupe entier d'un coup — pratique pour copier un enregistrement complet.

L'édition pour l'affichage

Pour présenter un nombre (et non le calculer), on utilise des symboles d'édition : Z remplace les zéros de tête par des espaces, la virgule et le point ajoutent des séparateurs.

Pièges fréquents

Piège fréquent

Confondre le V (virgule implicite, pour le calcul) et le . (point réel, pour l'affichage). Un champ PIC 9(4)V99 sert aux calculs ; un champ PIC 9(4).99 sert à l'affichage et ne doit pas être utilisé en arithmétique.

Pour aller plus loin

Pour aller plus loin

La clause USAGE (par ex. COMP-3, le « packed decimal ») contrôle le stockage interne des nombres pour gagner de la place et de la vitesse : omniprésente dans le code de production, c'est un détail à connaître pour lire l'existant.

Récap et vérification

  • Les niveaux (01, 05…) créent une hiérarchie de données.
  • PIC décrit le format : 9 chiffre, X caractère, A lettre ; (n) répète.
  • V = virgule implicite, S = signé ; VALUE initialise.
  • Les symboles d'édition (Z, ,, .) formatent un nombre pour l'affichage.
