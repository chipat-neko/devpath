OCaml est un langage fonctionnel né en France (à l'INRIA, années 1990), réputé pour marier trois qualités rares : un système de types extrêmement puissant, une inférence de types qui t'évite de tout annoter, et des performances proches du C. Sa devise pourrait être « le fonctionnel pragmatique » : pur quand c'est utile, impératif quand il le faut.

OCaml a profondément influencé la programmation moderne. Rust lui doit ses types algébriques, son pattern matching et son Option ; le compilateur Rust lui-même fut d'abord écrit en OCaml. ReScript et F# en descendent directement. Apprendre OCaml, c'est comprendre les idées qui façonnent les langages d'aujourd'hui.

Installer et lancer OCaml

On installe OCaml via opam (son gestionnaire de paquets). Pour expérimenter, le REPL utop est idéal : on tape une expression suivie de ;; et on voit immédiatement sa valeur et son type inféré.

Remarque : le REPL affiche toujours le type (int, string) en plus de la valeur.

Ton premier programme

Dans un fichier .ml, on lie des valeurs avec let et on affiche avec print_endline. Le point d'entrée est simplement le code au niveau supérieur.

Le mot-clé let

En OCaml, let nom = valeur lie un nom à une valeur. Par défaut, ces liaisons sont immuables : on ne réaffecte pas, on crée de nouvelles valeurs. Le typage est inféré automatiquement.

Les commentaires s'écrivent entre (* et *) et peuvent s'imbriquer.

int et float sont distincts

Particularité à connaître d'emblée : OCaml sépare strictement les entiers et les flottants. Les opérateurs flottants portent un point : +., -., *., /.. Pas de conversion implicite !

Pièges fréquents

Piège fréquent

Utiliser + sur des flottants : 1.5 + 2.5 est une erreur de type en OCaml. Les flottants exigent +.. C'est déroutant au début, mais c'est cohérent avec la rigueur du langage : aucune conversion ne se fait dans ton dos.

Pour aller plus loin

Pour aller plus loin

La grande force d'OCaml est que « si ça compile, c'est souvent correct ». Le compilateur attrape une énorme classe d'erreurs avant l'exécution. Beaucoup de programmeurs OCaml ne lancent leur code qu'après avoir satisfait le typeur — un gain de fiabilité considérable.

Récap et vérification

  • OCaml : fonctionnel pragmatique, typage puissant + inférence, performances élevées.
  • Il a influencé Rust, F#, ReScript ; le REPL utop affiche valeur et type.
  • let nom = valeur lie une valeur immuable ; types inférés.
  • int et float sont distincts : opérateurs flottants avec un point (+.).
