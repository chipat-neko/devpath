Le système de types d'OCaml ne sert pas qu'à vérifier : il sert à modéliser. Avec les types variants (types somme), tu définis tes propres types qui représentent exactement les valeurs valides de ton domaine — ni plus, ni moins. Combinés au pattern matching, ils rendent les états impossibles… vraiment impossibles à représenter.

Définir un variant

Un type variant énumère des cas (des constructeurs), séparés par |. C'est l'équivalent d'une énumération, en plus puissant.

Les constructeurs commencent par une majuscule. Le match est exhaustif : oublier Bleu déclenche un avertissement.

Des constructeurs qui portent des données

Chaque cas peut transporter une valeur (ou plusieurs). C'est ce qui distingue les variants d'OCaml des simples enums : on modélise des formes différentes de données.

Rendre l'invalide impossible

Idée forte d'OCaml : « make illegal states unrepresentable ». En modélisant précisément avec des variants, on garantit qu'aucune valeur invalide ne peut exister. Exemple : un statut de paiement.

Les types récursifs : les arbres

Un variant peut se référer à lui-même : on modélise ainsi des structures récursives comme les arbres, naturellement.

Le polymorphisme paramétrique

Un type peut être générique sur un autre, grâce aux variables de type ('a, lire « alpha »). On définit ainsi une structure valable pour tout type d'élément.

Le type option de la stdlib (leçon 6) est précisément un variant polymorphe : type 'a option = None | Some of 'a.

Pièges fréquents

Piège fréquent

Oublier la majuscule des constructeurs : rouge serait interprété comme une variable, pas un constructeur du type. Les constructeurs de variants commencent toujours par une majuscule (Rouge), les variables et fonctions par une minuscule.

Pour aller plus loin

Pour aller plus loin

Cette combinaison « types variants + pattern matching exhaustif » est exactement ce qu'on appelle les types algébriques de données (ADT). Rust (enum), Swift (enum), Haskell (data) et Scala (sealed) l'ont tous adoptée. OCaml en est l'un des pionniers grand public.

Récap et vérification

  • Un variant (type t = A | B | C) énumère des cas ; les constructeurs commencent par une majuscule.
  • Un constructeur peut porter des données (Cercle of float) — au-delà d'un simple enum.
  • Les variants récursifs modélisent les arbres ; les variables 'a donnent le polymorphisme.
  • On rend ainsi les états invalides impossibles à représenter.
