OCaml étant fonctionnel, on répète par récursion plutôt que par boucles, et on manipule des listes immuables plutôt que des tableaux modifiables. Cette leçon couvre les conditions, les listes et la récursion — le trio de base pour traiter des données à la façon d'OCaml.

if / else est une expression

En OCaml, if cond then a else b renvoie une valeur. Les deux branches doivent donc avoir le même type. Le else est obligatoire (sauf si le résultat est unit).

Comparaisons : = (égal), <> (différent), <, >, <=, >=. Attention : = compare les valeurs, pas ==.

Les listes

Une liste OCaml est immuable et homogène (tous les éléments du même type). On la note entre crochets, éléments séparés par des points-virgules.

Les éléments sont séparés par ; (et non ,, qui crée un tuple !).

Construire avec ::

L'opérateur :: (cons) ajoute un élément en tête d'une liste. C'est l'opération fondamentale : une liste est une tête suivie d'une queue.

Prépendre avec :: est instantané ; concaténer avec @ est plus coûteux (proportionnel à la liste de gauche).

La récursion : let rec

Une fonction récursive doit être déclarée avec let rec (le rec autorise la fonction à s'appeler elle-même). On traite la liste par tête et queue.

Le match (leçon 4) distingue ici la liste vide [] et la liste tete :: queue.

Construire une nouvelle liste

Même schéma pour transformer : on traite la tête et on la :: devant le résultat récursif sur la queue.

L'immuabilité par défaut

Une liste ne se « modifie » pas : 0 :: liste crée une nouvelle liste, l'ancienne reste intacte. Ce style sans mutation rend le code prévisible et facilite le raisonnement. (Pour de la vraie mutation, OCaml a les tableaux et références — leçon 9.)

Pièges fréquents

Piège fréquent

Séparer les éléments d'une liste par des virgules : [1, 2, 3] n'est pas une liste de trois entiers ! C'est une liste d'un élément, le tuple (1, 2, 3). Dans une liste OCaml, le séparateur est le point-virgule : [1; 2; 3].

Pour aller plus loin

Pour aller plus loin

Le module List de la bibliothèque standard fournit des dizaines de fonctions prêtes à l'emploi : List.length, List.rev, List.map, List.filter… On les verra en leçon 7. En pratique, on écrit rarement une récursion à la main pour ces opérations courantes.

Récap et vérification

  • if ... then ... else est une expression ; les deux branches ont le même type.
  • Les listes sont immuables et homogènes ; séparateur ; (pas ,).
  • :: préprend (rapide), @ concatène ; [] est la liste vide.
  • La récursion (let rec) traite la liste par tête/queue ; immuabilité par défaut.
