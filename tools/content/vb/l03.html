Un programme utile doit décider et répéter. Visual Basic offre pour cela des structures lisibles, fidèles à son esprit : If … Then se lit comme « si … alors », For Each comme « pour chaque ». Cette leçon couvre les conditions (If, Select Case) et les boucles (For, Do While, For Each) — l'ossature de tout traitement.

La condition If … Then … Else

La structure de base teste une condition. Sur plusieurs lignes, on la ferme avec End If ; ElseIf gère les cas intermédiaires.

Les comparaisons sont =, <> (différent), <, >, <=, >=. Pour une condition courte, on peut tout mettre sur une ligne sans End If : If x > 0 Then MsgBox("positif").

Combiner des conditions

On relie des conditions avec And, Or, Not — encore des mots, plus lisibles que des symboles.

Le choix multiple avec Select Case

Pour tester une même variable contre plusieurs valeurs, Select Case est plus clair qu'une cascade de If.

On peut utiliser des plages (1 To 5), des listes (6, 7) et un Case Else pour le reste. Très lisible et pratique pour les menus.

La boucle For

Quand on connaît le nombre de tours, For … Next fait avancer un compteur d'une valeur à une autre.

Step précise l'incrément (ici -2 pour descendre). Sans Step, le pas est de 1. La boucle se ferme par Next.

La boucle Do While

Quand le nombre de tours dépend d'une condition, Do While … Loop répète tant qu'elle est vraie.

Do While teste avant chaque tour ; Do … Loop Until teste après (donc s'exécute au moins une fois). Cette flexibilité couvre tous les cas.

La boucle For Each

Pour parcourir tous les éléments d'une collection (un tableau, une plage de cellules…), For Each est idéale : elle prend chaque élément à tour de rôle, sans gérer d'indice.

On retrouvera For Each en VBA pour parcourir les cellules d'une plage Excel (leçon 7) : c'est l'un des outils les plus utiles du langage.

Pièges fréquents

Piège fréquent

Créer une boucle infinie avec Do While en oubliant de faire évoluer la condition. Si tu écris Do While n > 0 mais ne modifies jamais n à l'intérieur, la boucle ne s'arrête plus et le programme se fige. Vérifie toujours qu'une variable de la condition change à chaque tour pour qu'on atteigne la sortie. En VBA, Échap ou Ctrl+Pause peut interrompre une macro emballée.

Pour aller plus loin

Pour aller plus loin

En VBA, les boucles sur de grandes plages Excel peuvent être lentes si on lit chaque cellule une par une. L'astuce des experts : charger toute la plage dans un tableau en mémoire d'un coup, boucler sur le tableau (très rapide), puis réécrire le résultat en bloc. On peut ainsi accélérer une macro d'un facteur 100. Un réflexe à garder pour plus tard.

Récap et vérification

  • If … Then … ElseIf … Else … End If ; opérateurs And, Or, Not.
  • Select Case pour le choix multiple (plages 1 To 5, listes 6, 7, Case Else).
  • For … Next (avec Step) et Do While … Loop (test avant ou après).
  • For Each … In parcourt une collection sans gérer d'indice.

Vérifie ta compréhension

  1. Quel opérateur teste l'inégalité ?
  2. Quelle différence entre Do While et Do … Loop Until ?
  3. Quand préférer For Each ?
