Visual Basic est l'un des langages les plus utilisés au monde — souvent sans qu'on le sache. Chaque fois qu'une macro automatise un tableur Excel, qu'un formulaire Access traite des données, qu'une vieille application de gestion tourne en entreprise, il y a de fortes chances que ce soit du Visual Basic. Conçu par Microsoft pour rendre la programmation accessible, il mise sur une syntaxe lisible, proche de l'anglais. Cette première leçon présente ses deux visages et son immense champ d'application.

Deux langages sous un même nom

« Visual Basic » recouvre en réalité deux univers proches :

  • VBA (Visual Basic for Applications) : le langage des macros Office — Excel, Word, Access. Il vit à l'intérieur de ces logiciels et les automatise.
  • VB.NET : le Visual Basic moderne, membre à part entière de la plateforme .NET de Microsoft, pour créer des applications complètes.

Les deux partagent l'essentiel de la syntaxe. Ce cours t'apprend ce socle commun, puis explore VBA (leçon 7) et VB.NET (leçon 8) séparément.

Une syntaxe pensée pour être lue

Visual Basic privilégie les mots anglais aux symboles. Là où d'autres langages utilisent des accolades, VB écrit If … Then … End If, Sub … End Sub. Le code se lit presque comme une phrase, ce qui en fait un excellent langage pour débuter.

Les commentaires commencent par une apostrophe '. L'opérateur & assemble (concatène) des chaînes. MsgBox affiche une boîte de message — l'équivalent visuel d'un « afficher ».

Afficher un message

Selon le contexte, on affiche différemment. En VBA, MsgBox ouvre une petite fenêtre ; en VB.NET console, on utilise Console.WriteLine.

Une histoire de démocratisation

Visual Basic naît en 1991 avec une idée révolutionnaire pour l'époque : créer des applications Windows en dessinant l'interface à la souris, puis en écrivant un peu de code derrière. Cette approche « visuelle » (d'où le nom) a permis à des millions de personnes — y compris non-informaticiens — de produire des outils utiles. VBA a étendu cette puissance à toute la suite Office, et VB.NET l'a modernisée pour le XXIe siècle.

À quoi sert Visual Basic aujourd'hui

VB reste massivement présent :

  • Automatisation bureautique : des macros VBA font gagner des heures dans des millions d'entreprises ;
  • applications de gestion : d'innombrables logiciels métier tournent en VB.NET ou VB6 ;
  • prototypage rapide : créer vite un petit outil interne ;
  • maintenance : un vaste parc de code existant à entretenir.

Pièges fréquents

Piège fréquent

Confondre VBA et VB.NET. Ils se ressemblent mais ne sont pas interchangeables : VBA s'exécute dans Office et manipule ses objets ; VB.NET est un langage .NET autonome avec ses propres bibliothèques. Du code VBA ne tourne pas tel quel en VB.NET et vice versa. Garde en tête lequel tu vises : cela évite bien des confusions en cherchant de l'aide.

Pour aller plus loin

Pour aller plus loin

VBA est techniquement « ancien » (basé sur VB6, figé depuis les années 2000), et pourtant indéboulonnable : il est intégré à Office, installé sur des centaines de millions de postes, et capable d'automatiser n'importe quelle tâche répétitive d'Excel. Savoir écrire ne serait-ce qu'une petite macro est une compétence à fort retour sur investissement dans n'importe quel métier de bureau.

Récap et vérification

  • Deux visages : VBA (macros Office) et VB.NET (plateforme .NET moderne).
  • Syntaxe lisible, proche de l'anglais ; commentaires avec '.
  • & concatène les chaînes ; MsgBox (VBA) ou Console.WriteLine (VB.NET) affichent.
  • Usages : automatisation bureautique, applications de gestion, prototypage, maintenance.

VBA : c'est le langage intégré à Office, conçu précisément pour automatiser Excel, Word et Access depuis l'intérieur de ces logiciels. VB.NET, lui, sert à créer des applications .NET autonomes ; il peut piloter Office mais c'est plus lourd. Pour une macro qui agit sur un classeur, VBA est l'outil direct et naturel.
