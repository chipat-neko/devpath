Comme OCaml, F# repose sur l'immuabilité par défaut et l'inférence de types : tu écris peu d'annotations, le compilateur déduit et vérifie tout. Couplées aux fonctions et à la curryfication, ces fondations rendent le code concis et sûr. Voyons les valeurs, les types et les fonctions.

let et l'immuabilité

let nom = valeur lie un nom à une valeur. Par défaut, c'est immuable : on ne réaffecte pas. Pour une vraie variable modifiable, il faut le mot-clé explicite mutable (réservé aux cas qui le justifient).

L'inférence de types

Tu n'écris pas les types : F# les déduit de l'usage. On peut annoter quand on veut (clarté, contraintes).

Définir une fonction

let nom params = corps. Pas de return : la dernière expression est le résultat. On appelle sans parenthèses ni virgules : somme 3 4.

La curryfication

Comme en OCaml, une fonction à plusieurs arguments est en réalité une suite de fonctions à un argument. Le type de somme est int -> int -> int. Conséquence : l'application partielle.

Les fonctions anonymes

Le mot-clé fun crée une fonction sans nom — indispensable pour les fonctions d'ordre supérieur (leçon 3).

Les types de base

int, float, bool, string, char. Contrairement à OCaml, F# utilise les mêmes opérateurs (+, *…) pour entiers et flottants : l'inférence distingue selon le contexte. Les tuples regroupent des valeurs.

Les expressions let imbriquées

On crée des valeurs locales avec des let internes (alignés sous la fonction). La dernière expression fournit le résultat.

Pièges fréquents

Piège fréquent

Vouloir réaffecter une valeur let par habitude impérative : en F#, let x = 5 puis x = 6 ne réaffecte pas — = est ici une comparaison qui renvoie false ! Pour muter, il faut let mutable x et l'opérateur <-.

Pour aller plus loin

Pour aller plus loin

F# a des unités de mesure, une fonctionnalité unique : on peut typer un nombre comme « mètres » ou « secondes », et le compilateur empêche d'additionner des mètres et des secondes. Idéal en calcul scientifique et financier pour éviter les erreurs de dimension.

Récap et vérification

  • let lie une valeur immuable ; mutable + <- pour une variable modifiable.
  • L'inférence déduit les types ; appel sans parenthèses (somme 3 4).
  • Curryfication et application partielle ; fun pour les anonymes.
  • Mêmes opérateurs pour int et float (inférence) ; tuples et déstructuration.
