Le pattern matching est le compagnon naturel des unions discriminées : il déstructure les données, vérifie l'exhaustivité, et rend le code à la fois concis et sûr. F# y ajoute une fonctionnalité unique : les active patterns. C'est l'outil le plus expressif du langage.

match ... with

On compare une valeur à des motifs ; chaque cas commence par |. Le compilateur vérifie que tous les cas sont couverts et avertit si tu en oublies un.

Déstructurer unions et records

Le filtrage extrait directement les données portées par une union ou les champs d'un record.

Les listes

On filtre une liste par tête et queue — l'idiome des fonctions récursives.

Les gardes (when)

On affine un motif avec une condition when : la branche ne s'applique que si le motif correspond et que la garde est vraie.

Le mot-clé function

Raccourci pratique : function est un fun + match sur l'argument, pour des fonctions définies par cas.

Les active patterns

Fonctionnalité signature de F# : les active patterns permettent de définir tes propres motifs, en encapsulant une logique de décomposition. On obtient un filtrage lisible sur des données qui n'ont pas de structure de DU.

L'active pattern (|Pair|Impair|) s'utilise comme un cas de DU dans le match.

Pièges fréquents

Piège fréquent

Ignorer l'avertissement « incomplete match » : si tu oublies un cas, le compilateur le signale, et ton programme plantera à l'exécution sur ce cas non géré. Traite tous les cas (ou ajoute un _ explicite si c'est volontaire).

Pour aller plus loin

Pour aller plus loin

Les active patterns partiels ((|Entier|_|)) renvoient une option et servent à parser : tester si une chaîne est un entier, une date… Ils transforment le pattern matching en un outil de validation et d'analyse très élégant.

Récap et vérification

  • match ... with | motif -> ... déstructure et vérifie l'exhaustivité.
  • On filtre unions, records, listes ; les gardes (when) affinent ; | regroupe.
  • function est un raccourci pour une fonction définie par cas.
  • Les active patterns définissent tes propres motifs réutilisables.
