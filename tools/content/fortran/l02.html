Fortran est un langage de calcul : ses types sont pensés pour les nombres. Comprendre les types — surtout les réels et leur précision — est fondamental, car en calcul scientifique, une précision mal maîtrisée fausse les résultats. Voyons les types, leur déclaration et les opérations.

Les types fondamentaux

Cinq types intrinsèques : integer (entiers), real (réels à virgule flottante), complex (nombres complexes !), logical (booléens), character (texte).

Les booléens s'écrivent .true. et .false., avec des points.

La précision des réels (kind)

Un real simple précision (32 bits) suffit rarement en science. On veut la double précision (64 bits). La façon moderne et portable utilise un paramètre de kind tiré du module standard.

Le suffixe _dp sur une constante (3.0_dp) garantit qu'elle est bien en double précision — un détail crucial.

Opérations arithmétiques

Les opérateurs habituels, plus ** pour la puissance. Attention à la division entière : entre deux entiers, le résultat est tronqué.

Conversions de types

On convertit explicitement avec des fonctions intrinsèques : real(), int(), nint() (arrondi).

Les chaînes de caractères

Une chaîne a une longueur fixe déclarée. On les concatène avec // et on dispose de fonctions (len, trim, index).

Les fonctions intrinsèques

Fortran fournit une riche bibliothèque mathématique intégrée : sqrt, sin, cos, exp, log, abs, max, min… Elles fonctionnent même sur des tableaux entiers (leçon 4).

Pièges fréquents

Piège fréquent

La division entière silencieuse : 1/3 vaut 0, pas 0.333 ! Et écrire real :: x = 1/3 stocke 0.0, car la division se fait avant la conversion. Écris 1.0/3.0 ou convertis avec real().

Pour aller plus loin

Pour aller plus loin

Le module iso_fortran_env fournit aussi real32, int64, etc. C'est la manière portable de fixer les précisions : ton code donnera les mêmes résultats sur n'importe quelle machine et compilateur.

Récap et vérification

  • Types : integer, real, complex, logical (.true./.false.), character.
  • La précision se contrôle via kind (real(dp)) et le suffixe _dp sur les constantes.
  • Attention à la division entière ; convertis avec real(), int(), nint().
  • Riche bibliothèque intrinsèque : sqrt, sin, abs, max…
