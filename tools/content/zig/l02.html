Zig est un langage à typage statique fort : chaque valeur a un type précis, connu à la compilation, et Zig refuse les conversions hasardeuses. Cette rigueur, alliée à des types entiers de taille exacte, donne un contrôle total sur les données — essentiel en programmation système.

const et var

Deux façons de déclarer : const (immuable, à privilégier) et var (modifiable). Zig exige que tu utilises const si la valeur ne change pas — sinon, erreur de compilation.

Le type s'annote après :. Souvent, Zig le déduit de la valeur.

Les types entiers précis

Atout majeur : Zig nomme les entiers par leur taille exacte en bits. u8 = entier non signé 8 bits, i32 = signé 32 bits, etc. Il existe même usize (la taille d'un pointeur, pour indexer).

Zig autorise même des tailles arbitraires : u3 (3 bits !), utile pour le code bas niveau et les registres matériels.

Les flottants et booléens

Flottants f32 et f64 ; booléens bool (true/false).

Pas de conversions implicites

Règle de fer : Zig n'effectue jamais de conversion silencieuse qui perdrait de l'information. Mélanger un u8 et un i32 exige une conversion explicite avec @intCast ou similaire. C'est verbeux, mais ça élimine toute une classe de bugs.

Les fonctions

Une fonction : fn, un nom, des paramètres typés, le type de retour après ). pub la rend publique (accessible d'un autre fichier).

Afficher avec un format

std.debug.print prend une chaîne de format (avec des {}) et un tuple d'arguments .{ … }. On peut préciser le format dans les accolades.

{d:.2} formate un nombre avec 2 décimales ; l'ordre des {} suit l'ordre du tuple.

Pièges fréquents

Piège fréquent

Déclarer var alors que la valeur ne change jamais : Zig le refuse avec « local variable is never mutated ». Utilise const par défaut, et passe à var uniquement quand tu modifies vraiment la variable.

Pour aller plus loin

Pour aller plus loin

Zig détecte les débordements d'entiers en mode debug (un calcul qui dépasse la capacité du type plante au lieu de « boucler » silencieusement). Pour un débordement volontaire, des opérateurs dédiés existent (+%, *%). Encore une fois : explicite.

Récap et vérification

  • const (immuable, par défaut) et var (modifiable) ; type après :.
  • Entiers de taille exacte (u8, i32, usize) ; flottants f32/f64.
  • Aucune conversion implicite : utilise @as/@intCast.
  • fn définit une fonction ; std.debug.print("{}", .{x}) affiche.
