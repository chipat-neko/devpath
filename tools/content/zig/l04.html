En programmation système, on manipule sans cesse des séquences d'octets et de nombres. Zig propose deux outils complémentaires : les tableaux (taille fixe, connue à la compilation) et les slices (une vue sur une portion de données, de taille connue à l'exécution). Bien les distinguer est essentiel.

Les tableaux de taille fixe

Un tableau a une taille fixée à la compilation, écrite entre crochets. [_] laisse Zig compter les éléments.

La taille fait partie du type : [3]i32 et [4]i32 sont des types différents.

Modifier un tableau

Pour modifier des éléments, le tableau doit être déclaré var.

Les slices : des vues

Un slice, noté []T, est une vue sur une suite contiguë d'éléments : il contient un pointeur et une longueur. Contrairement au tableau, sa taille n'est pas dans son type — il peut désigner n'importe quelle portion.

Le découpage tableau[début..fin] ne copie rien : il crée une vue sur les mêmes données.

Parcourir un slice

Les slices se parcourent comme les tableaux, avec for et la capture.

const vs mutable

Un slice peut être en lecture seule ([]const T) ou modifiable ([]T). Cette distinction protège les données : une fonction qui reçoit un []const u8 promet de ne pas les altérer.

Les chaînes : des slices d'octets

Révélation : en Zig, une chaîne littérale est un slice d'octets ([]const u8), encodé en UTF-8. Il n'y a pas de type « String » magique ; une chaîne est une suite d'octets.

Le format {s} sert à afficher un slice d'octets comme une chaîne lisible.

Pièges fréquents

Piège fréquent

Un slice pointe vers des données qu'il ne possède pas : si le tableau d'origine disparaît (sort de portée), le slice devient invalide (dangling). Assure-toi que les données vivent au moins aussi longtemps que le slice qui les regarde.

Pour aller plus loin

Pour aller plus loin

En mode debug, Zig vérifie les accès hors bornes à l'exécution : indexer v[10] sur un tableau de 3 éléments plante proprement au lieu de corrompre la mémoire comme en C. Une sécurité offerte sans coût en mode release.

Récap et vérification

  • Un tableau [N]T a une taille fixe, partie de son type.
  • Un slice []T est une vue (pointeur + longueur) sur des données ; le découpage ne copie pas.
  • []const T protège les données en lecture seule.
  • Une chaîne est un slice d'octets []const u8 (affiché avec {s}).

Vérifie ta compréhension

  1. Quelle différence entre [3]i32 et []i32 ?
  2. Le découpage arr[1..3] copie-t-il les données ?
  3. Qu'est-ce qu'une chaîne en Zig ?
