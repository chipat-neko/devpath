Lisp est le berceau de la programmation fonctionnelle : les fonctions y sont la brique centrale, et — idée révolutionnaire pour 1958 — ce sont des valeurs comme les autres, qu'on peut nommer, passer en argument, renvoyer. Cette leçon t'apprend à définir et utiliser des fonctions.

Définir une fonction : define

On nomme une fonction avec define : le nom et ses paramètres entre parenthèses, puis le corps. La valeur du corps est renvoyée (pas de return).

La forme (define (nom params...) corps) est le sucre habituel pour définir une fonction.

Plusieurs expressions dans le corps

Le corps peut contenir plusieurs expressions ; elles s'évaluent dans l'ordre, et c'est la dernière qui fournit la valeur de retour.

Les fonctions anonymes : lambda

lambda crée une fonction sans nom. C'est la forme fondamentale : define n'est qu'un raccourci pour lier un nom à un lambda.

Les fonctions sont des valeurs

Conséquence majeure : une fonction peut être stockée dans une variable, rangée dans une liste, passée en argument. C'est ce qui rend Lisp si expressif (et que la leçon 6 exploitera).

Les fonctions pures

L'idéal fonctionnel : une fonction pure renvoie toujours le même résultat pour les mêmes arguments, sans effet de bord (elle ne modifie rien d'extérieur). Le code en devient prévisible, testable et composable. La plupart des fonctions de ce cours sont pures.

Paramètres variables

Certaines fonctions acceptent un nombre quelconque d'arguments. En Scheme, on capture le reste avec un point ; en Common Lisp, avec &rest.

apply applique une fonction à une liste d'arguments : (apply + '(1 2 3)) vaut 6.

Pièges fréquents

Piège fréquent

Confondre une fonction et son appel : carre est la fonction (une valeur), (carre 5) est son application. Passer carre en argument (sans parenthèses) est volontaire ; écrire (carre) tenterait de l'appeler sans argument.

Pour aller plus loin

Pour aller plus loin

Le lambda-calcul, dont Lisp descend, a montré que tout calcul peut s'exprimer avec des fonctions seules. C'est la racine théorique de la programmation fonctionnelle ; le mot-clé lambda de Python, JS, Java… vient directement de là.

Récap et vérification

  • (define (nom params) corps) définit une fonction ; le corps renvoie sa dernière valeur.
  • lambda crée une fonction anonyme ; define n'en est qu'un raccourci nommé.
  • Les fonctions sont des valeurs : on les stocke, les passe, les renvoie.
  • Vise des fonctions pures (sans effet de bord) pour un code prévisible.

Vérifie ta compréhension

  1. Quelle est la relation entre define et lambda ?
  2. Que signifie « les fonctions sont des valeurs » ?
  3. Qu'est-ce qu'une fonction pure ?
