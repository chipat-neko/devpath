Un programme prend des décisions et répète des actions. Ada offre pour cela des constructions claires et explicites, fidèles à sa philosophie : chaque bloc se ferme par un end qui rappelle ce qu'on ferme, et rien n'est laissé à l'ambiguïté. Cette leçon couvre les conditions (if, case) et les trois formes de boucle d'Ada.

La condition if

La structure if … then … end if décide selon une condition booléenne. Pour les cas intermédiaires, Ada utilise elsif (en un seul mot).

Noter le end if qui referme clairement le bloc : pas d'ambiguïté sur la portée, contrairement aux langages où une accolade oubliée change tout. Les opérateurs de comparaison sont =, /= (différent), <, >, <=, >=.

Le choix multiple avec case

Quand on teste une même valeur contre plusieurs possibilités, case est plus lisible qu'une cascade de if. Ada impose de couvrir tous les cas (via when others si besoin) : impossible d'oublier une branche.

On peut grouper des valeurs avec | (le « ou ») et utiliser des plages avec ... L'obligation de tout couvrir est typiquement Ada : le compilateur refuse un case incomplet, ce qui élimine les oublis.

La boucle générale loop

La forme la plus simple, loop … end loop, répète indéfiniment ; on en sort avec exit, souvent conditionné par exit when.

Integer'Image convertit un entier en sa représentation texte (un attribut, qu'on approfondira leçon 5). exit when se lit naturellement : « sors quand… ».

La boucle while

Quand la condition se teste avant chaque tour, on emploie while … loop.

La boucle for

Pour parcourir une plage connue, for est idéale : elle déclare implicitement une variable de boucle, locale et en lecture seule, qui prend chaque valeur de la plage.

La variable I n'existe que dans la boucle et ne peut pas être modifiée à l'intérieur : une garantie de plus contre les erreurs. reverse parcourt la plage à l'envers.

Pièges fréquents

Piège fréquent

Vouloir modifier la variable d'une boucle for à l'intérieur du corps : Ada l'interdit, car cette variable est en lecture seule. Si tu as besoin d'un compteur que tu contrôles toi-même, utilise une boucle while ou loop avec ta propre variable. C'est une protection : dans la plupart des langages, modifier l'indice d'un for est une source de bugs sournois.

Pour aller plus loin

Pour aller plus loin

Les boucles Ada peuvent porter un nom : Externe: loop … end loop Externe;. On peut alors écrire exit Externe; depuis une boucle interne pour sortir directement de la boucle englobante nommée. C'est plus sûr et lisible qu'un saut anonyme : on voit exactement de quelle boucle on sort, même imbriquée profondément.

Récap et vérification

  • if … elsif … else … end if ; comparaisons =, /=, <, >, <=, >=.
  • case doit couvrir tous les cas (when others) ; | groupe, .. pour une plage.
  • Trois boucles : loop (+ exit when), while, for I in plage.
  • La variable de for est locale et en lecture seule ; reverse inverse le parcours.
