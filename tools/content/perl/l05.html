Rechercher un motif, c'est bien ; transformer le texte, c'est mieux. Perl excelle à reformater, nettoyer et restructurer des chaînes. Cette leçon réunit les outils du quotidien : la substitution s///, le découpage split, l'assemblage join, et la translittération tr///.

La substitution s///

L'opérateur s/motif/remplacement/ remplace, sur la variable liée par =~, la première occurrence du motif. Avec le drapeau /g, il remplace toutes les occurrences.

Substitution avec capture et expression

Le remplacement peut réutiliser les groupes capturés ($1, $2). Avec le drapeau /e, le remplacement est évalué comme du code Perl — très puissant.

Le /e transforme le côté droit en code à exécuter : idéal pour calculer un remplacement.

Découper avec split

split coupe une chaîne selon un séparateur (souvent une regex) et renvoie une liste. C'est l'outil pour lire des données tabulées (CSV simple, lignes de log…).

Assembler avec join

join fait l'inverse : il relie les éléments d'une liste avec un séparateur.

Translittérer avec tr///

tr/abc/xyz/ remplace caractère par caractère (a→x, b→y, c→z). Il sert aussi à compter des occurrences sans rien remplacer.

Nettoyer : chomp, trim, casse

chomp retire le saut de ligne final (essentiel après une lecture) ; lc/uc changent la casse ; un s/// retire les espaces de bord.

Formater avec sprintf

sprintf construit une chaîne formatée (nombres alignés, décimales fixes…), comme dans beaucoup de langages.

Pièges fréquents

Piège fréquent

Oublier chomp après avoir lu une ligne : ta variable contient un \n invisible qui fait échouer les comparaisons ($x eq "oui" est faux si $x vaut "oui\n"). Prends le réflexe de chomp chaque saisie.

Pour aller plus loin

Pour aller plus loin

Pour du vrai CSV (avec guillemets et virgules dans les champs), split ne suffit pas : utilise le module Text::CSV de CPAN. La règle d'or : split pour les formats simples, un module pour les formats normalisés.

Récap et vérification

  • s/motif/remp/ substitue (/g global, /e évalue le remplacement).
  • split découpe une chaîne en liste ; join assemble une liste en chaîne.
  • tr/// translittère et compte les caractères.
  • chomp, lc/uc, sprintf nettoient et formatent.

Vérifie ta compréhension

  1. Quel drapeau remplace toutes les occurrences dans un s/// ?
  2. Comment transformer "a,b,c" en liste de trois éléments ?
  3. Pourquoi chomp est-il indispensable après une lecture ?
