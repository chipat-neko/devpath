Nous voici au domaine où Perl est devenu légendaire : les expressions régulières. Une expression régulière (ou regex) décrit un motif de texte : « un mot qui commence par une majuscule », « une suite de chiffres », « une adresse e-mail ». Perl les a intégrées si profondément que sa syntaxe a inspiré presque tous les autres langages (on parle de regex « PCRE » : Perl Compatible).

Rechercher un motif

L'opérateur de correspondance s'écrit m/motif/ (le m est souvent omis : /motif/). On l'applique à une variable avec l'opérateur de liaison =~.

=~ teste la correspondance ; !~ teste l'absence de correspondance.

Classes de caractères

Entre crochets, une classe liste les caractères acceptés. Des raccourcis existent : \d (chiffre), \w (lettre, chiffre ou _), \s (espace). Leurs majuscules sont les négations.

Quantificateurs et ancres

Les quantificateurs disent combien de fois : * (0 ou plus), + (1 ou plus), ? (0 ou 1), {n,m} (entre n et m). Les ancres ^ (début) et $ (fin) fixent la position.

Capturer des groupes

Les parenthèses capturent une portion du texte, récupérable ensuite dans $1, $2, etc., dans l'ordre des parenthèses ouvrantes.

Ici on a choisi m{…} comme délimiteurs pour éviter d'échapper les / de la date : Perl autorise presque n'importe quel délimiteur.

Les drapeaux

Après la regex, des lettres modifient son comportement : /i (insensible à la casse), /g (toutes les occurrences), /x (autorise espaces et commentaires pour la lisibilité), /m (multiligne).

Une regex lisible avec /x

Pour une regex complexe, le drapeau /x permet de l'aérer et de la commenter.

qr// compile une regex dans une variable réutilisable.

Pièges fréquents

Piège fréquent

Les quantificateurs sont gourmands par défaut : /<.+>/ sur <a><b> capture tout d'un coup. Ajoute un ? pour les rendre paresseux : /<.+?>/ s'arrête au premier >.

Pour aller plus loin

Pour aller plus loin

Les groupes nommés (?<jour>\d{2}) se récupèrent via le hachage %+ ($+{jour}) : bien plus lisible que $1, $2 quand il y a plusieurs captures.

Récap et vérification

  • $texte =~ /motif/ teste une correspondance ; !~ teste l'absence.
  • Classes (\d, \w, […]), quantificateurs (* + ? {n,m}), ancres (^ $).
  • Les parenthèses capturent dans $1, $2, …
  • Drapeaux : /i casse, /g global, /x lisible.

  2. Comment récupérer le texte capturé par la deuxième paire de parenthèses ?
  3. Quelle est la différence entre .+ et .+? ?
