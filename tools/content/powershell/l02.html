Maintenant que tu sais lancer des commandes, il te faut de quoi stocker et manipuler des données. En PowerShell, une variable se reconnaît à son préfixe $, et derrière chaque valeur se cache un type .NET — c'est ce qui donne au langage sa richesse. Voyons les variables, les types, les chaînes et les opérateurs qui te serviront partout.

Déclarer une variable

Pas de mot-clé : on affecte directement avec =. Le nom commence par $. PowerShell déduit le type tout seul, mais tu peux l'imposer en plaçant un type entre crochets devant la variable.

Sans annotation, PowerShell choisit le type le plus adapté à la valeur.

Les types de base

Les types viennent du monde .NET : String, Int32, Double, Boolean, DateTime, Array… Les booléens s'écrivent avec les variables automatiques $true et $false. L'absence de valeur, c'est $null.

Les chaînes : simples et doubles guillemets

La distinction est importante. Les guillemets doubles autorisent l'interpolation (les variables sont remplacées par leur valeur) ; les guillemets simples prennent le texte tel quel, à la lettre.

Opérateurs arithmétiques

Rien de surprenant : +, -, *, /, et % pour le reste (modulo). Le + sert aussi à concaténer des chaînes et à fusionner des tableaux.

Comparaisons : des opérateurs en toutes lettres

Voici LA particularité à retenir : PowerShell n'utilise pas > ou < pour comparer (ces signes servent à la redirection). Les comparaisons s'écrivent avec des opérateurs préfixés d'un tiret : -eq (égal), -ne (différent), -gt (supérieur), -lt (inférieur), -ge, -le.

Les comparaisons de chaînes ignorent la casse par défaut ; préfixe par c pour la respecter.

Opérateurs logiques

Pour combiner des conditions : -and, -or, -not (ou son raccourci !).

Pièges fréquents

Piège fréquent

Utiliser > pour comparer : 5 > 3 ne compare pas, il redirige la sortie « 5 » vers un fichier nommé « 3 » ! Pour comparer, c'est toujours 5 -gt 3.

Astuce

Compare toujours $null à gauche : $null -eq $x et non $x -eq $null. Avec un tableau à droite, la seconde forme donne des résultats trompeurs.

Pour aller plus loin

Pour aller plus loin

Comme tout est objet .NET, une chaîne possède des dizaines de méthodes : "texte".ToUpper(), .Trim(), .Replace("a","b"), .Split(","). Lance "x" | Get-Member pour les explorer toutes.

Récap et vérification

  • Une variable s'écrit $nom et reçoit sa valeur avec = ; le type peut être imposé avec [type].
  • Guillemets doubles = interpolation ; simples = texte littéral ; $(...) évalue une expression.
  • Les comparaisons utilisent -eq, -gt, -like, -match… jamais >/<.
  • Les comparaisons de chaînes ignorent la casse par défaut.

Vérifie ta compréhension

  1. Que donne 'Total : $prix' par rapport à "Total : $prix" ?
  2. Comment tester si $x est strictement supérieur à 10 ?
  3. Pourquoi "abc" -eq "ABC" renvoie-t-il True ?
