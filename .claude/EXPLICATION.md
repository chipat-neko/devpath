# .claude/ — les réglages de Claude Code pour ce projet

| Élément | Rôle |
|---|---|
| `settings.local.json` | Les permissions accordées à Claude Code dans ce dossier. |
| `launch.json` | Les serveurs de prévisualisation que Claude Code peut démarrer ; il liste aussi ceux d'autres projets de Noah (Un Monde Sans, Le Bocal). |
| `plans/` | Des plans de travail écrits avant de grosses modifications (refonte de l'accueil, fils rouges), gardés comme trace. |
| `scheduled_tasks.lock` | Verrou technique des tâches planifiées de Claude Code ; ne pas modifier. |

Ce dossier ne contient rien du site. Les plans de l'**autonomie** sont ailleurs, dans
`docs/chantiers/`.
