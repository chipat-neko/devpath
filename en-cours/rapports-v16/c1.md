## Textes corrigés (12 pages : 13 affirmations devenues fausses, dont une aussi dans un QCM, et 1 erreur de fait)

Chaque correction est datée du jour et, quand elle reste une affirmation sur l'état du monde,
porte une marque.

**typescript**
1. `lecon-01` — « Un navigateur **ou Node.js** ne sait pas lire un fichier `.ts` » : faux.
   Node exécute un `.ts` sans drapeau depuis **22.18 et 23.6** (type stripping, « Stable » depuis
   24.12 / 25.2), en effaçant les types **sans les vérifier**. Source : nodejs.org/api/typescript.html ;
   **exécuté** : `node essai.ts` sous Node 24.16 affiche « TTC : 120 », sans avertissement. Le
   texte garde la leçon (compiler avec `tsc` pour vérifier) et dit pourquoi.
2. `lecon-08` — décorateurs « désormais standardisés » → « toujours en cours de
   standardisation au TC39 ».
3. `lecon-13` — « (étape 3 du TC39) » → **étape 2.7** : la proposition a été **ramenée de
   l'étape 3 le 2026-05-19** (« Decorators moved back to Stage 2.7 »), aucun moteur ne l'ayant
   livrée. Sources : notes TC39 `meetings/2026-05/may-19.md`, README de `tc39/proposal-decorators`
   (« Stage: 2.7 »), liste `tc39/proposals` (rangée en « Stage 2.7 »).
4. `lecon-13`, **QCM q1 — faute prouvée, intouchable modifié** : la bonne réponse et les trois
   distracteurs disaient « le standard (**norme récente**) » et l'`explain` « les décorateurs
   **standardisés** ». Remplacé par « (proposition TC39) » **dans les quatre options à
   l'identique** (même écart de longueur partout, aucun indice créé) et « les décorateurs
   standard (proposition TC39) » dans l'`explain`. `mesure-qcm-intouchable typescript` le
   rapporte : **2 atteintes** (bonne réponse, explication) — ce sont celles-là, et ce sont les
   seules.
5. `lecon-13` — preset `@tsconfig/node20` → `@tsconfig/node26` : Node 20 est en fin de vie
   depuis le 2026-03-24 et Node 26 est « Latest LTS » (nodejs.org) ; `@tsconfig/node26` existe
   (registre npm, v26.0.1).
6. `lecon-19` — « Rares sont les projets qui démarrent en TypeScript » : faux aujourd'hui.
   → « Beaucoup de projets n'ont pas démarré en TypeScript : même si la plupart des grands
   frameworks front créent aujourd'hui leurs projets en TypeScript par défaut, on hérite
   souvent d'une base JavaScript… ». Source : GitHub Octoverse 2025 (TypeScript premier langage
   de GitHub en août 2025 ; Astro, Next.js, Angular génèrent leurs projets en TypeScript par
   défaut).

**nodejs**
7. `lecon-01` — « Les versions LTS portent un numéro pair… les versions Current un numéro
   impair » : devient faux. **À partir de Node 27**, le rythme est annuel et **chaque version
   majeure devient LTS** ; une phase **Alpha** couvre octobre à mars (Node 27 est en Alpha depuis
   le 2026-10-29, la page de téléchargement n'affiche plus que « LTS » et « Alpha »). Sources :
   nodejs.org, « Evolving the Node.js Release Schedule », page des versions et page de
   téléchargement. Corrigé dans la note, la liste LTS/Current, et « (numéro pair) » retiré du
   glossaire et du récapitulatif (le QCM de la leçon n'en parle pas).
8. `lecon-01` — « Tout l'outillage moderne du front… est écrit en JavaScript » : faux pour
   esbuild (Go, FAQ esbuild) et Rolldown, le bundler de Vite 8 (Rust, rolldown.rs). → « Presque
   tout… se lance avec Node, même quand son moteur est écrit dans un langage compilé ».
9. `lecon-02` — `require("chalk")` « tombe alors sur `ERR_REQUIRE_ESM` » : n'est plus vrai que
   **avant Node 22.12 (ou 20.19)**. Depuis, `require()` charge l'ESM et renvoie l'objet module ;
   l'export par défaut est dans `.default`. **Exécuté** sous Node 24.16 sur un paquet ESM imitant
   chalk 5 : clés `__esModule, default, supportsColor`, `chalk.red` indéfini,
   `chalk.default.red` fonction. (Fait de compatibilité : corrigé, non marqué.)
10. `lecon-03` — « des centaines de milliers de paquets » → « plusieurs millions »
    (`replicate.npmjs.com` : `doc_count` 4 591 684 le 2026-11-11).
11. `lecon-15` — `node:sqlite` « stable depuis Node 24 : plus aucun avertissement » : faux.
    Il est « **release candidate** » (Stability 1.2) depuis 24.15 et 25.7, **pas stable**, même
    dans la doc de Node 26.13 ; sans drapeau depuis 22.13. Sources : docs `sqlite.html` v24 et
    v26 ; **exécuté** : aucun avertissement sous Node 24.16.
12. `lecon-16` — `bcrypt` présenté comme le choix par défaut : l'OWASP (Password Storage Cheat
    Sheet) place **Argon2id** en premier et réserve bcrypt « aux systèmes existants ». Le texte
    le dit ; la leçon garde `bcrypt` (le QCM q1, « bcrypt convient », reste vrai).
13. `lecon-21` — « Le plus populaire aujourd'hui est Prisma » : faux en téléchargements.
    → « l'un des deux plus utilisés aujourd'hui, avec Drizzle » (api.npmjs.org, dernier mois :
    `drizzle-orm` 156 050 269, `prisma` 90 591 446, `@prisma/client` 85 704 798, `typeorm`
    24 139 311, `sequelize` 13 804 452).
14. `lecon-23` — « des outils comme `pkg` » : `pkg` est **déprécié et archivé depuis le
    2024-01-13** (README `vercel/pkg`). → les *single executable applications* de Node
    (Stability 1.1, « encore expérimentales »).
15. **Hors fraîcheur, erreur de fait** — `lecon-11` : « `POST /v1/charges` crée un paiement
